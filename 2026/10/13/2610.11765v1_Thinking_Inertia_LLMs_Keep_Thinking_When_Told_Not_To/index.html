Thinking Inertia：LLM 被要求不思考时仍在思考

论文：2610.11765v1；来源：Hugging Face Daily Papers（2026-10-13 批次，默认顺序第 4 位）；精读归档日期：2026-10-13（Asia/Shanghai）。

标签：LLMs、LLM Reasoning、Instruction Following、Benchmark Evaluation、LLM-as-a-Judge。

0. 一句话结论

论文把”不思考”（no-thinking）从提示词层面的开关代理量重新定义为响应级可观测行为，用空思考率（Empty-Thinking Rate，ETR）、问题—前答相关性（Question–Pre-answer Relevance，QRel.）和显式推断率（Explicit Inference Rate，EIR）三级指标度量模型在前答文本中暴露的内容，并据此在六款模型、六个基准、六种干预下发现：关闭思考开关并不能可靠消除可见的显式推理，且该现象随答案空间（answer space）开放程度递增（”思考惯性”，thinking inertia）。在论文覆盖的英文单轮问答与确定性解码条件下，这一描述性结论有真人标注与跨家族裁判双重支撑，证据较强；但”为什么”的机制解释与真实推理成本均未被直接验证。

1. 论文具体想解决什么问题

延长推理时计算（test-time computation）能显著提升 LLM 表现，但带来时延与 token 开销，因此近期大量工作研究如何缩短、预算化或压缩思维链（chain-of-thought，CoT）。另一条动机是”类人自适应推理”：人类平时凭直觉直接回答，只在必要时才深思。于是厂商开始提供显式的思考模式开关与推理力度设置，用户也可在提示中要求”直接回答”——但”不思考”到底指什么、怎么测，社区并无共识（§1）。

现有做法（传统上）用三种表面代理量（surface proxies）判定”不思考”：提示侧控制（在 no-think 设置下运行或不做 step-by-step 提示）、格式侧控制（响应中没有 <think> 块或独立推理区）、长度侧控制（输出短即视为推理减少）（§2.1，Fig. 2）。论文指出三者的共同缺陷是：它们描述的是提示条件、可见格式或长度，而不是响应内容本身。三个反例说明代理量会失效——禁用思考模式后，模型仍可能在普通答案通道输出依赖问题的解释；移除 <think> 标签只移除了格式，推理可以普通语言出现；一句话内也可塞入紧凑的推理步骤（§2.1，Fig. 2(b)）。

这是论文的核心新观察：禁用思考模式或强令只答，不等于响应中不含可见推理。支撑证据包括 Fig. 1/2 的定性案例与 §3.2 的大规模量化（例如引言报告 DeepSeek-V4-Flash 在禁用思考设置下，开放式任务仍有 99.9% 的回答含可见显式推理，§1 第 (i) 条；全语料 M2 开放式 EIR 均值为 99.69%，Table D.3）。作者把问题归因于两层：其一，”不思考”缺少可操作定义，代理量把”指令控制”与”可见推理被抑制”混为一谈；其二，能否直接作答取决于任务”答案空间”提供的结构支撑——开放式生成缺少可核对的候选答案，需要更多具现化的中间计算（§3.2，§3.5）。论文要验证的核心假设是：不思考应作为响应级行为被测量，且响应中是否残留问题条件化的显式推断，主要由答案空间结构而非开关本身决定。

需要区分三类问题：领域一般问题（推理开销大、需要按需推理）早已存在；本文的新观察是”代理量不可靠 + 推理残留随答案空间递增”；实际解决的子问题则是”给出可测定义与系统刻画”——论文并未训练任何新模型去真正实现”按需停止思考”，而是先解决测量与现象确认（§5.2 把训练干预列为未来工作）。

图 1 归纳了论文对这三种代理量及其失效案例的分析。

图 1（论文 Fig. 2）：左半部分是”现有方法如何识别不思考”的三类代理量——问题入口处的思考开关（prompt-side control）、输出中的专用思考标记（thinking special token）、输出长度（token len.）；右半部分用同一道代数题给出对应的三个失效案例：开关关闭后输出仍含推导、没有 <think> 标记但推理以普通文本出现、输出很短但内含紧凑推理（”3x=9, so x=3”）。读者应理解的是：这三类信号监测的都是模型的”配置或形式”，而论文要测的是最终可见文本里是否真的残留了针对问题的推断步骤，这是后续三级指标（ETR/QRel./EIR）要解决的测量缺口。

正因代理量与目标行为错位，作者抛出的”不思考缺失定义”并不是措辞问题，而是一个可以实验化的测量问题——这直接引出第 2 节的度量重构。

2. 创新点是什么

总的真增量是一个”测量重构 + 系统刻画”的组合：把不思考从提示/格式代理量改写为响应级三级指标（ETR、QRel.、EIR），并配以真人标注校准；再用它系统测量六款模型 × 六个基准 × 六种干预，得出三个此前未被如此干净地展示过的经验规律：思考惯性、不思考—性能权衡、答案空间决定可压缩性。三点均以评测和轻量提示实验为主，不需要训练。

  1. 响应级三级度量框架：把响应分解为前答文本 T 与最终答案 A，分层测”严格只答（ETR）→ 剩余文本是否与问题相关（QRel.）→ 是否含显式推断步骤（EIR）”，准确率单独评 A。与最接近的已有做法（把 no-think 设置、<think> 缺失或短输出直接等同不思考）相比，这是度量对象的重定义，属新研究思想而非组件替换；对应 §1 的”代理量不可靠”问题。证据一句话：§4.3 汇总了真人边界审计 94.2% 一致、相关性 ρ=0.829、裁判一致性 98.8% 等构念验证。

  2. 六模式干预谱（M1–M6）：将思考开、原生关、再激发（step-by-step）、软约束、强约束、结构前缀强制（prefix forcing）排在单一”不思考强度”轴上，M6 用预填答案模板绕过指令遵循通道，是谱系中质上不同的分支。相较多数已有工作只比较”开/关”，其差异在于把”抑制强度”做成可扫描的自变量，并据此发现 M6 并不比 M5 更严格（非单调）。证据指向 §4.2 的 Fig. 5 与 Table H.1。

  3. 同题答案空间重写对照：对匹配的数值答案子集，只改答案接口（多选↔Boolean 核验↔开放式生成）而固定题目本身，排除了”不同基准难度不同”的解释。对应 §1 的”答案空间决定支撑”假设，是本文对因果方向最接近的受控设计（仍非机制级因果）。证据指向 §4.2 的 Fig. 6 与 §4.3 的噪声控制表（Tables I.3–I.5）。

3. 作者如何解决

直觉上，作者不信任任何”开关/格式/长度”信号，而是直接追问：把最终答案之前的所有可见文本单独拿出来审——它是空的吗（同不同意只答）？它与问题相关吗？它含有一步真正的推断吗？把这三个问题分别用三个可复核的指标回答，就能在同一把尺子下比较模型、基准和干预；再用”同一道题换答案接口”把答案空间的作用从基准难度中剥离出来。

按实际运行流程走查（§2.2–§2.4，§3.1）：

  1. 形式化与输入构造：每题记为 Q=(q, c, A)，q 为问题、c 为可选上下文、A 为允许的答案空间（如 {yes, no}、{A,B,C,D} 或自由生成）。外部干预 S(·) 把 Q 包装成模型输入 S(Q)，模型 π 输出响应 π(S(Q))=(T, A)：A 是最后一个可解析的最终答案，T 是它之前的全部可读可见文本（包括专用推理区、普通答案通道和短引导语）。干预分两类：问题无关的（只改指令/开关/输出约束）与问题相关的（改题型或答案空间，§2.2）。

  2. 六种模式固定执行（问题无关干预，Table 2）：所有模式共享同一任务题干与”把最终答案放进 \boxed{}”的要求，只切换 enable_thinking（思考开关）与追加指令。M1 Think-On 开思考；M2 Think-Off 原生关闭（基线）；M3 关闭但加”Think step by step”再激发推理；M4 Soft 关闭并允许短引导语但禁止解释；M5 Strict 关闭并要求”直接给答案、不要任何推理”；M6 Prefix 关闭并在生成起点预填模板”The answer is \boxed{“，绕过指令遵循通道（作者视其为独立分支而非 M5 的加强版）。这些由固定流程控制，模型只决定实际生成什么。

  3. 响应解析与三级度量（§2.3，由固定管道执行）：首先做 ETR——对输出 i，e_i=1 当且仅当 A_i 可解析、且完整输出在允许的答案包装之外没有实质文本（A 之后出现实质内容或答案格式坏掉都算违规），ETR 是 e_i 在 N 条输出上的百分比均值，对应”严格只答”。其次做 QRel.——用指令感知的 Qwen3-Embedding-4B 嵌入模型（后文简称 Qwen3-Embedding）把 Q 作为查询、T 作为候选段落编码，查询指令为”给定一个问题，检索包含与该问题相关推理的前答文本”；空 T 记 0，非空取两向量 L2 归一化后的余弦相似度，聚合时对所有输出取均值。最后做 EIR——用一个盲评裁判（blinded LLM judge，GPT-5.5，temperature 0，只看 (Q, T)，隐藏模型身份、干预模式、最终答案与正误）在五标签互斥评分细则（rubric：generic/off-topic、paraphrase-only、relevant non-inferential、explicit reasoning、unclear）中选择一个，只有 explicit reasoning 计 1，空 T 不经裁判直接记 0，EIR 为全输出百分比均值。准确率独立地评 A。

  4. 训练与模型侧变化：全程不做任何训练，属于 training-free 的评测研究；推理阶段的变化仅在提示与接口层面（切换开关、追加约束、预填模板，以及问题相关干预里的题型改写）。解码统一为确定性设置：temperature 0，各模式同一 8,192 token 预算，前沿模型重跑使用种子 20260502（§3.1，Table B.2）。

  5. 人工研究闭环（§2.3 末、§3.6、Appendix D.3）：从六个基准各抽 100 条共 600 条输出（保持各基准空/非空 T 比例），五名标注员在盲评界面分别给非空 T 打 1–5 级相关性与同一套五标签推理类别；空 T 按定义直接记相关性 1、无可见推断。这一步同时检验指标效度（与 ETR 边界、QRel.、EIR 的对照）和主要结论是否在人工标注下复现。

  6. 最终输出：每个（模型，基准，模式）单元给出 Acc./ETR/QRel./EIR 四个数，共 572,688 条成功输出构成总语料（本地 Qwen3-4B/32B 用完整切分各 218,100 条；四款 API 模型每模式 5,687 题、六模式共 34,122 条，§3.1、Appendix B）；外加人工研究与若干稳健性审计。

三级指标的分工可用一个教学简化示例（非论文实验）说明：对 42+79 的回答”Let me compute. 2+9=11, carry 1, so 121.”，T 非空且含一步进位计算——ETR 失败、QRel. 高、EIR=1；换成”The answer is 121.”，T 为非空模板语——ETR 仍失败、QRel. 低、EIR=0；只有”\boxed{121}“此类零前答文本才算通过 ETR。这正是论文 Fig. 3 底部用真实响应示例展示的分层逻辑。

图 2 给出了整套响应级度量框架与六种典型响应形态的示意。

图 2（论文 Fig. 3）：上半部分是推理流程与度量挂载点——问题 Q 经干预 S(·) 变为模型输入，模型 π 输出被拆成前答文本 T 与答案 A，然后在 T 上依次施加三种测量（ETR 判空、QRel. 算相关、裁判判显式推断），A 单独进准确率；下半部分对同一道题”42+79=?”给出六种 T 的形态（空答、短而高相关、短而无关、长而高相关、长而无关、长而中等相关），说明长度、相关性与推断性都可以相互独立地变化。读者应理解：这套分解是全文所有实验的统一观测口径，后续每个模型—模式—基准组合的报告值都是在这条管道上聚合得到的。

下面第 4 节检验这套管道在多大范围上成立：先看主要结果与真人校验，再检查它是否经得起替代解释，最后界定成本与适用边界。

4. 解决得怎么样

4.1 实验设置

任务与数据集：按答案空间分三族，每族一易一难——Boolean 核验用 BoolQ（验证集 3,270）与 StrategyQA（687）；多选用 MMLU（14,042）与 MMLU-Pro（12,032）；开放式生成用 GSM8K（1,319）与 MATH（5,000）（§3.1，Table B.1）。模型：Qwen3-4B/32B（本地，enable_thinking 真/假）、Qwen3-235B-A22B、DeepSeek-V4-Flash（284B）、GPT-5.4、Gemini-3-Flash（推理力度 high/minimal；minimal 被视为”近关”而非严格关）（Table 3，Table B.2）。比较对象即六模式的互比：M1/M3 为思考侧参照，M2 为原生基线，M4/M5/M6 为抑制强度递增的干预。指标为 Acc./ETR/QRel./EIR，全部以全输出为分母（空 T 对 QRel. 记 0、对 EIR 记 0）。公平性控制：温度 0、各模式统一 8,192 token 上限（上限命中率最高 0.35%）、API 模型同套题面与同预算。主实验回答”开关是否可靠、抑制强度如何改变行为与准确率”，附录回答度量稳健性（D）、审计（E）、案例（F）、全局与领域视图（G/H）、问题结构控制（I）。

4.2 关键结果

  • 原生开关远不可靠，且随答案空间恶化（§3.2，Fig. 4）：M2 下多数模型在 Bool 上 ETR 达约 80–100%，多选 ETR 跨度极大（近 0 到 95%），开放式则 ETR 几乎处处塌到 0；全语料 M2 的 EIR 为 Bool 5.15% → 多选 45.57% → 开放式 99.69%（Table D.3）。即”关不掉”的推理随答案空间开放递增——论文称之为思考惯性。
  • 强指令抑制换来的是权衡而非解决（§3.3，Fig. 5）：在五款可完全关闭思考的模型上，M2→M5 把开放式平均 ETR 从近 0 抬到约 40%，同时平均准确率下降约 15 个百分点；EIR 从 99.69% 降到 62.00%，Bool（5.15%→0.12%）与多选（45.57%→25.39%）的 EIR 同样下降但准确率基本持平。开放式任务上”只答合规”与”答对”出现明显拉扯。
  • M6 前缀强制不是更强约束（§3.3，Fig. 5）：预期 M6 应进一步提高 ETR、压低 QRel./EIR，实际在多选与开放式上平均 ETR 反而从 M5 回落，QRel. 与 EIR 在三个答案族全部反弹，作者据此判定其与 M5 不构成同一强度轴。
  • 同题改写坐实答案空间的作用（§3.5，Fig. 6）：Qwen3-32B 在 M2 下，对匹配的数值答案子集把多选改写为 Boolean 核验，准确率几乎不变（77.8→78.9），但 ETR 从 10.5% 升到 62.5%，QRel.（0.709→0.314）与 EIR（86.95%→36.90%）大降；改写为开放式则准确率跌至 52.6%，ETR 为 0，QRel. 升至 0.810、EIR 升至 90.14%。提升小或无提升的情形也存在：Bool/多选上 M2→M5 准确率基本不动；表 4 显示即便固定四选一接口，学科域内 ETR 仍有 0.3–36.4% 的巨大差异（STEM 准确率最高但 ETR 最低）；规模效应不单调（Table H.2：M5 开放式 EIR，Qwen3-4B 97.78%、32B 56.73%、235B 98.90%）。方差方面 Fig. 5 给出均值 ±1 标准差带，但没有置信区间或显著性检验；确定性解码下也没有多次抽样方差的报告。

图 4（论文 Fig. 5）：列为三个答案族，行为 Acc./ETR/QRel./EIR，横轴是模式 M2（原生关闭）→M4（软约束）→M5（强约束）→M6（前缀强制），彩线为各模型、黑线与灰带为均值±1 标准差（ETR 行只纳入有严格关闭条件的模型）。读法上应关注三点：开放式一列的准确率在 M2→M5 间整体下沉而 ETR 抬头——这就是权衡；M5→M6 时 ETR 回落、QRel./EIR 反弹——前缀强制未沿强度轴前进；Bool 列几乎全程平坦，说明准确率代价集中在需要生成答案的答案空间。

图 5 是同一批问题在三种答案空间下的三级指标重写对照。

图 5（论文 Fig. 6）：对 Qwen3-32B 在 M2 下的匹配数值题，把同一批问题分别以多选、Boolean 核验、开放式三种接口问出，四联图依次报告 Acc./ETR/QRel./EIR，红字为相对多选的变化量。它把 §4.2 第二条的”答案族差异”从跨基准现象收紧为同题受控结果：给出候选答案核对（Boolean）能几乎零代价地压缩前答文本，移除候选（开放式）则推高相关性与显式推断并付出准确率代价——答案接口本身在重塑是否”直接回答”。

三张结果图指向同一结论：不思考的可实现程度由题目提供的答案支撑结构决定，而非由开关决定；下面的机制证据检验这一结论的量表是否可信。

4.3 机制证据

区分”有效”与”为什么有效”。度量侧：ETR 的严格边界与人工检查在 600 条上 94.2% 一致（35 条差异来自”答案须可解析”的附加要求）；QRel. 与五名标注员的逐题相关性均值 ρ=0.829（对照的 all-MiniLM-L6-v2 为 0.809，Table 6）；EIR 与人类二分类标签平均一致率 98.8%（GPT-5.5）/96.7%（Claude Opus 4.8），标注员间 Krippendorff’s α 为五分类 0.873、二分类 0.948、相关性 0.919（Tables 5–6、D.6–D.9）。跨家族裁判复现了全部排序关系（Opus 在 M5 开放式仍判 61.02% 含显式推断，逼近 GPT-5.5 的 62.00%，Table D.3），说明 EIR 结论不依赖单一裁判家族。对 §2 三个方法侧创新逐项核对：三级框架方面，论文未做”移除某一级”的消融，但给出了层级不可互相替代的构念证据——近似逐字复述仅 301/572,688（0.053%，最悲观情形对全局 QRel. 影响 ≤0.00053）、纯转述仅 355 条（0.06%）且不计入 EIR、答案先于解释的响应仅 0.028%（Appendix E），并用替换编码器（BGE、E5、MiniLM）验证层级 2 的方向稳定性（Table D.1–D.2）；六模式谱方面，模式即实验自变量，M5<M2 与 M6 非单调均有全语料数字支撑；答案空间重写方面，选项顺序/标签扰动（Table I.3）与 Boolean 正/负提案拆分（Table I.4）排除了”表面秩序”与”一律附和提案”的替代解释。

排除替代解释的检查：提示歧义——作者用独立 GPT 解读 M5 指令，确认其字面义就是只给结果（Fig. E.1）；预算——各模式同为 8,192 上限且命中率 ≤0.35%；难度——同题重写设计排除跨基准难度差；重述通胀——上述审计已量化。未能排除的：思考惯性”为什么”由答案空间组织——论文只给出”与开放式任务需要更多任务相关中间计算相一致”的解释（§3.2）、属于事后诠释，没有直接操纵计算需求的实验；也明确声明不测量隐藏状态是否仍在计算（§5.1），因此”可见推理减少”不能等同于内部计算停止。此外，M6 的行为差异是否来自预填模板本身干扰了答案解析（而非”绕过指令通道”），论文未做模板消融。

4.4 成本与适用范围

训练成本为零（不训练任何模型）；但评测成本论文未报告——裁判 GPT-5.5 需要对约 57 万条输出逐条判定、Opus 4.8 全量复判、Qwen3-Embedding 全量嵌入，外加四款前沿 API 模型（GPT-5.4、Gemini-3-Flash、DeepSeek-V4-Flash、Qwen3-235B-A22B）的推理调用，这些 API 费用与总 token 数、时延均未报告。人工标注为 600 条 × 5 名标注员（其中非空 T 402 条），协议与一致性统计公开（Appendix D.3），成本未报告。外部依赖较重：结论的一半建立在闭源端点（含裁判模型是”用同类模型评同类模型”）。论文公开了项目页（https://thinking-inertia.github.io/）、代码（https://github.com/thinking-inertia/code）与轨迹数据集（HF 数据集 llm-nothinking-trajectories，PDF p.1 超链接）。

改善了什么：给出了可复用的不思考度量工具与大规模证据，量化了禁用开关的不可靠程度，并识别出答案空间这一被忽视的结构变量。仍未解决：如何真正让模型按需停止显示推理（训练侧干预被列为未来工作）；响应合规是否降低真实算力/时延开销（论文自己提醒”可见合规不等于推理成本下降”，§5.2）；多语言、代码、工具使用、多轮与随机解码下的泛化；以及隐藏计算通道的行为。适用范围：英文单轮问答、确定性解码、六款 2026 年前沿模型，结论边界止于可见输出层。

5. 最容易受到审稿人质疑的地方

质疑：核心指标建立在同类大模型之上，”用 LLM 评 LLM”的构念效度风险集中

  • 原文依据：EIR 由 GPT-5.5（temperature 0）盲评产生，QRel. 由 Qwen3-Embedding-4B 产生（§2.3，§3.1）；人工验证仅覆盖 600 条抽样（§3.6，Table 5）。
  • 为什么重要：论文反抗”表面代理量”的武器本身依赖模型判断；若裁判对”显式推断”的判定与人类在更大样本上系统性偏离，或裁判家族倾向与所评模型行为相关（例如都偏好公式化输出），思考惯性的量级会被系统性放大或缩小，直接影响主结论。
  • 当前能够得出的判断：论文的验证在同规模研究中已属充分（人工一致 98.8%、跨家族 Opus 复判 96.7%、α≥0.87），但 600 条中非空 T 仅 402 条、McNemar/置信区间等统计细节未给；跨家族一致只能说明两族裁判”一致”，不能完全排除共同的模型化偏差。
  • 如何验证或补强：扩大到开放式任务的分层随机样本（如每模型-模式单元 ≥200 条）做人工判定并报告精度/召回；加入人类不参考任何 LLM 判定的双盲基线；对 EIR 边界案例（单步短推理）单独报告敏感性。
  • 严重程度：主要问题。

质疑：”思考惯性由答案空间组织”只被观测到，机制解释（计算需求）未经因果检验

  • 原文依据：§3.2 用”consistent with greater computational demands”解释阶梯；§3.5 的同题改写证明接口效应但未操作化”计算需求”；§5.1 声明不触碰隐藏状态。
  • 为什么重要：结论若只是”开放式任务更难压缩输出”，与”模型有内在的惯性”是不同的科学主张；机制不清意味着难以设计训练侧修复，也难预测新任务类型上的行为。
  • 当前能够得出的判断：观察—解释之间证据不足。可替代解释包括：开放式任务缺少可核对候选项导致模型”不自信”而展示过程、以及各基准输出格式习惯（英文数学题训练分布）差异；论文用同题改写削弱了后者但未彻底排除（改写本身也改变了题面表述）。
  • 如何验证或补强：操纵同一题的计算需求（如难度分层/提供中间馈赠步骤）看 EIR 是否随之变化；对模型隐藏状态做探针（probing）检验禁用思考模式下内部计算是否仍在进行；测试在答案空间相同但计算需求不同的数据上惯性是否仍在。
  • 严重程度：主要问题。

质疑：论文动机是效率，但全文未测量任何真实成本，实际收益无从评估

  • 原文依据：引言以时延/token 开销立论（§1）；正文与附录未报告推理时延、总 token、或提供者侧推理 token 数；§5.2 自认”visible compliance should not be equated with lower inference cost”。
  • 为什么重要：读者最可能的落地问题是”把开关关了、把提示写死，能省多少”，而论文无法回答该问题；若模型只是把计算藏在不可见通道，则本文的合规度指标与省钱目标完全脱钩，实践者可能据此做出错误的部署决策。
  • 当前能够得出的判断：论文未报告，无法确认。好在作者明确把结论限定在可见层，减少了对结论本身的威胁，但这使”不思考”作为能力的经济意义悬置。
  • 如何验证或补强：报告各模式的实际 token 计费/时延；征用提供者暴露的推理 token 通道；配合内部探针给出”省了多少真实计算”的下界。
  • 严重程度：次要问题（影响外部解读与实用性，不影响主结论内部有效性）。

质疑：统计呈现不完整，且部分聚合口径混合了完整切分与抽样子集

  • 原文依据：本地模型用完整切分、API 模型每基准抽 1,000 条（StrategyQA 全量，§3.1、Appendix B.1）；Table 4 注释说明 API 模型的 Acc./ETR 用完整 MMLU 聚合、QRel./EIR 用 1,000 条子集；Fig. 5 的 ETR 均值排除 Gemini（其”minimal”非严格关，Table B.2）；正文无置信区间、显著性检验，且温度为 0 无多次采样。
  • 为什么重要：主结论的每个聚合数字对”哪些模型/哪些样本进入平均”敏感；选择性纳入会改变阶梯的高度（虽然方向目前稳健）；无区间估计使”约 40%””约 15 个百分点”这类关键数字精确度不明。
  • 当前能够得出的判断：当前证据支持方向性结论（多裁判、多模型、多审计交叉一致），但精确幅度处于不确定性之中；这属于披露不足而非结论被证伪。
  • 如何验证或补强：对每个聚合报告样本量与自助法（bootstrap）置信区间；将 Gemini 的处理方式做敏感性分析（纳入/剔除各算一遍）；说明 API 抽样与完整切分之间结论是否一致。
  • 严重程度：次要问题。

质疑：M6 前缀强制的行为异常可能更多来自模板设计，而非所声称的”绕过指令通道”

  • 原文依据：M6 在生成起点预填”The answer is \boxed{“（Table 2）；正文报告 M6 平均 ETR 回落、QRel./EIR 反弹（§3.3，Fig. 5），并解释为 M6”绕过指令遵循通道”；定性示例中 M6 的输出常先叙事再补一个词法上不完整的 \boxed{} 结果（PDF p.13），论文未做预填模板的对照（如仅预填不带指令、或换预填内容）。
  • 为什么重要：若异常源于预填文本干扰了答案解析或收尾格式（例如模型把解释写进预填起点之后），”前缀强制不比强指令更强”的解释就需要修正；这影响对”结构约束 vs 语义约束谁更有效”这一节结论的可靠性。
  • 当前能够得出的判断：现象（非单调）有全语料数字支撑，但机制归因未被隔离验证；结论证据显示作者的解释证据不足。
  • 如何验证或补强：增加多种预填模板的消融（含无语义载荷的占位模板、不同预填长度）并交叉检查答案解析失败率在 M6 是否异常；报告 M6 下答案出现在预填之外的占比。
  • 严重程度：次要问题。

6. 审稿式总评

作者发现”禁用思考开关/强令只答”并不能消除响应中可见的显式推理，且现有”不思考”判别全靠开关、<think> 标记与长度三类不可靠的代理量，因此把不思考重定义为响应级三级测量（ETR/QRel./EIR）并配以人工与跨家族裁判验证，在六款模型、六个基准、六种干预与 57 万余条输出上刻画了”思考惯性随答案空间递增”、不思考—性能权衡与同题重写效应。实验在答域、干预、模型维度上的覆盖与审计密度超出该类研究常见水平，描述性结论证据较强；但机制解释（为何随答案空间组织）止于事后诠释，”用同类模型度量同类模型”的构念风险与未测量真实计算成本限制了外推。本文最有价值的部分是提供了一个可复用的、经人类校验的”不思考”测度框架和一组很难被既有开关叙事解释掉的实证事实；最大的审稿风险是核心量表的效度边界（裁判依赖）与因果措辞的克制程度。

  • 问题定义清晰度：强。开篇即用三个具体失效案例把”代理量不可靠”定义清楚，并给出形式化的 T/A 分解与三级操作定义（§2.1–2.3）。
  • 创新性证据：中。度量框架与六模式谱中的 M6 分支属新构造且有验证，但论文价值偏”测量重构 + 现象确认”，不含算法创新；作者也未声称普适的新方法。
  • 方法可信度：中。三级指标有真人校准、跨裁判与多重审计支撑，同时作者明确限定可见层；但构念依赖 LLM 裁判、机制解释为相关性层面（§4.3）。
  • 实验支持力度：强。六模型 × 六基准 × 六模式 × 572,688 条输出、同题受控重写与系列排除性审计（Tables D/E/I）；扣分点是无置信区间/显著性检验与聚合口径混用（§4.4）。
  • 可复现性：中。本地 Qwen 全量实验、确定性解码、公开代码/数据/项目页支持复现；但前沿结果依赖 2026 年闭源端点（含裁判）的持续可用性，人工研究亦难完全重放（§4.4）。
  • 综合阅读价值：高。对研究”按需推理/推理预算/指令遵循”的读者，这是少见的把测量问题当作第一性问题处理、且审计相当彻底的论文；即便不关心工程落地，其关于答案空间结构作用于”是否直接作答”的结论也值得记录。
