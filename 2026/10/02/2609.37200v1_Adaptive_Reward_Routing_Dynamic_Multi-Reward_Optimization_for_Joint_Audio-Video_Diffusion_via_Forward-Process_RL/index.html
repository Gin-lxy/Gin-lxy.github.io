0. 一句话结论

本文解决的是联合音视频扩散模型在（DiffusionNFT 式）前向过程 RL 后训练中的两个动态问题：”奖励驱动的更新应当作用在哪些 token 和跨模态层上”以及”多个互相冲突的奖励（画质、音质、文本一致性、音视频同步）如何随时间协调”——现有方法（GDPO 固定权重、MARBLE 纯梯度几何、OmniNFT 固定路由）都是静态的。核心思路是把采样前向中零成本产生的双向 cross-attention 响应范数当作”跨模态影响力”代理，用它动态生成 token 级损失权重与 layer 级梯度缩放，并把用户先验权重作为地板、把分支内梯度冲突系数作为 warm-up 后的残差修正。证据边界：在 LTX-2 (19B) 与 LTX-2.3 (22B) 两个骨干、JavisBench 10,140 prompts、3 seed 的实验中，同预算下几乎全部指标优于所有基线（相对同预算 OmniNFT，LTX-2 上 10/10、LTX-2.3 上 9/10 更优），干预实验（Spearman 0.98/0.97；冻结路由退化到 0.56/0.38）为代理有效性提供了较强证据；但绝对增益不大、评测指标与训练奖励部分重叠、关键超参未报告，且 Limitations 声称的 JavisDiT++ 验证在正文中没有任何对应实验。

1. 论文具体想解决什么问题？

研究背景与具体任务（领域一般问题）。 联合音视频生成模型（如 LTX-2）用两路流（video / audio）通过双向 cross-attention 互相耦合（Eq. 1），其”高质量”同时包含四个维度：画面质量、音频质量、文本一致性、音视频同步。单一监督目标难以同时表达这些要求，因此实践中用多个奖励模型做 RL 后训练。本文采用 DiffusionNFT（Zheng et al., 2025）的 forward-process RL 框架：用可训练策略与更新策略构造隐式正/负策略（Eq. 2），按组内相对优势把每个样本映射为”偏向正策略”的概率 r(n)=12+12 clip(A(n)/Amax⁡,−1,1)r^{(n)}=\tfrac12+\tfrac12\,\mathrm{clip}(A^{(n)}/A_{\max},-1,1)r(n)=21​+21​clip(A(n)/Amax​,−1,1)（Eq. 3），再加权正/负策略的流匹配损失（Eq. 4）。在这一范式下，论文把后训练形式化为沿两个耦合维度的动态多奖励优化：（i）奖励路由——更新应作用在哪个模态分支、哪些 token、哪些跨模态层；（ii）奖励协调——多个奖励如何加权。这个”两维度”提法本身属于对既有工程问题的整理（多任务冲突、credit assignment 在生成模型后训练中的具体化）。

现有方法怎么做，在哪些条件下失效。 固定奖励协调：GDPO 对每个奖励独立归一化后用固定权重相加（§3），无法对冲突做出反应；纯梯度几何协调：MARBLE 按最小化加权梯度范数解单形系数，但不编码用户偏好与模态责任；静态路由：OmniNFT 为联合音视频生成引入模态级 credit assignment 与层级梯度手术，但其路由由基座模型决定、训练中不再更新（§1、§5.1）。

作者的新观察（原文事实，Fig. 1 支撑）。 论文用四组诊断说明静态方案会逐渐失效：

  1. 同步关键层在训练中漂移（Fig. 1(a)，Forward KV Ablation）：按层段屏蔽 cross-modal K/V 后测 DeSync（越低越好，退化越大说明该层对同步越重要），对比 base 与 OmniNFT 训练后的 checkpoint（§1 原文：”probing of the base and OmniNFT-trained checkpoints”）。读图可见敏感层段的相对剖面发生移动：A2V 的最大退化层段从 Base 的 L10–19（DeSync 0.68）移到 Trained 的 L30–39（0.38）；V2A 的分布也明显重排（例如 L10–19 从 0.58 跌到 0.09，而 L20–29 保持相对最高）。注意两次探测的整体数值因 trained 模型同步本来就更好而普遍下降，关键是相对峰位与分布的变化。
  2. 跨模态梯度路径同样漂移（Fig. 1(b)，Backward Gradient Analysis）：统计两支中 Q（分支内）与 K/V（跨模态）梯度的逐层 ℓ2 范数，base 与 trained 的峰值位置不同，说明静态路由会逐渐”过时”。
  3. 奖励之间频繁冲突（Fig. 1(c)，Reward Conflicts）：按 prompt 归一化后，两个奖励偏好符号相反即记为冲突；热图显示冲突率普遍很高，例如 CLAP 与 HPSv3 冲突率 65%、AV-DeSync 与 HPSv3 55%、AV-DeSync 与 VideoAlign 52.5%（图中另标 30–45% 多个格）。这支持”固定权重/固定分支归属不足以处理冲突”。
  4. 纯梯度几何加权会压制关键目标（Fig. 1(d)，Gradient-Based Weight Drift）：只按奖励梯度几何推导权重时，AV-DeSync 的权重轨迹趋近于零（近零=目标被抑制），而 HPSv3 权重几乎恒定贴地、AudioBox 从约 1.35 缓降。这是作者反对”只用 MARBLE 式系数”的直接依据。

这张图是全文所有设计选择的依据，四块诊断各司其职：(a) 前向 KV 屏蔽实验——行是方向（Video-to-Audio / Audio-to-Video），列是 5 个层段（L0–9 … L40–47），每格数值是屏蔽该层段跨模态 K/V 后的 DeSync（越大越差，说明该层段对同步越重要）；Base 与 Trained 两套剖面对比说明”哪些层管同步”在训练中会移动。(b) 反向梯度分析——四个子图（音频/视频分支 × Base/Trained）画 Q（分支内信号）与 K/V（跨模态信号）梯度的逐层 ℓ2 范数（对数轴），红蓝曲线峰值位置在训练前后变化，说明梯度路径同样漂移；这两块合起来支撑”固定路由会过时”。(c) 奖励冲突矩阵——五个奖励两两的”偏好符号相反率”，颜色越深冲突越频繁；它支撑”固定权重无法处理冲突”。(d) 梯度几何权重漂移——只由奖励梯度几何决定的权重随训练的变化，AV-DeSync（红线）被压到近零，说明纯几何方案会”饿死”弱目标；它直接支撑”必须给先验权重留地板”。读图时注意 (a)(b) 的纵轴/颜色都是相对量且两次探测的整体水平不同，应比较相对分布而非绝对高低。

作者认为的原因（作者主张）。 后训练会改变模型的跨模态函数与梯度流，因此 (i) 固定路由逐渐与新模型错位；(ii) 固定权重无法应对演化的冲突；(iii) 仅靠梯度兼容性（geometry）度量会牺牲”弱但必要”的目标（如同步）——因为这类目标的早期梯度噪声大或不兼容（§4.3 Motivation）。注意：现象部分有 Fig. 1 的测量支撑；”动态适配才能带来更好训练结果”属于作者的解释性主张，其中”冻结路由会 stale”由 Fig. 5(b) 直接验证，”动态路由带来收益”则由 Table 2 消融间接支持（见 §4.3）。

核心假设。 在训练过程中，(a) 用当前模型的 cross-attention 响应（而非基座固定的路由图）重新计算 token/layer 路由，且 (b) 把分支内的梯度冲突系数作为用户先验权重的残差修正（而非替换），能比静态路由 + 固定/纯几何加权更稳定地同时改进画质、音质、语义一致性与音视频同步。

区分三类问题。 领域一般问题：多奖励冲突与 credit assignment 是 RL/多任务学习的长期话题。本文新观察：在联合音视频扩散 RL 的具体设定下量化了”跨模态函数与梯度路径随微调漂移””几何加权压制同步奖励”两类现象。本文实际解决的子问题：为 LTX-2 系双流架构设计了一套训练期动态路由与协调机制，并给出与 GDPO/MARBLE/OmniNFT 的同预算对比。

2. 创新点是什么？（先说真正增量）

一段话概括。 技术增量是一套插入 DiffusionNFT 训练循环的轻量自适应机制：① 用采样前向免费得到的跨模态 cross-attention 响应范数（pre-gate response，Eq. 6）作为”影响力代理”，在 token 级把它变成损失权重（Eq. 7、Eq. 13），在 layer 级把它变成对 K/V 反向梯度的缩放（Eq. 8–9，前向数值不变、只改梯度）；② 把奖励协调建模为”用户先验权重 + 分支内 MARBLE 冲突系数的残差修正”，warm-up 后启用（Eq. 10–11）。再加一组以真实干预实验为基准的代理验证（§5.4）。方法没有任何新增可学习参数，也不改变推理。

不算创新的部分（审稿人判断）。 使用 19B/22B 的 LTX-2 骨干、五个现成奖励模型、DiffusionNFT 框架与 MARBLE 求解器都是既有组件；相对基座模型的巨大提升（如 VQ 1.883→3.336）主要来自”做了 RL 后训练”这件事实（同门基线 OmniNFT 也到 3.136），本文增量应聚焦在”相对同预算静态基线”的比较上。论文未声称任何”首次”，Abstract 与 §1 只用 “we propose / we show”。

原始性边界。 根据本文 related work 与实验对比，只能确认作者声称的差异：与 OmniNFT 的差异在”路由是否动态”，与 MARBLE 的差异在”是否含偏好与分支归属”，与 GDPO 的差异在”权重是否随冲突调整”。是否构成首次提出需要更完整的文献检索。

3. 作者如何解决？

直觉说明。 后训练过程中模型在变：哪些跨模态层重要、哪些 token 承载音视频耦合都在变；奖励之间的”谁和谁打架”也在变。既然两种信号都能”免费”拿到——(a) 采样前向里 cross-attention 的输出在”加门控之前”就记录了每个目标 token 从对侧模态接收了多少信息；(b) 每个奖励沿自己责任分支的梯度可以定期探测——那就让训练损失的位置选择（token 权重、层梯度缩放）和奖励加权都跟着这些信号走，而不使用一次性算好的静态配置。同时，因为纯几何系数会牺牲弱目标（Fig. 1d），先验权重必须保留为地板。

运行流程（按 Algorithm 1 与 §4.1 的实际顺序；Fig. 2 为总览图）。

这张图按训练循环的顺序分成五块，刻意把”数据流”与”梯度流”分开画：(1) Sampling——视频/音频隐状态各走 Self-Attention、文本条件 cross-attention（T2V/T2A）、双向跨模态 cross-attention（A2V/V2A）与 FFN，用更新后的策略生成一组样本，采样时顺带记录 pre-gate 响应（就是后面路由要用的免费信号）；(2) Evaluation——每个样本被视频、音频、跨模态奖励模型分别打分，画成”好/坏”笑脸，说明多奖励彼此可能不一致；(3) Reweighting（§4.3）——把先验权重与分支内冲突系数组合，得到两支的合成优势 AvA_vAv​、AaA_aAa​ 并映射为 rvr_vrv​、rar_ara​；(4) Routing（§4.2）——左侧示出第 l 层的 A2V/V2A cross-attention（QvKaVaQ_vK_aV_aQv​Ka​Va​、QaKvVvQ_aK_vV_vQa​Kv​Vv​ 与输出 oa→vo_{a\to v}oa→v​、ov→ao_{v\to a}ov→a​），右侧把各层响应做 layer 聚合（layer-level routing，即 Eq. 9 的梯度缩放）与 token 聚合（token-level routing，得到 λ_v、λ_a 两张空间权重图）；(5) Loss——λ 以逐 token 乘法进入负感知损失。为什么需要它：它把”奖励 → 分支 → token/层 → 梯度”这条链路完整画出来了，读者可以看清每个自适应量在哪一步产生、作用在哪一步；对照 Fig. 1 的四组诊断，每一块都对应一个被验证的失效模式。

  1. 输入：文本 prompt（训练用 19,487 条来自 VGGSound 派生语料的音视频 prompt，§5.1）、当前策略 vθv_\thetavθ​、更新策略 vupdatedv^{\mathrm{updated}}vupdated、五个奖励模型、用户先验权重 ωprior\omega^{\mathrm{prior}}ωprior。
  2. 采样与响应收集：vupdatedv^{\mathrm{updated}}vupdated 生成一组样本；同时收集”中间到晚期去噪窗口”内双向 cross-attention 的 pre-gate 响应（Eq. 6），detach 后只作统计用，不参与反传。
  3. 奖励评测与组内归一化：每个样本由五个奖励打分，各自做组内归一化得到优势 AkA_kAk​ 与 rrr（Eq. 3）——这一步继承自 DiffusionNFT。
  4. token 路由：对时间步与跨模态层平均响应 → Norm99 归一化 → λm,i\lambda_{m,i}λm,i​（Eq. 7）。作用在 token 级损失上（Eq. 13），相当于”跨模态影响力越大的位置，梯度份额越大”。
  5. layer 路由：对 token 与时间步平均响应 → 逐层归一化 → αml\alpha^l_mαml​（Eq. 8）；K/V 以 stop-gradient 插值（Eq. 9）参与采样前向——前向数值不变，但反向梯度按 1−αml1-\alpha^l_m1−αml​ 缩放。这是纯”反向路径手术”。
  6. 奖励协调：每个训练轮用缓存的 γˉ\bar{\gamma}γˉ​ 计算 ωm,k\omega_{m,k}ωm,k​（Eq. 10）。warm-up 之后、且在”刷新轮”，才重新探测：让每个奖励只沿其责任分支回传梯度（此时禁用 token 路由以免测量被偏置），解分支内 MARBLE 问题得到新系数并平滑进 γˉ\bar{\gamma}γˉ​。先验权重保证每个目标有非零地板。
  7. 损失与更新：合成分支优势（Eq. 11）→ 分支 r → token 级负感知损失 ℓ（Eq. 12，含 detached 残差归一化 w±w^\pmw±）→ 按 λ 加权平均得到 Lmpolicy\mathcal{L}^{\mathrm{policy}}_mLmpolicy​（Eq. 13）→ 加对固定参考策略的 KL 正则（Eq. 14）→ 反传经过被路由的 KV 路径更新 θ（LoRA）→ 按 DiffusionNFT 调度更新 vupdatedv^{\mathrm{updated}}vupdated。
  8. 推理阶段：所有自适应机制只存在于训练循环；推理时就是微调后的模型本身，不引入额外网络或推理步骤（论文未单列推理成本，此为按方法描述的分析者判断）。

模型决定 vs 固定流程。 由模型/数据决定：λ、α、γ、ω 的取值都是当前模型与当前采样批次的函数，每轮重算；由固定流程决定：公式形式（Norm99、α=(1−δ)1/τ\alpha=(1-\delta)^{1/\tau}α=(1−δ)1/τ、先验+残差混合）、warm-up 与刷新节奏、KL 与超参。训练的部分只有策略 θ（§5.2 明确”same data, LoRA, and optimization budgets”，即用 LoRA 微调）；奖励模型与代理统计全部冻结/detach，无新增可学习参数。

关键设计假设。 (i) pre-gate 响应范数 ≈ 功能影响力——这不是不证自明的假设，§5.4 用干预实验检验（见 §4.3）；(ii) 用户先验权重应作为不可被梯度几何覆盖的地板；(iii) 弱耦合跨模态层的梯度是干扰，应被软性切断。

教学简化示例（非论文实验）。 假设一个生成样本里，说话人嘴部附近的视频 token 在 A2V 通路上从音频接收到的响应远高于背景 token：Norm99 之后它的 λ 会接近上限 λ_max（论文未报告 λ_max 数值），于是这些 token 在损失中占更大梯度份额；同时容纳这些高响应 token 的层由于 δ 高、α 低，其 K/V 的反向梯度被保留得更多。这个例子的每个环节都只是对 Eq. 7–9 的具象化；”高响应=真重要”正是 §5.4 要检验的命题，而非已成立的前提。

与现有工具的关系。 论文提出的：响应代理路由（token/layer）、偏好保持的分支感知协调、分支内梯度探测流程。直接使用的：LTX-2/LTX-2.3 骨干、DiffusionNFT 的隐式正负策略与优势归一化、MARBLE 求解器（作为子过程）、五个奖励模型（VideoAlign、HPSv3、AudioBox Aesthetics、CLAP、DeSync 转换）、ImageBind/CLIP/CLAP/JavisScore 等评测指标、JavisBench 与 VGGSound 派生语料。

4. 解决得怎么样？

4.1 实验设置

  • 骨干与数据：LTX-2 (19B) 与 LTX-2.3 (22B)，均为”音视频双流 + 双向 cross-attention”结构；训练用 19,487 条 VGGSound 派生语料的音视频 prompt（每条含模态特定描述与联合 prompt）（§5.1）。
  • 奖励模型（5 个）：VideoAlign、HPSv3（视频质量/偏好）；AudioBox Aesthetics（音质）；CLAP（文本-音频对齐）；DeSync 转成越大越好的 AV-DeSync（训练用），评测仍报原始越小越好的 DeSync（§5.1）。
  • 基线：No Post-Training（基座）；GDPO（固定权重）；MARBLE（全局梯度几何协调，无模态路由）；OmniNFT（模态级 credit assignment + 固定路由，最接近的同类）；OmniNFT*（原作者的已发布 checkpoint，无 std）。
  • 评测：完整 JavisBench（10,140 prompts；输出规范化为 4 秒/24 FPS/16 kHz），四组指标：AV-Quality（VQ、AQ）、Text-Consistency（TV-IB、TA-IB、CLIP、CLAP）、AV-Consistency（AV-IB、AVHScore）、AV-Synchrony（JavisScore、DeSync）（§5.1）。
  • 公平性口径：GDPO/MARBLE/OmniNFT/Ours 四个可训练方法使用相同数据、LoRA 与优化预算，各自 3 个随机种子，报均值±std；基座与 OmniNFT* 为固定 checkpoint（§5.2、Table 1 表注）。
  • 各实验回答什么：Table 1 主对比回答”是否优于强基线”；Table 2 两条消融链分别隔离”路由”与”奖励协调”两个轴；Fig. 4(a) 看训练动态是否均衡；Fig. 5 回答”代理是否真的指认了重要层/token、冻结路由是否 stale”。

4.2 关键结果

主结果（Table 1，3 seed 均值±std，同预算比较）。

  • LTX-2：Ours VQ 3.336±0.0094 对同预算 OmniNFT 3.136±0.0108、GDPO 2.722、MARBLE 2.384、基座 1.883；AQ 5.868 对 5.614 / 5.450 / 5.100 / 5.201；JavisScore 0.206 对 0.195（OmniNFT）/ 0.193（OmniNFT*）/ 0.153（基座）；DeSync（越低越好）0.341 对 0.390 / 0.378 / 0.604。
  • LTX-2.3：Ours VQ 3.599 对 3.489（OmniNFT）/ 3.537（OmniNFT*）/ 2.032（基座）；AQ 5.979 对 5.693；JavisScore 0.236 对 0.224；DeSync 0.302 对 0.369 / 0.335 / 0.504。
  • 作者称每种骨干上”十项指标中九项最佳”。逐项核对 Table 1：LTX-2 上确为九项严格最优，唯一例外是 CLIP——Ours 0.314±0.0011 与已发布检查点 OmniNFT* 0.314 并列（同预算 OmniNFT 0.312）；LTX-2.3 上也是九项最优，唯一例外仍是 CLIP（Ours 0.314±0.0011 低于同预算 OmniNFT 的 0.316±0.0010，差 0.002，约为其 std 的两倍）。
  • 失败/弱势面：GDPO 的失败模式被复现——它把 VQ 提到 2.722 但同步变差（DeSync 0.671 比基座 0.604 还高）；MARBLE 在 LTX-2 上 AQ 5.100 低于基座 5.201、VQ 2.384 低于 GDPO，说明”纯几何协调”在本设定下并不稳健。CLIP 在各方法间几乎不变、区分度很低（LTX-2 上全部落在 0.311–0.314；LTX-2.3 上 0.308–0.316）。相对提升最大的维度是同步（DeSync 相对同预算 OmniNFT 降 0.049/0.067）；提升最小的语义类指标 TA-IB 只多 0.022/0.014。

Fig. 4(a) 是五个奖励各自的训练曲线加一条”Average”：对固定权重的 GDPO、纯几何的 MARBLE、静态路由的 OmniNFT 与本文方法做同轴对比——Ours（绿）在大多数子图上全程最高，且没有以牺牲某个奖励换另一个奖励的迹象，这是”协调而非偏科”这一说法的主要可视化证据；需要注意曲线只反映训练激励（奖励模型打分），不是人类感知。Fig. 4(b) 是两条消融链：左侧 Routing Ablation 从 GDPO 出发依次叠加 token 加权、layer scale、两者并用，直到完整方法的平均奖励逐级升高；右侧 Weighting Ablation 从 MARBLE 出发依次加分支感知、残差修正、warm-up，同样单调抬升。横轴刻度延伸到约 1000（论文未在正文说明该轴的具体单位与训练总预算），两组曲线在训练全程都保持次序，说明不是某一时刻的偶然交叉。

消融（Table 2，LTX-2，3 seed）。

  • 路由消融（以 GDPO 为底）：+Token Weighting（VQ 3.008，DeSync 0.482）、+Layer Scale（VQ 3.192，DeSync 0.366）、+Token+Layer（VQ 3.315，DeSync 0.343）三个配置均优于 GDPO（2.722 / 0.671），两者结合最强，token 与 layer 增益互补（§5.3(i) 原文称 “combining the two produces the strongest routing-only configuration”）。
  • 权重消融（以 MARBLE 为底，灰色行，不含路由）：+Branch-Aware（VQ 2.612，DeSync 0.492）、+Residual（2.891，0.455）、+Warm-Up（2.999，0.369）三行相对 MARBLE（2.384 / 0.618）逐行改善，可见”先验地板 + 残差修正”显著缓解了 MARBLE 的同步与画质劣势（三行的叠加语义论文未逐句说明，此处按 Table 2 行序呈现）。
  • 完整方法（Routing + Weighting）：3.336 / 5.868 / 0.206 / 0.341，两个轴组合后整体最优，且并非某一轴的简单叠加（两链各自的最强配置仍低于完整模型的大部分指标）。作者也承认中间配置”不必然每个指标单调改进”，只有整体平衡变好（§5.3(iii)）。

4.3 机制证据（”有效” vs “为什么有效”）

代理的因果验证（本文最硬的一段）。 §5.4 用真实干预替代相关性论证：(i) 在四个训练 checkpoint 上逐一屏蔽 48 个 A2V/V2A block，测最终速度预测的变化，代理排序与干预排序的 Spearman 相关为 0.98（A2V）/0.97（V2A）；(ii) 冻结在初始化的代理与当前模型的一致性随训练跌到 0.56（A2V）与 0.38（V2A），而”随训练重算”的代理全程 >0.96——这直接证明了 Fig. 1 的”静态路由会 stale”不是口号；(iii) 遮蔽代理得分 top-10% 的 token 造成的变化比同规模的随机组大 1.62×（A2V）/1.74×（V2A）——遮蔽规模相同，排除了”遮蔽比例”这一替代解释。

Fig. 5(a) 每个点是一个层：横轴是代理分数，纵轴是真实屏蔽该层后最终预测的相对变化，两者高度贴近对角线（Spearman≈0.98/0.97），这是”代理量测的就是功能重要性”的证据；(b) 的实线（Ours，随训练重算）全程贴着 1.0，而虚线（Frozen，固定在初始化）从 Middle 之后快速下滑——路由必须跟着模型走；(c) 是唯一带”对照规模”的 token 实验：High 组、Random 组、Low 组三条柱依次递减（论文报告 top-10% 相对随机 10% 的变化倍率为 A2V 1.62×、V2A 1.74×；读图近似值 High≈0.12/0.11、Random≈0.08/0.06、Low≈0.04/0.03），说明代理分数排序与 token 功能贡献单调对应。三张子图合起来把”代理有效性”从假设升级为被验证的机制，但它们验证的是代理，不是训练收益。

训练收益的归因边界。 Table 2 的两条消融链显示”每加一个组件整体指标变好”，但：(i) 没有从完整模型中做 leave-one-out（例如完整方法去掉 layer 路由、去掉 residual、去掉 warm-up 各自会怎样）；(ii) 没有”动态但无信息”的对照（例如随机时变路由、打乱响应的路由），因此无法排除”任何随训练变化的正则化/加权都会带来部分增益”这一替代解释；(iii) Fig. 5(b) 证明的是”冻结代理不再对准当前模型”，它不自动等价于”采用动态代理的训练一定更好”——中间的因果跳步由 Table 2 的 aggregate 数字承接，强度弱于 §5.4。论文没有把”哪一类 token 的梯度因此改变了多少”这类有效学习信号的直接分析做出来。

4.4 成本与适用范围

  • 训练成本：论文未报告硬件、时长、FLOPs 或训练轮数；”same data, LoRA, and optimization budgets”（§5.2）没有给出任何数值，因此无法核对与基线的预算是否严格相等。额外的计算来自：warm-up 后在刷新轮对五个奖励分别沿责任分支做梯度探测（Algorithm 1 第 8–9 行）——其频率与开销论文未报告。
  • 推理成本：按方法描述，所有机制只作用于训练（响应统计、路由、权重都在训练循环内完成），推理时不需要任何额外模块（分析者判断；论文没有单列推理时延）。相对收益而言这是本方法的一个重要工程优点。
  • 外部依赖：需要五个奖励模型同时在训练管线里（其中 DeSync 需符号转换）；奖励模型本身的质量与偏置会直接进入优化目标。Limitations (i) 承认”没有统一的音视频奖励”，人类偏好模型也只是补充。
  • 适用范围：路由需要”模态 token 可辨识 + 方向性交互响应可分离”（Limitations (iii)），因此适用于 LTX-2 这类双流架构；协调部分与架构无关。对不可分离的模态表示，论文称留作未来工作。
  • 仍未解决：多奖励冲突只是被”平衡”而非消除；奖励被过度优化（reward hacking）的风险没有任何检验；绝对增益幅度有限；没有人类主观评测；没有报告失败率或生成样本的退化案例。

5. 最容易受到审稿人质疑的地方

质疑：评测指标与训练奖励高度重叠，主要结论可能是”对同一族奖励模型的再优化”而非感知质量提升

  • 原文依据：训练用五个奖励 = VideoAlign、HPSv3、AudioBox Aesthetics、CLAP、DeSync（§5.1）；评测端 VQ/AQ 引自 VideoAlign 论文（Liu et al., 2026b，§5.1 (i)）、CLAP 与 DeSync 直接就是同名的训练奖励，Text 一致性还用了与 CLAP 同源的自动指标；论文没有任何人类评测或”留出奖励”上的结果。
  • 为什么重要：如果评测与训练目标同源，指标上升可能主要反映”优化器成功地迎合了这些奖励模型”，而不是”生成质量更好”。这直接决定主结论（”consistently improves modality quality…”）的强度。
  • 当前能够得出的判断：在”同源自动指标上更优”这一点上证据充分；但”更优的感知质量”当前材料无法确认。作者对 reward hacking 未做任何检验，也未讨论。
  • 如何验证或补强：在训练未使用的奖励（或独立的人类偏好模型，如论文自己引用的 VA-Judger）与人类主观评测上复测；报告奖励模型的过优化曲线（训练奖励 vs 留出奖励随步数的关系）；对生成样本做盲评。
  • 严重程度：主要问题。

质疑：消融没有隔离”动态跟踪”这一核心变量，替代解释未被排除

  • 原文依据：Table 2 两条链是”从 GDPO 或 MARBLE 出发逐项相加”，没有从完整方法做 leave-one-out；没有”无信息动态”对照（随机/打乱响应的路由或随机时变权重）；Fig. 5(b) 只证明冻结代理会与当前模型失配，不直接证明动态代理带来训练收益（§5.3、§5.4）。
  • 为什么重要：论文的卖点是”因为函数在演化，所以路由/权重必须动态”，若收益中有相当部分来自”任何额外的时变加权/梯度缩放”，则核心叙事被高估。
  • 当前能够得出的判断：证据支持”这套具体机制在同预算下有效”；”必须动态跟踪”只被部分支持（冻结代理失配 + 消融的间接证据）。论文观察到了现象并给出机制验证，但”动态性本身”的关键因果对照缺失。
  • 如何验证或补强：完整模型的 leave-one-out（去掉 layer 路由 / 去掉 residual / 去掉 warm-up）；冻结代理路由 vs 动态代理路由的同预算直接对打（论文已具备做这个实验的组件）；打乱响应的伪代理对照。
  • 严重程度：主要问题。

质疑：Limitations 宣称在 JavisDiT++ 上做过验证，但正文没有任何对应实验

  • 原文依据：§6 Limitations (iii) 原文：”We validate our method on both dual-stream LTX backbones and the unified single-stream JavisDiT++ backbone.” 但通读 v1 全文（HTML 与 PDF 逐页）只找到 §5.1 的 LTX-2/LTX-2.3 两个骨干的实验，没有 JavisDiT++ 的任何表格、图或数字；论文亦无附录。
  • 为什么重要：这是一个”宣称已做但无法在论文中找到证据”的可用性范围声明，直接影响结论外推（单流架构能否受益是方法与 OmniNFT 差异化叙事的一部分）。
  • 当前能够得出的判断：在 v1 版本中该宣称无法核实，疑为写作残留或删减后未同步；不足以否定 LTX 上的主结论，但会削弱审稿人对全文严谨性的信任。
  • 如何验证或补强：补充 JavisDiT++ 实验或修正 Limitations 措辞；若结果存在于被裁剪的附录，随版本公开。
  • 严重程度：主要问题。

质疑：关键超参、训练预算与实现细节缺失，复现与公平性核对都无从谈起

  • 原文依据：λ_max、τ（Eq. 7–8）、e_warm 与刷新频率、κ、ρ（Eq. 10）、LoRA 配置、学习率、训练轮数、采样组大小 N、β、λ_KL、先验权重 ω_prior 的具体数值、”中间到晚期去噪窗口”的定义全部未报告；正文没有给出代码仓库或项目页链接（参考文献中的 arXiv 链接除外）；”same data, LoRA, and optimization budgets”（§5.2）无任何数字支撑。
  • 为什么重要：这些超参（尤其 λ_max、τ、warm-up 时机和刷新频率）正是决定方法行为与开销的关键旋钮；缺少它们既无法复现，也无法核查”同预算”是否成立（例如刷新轮的额外梯度探测成本如何分摊）。
  • 当前能够得出的判断：在 v1 版本+无代码的状态下，独立复现完整方法不可行，只能近似复现（依赖 DiffusionNFT/MARBLE 的公开实现与论文公式）。
  • 如何验证或补强：公开代码与训练配置；在附录列出全部超参、预算（GPU 时）与敏感性分析（λ_max、τ、e_warm 的扫描）。
  • 严重程度：主要问题。

质疑：结论强度受限于单一基准、单一 RL 配方与较小的绝对增益

  • 原文依据：全部结果基于 JavisBench + 五个特定奖励 + DiffusionNFT（§5.1–5.2）；增益幅度小（JavisScore 0.206 对 0.195；TA-IB 0.167 对 0.145）；CLIP 在 LTX-2.3 上低于同预算 OmniNFT（Table 1）；定性比较（Fig. 3）只给四个示例且未说明挑选标准；模型在 Fig. 1 中对”Trained”检查点的选择（OmniNFT 训练产物）也让”stale”的结论绑定于这一特定基线。
  • 为什么重要：Abstract 的 “consistent improvements” 与 Limitations 对架构范围的谨慎形成张力；细粒度差异是否在感知上可见，自动指标无法回答。
  • 当前能够得出的判断：”在两个 LTX 骨干、JavisBench、指定奖励集合下稳定优于对比方法”成立；更广的”普遍更好”不能推出。
  • 如何验证或补强：多个基准（如自建集或 VBench 系音视频子项）、不同奖励组合与 RL 配方下的复测、失败案例分析、统计显著性检验（目前只有 seed std，无显著性测试）。
  • 严重程度：次要问题。

6. 审稿式总评

作者观察到多奖励 RL 后训练里”更新应当落在哪里”和”多个奖励如何权衡”都随训练演化，静态方案（固定路由/固定权重/纯梯度几何）会逐渐失配甚至压制关键目标（Fig. 1 四组诊断），因此提出 Adaptive Reward Routing：用采样前向免费产生的跨模态 cross-attention 响应代理动态生成 token 级损失权重与 layer 级梯度缩放，并把分支内的 MARBLE 冲突系数作为用户先验权重的残差修正（warm-up 后启用、先验保底）。实验在 LTX-2/LTX-2.3 两个骨干、JavisBench 10,140 prompts、3 seed 下表明：同预算时几乎全部指标优于 GDPO/MARBLE/OmniNFT，且 §5.4 的干预实验（Spearman 0.98/0.97，冻结代理退化到 0.56/0.38，top-token 遮蔽效应 1.62×/1.74×）为”代理指认真实影响力”提供了较强的因果证据；但”动态性本身带来收益”缺少 leave-one-out 与无信息对照，评测指标与训练奖励部分重叠且无人类评测，全部关键超参与预算未报告，Limitations 中的 JavisDiT++ 验证声明在正文没有任何对应实验。本文最有价值的部分是它把”训练期动态路由 + 偏好保底协调”做成了一套推理零成本、无新增参数的轻量方案，并用干预实验认真验证了自己的代理量；最大的审稿风险是主要结论依赖与训练奖励同源的评测指标，且复现信息缺失使第三方难以独立检验。

  • 问题定义清晰度：强（两个维度界定明确，Fig. 1 把”静态方案失效”逐条可视化）。
  • 创新性证据：中（组件级增量清晰、动机与消融对应，但多为已有模板的新组合；”必须动态”这一核心叙事缺直接对照）。
  • 方法可信度：中（设计轻量、无新增参数、推理零成本、代理有干预验证；但关键超参与刷新策略未报告，机制解释仍有跳步）。
  • 实验支持力度：中（两骨干、3 seed、完整基准、公平口径声明；但评测与训练奖励重叠、无人类评测、无显著性检验、增益较小）。
  • 可复现性：弱（无代码/项目页，超参、预算、窗口定义均未报告，依赖五个外部奖励模型）。
  • 综合阅读价值：中（对”多奖励扩散 RL 后训练中的动态 credit assignment”给出了可迁移的工程范式与值得学习的机制验证方法；但结论强度受证据重叠与信息缺失限制）。
