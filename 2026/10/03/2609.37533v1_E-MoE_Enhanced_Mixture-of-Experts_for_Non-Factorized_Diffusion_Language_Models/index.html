0. 一句话结论

论文针对掩码扩散模型（MDM）反向过程按位置因子化、少步（低 NFE）采样时同一步解掩码的 token 之间缺乏关联这一问题，提出 E-MoE：不再训练额外的 VAE 与固定高斯先验，而是把 MoE 骨干路由器已有的路由决策当作离散共享潜变量，用同一次网络前向在噪声序列与干净序列上分别产生先验与后验路由，以路由 KL 对齐二者，从而以”混合因子化专家”的形式构造非因子化反向过程。在论文报告的合成 2D 密度、Binarized-MNIST 与 LM1B 三个设定下，低 NFE 生成质量大幅优于因子化 MDLM 与连续潜变量基线 VADD（LM1B NFE=1 生成困惑度 643.8 对 1270.8/1433.8，Table 4），采样期”关掉混合”消融（Table 9）给出了机制层面的直接证据；但最接近基线 VADD 的调优公平性、训练期组件的独立消融、以及统计稳定性（多种子/方差）仍缺少充分支持，结论应限定在论文报告的低 NFE 区间与三个小规模设定内。

1. 论文具体想解决什么问题？

研究背景与具体任务。 自回归（AR）语言模型逐 token 解码，长度 LLL 的序列需要 LLL 次前向且无法并行（§1，原文事实）。掩码扩散模型（MDM，如 MDLM、SEDD）提供另一条路线：前向过程逐步加掩码，反向过程用双向注意力一次预测多个位置，T<LT < LT<L 步即可生成整条序列（§1、§2，原文事实）。其代价是反向过程通常对位置因子化：

pθ(xs∣xt)=∏ℓ=1Lpθ(xsℓ∣xt)=∏ℓ=1Lq(xsℓ∣xt,xθℓ)(Eq. 3)p_{\theta}(\mathbf{x}_{s}\mid\mathbf{x}_{t})=\prod_{\ell=1}^{L}p_{\theta}(\mathbf{x}_{s}^{\ell}\mid\mathbf{x}_{t})=\prod_{\ell=1}^{L}q(\mathbf{x}_{s}^{\ell}\mid\mathbf{x}_{t},\mathbf{x}_{\theta}^{\ell}) \quad \text{(Eq. 3)}pθ​(xs​∣xt​)=ℓ=1∏L​pθ​(xsℓ​∣xt​)=ℓ=1∏L​q(xsℓ​∣xt​,xθℓ​)(Eq. 3)

现有方法在哪里表现不好。 因子化意味着同一步内被解掩码的多个位置是从各自的边缘分布独立采样，丢弃了它们之间的依赖；每步解掩码越多，该误差越大，而这恰恰是低 NFE（1–2 步）让扩散相对自回归的并行优势最有价值的区间（§1，原文事实；依赖模型条件独立采样的错误来源引用了 Liu et al., 2025）。论文进一步指出 pθ(xs∣xt)p_{\theta}(\mathbf{x}_{s}\mid\mathbf{x}_{t})pθ​(xs​∣xt​) 作为边缘分布之积是真实联合分布的 rank-one 近似，无法表示被揭示 token 之间的任何依赖（§2，原文事实）。最接近的解决路线是 VADD（Xie et al., ICLR 2026）：引入连续共享潜变量 z∈Ru\mathbf{z}\in\mathbb{R}^{u}z∈Ru，把反向过程写成 ∫zpθ(xs∣xt,z)p(z) dz\int_{\mathbf{z}}p_{\theta}(\mathbf{x}_{s}\mid\mathbf{x}_{t},\mathbf{z})p(\mathbf{z})\,d\mathbf{z}∫z​pθ​(xs​∣xt​,z)p(z)dz，其中各位置条件因子化但边缘因对 z\mathbf{z}z 积分而非因子化（§2，Eq. 4；原文事实）。论文对 VADD 的两点批评属于作者主张：其一，连续潜变量必须配参数化先验（实践中为固定高斯），无法直接构造数据自适应的更信息性先验；其二，训练 VADD 需要额外交互网络（VAE 式识别网络），增加训练阶段的可学习参数（§1）。

作者的新观察与支撑证据。 论文在自己的 LM1B 复现中发现，VADD 的潜变量 KL 随退火下降到约 0.14 nats/token 后保持在该水平，作者据此判断”后验携带信息很少、潜变量接近崩溃（posterior collapse）”——注意这是作者在其复现配置下对 VADD 的诊断（§C.3.3，Fig. 9；作者主张），不是对 VADD 原论文结论的否证。与之相对，E-MoE 的路由 KL 稳定在约 0.65 nats/token 且无需 warmup，重构项相应更低（§C.3.3，Fig. 9；原文事实）。

作者认为的问题根因与核心假设。 根因是反向过程的因子化本身（§1、§2）。核心假设是：可以不引入固定先验与额外网络，直接复用 MoE 骨干已在计算的路由决策作为”离散共享潜变量”——同一个 router 在噪声序列与干净序列上分别给出先验与训练期后验，对路由分布的 KL 对齐迫使噪声一路能预测干净一路的路由；采样时只走噪声一路，随机路由把单步解掩码变成对混合成分的采样，从而在活跃参数不增加的前提下获得跨位置关联（§1 贡献列表、§3；作者主张，后由 §5 实验与 §C.3.2 消融支持）。

区分三个层次。 领域早已存在的问题：MDM 反向过程的因子化误差及其在少步采样的危害（论文引用 Liu et al., 2025、VADD 等，非本文独创）。本文的新观察：路由决策可以直接充当共享潜变量，且作者在自己的复现中观察到连续潜变量路线的崩溃倾向。本文实际解决的子问题：在不加识别网络、不加活跃参数的前提下，给出一个带可解 KL 的混合反向过程训练目标，并在三个小规模设定上验证低 NFE 生成质量的增益。论文没有解决：大规模 LLM 规模（LLaDA-MoE 式）上的验证只在 Appendix D 作为设想提出（作者主张）。

2. 创新点是什么？

一段话概括。 真正的技术增量是把”共享潜变量混合”路线（VADD）中的潜变量从”额外 VAE 学出的连续全局向量”改写为”MoE 骨干路由器本就输出的离散路由码”：潜变量空间为 {1,…,E}L×D\{1,\dots,E\}^{L\times D}{1,…,E}L×D（每 token 每层一个专家选择），先验 pθ(z∣xt)p_{\theta}(\mathbf{z}\mid\mathbf{x}_{t})pθ​(z∣xt​) 由同一 router 在噪声输入上给出、是数据自适应的、无需设计先验分布；训练期后验 qθ(z∣xt,x0)q_{\theta}(\mathbf{z}\mid\mathbf{x}_{t},\mathbf{x}_{0})qθ​(z∣xt​,x0​) 由同一 router（共享权重）在噪声+干净输入上给出，无需额外识别网络；配套推导了该混合参数化下 NLL 的上界，并把潜变量 KL 化简为逐层逐 token 的路由分类分布的 KL（T⋅KLrouteT\cdot\mathbf{KL}_{\text{route}}T⋅KLroute​，Eq. 8–9）。其余组件（掩码扩散的加噪/反噪机制、Transformer/UNet 骨干、Gumbel-Softmax 直通估计、top-k 路由）均为已有技术的组合与改造。

创新点 1：以 MoE 路由决策作为离散共享潜变量（核心机制）。

  • 新增了什么：反向过程写成 ∑zpθ(z∣xti)∏ℓpθ(xℓ∣xti,z)\sum_{\mathbf{z}}p_{\theta}(\mathbf{z}\mid\mathbf{x}_{t_{i}})\prod_{\ell}p_{\theta}(\mathbf{x}^{\ell}\mid\mathbf{x}_{t_{i}},\mathbf{z})∑z​pθ​(z∣xti​​)∏ℓ​pθ​(xℓ∣xti​​,z)（Eq. 5）；z\mathbf{z}z 每 token、每层取一个专家编号，由路由器输出；干净一路的路由作为对齐目标（§3.1–3.2）。
  • 与最接近方法（VADD）的差异（Table 1，原文事实）：潜变量空间连续 Rd\mathbb{R}^{d}Rd / 全局每序列一个 vs 离散 {1,…,E}L×D\{1,\dots,E\}^{L\times D}{1,…,E}L×D / 每 token 每层一个；先验固定高斯 vs 数据依赖、可学习；后验来自额外 VAE 网络 vs 同一网络；VADD 总参数高于其活跃参数（LM1B：256.5M/139.9M），E-MoE 总参数更大但活跃参数与稠密基线持平（536.1M/139.4M，§B.3）。
  • 是否新思想：把经典”专家混合即混合分布”的密度建模想法迁移到掩码扩散的反向过程，并补上相应的变分目标与路由对齐训练法，属于”新组合 + 新推导”；”首次提出”无法从本文确认（见下方边界说明）。
  • 对应问题：因子化误差（§2）——对路由（作为潜变量）积分/采样使同一步的 token 通过共享的随机路由配置产生依赖。
  • 证据：采样期把路由改为贪心（τs→0\tau_{s}\to 0τs​→0、权重不变）后生成困惑度上升 1.72×（NFE=1）与 2.14×（NFE=2），向 MDLM 靠拢（§C.3.2，Table 9）；潜变量使用曲线显示路由 KL 全程稳定（§C.3.3，Fig. 9）。
  • 移除后：退化为逐 token 单专家的因子化模型（§C.3.2 论证）；Table 9 给出具体数值差。

创新点 2：混合反向过程的 NLL 上界与可解路由 KL（理论增量）。

  • 新增了什么：Proposition 3.1 给出负对数似然的上界（正文 Eq. (6)，附录 A.3 复述为 Eq. (25)）：重构项（仅对掩码位置、按 1/ti1/t_i1/ti​ 加权）加 T⋅KL(qθ(z∣xti,x0) ∥ pθ(z∣xti))T\cdot\mathrm{KL}(q_{\theta}(\mathbf{z}\mid\mathbf{x}_{t_{i}},\mathbf{x}_{0})\,\|\,p_{\theta}(\mathbf{z}\mid\mathbf{x}_{t_{i}}))T⋅KL(qθ​(z∣xti​​,x0​)∥pθ​(z∣xti​​))；当先验与后验都按逐层逐 token 条件分解时（Eq. 7），潜变量 KL 精确化为逐项分类 KL 之和（Eq. 8），可直接由两个 router 输出的分布计算。
  • 与已有方法差异：MDLM 的 ELBO 无潜变量项；VADD 的潜变量 KL 是对固定高斯先验的 KL 且需要近似后验网络；这里 KL 两侧都来自同一 router、随数据变化。
  • 证据：证明在 Appendix A.2（Lemma 1）与 A.3；Appendix A.1 给出掩码扩散 ELBO 的完整推导作为基础。
  • 边界（审稿人判断）：证明链条本身我核对了结构但未逐行复核；且该界是针对”离散精确采样”模型的，实践中的 Gumbel-Softmax 直通估计与温度退火是近似实现（§3.3），界与优化目标之间并非严格一致。

创新点 3：两遍前向的路由对齐训练流程与只走先验的采样器。

  • 新增了什么：每个训练步两次前向——第一遍（posterior）在 xti\mathbf{x}_{t_{i}}xti​​ 与 x0\mathbf{x}_{0}x0​ 的拼接输入上算后验路由并用所选专家给出 xθ\mathbf{x}_{\theta}xθ​ 的 token 分布；第二遍（prior）只在 xti\mathbf{x}_{t_{i}}xti​​ 上算先验路由；用 Eq. 9 更新（Algorithm 1）。采样时仅做一遍：在单次前向内采样先验路由并顺带得到专家输出，因此 1 NFE 仍是 1 次前向（Algorithm 2，§B“Number of function evaluations”）。
  • 与已有方法差异：VADD 也是每训练步 2 次前向、每采样步 1 次（Table 1），但第二遍对应独立识别网络；这里是共享权重的同一个网络，训练目标更”本地”。
  • 证据：采样时混合开/关的对照（Table 9）支持”随机路由”是效果来源；训练期对齐项的必要性没有被单独消融（见 §5 质疑 2）。

创新点 4（工程目标）：“不增加活跃参数”。

  • 事实核对（原文事实）：LM1B 上 E-MoE 总参数 536.1M，但每 token 仅一个专家活跃，活跃参数 139.4M，稠密 MDLM 为 139.3M，多出的 0.07M 是 router（§B.3，Table 7）；MNIST 上 E-MoE 总参数 2.49M、每位置活跃 2.18M，而 MDLM 为 2.07M（§B.2，Table 3）——MNIST 设定下活跃参数比因子化基线多约 5%，摘要中”without increasing active parameters”的表述在该设定下并不严格成立（审稿人判断）。
  • 与已有方法差异：VADD 增加训练期网络与参数；E-MoE 以总参数换活跃参数不变。

创新边界说明。 根据本文的 related work 与实验对比，只能确认作者声称的差异（相对 MDLM/VADD 的具体机制区别）；”首次提出”需要更完整的文献检索。此外，”专家混合作为混合分布”在密度估计文献中是经典思想，本文的贡献应理解为把它与掩码扩散的变分目标、路由对齐训练结合，而非该思想本身（审稿人判断）。

3. 作者如何解决？

直觉说明。 稠密因子化模型的每一层 MLP 对所有 token 共享参数；E-MoE 把每个 MLP 换成”一个路由器 + 一组专家”，token 在选择专家时会产生一个离散选择。作者的直觉是：这个”选哪个专家来解释这段噪声”的选择本身就是对数据模式的离散编码——如果让干净序列的路由作为目标、让噪声序列的路由去预测它，那么采样时每一次随机的专家选择相当于对”哪个生成模式该被使用”的一次抽样；同一步解掩码的所有 token 共享同一次抽样出的路由配置（路由在层间通过注意力影响后续所有位置），于是边缘上不再是各自独立采样的乘积。作者在 §6 的表述是”对路由求边缘把同一步解掩码的 token 耦合起来”（原文事实；其通过注意力传播的具体路径是分析者推断）。

运行流程（以论文实际设定为准）。

  1. 输入与加噪。 序列 x0\mathbf{x}_{0}x0​（LM1B 用 bert-base-uncased，L=128L{=}128L=128，K=30,522K{=}30{,}522K=30,522；MNIST 为 32×3232\times3232×32 二值图像展平成 L=1024L{=}1024L=1024，K=2K{=}2K=2；2D 玩具 L=2L{=}2L=2、每坐标 50 个离散 token），前向吸收态掩码过程 q(xt∣xs)q(\mathbf{x}_{t}\mid\mathbf{x}_{s})q(xt​∣xs​) 逐 token 独立加掩码（Eq. 1，原文事实）。时间被离散到网格 ti=i/Tt_{i}=i/Tti​=i/T（§3.1）。

4. 解决得怎么样？

4.1 实验设置

论文在三个设定上评测（§5）：(a) 2D 合成密度——8-modes 与 Swiss-roll，各 2 万训练点、L=2L{=}2L=2、每坐标 50 token，指标为”有效性”（生成的 3000 个样本中落在数据支撑集内的比例，阈值 rrr 取训练点最近邻距离的 90 分位，Eq. 39；3 seeds 均值，§B.1）；(b) Binarized-MNIST——按 VADD 的评测协议，32×3232\times3232×32 二值化、L=1024L{=}1024L=1024，指标 test BPD（对 Lemma 1 界做单次 ttt 采样的估计，Eq. 40，§B.2）；(c) LM1B 无条件文本生成——DUO 协议（Sahoo et al., 2025），L=128L{=}128L=128、1M 步、全局 batch 512（4 GPU×128），共见 65B token，指标为 GPT-2-large 判别的生成困惑度（Gen-PPL，Eq. 41）、样本熵 HHH（Eq. 42；真实 LM1B 文本为 4.32）与 MAUVE（Eq. 定义见 §B.3），每模型每 NFE 采 2000 条，p=1.0p{=}1.0p=1.0 无截断，网络 fp32、类别采样 fp64（§B.3）。

基线与公平性口径：玩具/MNIST 对比 MDLM（因子化）与 VADD（连续潜变量）；文本额外引入 SEDD、BD3-LM（不同 block 大小训练）与 AR 参考。作者声明三个模型”matched in backbone size, optimizer and training budget”（§5）；更准确的口径是”活跃参数与优化设置匹配”——LM1B 上 E-MoE 总参数 536.1M（3.85×）但活跃 139.4M≈MDLM 139.3M、训练步数/数据一致（§B.3，Table 7）。主实验回答”低 NFE 生成质量是否更好”；Table 9 消融回答”增益是否来自随机路由混合”；§C.3.3 回答”潜变量是否真被使用”；§C.1/§C.2 提供完整 NFE 扫描与样本图。

  • LM1B 少步生成（Table 4，原文事实）：NFE=1 时 E-MoE 生成困惑度 643.8，MDLM 1433.8、SEDD 1578.8、VADD 1270.8；NFE=2 时 383.7 对 997.5 / 1059.3 / 763.2。与 MDLM 的比值 2.23×（NFE=1）与 2.60×（NFE=2），与 SEDD 为 2.45×/2.76×，与 VADD 为 1.97×/1.99×——论文正文表述为”2–2.6× relative to every baseline”（§5.3），与 VADD 的实际比值略低于 2×、与 SEDD 略高于 2.6×（审稿人判断：表述不精确，方向不受影响）。
  • 优势随 NFE 收敛（Table 4，原文事实）：NFE=16 时 146.4 对 MDLM 179.4 / VADD 168.4 / SEDD 166.7；NFE=32 时 135.1 对 148.6 / 139.6 / 136.1；但 NFE=64 时 E-MoE 128.1 已略差于 SEDD 125.6，NFE=128 时 126.3 差于 SEDD 118.5 与 VADD 118.4。论文没有回避这一点，明确说优势随步数增加而缩小（§5.3）。
  • MAUVE（Table 8，原文事实）：NFE=2 时 E-MoE 24.58%±0.62，MDLM 2.95%±0.29、VADD 3.76%±0.13；NFE=4 时 58.25% 对 17.09%/25.16%；但 NFE=64/128 时 E-MoE 88.53%/89.02% 略低于 MDLM 的 91.17%/91.29%（论文在 §C.3.1 说明”NFE≥32 后三者都到 86–92%，E-MoE 最多落后 3 个点”）。
  • 2D 玩具（Table 2，原文事实）：NFE=1 时 8-modes 有效性 E-MoE 94.4 vs VADD 91.8 vs MDLM 37.7；但 Swiss-roll 上 E-MoE 在低 NFE 反而弱于 VADD：NFE=1 为 90.3 vs 93.8、NFE=2 为 92.6 vs 95.9、NFE=8 为 96.4 vs 97.6，直到 NFE=16 才反超（98.6 vs 98.2）。论文的措辞是”consistently outperforming VADD on 8-modes and remaining competitive on Swiss-roll”（§5.1）——属于对局部不利结果的淡化表述（审稿人判断）。

  • 管线正确性自证（§B.3，原文事实）：作者复现的 MDLM/AR 官方测试困惑度为 31.90/22.83，对照公开值为 31.87/22.8——这是评分管线可信度的一个正面证据。

4.3 机制证据

需要区分”方法有效”与”为什么有效”两层：

  • 效果证据：Table 4/8/3/2 的指标对比显示 E-MoE 在低 NFE 更好；量级最大、最一致的是 LM1B 的 NFE=1–2 与 MAUVE，且同时匹配了样本熵（4.34–4.35 vs 数据 4.32），排除”以多样性换困惑度”的简单解释（§5.3，作者主张有熵数据支持）。
  • 机制证据（较强）：Table 9 在同一训练检查点上开关混合——把路由从按分布采样（τs=1\tau_{s}{=}1τs​=1）改为贪心（τs→0\tau_{s}\to 0τs​→0）后，生成困惑度从 626.1 → 1079.5（NFE=1，1.72×）、389.0 → 834.2（NFE=2，2.14×），权重不变。由于两行模型完全相同，这直接排除了”参数更多/训练更久”作为该差距的解释，把”随机路由混合”钉在因果链上（§C.3.2，原文事实 + 作者解释；审稿人判断：这是全文最强的一个机制实验）。
  • 机制证据（中等/相关性）：Fig. 9 的训练曲线显示 VADD 潜变量 KL 收敛到 0.14 nats/token、E-MoE 路由 KL 稳定在 0.65 nats/token，且 E-MoE 的重构项更低（§C.3.3）。这支持”E-MoE 的潜变量没有崩溃”，但”KL 大 = 潜变量在用”只是间接推断：KL 是优化目标中的代价项，其大小同时受对齐难度影响；论文没有给出路由熵、专家使用分布或反事实实验来进一步佐证（审稿人判断）。
  • 未能排除的替代解释：训练期路由 KL 项本身的必要性未做移除实验；”普通 MoE（有负载均衡、无路由 KL 对齐）”这一同规模对照组缺席；因此”增益具体来自对齐训练，还是仅来自 8 专家带来的更大总容量/更多随机性”只能部分归因（详见 §5 质疑 2）。

4.4 成本与适用范围

  • 参数与内存（原文事实）：LM1B：MDLM 139.3M（总/活跃相同）、VADD 256.5M 总/139.9M 活跃、E-MoE 536.1M 总/139.4M 活跃；MNIST：E-MoE 2.49M 总、2.18M 活跃，MDLM 2.07M、VADD 2.50M。活跃算力相当，但 E-MoE 需要为 8 份专家付存储与显存代价（显存或吞吐数字论文未报告）。
  • 训练成本：E-MoE 每训练步需要 2 次前向（后验+先验，Table 1），而 MDLM 为 1 次；GPU 型号、总 GPU 小时与墙钟时间均未报告（论文未报告）。
  • 推理成本：1 NFE = 1 次前向，与基线口径一致；每 token 仅一个专家活跃，算力与稠密基线相当；额外代价是路由采样本身的极少量计算与模型内存（§B“Number of function evaluations”，原文事实）。
  • 数据与依赖：全部使用公开数据（合成 2D、MNIST、LM1B）；无人工标注；生成困惑度使用 GPT-2-large 判别器（现成模型）；无闭源服务依赖（原文事实）。
  • 适用范围与遗留问题：收益集中在低 NFE（论文自限于”few-step”）；NFE 增大后退化为与基线相当（§5.3、§D）。方法依赖”噪声一路的路由能对齐干净一路的路由”——论文自己指出若路由分布崩溃或无法对齐，混合会退化为单一因子化成分（§D，作者主张）。在 LLM 规模（LLaDA-MoE 式）上的可行性未做实验，只是作为潜在影响讨论（Appendix D，论文未报告）。MNIST 上小幅度、无方差的结果提示该方法在中小规模图像离散扩散上的优势可能较弱（审稿人判断）。

5. 最容易受到审稿人质疑的地方

质疑：最接近的基线 VADD 可能没有被调到最强，”连续潜变量易崩溃”的判断建立在对单一复现配置的诊断上

  • 原文依据：作者自己的 Fig. 9/§C.3.3 显示其复现的 VADD 潜变量 KL 降到 0.14 nats/token 并停留，作者据此称”latent is close to collapse despite the annealing”；VADD 的超参按其原论文处方设置（d_z=512、KL 0→1 退火 100k 步、识别网络与骨干同规模，§B.3），但没有报告任何反崩溃变体（free bits、KL 循环退火、不同 d_z 或识别网络规模）的对照；同时 VADD 的潜变量是”每序列一个全局向量”，而 E-MoE 是”每 token 每层一个离散选择”，两者在容量与结构上并不对称（Table 1）。
  • 为什么重要：论文的核心竞争力表述是”混合路线中离散路由优于连续潜变量”；如果 VADD 的弱表现来自调参/结构瓶颈而非范式缺陷，该结论的范围就要从”连续潜变量路线”收窄到”该复现配置”。（附加事实：VADD 在 Table 4 中仍优于 MDLM，说明其潜变量并非完全被忽略——这与”崩溃”的强解读存在张力，审稿人判断。）
  • 当前能够得出的判断：在论文的复现与预算下，E-MoE 明显更强是事实；”连续潜变量方法天然更易崩溃”属未充分验证的一般性主张。作者只给了自己一侧的崩溃诊断，未给 VADD 原报告数字或更强配置。
  • 如何验证或补强：为 VADD 引入标准反崩溃机制并扫描 d_z 与先验参数化；报告其最优配置下的 LM1B 数字；或引用 VADD 原论文在其自身设置下的 LM1B 结果并说明协议差异。

质疑：与”解决因子化”的其他同类方法零定量比较，路线选择（潜变量混合）的优越性未被独立检验

  • 原文依据：§4 相关工作列出 DCD（copula）、CoDD（相关层）、ReDi（轨迹重耦合）、FLDD（可学习前向过程）等直接针对因式化误差的方法，仅以”或开销大、或需后训练微调”一句话划出范围之外，没有任何数字；实验对照只有 MDLM、SEDD、BD3-LM 与 VADD；蒸馏类方法（SDTT、DUO、DiMO、IDLM）也全部划为 out of scope（§4，作者主张）。
  • 为什么重要：论文的路线选择（复用 MoE 路由）与这些方法构成竞争关系；如果 DCD/CoDD 在小规模下能以更低总参数达到相近效果，则 E-MoE”总参数 3.85×、训练两遍前向”的代价需要重新权衡。当前读者无法判断”潜变量混合”是否优于”相关层/轨迹重耦合”。

  • 如何验证或补强：至少在 2D 玩具与 MNIST 两个低成本设定上加 DCD/CoDD 的对照实现；或在正文给出这些方法与 E-MoE 在每步开销、训练依赖（是否需要预训练模型）上的量化对照表。

6. 审稿式总评

作者发现（并由文献与自身复现佐证）掩码扩散模型反向过程的逐位置因子化在低 NFE 区间造成严重的跨位置依赖缺失，且现有连续潜变量路线（VADD）需要额外识别网络与固定先验、在其 LM1B 复现中潜变量近乎崩溃，因此提出 E-MoE：把 MoE 路由器输出的离散路由决策直接当作共享潜变量，用同一网络在噪声与干净两路上分别产生先验与后验路由，以逐层逐 token 的路由 KL 对齐二者，采样时只走噪声一路且不增加活跃参数。实验在合成 2D 密度、Binarized-MNIST 与 LM1B 上表明：低 NFE（1–2 步）生成质量显著优于 MDLM/VADD（LM1B Gen-PPL 643.8 对 1270.8/1433.8；MAUVE 24.6% 对 3.8%/3.0%），且同检查点的”关混合”消融把增益锁定在随机路由机制上；其中采样期混合的因果证据与潜变量全程序用的训练曲线较有说服力，但最接近基线 VADD 的调优公平性、训练期组件的独立消融、以及主结果的方差与统计稳定性仍缺少充分支持。本文最有价值的部分是”路由即潜变量”这一无需额外网络的非因子化构造及其可解的路由 KL 目标，最大的审稿风险是对 VADD 基线强度与训练期机制归因的质疑可能收窄其解释范围。

  • 问题定义清晰度：强 —— §1–§2 用 factorized reverse process、”rank-one 近似”、低 NFE 场景把问题界定得具体，并明确区别于蒸馏路线；VADD 被准确指认为最接近工作（Table 1 的设计对照表述清晰）。
  • 创新性证据：中 —— “路由即离散潜变量 + 路由 KL 对齐”是有辨识度的增量且实现了活跃参数不变；但该构造是经典”专家混合即混合分布”思想与扩散变分目标的组合，训练期各组件（对齐 KL、共享 router）的必要性未被独立消融证明，”首次”亦无法从本文确认。
  • 方法可信度：中 —— 理论部分（Lemma 1、Prop. 3.1、Eq. 8 的 KL 分解）结构完整、目标与采样流程自洽，实验管线经官方数字复现自证（31.90/22.83）；扣分点在记号前后矛盾（Eq. 7 与 Fig. 3/Prop. 3.1 的 q/p 互换）、A.3 内部不一致、以及精确界与 Gumbel 近似实现之间的缝隙未讨论。
  • 实验支持力度：中 —— 三个设定、多指标（Gen-PPL/熵/MAUVE/BPD/有效性）、关键消融（Table 9）与完整 NFE 扫描使主要方向可信；但 LM1B/MNIST 单次运行无方差、MNIST 边际仅 0.002 BPD、Swiss-roll 低 NFE 落后 VADD、高 NFE 略逊 SEDD，且缺同类非因子化方法的横向比较。
  • 可复现性：中 —— 超参表（Table 5–7）、数据协议、指标定义与评测细节（采样器、fp64 类别采样、2000 样本）都相当具体，且声明有复现代码；但代码在 arXiv v1 上不可达、未发现公开仓库，记号不一致与两处实验设置差异（负载均衡、温度表）增加重写的出错风险；未报告 GPU 小时与显存。
  • 综合阅读价值：高 —— 对做扩散语言模型、少步生成与 MoE 架构的读者，”把已有路由决策直接变分复用”这一构造、T⋅KLrouteT\cdot\mathbf{KL}_{\text{route}}T⋅KLroute​ 的目标形式、以及”同检查点开关混合”的消融设计都有直接参考价值；阅读时建议把 Table 4 的高 NFE 行与 Table 2 的 Swiss-roll 列一并看，以把握该方法的真实适用边界（低 NFE、高并行解掩码区间）。
