0. 一句话结论

本文解决 Delta-rule 线性注意力中持久循环状态（recurrent state）在并发服务时成为内存瓶颈、而直接低比特量化会因误差沿状态更新反复累积而严重掉点的问题，核心思路是按”误差能存多久（时间维度）”和”误差落在哪里（空间维度）”两个维度分配精度：用门控寿命加权的混合精度位分配加少量 FP16 枢轴，加上以键行读影响为权重、行/列双轴尺度联合拟合的量化器。证据链较完整（两个模型、13 个基准、消融与机制探针齐备），主要结论”在 Qwen3.8-27B 与 Kimi-Linear-48B-A3B-Instruct 上、标称 6 bit 时接近 FP32 状态精度，4 bit 时优于均匀 INT8”在论文报告范围内成立，但所有精度数字均为单次运行、无方差或置信区间，且缺少更细粒度的均匀量化与更近期的状态量化基线，因此”6 bit 与 FP32 几乎无差”的强度仍需外部复现验证。

本文发现的新现象/被忽略的问题。 作者把”误差影响”拆成两个此前没有被联合处理的性质（§1、§3、§4）：其一是时间维度，误差是递归写入的，衰减慢的单元（retention 接近 1）会让误差存活很多步；其二是空间维度，等范数的误差落在不同键行（key row）对读出的影响不同，且状态幅值在键行与值列（value column）两个轴上同时存在离群值（outlier），单轴 scale 无法同时容纳。

作者认为的原因。 直接原因是”对持久状态反复量化 → 误差递归累积”；更深一层是误差的两类非均匀性：时间上不同单元的保留门不同（ℓu=E[log⁡rt,u]\ell_u=\mathbb{E}[\log r_{t,u}]ℓu​=E[logrt,u​] 越大寿命越长），空间上不同键行的读出增益 ωi\omega_iωi​ 不同、且幅值在两个轴上同时离群。因此”统一比特 + 单轴 scale”必然在两头同时失效。

核心假设。 若把”误差幅度 × 存活时间”（Ludu(bu)L_u d_u(b_u)Lu​du​(bu​)）和”读出影响 × 幅值几何”（wiw_iwi​ 与双轴尺度）都显式建模，就能把状态量化到 6 bit 甚至 4 bit 而精度接近 FP32，并且能在 SGLang 中落地为净收益（内存与吞吐都改善）。

区分三类问题。（1）领域早已存在的一般问题：线性注意力状态在并发服务下占用大、低比特状态量化掉点（Quamba2、Q-Mamba、DAMP 都在处理类似问题；论文自己在 §6.2 承认”GDN 循环状态的量化仍较少被探索”）。（2）本文的新观察：Delta-rule 矩阵状态中”门控寿命—累积误差”的关系（ρS≈0.80\rho_S\approx0.80ρS​≈0.80）、”键行读影响”可校准且可比（同精度同 head 内最高/最低八分位读误差比 117.4（Qwen）/35.1（KDA），Appendix B.3）、以及双轴离群同时出现的几何（§4.1–4.2；其中”双轴离群”本身与 Q-Mamba 对 Mamba 状态的观察同族，不算全新）。（3）本文实际解决的具体子问题：为 Qwen3.8-27B（GDN）与 Kimi-Linear-48B-A3B（KDA）这两类模型的持久状态设计一套可校准、可离线固定、可在 SGLang 中高效执行的 4/6 bit PTQ 方案。论文没有证明”寿命是误差的唯一或首要原因”——相关性证据较强，因果解释依赖 Appendix B.1 的干预实验，但该实验只隔离了 Delta 反馈这一项机制，未逐项排除”长寿 head 恰好幅值更大/层位更敏感”等混杂。

2. 创新点是什么？

总括。 技术增量可以概括为：把混合精度 PTQ 的”重要性”度量改造为”误差幅度 × 记忆寿命”（新目标函数 + FP16 枢轴），把空间量化从单轴 scale 扩展为”键行影响加权的行/列双轴拟合”（新的重要性来源 + 新的拟合目标），并为矩阵值 Delta 状态实现融合内核与异步写回。三者都不是全新的概念（混合精度、双轴 scale、pivot 保护分别在 Quamba2、Q-Mamba、DAMP、LLM.int8 等工作中出现过），但”寿命加权目标 + 读影响加权双轴”这一组合针对 Delta-rule 状态是新的，且作者给出了较扎实的校准—干预证据。属于”已有组件面向新对象（矩阵值 Delta 状态）的新组合 + 若干新的度量设计 + 系统实现”。

3. 作者如何解决？

直觉。 权重矩阵量化一次就够了，而循环状态每生成一个 token 就被重写一次，因此量化器实际决定的是”状态轨迹”。对轨迹而言，两件事才有意义：错误能活多久（半衰期长、保留门接近 1 的单元，错误会反复被带进后续步），以及错误落在哪（同一时刻不同键行的错误对本次读出的贡献可差两个数量级）。所以策略是：把比特给”错误大且活得久”的单元，把 scale 给”幅值大且影响大”的方向，再把极少数最难量化的单元原样留在 FP16。

4. 解决得怎么样？

4.1 实验设置

  • 任务与数据集。 长生成推理七项：LiveCodeBench v6、EvalPlus、AIME 2026、MATH-500、HMMT February 2026、GPQA Diamond、IFBench，每题采样 5/5/64/4/64/8/4 个样本，T=1.0T=1.0T=1.0、top-k 20、top-p 0.95、最多生成 65536 token（§5.1）。短生成理解六项：MMLU、ARC-C、OpenBookQA、HellaSwag、WinoGrande、LAMBADA，贪心解码并评测”生成答案”而非候选似然（§5.1、Appendix E.1）。
  • 基础模型与硬件。 Qwen3.8-27B（48 个循环层 × 48 head = 2304 个分配单元）与 Kimi-Linear-48B-A3B-Instruct（20 个循环层 × 32 head，键行单元 81,920 个）；权重用 BF16 与 4-bit AWQ 两种格式；四张 NVIDIA A800、TP4，SGLang 0.5.12（§5.1、Table C1）。
  • 基线。 FP32 SSM state（SGLang 默认）作为全精度参照；对称逐行 absmax 的 INT4/6/8 均匀量化；消融中另加适配自 Q-Mamba 的 DSQ 双轴量化组件（§5.1、§5.4）。
  • 指标。 任务精度（%）与七任务平均；生成长度（千 token）；服务侧总内存、状态内存、状态更新耗时、解码吞吐（tok/s）。
  • 预算公平性。 所有量化方法在同一”标称比特预算”下比较（§5.4 明确 “All quantization methods are evaluated under the same nominal bit budget”）；但 STEPQuant 的标称预算不含 scale 元数据与 FP16 枢轴成本，实际为 6.36/4.62 bit（Qwen）、6.30/4.30 bit（KDA），论文在 Table C1 与 Appendix D 单独列出并计入账面，属于披露充分但”标称”与”实际”不同名的做法。校准数据对所有方法一致（32×2048 WikiText-2）。
  • 各实验回答什么。 主实验（Table 1–3）回答”低比特状态量化能否保住精度、能否与 W4 权重叠加”；消融（Table 4、E6）回答”空间与时间组件各自及组合的贡献、枢轴是否必要”；生成长度（Fig. 3a–b、E.4–E.5）回答”是否出现量化导致的过度思考”；效率实验（§5.6、Appendix F）回答”系统收益是否真实”；Appendix B 的机制探针回答”为什么会这样”；Appendix G 回答”与并行工作 DAMP 的相对位置”。

6. 审稿式总评

作者发现 Delta-rule 线性注意力把 KV cache 换成固定大小的循环状态后，状态在并发服务下成为新的内存瓶颈，而直接低比特量化会因为每步”更新—重量化”的递归回灌而严重掉点；因此提出 STEPQuant，用量化误差的两个维度——能存活多久（门控寿命加权的混合精度位分配 + 少量 FP16 枢轴）与落在哪里（键行读影响加权的行/列双轴 scale 拟合）——来组织 PTQ，并通过 SGLang 中融合重建/Delta 更新/读出的打包状态内核与异步写回把压缩落地为系统收益。实验在 Qwen3.8-27B 与 Kimi-Linear-48B-A3B 上、BF16 与 W4 两种权重、七个长生成推理与六个短生成任务、两种比特预算下表明：标称 6 bit 时七任务平均与 FP32 状态差 0.01/0.05 点，4 bit 时 Qwen 达 80.51%（高于均匀 INT8 的 71.86%），并且把生成长度拉回 FP32 附近、把状态内存与更新耗时分别降低 80.1%/65.6%。其中证据较强的是：误差递推的非扩张性有证明支撑、寿命—误差与行影响—读误差两条曲线都有干预实验（精确读出 oracle、单位范数注入）与全量统计（ρS\rho_SρS​ 0.8004/0.8017、同精度行影响比 117.4/35.1），系统侧的内存/吞吐数字自洽且我独立复算了其内存占用推算与跨论文归一化口径均可对上。但”6 bit 等于 FP32”仍缺少充分支持：所有精度数字单次运行、无方差，最接近的强基线（分组均匀量化、旋转类、DAMP 的受控复现）缺失，且最核心的”寿命加权”没有 Lu≡1L_u\equiv1Lu​≡1 的等预算消融来隔离。本文最有价值的部分是把”状态量化误差的时间/空间非均匀性”变成可校准、可复用的工程方案并真正在服务框架里跑通；最大的审稿风险是核心机制未被单独隔离加统计稳定性缺失，使”何时何地给比特”这一主张目前更像有强相关证据支撑的设计选择，而非已被证实的必要组件。

  • 问题定义清晰度：强。问题被拆成”状态池内存随并发增长”（§1、Fig. 1a）与”递归重量化导致掉点”（§5.2）两个可测量现象，并进一步给出时间/空间两维的可操作定义与校准量（ℓu\ell_uℓu​、ωi\omega_iωi​）。
  • 创新性证据：中。寿命加权的混合精度与双轴 scale 都能在 DAMP、Q-Mamba、KIVI 找到近亲，真正的增量是”读影响注入行尺度 + 影响加权列拟合 + 面向 Delta 状态的实现”这一组合；作者对 DAMP 的差异做了文字说明但未做受控实验，消融也没有隔离寿命权重本身。
  • 方法可信度：强。公式链条完整（Eq. 1–14、A.1 证明、C.1 闭式解），离线校准—在线确定性拟合的流程没有引入额外可学习自由度，且关键恒等式（单行扰动 → gt,i2g_{t,i}^2gt,i2​）被数值验证到 7.1×10−77.1\times10^{-7}7.1×10−7；主要弱点是 HHH、γ\gammaγ、枢轴预算等超参未披露。
  • 实验支持力度：中。覆盖两个模型、13 个基准、两种权重格式、逐组件消融、机制探针与系统级测量，广度足够；扣分在缺少统计不确定性、缺少更细粒度均匀基线与受控的 DAMP 对比，以及 4 bit 下 KDA 的掉点与 W4 下输出变长这类负面结果对结论范围的限制。
  • 可复现性：中。校准数据、候选位宽、分配求解器、解码步骤（Table C2）、存储账目（Appendix D）与 SGLang 版本都写明，代码链接给出；但 HHH 缺失、γ\gammaγ 与枢轴数量无敏感性、精度实验无重复设置，且我未核验仓库内容，独立复现存在实际风险。
  • 综合阅读价值：高。对做线性注意力/SSM 推理优化、KV cache 或状态量化、以及服务系统的人来说，本文给出的是一套”如何把误差的时空不均匀性翻译成 scale 与比特”的完整范式与可复用的校准统计，附录的机制探针设计（matched single-injection、精确读出 oracle、固定精度行的等范数注入）本身也值得借鉴；阅读时需把”精度持平”一类的结论按单次运行对待。
