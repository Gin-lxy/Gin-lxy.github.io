0. 一句话结论

InternVLA-A1.5 试图解决统一视觉-语言-动作模型（Vision-Language-Action, VLA）中「语义保持」与「动力学先验注入」相互对抗的问题：让原生 Qwen-3.5 2B 视觉语言骨干继续接受 VQA 与子任务监督，由一个 460M 的统一专家（unified expert）负责流匹配（flow matching）连续动作生成，并用 50 个可学习 foresight token 在冻结的 WAN2.2-5B 视频生成模型监督下把世界模型（world model）动力学蒸馏进策略、推理时整条视频分支丢弃。论文在六个仿真基准、真机 held-out 指令绑定与长时程 MOF 任务上报告了最好或领先的成绩，支持「设计有效」；但由于基线数字多取自既往研究、消融未隔离语义保持设计、统计信息缺失，「在所报告的设置下有明确但幅度有限的优势」这一结论成立，而「机制已被充分验证」尚不成立。

1. 论文具体想解决什么问题？

通用机器人操作策略同时需要两类能力：语言与物体语义的先验（来自预训练视觉语言模型），以及对物理动力学的直觉（来自对未来画面的预测）。前者由 VLA 模型继承，后者由 Video Action / World Action 类模型通过预测未来视觉状态获得；近年来出现一批「统一模型」尝试在一个架构里同时训练未来预测与动作生成，作者团队的上一代工作 InternVLA-A1 也在其列。论文认为，这些统一模型虽然有效，但其失效根源在于两类目标的组合方式，并列出三条具体局限（§1）。

第一，加装生成与动作等重目标后，理解组件不再参与大规模 VQA 或语言训练，预训练骨干的语义知识逐渐漂移，指令跟随能力被削弱。第二，各子模块的目标形式与尺度异构（回归未来视觉 latent、流匹配动作预测、语言建模），联合训练时互相干扰。第三，视觉预测模块通常从头训练以重建未来像素，未利用预训练视频生成模型已经具备的时空与动力学先验。作者将这三条归纳为同一矛盾：如何在不损坏语义、又不支付像素级生成全成本的前提下，把世界动力学知识注入策略。

需要区分的是：这三条属于对既有文献的归纳（论文引用 Lu et al. 2025、Liu et al. 2026、Cai et al. 2026a、Sun et al. 2026、Luo et al. 2026 等多篇统一模型工作），论文没有给出「语义漂移」的直接测量——全文没有报告联合训练前后的 VLM 理解基准对比，也没有验证漂移随训练步数的变化。本文真正落地验证的具体子问题是：把未来预测从「学生成」改成「学查询」（用少量 latent token 蒸馏冻结视频模型），并让理解、预见与动作共享 VLM 原生接口；在真机上则聚焦一个可检验的能力——组合泛化（compositional generalization）：训练只见部分（试管颜色，目标位置）指令绑定（instruction binding），测试评估被扣留的绑定，要求从语言独立接地物体与目标，而不是复现记忆中的动作轨迹（§5.1，附录 A.1）。

论文要验证的核心假设可以概括为三条：(1) 少量 latent token 足以编码动作学习所需的未来信息，因此不需要学习像素级生成；(2) 冻结的预训练视频生成模型可以作为监督者，把动力学先验经条件通路反传进策略表示；(3) 把机器人状态、控制模式、动作都纳入 VLM 原生 chat 模板并共享同一词表与下一 token 损失，可以保住预训练模型的语义与指令跟随能力。

2. 创新点是什么？

真正的技术增量有两处：其一，把未来预测重构为「查询」而非「生成」——用少量可学习 token 查询多模态上下文，其输出作为冻结预训练视频生成模型的条件，视频监督损失沿条件通路反传，从而以蒸馏方式吸收世界模型先验，不学像素生成、不把视频模型带进推理端；其二，把理解、预见与动作组装进「VLM 原生接口 + 轻量 MoT 专家」的系统：统一 token 与词表、单一交叉熵，加上共享全注意力、分离线性注意力的模态隔离，以及配套的注意力掩码与双动作接口。其余为已有组件的系统整合与数据工程。

  1. Latent-querying 式未来预测（核心）。新增 50 个可学习 foresight token 作为 latent query，其与上下文交互的输出经投影替换 WAN2.2-5B 原有的 T5 文本编码器，成为视频生成的条件；视频流匹配损失经冻结生成器反传，只更新 foresight token 与产出条件的专家上游层（§2、§3.2，论文 Fig. 4）。与最接近的已有做法（InternVLA-A1、Motus 等把未来视觉 latent 或帧直接作为回归/生成目标）的差异在于监督方式：策略学的是「如何从当前上下文读出未来」，而不是「如何画出未来」，属于新的研究思想；对应 §1 问题(3)。证据一句话：Table 8 两项消融在四个基准上一致正向，论文 Fig. 11 提供定性支持（详见 §4.3，机制解释仍有纠缠）。
  2. 语义保持的原生训练配方。第一阶段把 VQA、子任务描述、FAST 离散动作编入 Qwen 原生 chat 模板，所有目标共享同一词表与同一 next-token 交叉熵，不加辅助头、不设损失权重（§3.1，论文 Fig. 3）。论文自述其联合训练思路「in the spirit of π0.5」，差异主要在把 FAST 动作词表（2048）并入 VLM 词表——属于已有组件的新组合与工程策略；对应 §1 问题(1)。证据一句话：真机 held-out 绑定优势（§4.2）支持「有效」，但论文没有任何隔离该设计的消融（§4.3）。
  3. MoT 统一专家与注意力隔离。460M 专家与 VLM 共享全注意力层、保留独立的 Gated DeltaNet 层；训练时显式切断专家对 FAST 离散动作 token 的注意力，并把专家的位置 id 对齐到子任务 span 之后而非 FAST span 之后（§2、§3.3，论文 Fig. 5）。混合变换器（Mixture-of-Transformers, MoT）与混合注意力是已有架构，掩码与位置布局是针对「离散+连续双动作目标」的具体化设计；对应 §1 问题(2)。证据一句话：SFT 损失曲线（论文 Fig. 10，§5.3）与消融仅间接支持，未单独隔离。
  4. 数据与采样工程。六个来源（一个仿真、五个真机）共 1.2M episodes / 861.5M frames 统一到单一动作空间，加约 3M 多模态样本；两级分组采样（组内按帧数幂律，组间权重先由 Re-Mix 获得再人工微调），机器人:多模态固定 0.15:0.85（§4，论文 Fig. 6）。差异类型为工程与数据构造改进，回应机器人数据长尾与异构的一般问题。证据一句话：论文未做数据配比消融（§4.3）。

3. 作者如何解决？

核心洞察是：策略真正需要的未来信息是「任务相关的紧凑编码」，而不是像素级视频。既然已经存在强大的视频生成模型，就可以把它当作训练期的「监督者」——让少量 token 学会从当前上下文查询出能驱动该模型走向正确未来的编码，动力学先验便随梯度被搬运进策略，而推理时生成器完全不出场。配合的第二条主线是「住进 VLM 原生接口」：状态、动作、语言共享同一 token 流与损失函数，避免多目标在训练中撕扯表示。两者分别对应 §1 的问题(3)(1)，中间用 MoT 专家与注意力隔离处理问题(2)。整体架构与数据流见 图 1。

图 1（论文 Fig. 2）：这张架构图回答「一个模型如何同时理解、预见与行动」。多视角图像、指令、控制模式与离散化状态先进入预训练 VLM（Qwen-3.5 2B，按「1 层全注意力 + 3 层 Gated DeltaNet」的单元堆叠，图中标注 ×6），VLM 一侧继续输出 QA/子任务文本与 FAST 离散动作 token；右侧统一专家（460M）与 VLM 同构但隐藏维更小，二者只在共享的全注意力层交换信息、DeltaNet 层各自独立——这是「共享全局上下文、隔离模态专属处理」的关键，也是保护语言侧表示不被动作目标侵蚀的结构基础。专家序列中追加两类 token：可学习 foresight token 经 foresight reasoning 投影为冻结视频模型（WAN2.2-5B）的条件，action token 则经流匹配头解码为连续动作 chunk。

继续沿数据流走一遍。输入与统一表示：K 路观测经 Qwen3.5 视觉管线切成图像 token 块；指令为文本；控制模式 m 取 {, , } 之一，指定动作空间（或标明这是 VQA 样本）；机器人本体感受状态（proprioceptive state）q_t（维数 D≤32）按维做 256 档均匀分箱（uniform binning，区间 [-1,1]）转成离散 token；动作 chunk a_{t:t+H} 经 FAST tokenizer 压成短 token 序列，动作词表 2048 直接追加进原词表，与语言共享 embedding 与输出投影。这一步全部由固定管线执行，模型不参与——设计意图是让输入保持预训练 VLM 的「母语」格式。

第一阶段（VLM transferring）：VQA 样本与机器人样本共用一套 chat 模板（论文 Fig. 3），差别只在控制模式字段与标签内容：机器人样本的标签是「子任务描述 + FAST 动作 token 段」，VQA 样本是答案 span（含绝对坐标）。监督目标是标签部分的 next-token 交叉熵；由于子任务文本排在动作 token 之前，自回归分解让动作以预测出的子任务为条件——即先说要做什么，再给动作。这一阶段只训练 VLM，论文把其作用表述为「把 VLM 变成 VLA 执行器，同时保留推理与指令跟随能力」，并称离散动作目标提供加速收敛的 action-aware 信号（属作者主张，无单独消融，见 §4.3）。训练规模 300K 步、batch 1024（§3.4，Table 1）。

第二阶段（foresight 与动作生成）：引入统一专家，并以 MoT 方式与 VLM 联合训练。Foresight 的机制见图 2：50 个可学习 foresight token（Q^f）插入专家序列，与视觉语言上下文交互后取其在 foresight 位置上的输出 Z_t^f，经投影 P_WAN 得到条件 C_t^f；C_t^f 不是喂给策略网络的，而是替换 WAN2.2-5B 扩散 Transformer 的 T5 文本编码器，走其原生 cross-attention 层充当「未来生成」的条件。监督信号来自对每条动作 chunk 对应的未来片段（均匀采样 N=4 帧）的流匹配视频损失。

图 2（论文 Fig. 4）：这张图的关键在梯度路径。当前帧与未来帧拼接的视频片段经 3D-VAE 编码为干净 latent，加噪后在冻结的 Video DiT 中被要求预测速度场，而条件输入 C_t^f 来自统一专家的 foresight token。由于生成器参数冻结，监督信号沿条件通路反向传播，只更新 foresight token 与产出 C_t^f 的专家层——视频模型因此只是训练期的「教师」：它逼着 token 从当前上下文里读出「能驱动世界模型走向正确未来」的编码，这些编码随后又被动作生成复用。推理时生成器与其条件投影一并丢弃。

视频监督损失写作如下，其中 u 是冻结的 WAN 去噪 Transformer，x_s=(1−s)x_0+s x_1 是噪声 latent 与干净 latent 的插值，v_s=x_1−x_0 是目标速度：

Lvideo=Ex0,x1,Ctf,s∥u ⁣(xs,Ctf,s)−vs∥2 \mathcal{L}_{\mathrm{video}}=\mathbb{E}_{x_{0},x_{1},C_{t}^{f},s}\left\|u\!\left(x_{s},C_{t}^{f},s\right)-v_{s}\right\|^{2} Lvideo​=Ex0​,x1​,Ctf​,s​​u(xs​,Ctf​,s)−vs​​2

动作生成：与 foresight 并行，专家用流匹配生成连续动作 chunk：从高斯噪声 ε 与真值 a 做插值 a^τ=(1−τ)ε+τa（τ 采自 Beta(1.5,1.0)），网络学习速度场以回归目标速度 a−ε；推理时从纯噪声出发做欧拉积分（Euler integration）得到最终 chunk。第一阶段保留：子任务与 FAST token 的交叉熵仍参与训练，为子任务预测保底；第二阶段总损失由三部分加权组成（α=1，β=10）：

Lstage2=Lstage1+α Lvideo+β Laction,α=1, β=10 \mathcal{L}_{\mathrm{stage2}}=\mathcal{L}_{\mathrm{stage1}}+\alpha\,\mathcal{L}_{\mathrm{video}}+\beta\,\mathcal{L}_{\mathrm{action}},\quad \alpha=1,\ \beta=10 Lstage2​=Lstage1​+αLvideo​+βLaction​,α=1, β=10

注意力掩码是让「离散与连续双动作目标」互不污染的关键，布局见图 3。VLM 部分沿用 Qwen3.5 因果掩码；专家部分把 foresight token 与噪声动作 embedding 分成 token 组，组间因果（foresight 看 VLM 上下文，动作额外看 foresight），组内双向（允许整条动作 chunk 并行去噪，匹配流匹配的非自回归性质）。训练时显式切断专家到 FAST 动作 token 的注意力：既防止连续动作生成器直接「抄」离散动作标签，也避免两条动作分支的梯度互相干扰；位置 id 则假装 FAST span 不存在，让训练与推理（推理不解码 FAST）的位次一致。

图 3（论文 Fig. 5）：两张掩码矩阵对照训练与推理。左图（训练）中斜纹区域是专家→FAST token 的注意力切断处——「模型决定」的部分（子任务文本、foresight 编码、连续动作）与「防泄漏的固定约束」在此交汇；右图（推理）显示 FAST token 整列消失，其余可见性布局不变，因此推理可以复用 VLM 上下文的 KV cache，流匹配去噪的每一步只需重算与噪声相关的部分。能读到这张图，就理解了该架构为什么在训练时能同时保留语言监督、又不让动作分支走捷径。

后训练与数据：后训练沿用第二阶段配方，可选保留视频分支在下游示范上微调 foresight token（§3）。数据侧见图 4：机器人语料由六源构成，帧数从 396M（InternData-A1）到 5.4M（RoboMind 1.0）跨一个数量级以上，直接按帧比例采样会让大源统治 batch；作者的做法是两级分组采样——组内按帧数的幂律（γ 可调），组间权重先由 Re-Mix 计算再人工微调，刻意上采样 DROID、Galaxea、RoboMind 1.0 这类小体量真机源（如帧占比 3.2% 的 DROID 权重给到 0.15），并下压最大的合成源；全部与约 3M 多模态样本按 0.15:0.85 混合。统一动作空间沿用 InternVLA-A1 的定义，各形态的槽位填充到共享布局，使所有本体共用一个动作头。

图 4（论文 Fig. 6）：展示训练数据的组成与配比。机器人侧共 1.2M episodes / 861.5M frames，仿真与真机按帧数大致对半（46%:54%），但采样权重把有效混合推向真机小源；每张卡片给出 episode、帧数与权重，可以核对「权重 ≠ 帧占比」这一设计——这正是两级采样策略想表达的数据工程。多模态侧约 3M 样本分四类：General QA 637K 维持通用多模态能力，Box QA 879K（指称检测）、Point QA 832K（自由空间与物体点定位）、Trajectory QA 684K（末端路点预测）负责机器人取向的空间接地，全部用统一 QA 格式与绝对图像坐标，因此和机器人子任务、FAST 目标共用同一个下一 token 目标。

推理阶段的变化：部署时只保留 VLM 与统一专家——视频分支、条件投影、FAST 解码全部不需要；专家复用 VLM 的 KV cache，通过固定步数的欧拉积分输出 50 步动作 chunk，闭环执行。论文报告单次推理步骤（生成一条 chunk）在单张 RTX 5090 上约 0.1 秒（静态图执行 + SDPA + flash linear attention 库，§5.1）。

4. 解决得怎么样？

4.1 实验设置

仿真侧在六个基准上评测：LIBERO（7 自由度单臂，四个套件 Spatial/Object/Goal/Long，每套件 500 次 rollout）、LIBERO-Plus（在 LIBERO 检查点上零样本评估，测视角/语言/布局等扰动下的鲁棒性）、RoboTwin 2.0（50 个双臂任务，clean 与域随机化两档，fine-tune 用 27,500 条示范、执行动作 chunk 18、24 卡 100K 步，评测共 10,000 次 rollout）、DOMINO（动态操作，零样本与微调两档、3,500 次 rollout，指标 SR 与 Manipulation Score）、EBench（Isaac Sim 上的室内移动操作；本文只用 100K 梯度步，少于基线的标准训练量）、SimplerEnv（WidowX 真机到仿真，视觉匹配成功率）。所有微调从同一预训练检查点出发、遵循各基准的标准协议与数据格式（§5.2，附录 A.2）。基线以 π0.5 为主（每个基准都有可比数字），另引用各基准已发表数字（InternVLA-A1、Motus、LingBot-VA、Fast-WAM、Qwen-VLA、Xiaomi-Robotics-0、GR00T-N1.5/1.7、OpenVLA-OFT、EO-1 等）。

真机侧四个任务：Sort Tubes、Insert Tubes、Move Tubes 三个指令跟随任务采用 held-out 绑定设计（训练只见部分「颜色×目标」组合，测试只评被扣留组合，每绑定每设定 15 或 16 次试验），MOF 是 13 个子步骤的金属有机框架配制流程（20 次试验，随机初始摆放）。对比方法 π0.5 与 Motus，所有方法在同一批示范上微调、同一协议评测，单卡 RTX 5090 运行（§5.1，附录 A.1）。指标为主成功率（success rate, SR）（%），DOMINO 另有 MS、EBench 另有连续进度 Score。消融（Table 8）回答 foresight 组件贡献；训练效率（论文 Fig. 10）比较同设定下 60K 步 SFT 损失；附录回答任务与基准细节。

公平性层面的已知差异：真机对比做到了同示范、同协议；仿真表里的基线数字部分「compiled from prior studies」（Table 2 题注原文），即并非全部在同一协议下重跑；EBench 上本文微调步数少于比较对象（作者称这体现其收敛更快）。

4.2 关键结果

仿真（均为主指标，§5.2）：LIBERO 平均 98.9（Table 5），高于 Xiaomi-Robotics-0 的 98.7 与 π0.5 的 96.9；论文称「每个套件排名前二」，但严格按表格数值核对，Spatial 套件上 π0.5 与 Xiaomi-Robotics-0 同为 98.8、高于本文的 98.6，该表述只有在把两个 98.8 视为同一档时才成立；RoboTwin 2.0 平均 93.2（clean 93.3 / randomized 93.0，Table 3），高于 LingBot-VA 的 92.2、Fast-WAM 的 91.8 与 π0.5 的 79.8；LIBERO-Plus 零样本总分 84.8（Table 6），高于 π0.5 的 84.4，并在 camera（83.1 vs 78.4）、background（98.2 vs 94.1）、noise（95.6 vs 89.0）等扰动项领先；SimplerEnv 平均 80.8（Table 2），高于 π0.5 的 57.1 与次优 Xiaomi-Robotics-0 的 79.2；DOMINO 零样本 SR 27.7（Table 4），高于最佳基线 Qwen-VLA-Instruct 的 26.6，微调后 29.3；EBench Test SR 35.2（Table 7），高于 LingBot-VA 的 30.9。需要注意的负面/边界结果：LIBERO-Plus 的 Robot 扰动子集只有 55.1，明显低于 π0.5 的 73.6；LIBERO 对第二名的优势仅 0.2 点、RoboTwin 与 DOMINO 零样本的优势分别约 1.0 与 1.1 点；SimplerEnv 单项中 Stack Green Block 的 69.5 低于 EO-1 的 81.8；EBench Val-Train 的 Score 54.1 低于 LingBot-VA 的 55.9；所有仿真结果均未报告方差或置信区间。

真机总体结果（§5.1，论文 Fig. 8）：MOF 上 76.4%（π0.5 29.3%，Motus 在 20 次试验中无一成功，记 0.0）；Insert Tubes 72.5% vs π0.5 51.7%（+20.8）；Move Tubes 80.5% vs 72.7%（+7.8）；Sort Tubes 75.9% vs π0.5 77.8%——是唯一总体落后的任务。作者解释：Sort Tubes 接近普通抓放，π0.5 本就强；Insert/Move 需要插入精确孔位，差距才显现（§5.1）。总体对比见 图 5。

图 5（论文 Fig. 8）：四个真机任务、三个方法的总体成功率。读这张图要看到任务难度梯度上的分化：接近普通抓放的 Sort Tubes 上 π0.5 反而略高，说明本文模型并非在所有操作技能上更强；而在需要精确插入的 Insert/Move Tubes 与 13 步长时程 MOF 上差距急剧拉开——尤其 Motus 在 MOF 上为 0，反映出「无子任务结构的世界动作模型」在长流程跟踪上的困难。这一模式与论文的核心主张一致，但每条件试验次数为 15–20 次，读者应把它读作「方向明确」而非「估计精确」的证据。

本文「组合泛化」的主张落在 held-out 绑定这一主战场上（图 6）：Sort Tubes 的被扣留绑定 65.0% vs π0.5 63.6%、Insert Tubes 60.0% vs 56.7%、Move Tubes 83.3% vs 66.7%，三项全部领先；这也把 Sort Tubes 的总体落后放回语境——差距主要出现在见过的绑定上（83.0% vs 86.0%），而任务真正要考察的被扣留绑定上本文模型保持领先（§5.1）。论文还提醒，个别方法的 OOD 数字反而高于其 seen（如 Motus 在 Insert、Move 上），因为各目标的物理难度不同，seen→OOD 的落差不能单独解读为语言接地能力的下降。

图 6（论文 Fig. 9）：每个指令跟随任务拆成「训练见过的绑定」与「held-out 绑定」（虚线边框为 OOD）两组柱。它让「优势是否来自背记示范动作」变得可检验：本文模型在被扣留绑定上三项全部领先，且整体上 OOD 柱与 seen 柱之间的落差在两个方法上呈现不同形态，提示绑定难度本身随目标位置变化，性能拆分读出的信息要多于一个总体数字。

真机结果的关键保留意见：每条件仅 15/16/20 次试验，且论文未报告方差、置信区间或显著性检验；MOF 的优势（76.4% vs 29.3%）幅度大、较难用噪声解释，而 Sort Tubes 与 Move Tubes 这类小差距则以点估计呈现。

4.3 机制证据

论文对 foresight 机制的报告是移除式消融（Table 8，同一两阶段预训练设置下）：去掉视频监督损失后，LIBERO 97.9（−1.0）、LIBERO-Plus 78.0（−6.8）、RoboTwin 91.1（−2.1）、DOMINO 25.3（−2.4）；去掉 foresight token 后为 98.6（−0.3）、77.9（−6.9）、90.2（−3.0）、23.8（−3.9）。方向一致且零样本基准上落差更大，这支持「这个组件有用」，但存在两点无法排除的替代解释：其一，两个消融行彼此纠缠——删除 foresight token 后视频损失已无从计算，但论文未说明该行是否同时移除了视频损失，因此无法区分两项的独立贡献；其二，没有替换实验——不换视频生成模型、不改条件注入方式、不调 token 数（50）与未来帧数（N=4）、不报告敏感性分析，就不排除「任何等量的额外辅助监督都能带来相近正则化收益」这一解释。LIBERO 上 −1.0/−0.3 的降幅也提示收益主要体现在分布偏移与动态场景。

除移除式消融之外，论文对 latent foresight 的直接展示是定性可视化：把学到的 foresight 编码作为条件去驱动冻结的 WAN 模型，检查它展开的未来帧是否合理，以确认这些编码携带了可供生成器复现未来动态的信息（见 图 7）。

图 7（论文 Fig. 11）：用学到的 foresight embedding 条件化冻结的 WAN 模型后展开的未来帧（t 到 t+4）。前两例为标准评估场景：预测与真值在机械臂精细运动（插拔、抓取）上接近，第二例还包含液面变化这类环境改变的下游效应，说明条件编码携带的不只是运动学信息；第三例为零样本场景，仍保持时间连贯。它支持「foresight token 确实编码了可供世界模型使用的未来信息」这一定性判断，但属于作者挑选的可视化示例，论文未给出任何量化指标（如条件生成与真值的视频一致性分数），不能据此推断蒸馏保真度的总体水平。

对 §2 各创新点的证据逐项核对：latent-querying 有移除消融与定性可视化，但缺替换实验与量化机制指标；语义保持配方（VQA/子任务共同训练）没有任何隔离消融，且「语义漂移」问题本身是文献归纳而非本文测量——held-out 绑定上的优势也可能来自多模态数据（InternVLA-M1 语料）、模型规模或试验的随机性；MoT 与注意力隔离未见单独消融，只能由整体结果与训练曲线（论文 Fig. 10：A1.5 的 SFT 损失曲线起始值、收敛速度与最终值均优于 π0.5 与 InternVLA-A1，同设定 60K 步 ≈1.2 epoch）间接支持，而训练损失更低不等于策略性能更好；数据配方同样没有配比消融。此外，论文在 §5 开头声称还会考察「subtask-following ability」，但 §5.3 实际只有上述消融、训练效率与世界模型利用三部分，正文没有任何子任务准确率类实验——因此「MOF 优势归因于显式子任务预测」这一解释目前缺乏直接证据。

4.4 成本与适用范围

论文报告的训练成本：预训练两阶段共 900K 步（Stage 1 为 300K、Stage 2 为 600K）、batch 1024、bfloat16、AdamW、恒定学习率 5e-5；后训练 60K 步、batch 128（§3.4，Table 1）。RoboTwin 微调为 24 卡 100K 步（附录 A.2）。预训练总 GPU 时数、卡数与总 token 数未报告；训练期还需要冻结 WAN2.2-5B（50 亿级视频扩散模型）的前向与反向条件传播，其额外算力占比未单独报告；人工标注未报告（数据全部来自公开数据集）；组间采样权重「先由 Re-Mix 计算再人工微调」，人工调整的具体过程未报告。推理侧：单步约 0.1 秒（RTX 5090，静态图 + SDPA + flash linear attention），视频分支被丢弃、无生成开销，作者称这避免了世界动作模型部署时的秒级生成成本；这里的 0.1 秒是一次完整策略推理（产出一条 50 步动作 chunk），论文未报告端到端控制频率或长任务累计时延。存储复杂度未报告。

适用范围：结论覆盖真机桌面级双臂操作（试管分拣/插入/搬运、MOF 流程）与六个仿真基准所代表的单臂、双臂、移动操作任务；对需要显式长时程想象与规划的任务未验证——作者自述两条 limitation：foresight 监督只覆盖一个动作 chunk 的短时程，不做长时程想象；视频生成器保持冻结且通用，先验上限受其预训练对具身场景的覆盖度决定。改善的是：指令绑定组合泛化（真机）与零样本分布偏移（LIBERO-Plus/DOMINO）、长时程执行（MOF）以及推理时延；未解决的是：语义漂移的定量刻画、机制归因的隔离验证、统计稳定的性能估计，以及对分布外更广义任务的扩展。

5. 最容易受到审稿人质疑的地方

质疑：语义保持设计与组合泛化之间的因果链没有隔离实验

  • 原文依据：§1 将「语义漂移」列为问题(1)，§3.1 声称维持 VQA/子任务监督可保住语义；真机 held-out 绑定的优势（§5.1，论文 Fig. 9）被用来支撑该主张；但 Table 8 的消融只围绕 foresight（video loss 与 foresight token），全文没有任何「去掉 VQA 共同训练 / 去掉子任务监督 / 去掉 FAST 离散目标」的对照，也没有预训练前后 VLM 语义基准的测量。
  • 为什么重要：这是论文第二条核心里程碑主张（「preserved semantics → compositional generalization」）的直接证据缺口；held-out 优势还可能由多模态语料、数据规模、试验噪声等替代因素解释，属于典型的「相关性当因果」风险。
  • 当前能够得出的判断：证据不足。现象（held-out 绑定领先）是原文事实，归因（源于语义保持设计）未被隔离验证；「语义漂移」本身是文献归纳，非本文测量。
  • 如何验证或补强：在相同数据、步数与算力下训练去掉 VQA/子任务/FAST 任一目标的变体并在 held-out 绑定上对比；直接测量联合训练前后 VLM 在通用 VQA 或指令基准上的变化曲线。
  • 严重程度：主要问题

质疑：foresight 消融彼此纠缠且缺替换实验，机制解释不充分

  • 原文依据：Table 8 的「w/o foresight tokens」行未说明是否同时移除视频损失，两项消融无法分离独立贡献；全文没有替换实验（更换视频生成模型、改变条件注入方式、消融 token 数 50 与未来帧数 N=4）；论文 Fig. 11 只提供作者选例的定性 rollout，无量化条件保真度指标；§5.3 正文「same pretrained model while varying the inference-time configuration」的措辞与两个实为训练期改动的消融（去除损失项、去除结构组件）自相矛盾。
  • 为什么重要：直接影响方法可信度与创新性判定——「蒸馏了世界模型动力学先验」与「任何等量辅助监督带来的正则化」两种解释在当前证据下无法区分。
  • 当前能够得出的判断：消融方向一致（组件有贡献）可以确认；机制叙述中「tokens 编码未来、动作复用该编码」的具体路径超出证据，尚未被量化验证。
  • 如何验证或补强：用等算力的自监督/辅助目标替换视频监督作为对照；把 WAN2.2 换成未预训练或更弱的生成器，验证收益确与生成器预训练质量相关；报告 foresight 条件的量化指标与 token 数/帧数的敏感性曲线。
  • 严重程度：主要问题

质疑：基线数字来源不一、统计稳定性未报告，「全面最优」的幅度缺乏支撑

  • 原文依据：Table 2 题注明言基线数字「compiled from prior studies」；多张仿真表的对照数字来自不同论文、检查点与评测脚本；真机每条件 15/16/20 次试验且无方差/置信区间/显著性检验（§5.1，附录 A.1）；LIBERO-Plus 总分仅领先 π0.5 0.4 点（Table 6）、DOMINO 零样本领先 1.1 点（Table 4）、LIBERO 领先第二名 0.2 点（Table 5）。
  • 为什么重要：影响实验公平性与结论范围。协议不可比与无统计检验叠加时，「六个基准全面最优」难以超出「在本文报告的协议下略优」的范围。
  • 当前能够得出的判断：存在混杂因素与统计不确定性；方向性结论（优势主要出现在零样本、动态与长时程设定）可信，但小差距的具体数值不可过度解读。
  • 如何验证或补强：统一代码库、统一评测协议重跑主要基线；报告多随机种子的均值与置信区间；扩大真机试验数并给出显著性检验；对 SimplerEnv 等「二手数字」基准做同协议复测。
  • 严重程度：主要问题

质疑：声称的 subtask-following 分析未落实，页面内存在引证不一致

  • 原文依据：§5 开头声明「We further examine the training efficiency and the subtask-following ability」，但 §5.3 只有 Ablation Studies、Training Efficiency 与 World Model Exploitation，全文不存在任何子任务预测准确率/进度跟随的量化实验；HTML 版 §5.2 把 RoboTwin 结果引用为 Table 4，而同一 HTML 页面中 RoboTwin 表的题注为 Table 3（PDF 版引用为 Table 3）；§5.2 称 LIBERO「每个套件排名前二」，但 Table 5 中 Spatial 套件有两家（π0.5、Xiaomi-Robotics-0，均为 98.8）高于本文的 98.6。
  • 为什么重要：影响可复现性与表述可信度；MOF 长时程优势被作者归因于「显式子任务预测」，但既然该能力未被单独考察，归因目前没有自己的数据支撑。
  • 当前能够得出的判断：属表述与文档层面的缺陷；对核心实验结果无影响，但会削弱读者对论证链条完整性的信任。
  • 如何验证或补强：补充子任务预测/执行的量化评测（如 MOF 各步骤完成率）；勘误 HTML 引证并明确消融的运行配置描述。
  • 严重程度：次要问题

质疑：成本与复现透明度不足

  • 原文依据：Stage 1+2 共 900K 步 × batch 1024（§3.4，Table 1）但预训练卡数与总 GPU 时未报告；组间采样权重「refined manually」（§4.3）无过程披露；foresight token 数 50、未来帧数 N=4 与欧拉积分步数 K 均无数值依据或敏感性分析（K 仅以符号出现，全文未给出取值）；RoboTwin 微调 24 卡（附录 A.2）而预训练算力只字未提；训练期冻结 WAN2.2-5B 的额外开销未见报告。
  • 为什么重要：影响可复现性与成本评估——外部团队无法估计复现所需算力量级，也无法判断「数据工程与人工调参」对结果的实际贡献。
  • 当前能够得出的判断：论文未报告上述信息；复现门槛可能显著高于论文呈现的直观印象。
  • 如何验证或补强：披露分布式训练配置与总 GPU 时；给出采样权重的人工调整过程或敏感性实验；报告 K、M、N 的消融与冻结视频模型的训练开销占比。
  • 严重程度：次要问题

6. 审稿式总评

作者发现统一 VLA 模型在把未来预测、动作与语言目标叠加时，容易牺牲预训练语义、让异构目标互相干扰，并且从零学像素级未来预测浪费了预训练视频生成模型已有的动力学先验；因此提出 InternVLA-A1.5，用保留原生训练目标的 Qwen-3.5 2B 骨干加 460M 统一专家承担控制，并以 50 个 foresight token 在冻结 WAN2.2-5B 的监督下把「任务相关的未来」压缩成可驱动世界模型的隐编码，推理时整条视频分支被丢弃。实验在六个仿真基准与四个真机任务上表明其在零样本泛化、held-out 指令绑定与长时程 MOF 上取得最好或领先成绩；其中真机 MOF（76.4% vs 29.3%）与 held-out 绑定的差距较大、证据相对较强，但语义保持设计与组合泛化之间的因果链、foresight 机制的替代解释排除以及统计稳定性仍缺少充分支持。本文最有价值的部分是「查询而非生成」的未来预测重构及其真机长时程验证，最大的审稿风险是核心主张缺少隔离消融与同协议基线。

  • 问题定义清晰度：中——三条 limitation 表述明确、与设计一一对应；但「语义漂移」未直接测量，声明的 subtask-following 分析未落实。
  • 创新性证据：中——latent-querying 蒸馏冻结视频模型属于新思想且消融方向一致；但 MoT、FAST、flow matching、π0.5 式联合训练均为已有组件，整体是系统层面的新组合，且语义保持主张无隔离证据。
  • 方法可信度：中——流程、超参与数据构成披露较完整，推理路径清晰；但消融纠缠、K/M/N 无敏感性分析、梯度只走条件通路的实现细节依赖代码验证。
  • 实验支持力度：中——六个仿真加四个真机任务覆盖面广、真机做到了同协议对比；但领先幅度在多数基准上很小、基线数字来源不一、无方差与显著性检验。
  • 可复现性：中——数据源、超参、预训练权重与代码地址齐备；但预训练算力、人工调权过程、部分评测脚本依赖未完全披露。
  • 综合阅读价值：高——「语义-动力学张力」的问题表述与「查询而非生成」的 latent foresight 思路对 VLA 与世界模型方向有直接参考价值，真机长时程与组合泛化实验设计（held-out 绑定有意排除捷径）值得借鉴。
