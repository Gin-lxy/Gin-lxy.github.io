0. 一句话结论

LAPA 把无动作标签视频中的帧间变化量化为离散潜在动作（latent action），先让 7B 视觉-语言模型（vision-language model，VLM）在视频上做潜在动作的行为克隆（behavior cloning），再用少量机器人轨迹把潜在动作映射到真实动作；在论文的三个真实桌面任务上，LAPA（Open-X 预训练）平均部分成功率（partial success）50.1%，高于 OpenVLA（Open-X）的 43.9%，但它在 Language Table 跨环境设置上仍大幅落后于使用真实动作标签的 ActionVLA（33.6% 对 64.8%），因此证据支持“潜在动作预训练在这套真实机器人设置上有效”，不足以支持“普遍超越动作标签预训练”的强结论。

1. 论文具体想解决什么问题？

Vision-Language-Action models（视觉-语言-动作模型，VLA）通常由视觉编码器、语言模型和动作头组成，先在机器人数据上预训练，再针对下游任务微调（fine-tuning）。当前高质量机器人数据主要靠遥操作（teleoperation）采集，每条轨迹都带末端执行器（end-effector）或关节动作标签，成本高、规模受限，因此现有 VLA 通常要在机器人数据上做大规模预训练，再针对下游任务微调；互联网视频和人类操作视频则数量充足，却没有机器人动作标签，而且人类与机器人之间存在明显的具身（embodiment）和环境差异。论文要解决的具体问题是：能否只用这类无动作标签视频预训练一个单体 VLA，使它获得可迁移的操作先验，最后仅用少量带动作标签的机器人轨迹完成适配。

已有路线各有失效条件。UniPi 用视频扩散模型生成未来帧，再用逆动力学模型（inverse dynamics model，IDM）抽取动作；它的扩散规划器在长时程任务上容易生成错误计划（论文 §4.3、论文 Fig. 17）。VPT 先用带动作标签的数据训练 IDM，再用 IDM 给无标签视频打伪动作标签；论文报告 VPT 在跨环境设置中只有很小的正迁移（LAPA 33.6% 对 VPT 18.0%，论文 Table 1、PDF p. 6），作者将其归因于 IDM 对环境的鲁棒性不足。视觉表征预训练、可供性（affordance）提取和人类到机器人的动作重定向（retargeting）则往往任务特定，或需要对齐的人类-机器人数据。这些方法共同说明：缺少动作标签时，难点不只是“没有监督信号”，而是如何定义一个既不需要机器人动作、又能跨具身（cross-embodiment）共享的中间目标。作者把现有方法的困难归因于动作标签把预训练表示绑在特定具身上，而 IDM 或视频规划器提供的中间监督又会随环境变化而失真；潜在动作则试图给出一个与具身无关的帧间变化目标。

本文的核心假设是：相邻帧之间的变化可以被量化成离散潜在动作，这种潜在动作不依赖末端位姿、关节角等动作先验，因而可能在不同具身之间共享；让 VLM 从当前观测和语言指令预测潜在动作，相当于学习“会发生什么变化”，而不是学习某一种机器人的控制命令，因此可以把视频预训练迁移到真实机器人。作者用跨环境设置中 LAPA 33.6% 对 Scratch 15.6%、VPT 18.0%，以及真实世界 Bridge 预训练中 LAPA 36.8% 对 ActionVLA 32.6%（论文 Table 1、论文 Table 2、PDF p. 6–7）作为支持。

需要区分三个层次。一般问题是 VLA 对动作标签的依赖；本文的新观察是“帧间差分的离散量化可以作为跨具身的预训练目标”；本文实际解决的子问题是“在桌面操作、少量动作标注微调的条件下，这个目标是否比现有的无标签视频预训练方法更有效”。论文并没有解决通用机器人基础模型、开放世界操作或非操作视频的迁移问题。作者进一步主张潜在动作捕捉的是环境中心的动作（物体和相机运动，论文 §5.2、论文 Fig. 6、论文 Fig. 14）；这属于作者解释，论文只给出了定性可视化，没有做因果隔离，因此“为什么有效”仍不能视为已经证明。

2. 创新点是什么？

真正的技术增量不是新的 VLM 或新的机器人数据集，而是一条把无标签视频转成离散潜在动作监督、再用它预训练单体 VLA 的训练配方。它把 GENIE 式的潜在动作量化、VLA 的行为克隆和少量真实动作微调组合在一起；下面三项分别对应“学什么中间目标”“怎么把中间目标接到机器人动作”“如何跨具身共享”。

  1. 把无监督潜在动作量化直接用作 VLA 预训练目标。 新增的是一个基于帧对的 VQ-VAE（矢量量化变分自编码器）量化器：输入当前帧和未来帧，输出 4 个离散 token（词元，默认词表 8，即 8^4 的组合空间），不需要末端位姿、关节角或动作层级先验。与 GENIE 的区别在于，GENIE 把真实动作映射到潜在空间来构建交互式世界模型，而 LAPA 从观测本身推导潜在动作，并用它为无动作视频打标签；与 VPT 的区别在于，VPT 的 IDM 仍需带动作标签的数据训练。对应的问题是动作标签稀缺；证据指向 §4.2 中 Language Table、SIMPLER 和真实世界的无标签基线对比。这是已有组件的新组合，而不是全新的网络结构。

  2. 两阶段“潜在行为克隆 + 小规模动作微调”的配方。 第二阶段让 VLM 根据当前帧和指令预测潜在动作，第三阶段丢弃潜在动作头、换一个新的动作头，用少量真实机器人动作微调；视觉编码器全程冻结，语言模型解冻。与 UniPi 的“视频扩散规划 + IDM”相比，LAPA 不生成像素级计划，而是在离散潜在动作空间里做行为克隆；与 ActionVLA 的“预训练阶段就用真实动作标签”相比，LAPA 只在最后阶段使用动作监督。对应的问题是“无标签预训练如何落到可执行动作”；证据是真实世界 Bridge 设置中 LAPA 36.8% 对 ActionVLA 32.6%、OpenVLA 30.8%，但 Language Table 跨环境设置中 LAPA 33.6% 对 ActionVLA 64.8%（论文 Table 1、论文 Table 2）。这一项更接近训练流程创新和工程实现改进。

  3. 跨具身（cross-embodiment）共享的潜在动作空间，以及解码器作为世界模型（world model）的用法。 论文用同一套量化器处理 Open-X 中不同机器人、不同场景的数据，并声称同一个潜在动作在不同具身中对应相似的运动；还把 LAPA 预测的潜在动作送入量化器解码器，生成未来帧，做闭环神经推演。与只在游戏或固定动作空间中使用潜在动作的工作相比，本文把它扩展到真实机器人连续操作和人类视频；与按具身分别建模动作空间的做法相比，它试图用一个共享离散空间吸收差异。对应的问题是跨具身和人类视频迁移；证据是论文 Fig. 6 的定性可视化、人类视频预训练 34.0% 对 OpenVLA 30.8%，以及论文 Fig. 7 的闭环推演（§4.3）。这一项有新思想成分，但机制证据主要是定性的。

3. 作者如何解决？

直觉上，如果两帧之间的差异可以用一个离散码表示，这个码就像语言中的 token：它不规定某个机器人关节该怎么动，却描述了“发生了什么变化”。LAPA 先学会这套码，再让 VLM 学会从当前画面和指令预测码，最后用少量真实动作把码翻译成机器人动作。这样，前两阶段可以吃完全没有机器人动作标签的视频，第三阶段才需要动作监督。

输入是视频片段及配对的自然语言指令。每个训练样本由当前帧 x_t、未来帧 x_{t+H} 和指令 l 组成，H 是固定窗口。机器人视频按 5Hz 采样时默认 H=3，约 0.6 秒；人类视频用 2.4 秒，因为人类动作更慢、相邻帧变化更小（论文 Appendix F）。预训练数据包括 BridgeV2 60k 条、Open-X 970k 条和 Something-Something V2 约 200k 条（论文 §4.5 正文写 220K，论文 Table 3 写 200k，二者不一致）；潜在动作量化与潜在预训练使用同一批数据（论文 §3）。整体流程如图 1 所示。

图 1（论文 Fig. 2）：LAPA 的三段式流程。先训练一个编码器-解码器：编码器读取当前帧和未来帧，把两帧的差异压成码本中的离散潜在动作；解码器只拿当前帧和该潜在动作重建未来帧。然后固定编码器，把它当作逆动力学模型，为视频中的帧对打上潜在动作标签，再让 VLM 根据当前帧和语言指令预测这些标签。最后丢弃潜在动作头，换上新动作头，在少量带真实动作的机器人轨迹上微调。整条链路的关键是：前两段完全不需要机器人动作标签，第三段才引入动作监督；潜在动作是中间语言，不是可直接执行的控制量。

第一步是潜在动作量化（latent action quantization）。作者训练一个约 300M 参数的 C-ViViT 风格编码器-解码器（论文 Appendix F）。编码器先对 x_t 和 x_{t+H} 做 patch embedding，分别经过空间 Transformer，再送入带因果位置编码的时序 Transformer，得到连续表示 e_t 和 e_{t+H}；两者的差 d_t=e_{t+H}-e_t 经过一个 CNN 变成 4 个位置，每个位置在 8 个码本（codebook）向量中做最近邻量化，得到 4 个离散 token 组成的潜在动作 z_t。训练目标是让解码器在只看 x_t 和 z_t 的条件下重建 x_{t+H}：

zt=arg⁡min⁡ck∈C∥ (et+H−et)−ck ∥22 z_t=\arg\min_{c_k\in\mathcal{C}}\left\|\,(e_{t+H}-e_t)-c_k\,\right\|_2^2 zt​=argck​∈Cmin​∥(et+H​−et​)−ck​∥22​

其中 C 是码本。为了避免 VQ-VAE 常见的码本塌缩，作者使用 NSVQ（normalized stochastic vector quantization，归一化随机矢量量化）把量化误差替换为“原误差乘以归一化噪声向量”，并采用码本替换；解码时对 x_t 的 patch embedding 做 stop-gradient（停止梯度），只让解码器通过交叉注意力读取潜在动作，以减少表征塌缩。与 GENIE 的加性嵌入不同，这里用交叉注意力让 z_t 以 x_t 为条件，作者称这样能学到更有语义的潜在动作。编码器不使用更早的历史帧，原因是计算开销，作者把它留作未来工作（论文 §3.1 脚注 1）。量化器的完整结构见图 2。

图 2（论文 Fig. 8）：潜在动作量化模型的内部结构。两帧分别经过 patch embedding 和空间 Transformer，再送入带因果位置的时序 Transformer，得到连续表示；两者之差经 CNN 与码本最近邻搜索离散化为潜在动作 token，NSVQ 在解码前注入归一化噪声以稳定训练；解码器以当前帧的 patch 表示为条件、通过交叉注意力读取潜在动作，重建未来帧。这个结构说明潜在动作不是人工定义的末端位移，而是由重建目标端到端学出的帧间变化编码；离散化则让 7B VLM 可以用分类的方式预测它。

第二步是潜在预训练（latent pretraining）。量化模型训练好后，编码器被固定，作为 IDM 为所有帧对生成潜在动作标签 z_t。VLM 使用 7B 的 Large World Model（LWM-Chat-1M）；输入是当前帧 x_t 和视频片段的语言指令，输出是 z_t 的 4 个离散 token。作者没有复用 VLM 原来的语言模型头，而是额外接一个单层 MLP 作为潜在动作头，词表大小等于码本大小 8；默认只冻结视觉编码器，解冻语言模型。训练目标本质上是潜在动作空间里的行为克隆：给定观测和指令，预测视频中实际发生的帧间变化。作者报告，对所有 LAPA 模型（BridgeV2、Open-X、人类视频），一个 epoch 就足以达到最佳性能（论文 §4.6）；这既说明潜在动作目标比较“粗”，也意味着训练成本主要花在 7B 模型的一次前向/反向传播上。

第三步是动作微调（action finetuning）。潜在动作不是末端执行器位移或关节角，不能直接驱动机器人。作者丢弃潜在动作头，换一个新的动作头，把每个动作维度按等频分箱离散化（沿用 OpenVLA、RT-2 的做法），然后冻结视觉编码器、解冻语言模型，在少量带真实动作的轨迹上微调。真实世界每个任务 150 条轨迹，共 450 条；SIMPLER 用 100 条；Language Table 用 1k 或 7k 条。真实世界微调使用 batch size 128 和图像增强（论文 Appendix C）。Language Table 还要求模型先输出语言方向（如 “move up”）再输出动作，作者称这显著提升了性能（论文 Appendix B）。这一步的输出才是可执行的 delta end-effector（末端执行器增量）动作；潜在动作只是预训练阶段的中间表示。

推理阶段有两种用法。微调后的 LAPA 直接根据当前观测和指令输出机器人动作。只经过潜在预训练的 LAPA 不能直接执行动作，但可以把预测的潜在动作送入量化模型的解码器，生成未来帧，形成“神经推演”（neural rollout）；这条路径用于论文 Fig. 7 的闭环演示，不是真实机器人控制。整个方法没有强化学习、奖励模型、工具调用或多智能体流程；量化模型和 VLM 都是离线训练的，推理时不做在线适应。模型决定的是潜在动作和机器人动作的预测；固定流程决定的是帧对采样、码本量化、伪标签生成和动作分箱。主要瓶颈是：量化模型需要按数据集训练，窗口长度和码本大小是敏感超参数，7B VLM 的实时推理延迟也没有解决（论文 §6 承认延迟问题，但未报告具体数值）。

4. 解决得怎么样？

4.1 实验设置

论文在三类环境上评估。Language Table 是 2 自由度推块模拟环境，包含 5 个子任务类别，评估 seen 和 unseen 两种条件；预训练用 181k 条模拟轨迹，跨环境设置改用 442k 条真实轨迹，微调用 1k 条（in-domain）、7k 条（cross-task）或 1k 条（cross-env），每个子任务 50 次评估，共 250 次/模型（论文 Table 1、论文 Table 3、论文 Appendix G.1）。SIMPLER 是 4 个 7 自由度 WidowX 操作任务，微调数据是作者用 BridgeV2 训练的 VLA 成功 rollout 中筛出的 100 条轨迹，每个任务评估 24 次（论文 §4.1、论文 Appendix B、论文 Table 11）。真实世界使用 7 自由度 Franka Emika Panda，三个多指令桌面任务：把物体放进水槽、用毛巾盖住物体、把物体击倒；每个任务 150 条轨迹，共 450 条微调数据，每个模型 54 次 rollout（每个任务 3 种能力 × 每种 6 次），采用部分成功（partial success）评分（论文 Appendix B）。

基线包括：Scratch（只用下游数据微调同一个 VLM，不预训练）、UniPi（视频扩散规划 + IDM）、VPT（用带动作标签数据训练 IDM，再用 IDM 给无标签视频打伪动作）、ActionVLA（预训练阶段就使用真实动作标签，和 LAPA 共用 LWM 骨干，作者称其为上界）、OpenVLA（在 970k Open-X 轨迹上预训练的开源 SOTA VLA）。除 OpenVLA 外，所有模型共用 7B LWM-Chat-1M；OpenVLA 使用 Prismatic 7B。这个差异很重要：LAPA 与 OpenVLA 的对比是系统级对比，不是同骨干对比。公平性控制方面，作者匹配训练图像分辨率、使用相同物体初始位置、尽量在同一天评估；但 OpenVLA 用 LoRA 微调到 95% 动作准确率，LAPA 全量微调语言模型；OpenVLA（Bridge）训练 30 个 epoch，ActionVLA 约 3 个 epoch 达到最佳动作 token 准确率，LAPA 只需 1 个 epoch（论文 Appendix C、论文 §4.6）。论文没有报告多种子方差或置信区间，Language Table 的 ± 是 StdErr，真实世界只有部分成功率的点估计。版本方面，v1（2024-10-15）是预印本，v2（2025-05-15）是 ICLR 2025 版本；两者主方法和主结论一致，但 v2 的论文 Table 3 把 Something-Something V2 记为 200k，v1 的表格记为 220k，而 v2 正文仍写 220K。

主实验回答三个问题：跨任务/环境/具身时 LAPA 是否有效（Q1）；多具身预训练时潜在动作是否优于真实动作（Q2）；只用人类视频能否得到可用策略（Q3）。消融实验回答模型规模、数据规模、潜在动作长度/词表、窗口大小和微调数据量的影响（论文 §5.1、论文 Appendix F）；附录给出逐任务、逐物体的详细结果和 UniPi 的失败案例。

4.2 关键结果

Language Table 上，LAPA 稳定优于无动作标签基线，但没有超过 ActionVLA。In-domain seen 设置中，LAPA 62.0%，Scratch 15.6%，VPT 44.0%，ActionVLA 77.0%；unseen 设置中 LAPA 49.6%，VPT 32.8%，ActionVLA 58.8%（论文 Table 1、PDF p. 6）。Cross-task seen 设置中 LAPA 73.2%，VPT 72.0%，ActionVLA 77.0%；但 cross-task unseen 中 LAPA 54.8% 反而低于 VPT 60.8%（论文 Table 1）。Cross-env 是差距最大的设置：LAPA seen 33.6%、unseen 29.6%，虽然高于 Scratch 的 15.6%/15.2% 和 VPT 的 18.0%/18.4%，但远低于 ActionVLA 的 64.8%/54.0%（论文 Table 1、PDF p. 6）。这组数字说明潜在动作预训练确实能在环境差异下提供正迁移，但“无标签潜在动作”并不能替代真实动作标签。

SIMPLER 上的结论类似。BridgeV2 预训练时，LAPA 成功率 57.3%，Scratch 34.4%，VPT 51.0%，ActionVLA 63.5%，OpenVLA 36.4%（论文 Table 11、PDF p. 21）；LAPA 优于所有无标签基线，但仍低于使用真实动作标签的 ActionVLA。只用 Something-Something V2 人类视频预训练时，LAPA 52.1%，VPT 45.8%，UniPi 0.7%，Scratch 34.4%；只用 10% 人类视频时 LAPA 仍有 50.0%（论文 Table 12、论文 Fig. 4(a)）。人类视频的规模消融只带来约 2 个百分点的提升，作者也承认这还不足以证明 scaling law。

真实世界桌面任务的结果是论文最强的证据。LAPA（Open-X）平均部分成功率 50.1%，OpenVLA（Open-X）43.9%，相差 6.2 个百分点；LAPA（Bridge）36.8%，OpenVLA（Bridge）30.8%，ActionVLA（Bridge）32.6%，Scratch 21.2%（论文 Table 2、PDF p. 7）。值得注意的是，LAPA（Bridge）在预训练阶段没有用任何动作标签，却略高于同骨干、使用真实动作标签的 ActionVLA；作者猜测 ActionVLA 过拟合了 BridgeV2 的 WidowX 动作空间，跨具身微调时反而不如潜在动作表示（论文 §4.4）。这个解释是作者假设，论文没有做动作分布或表征层面的验证。按任务拆开看，LAPA（Open-X）在 Knock 上 52.8% 对 OpenVLA 38.9%，在 Cover 上 51.7% 对 38.6%，但在 Pick & place 上 45.8% 对 54.2%，平均优势主要来自前两类任务（论文 Fig. 3）。LAPA（Bridge）在 Pick & place 上则是 43.1%，高于 OpenVLA（Bridge）19.4% 和 ActionVLA 22.2%，说明“LAPA 不擅长抓取”并不是所有预训练数据下都成立，而是与预训练任务分布有关。作者还报告，忽略平局时 LAPA（Open-X）对 OpenVLA（Open-X）的成对胜率为 65.4%；计入平局时为 31.5% 胜、16.7% 负、51.9% 平（论文 Appendix D、论文 Fig. 11）。真实世界的逐任务结果见图 3。

图 3（论文 Fig. 3）：真实桌面任务的按任务平均部分成功率。六个模型在 Average、Knock、Cover、Pick & place 四组柱状结果中对比；LAPA（Open-X）的平均值最高，优势主要来自 Knock 与 Cover，在 Pick & place 上低于 OpenVLA（Open-X）。图中误差条是 rollout 的 StdErr，不是跨训练随机种子的方差。读者应从中看到：总体平均的提升掩盖了明显的任务差异，抓取类任务仍是 LAPA 的弱项。

人类视频的结果更弱一些。LAPA（Human Videos）平均 34.0%，高于 OpenVLA（Bridge）30.8%，但低于 LAPA（Bridge）36.8%（论文 Table 2、论文 Fig. 4(b)）。按泛化类型拆开，LAPA（Human Videos）在 unseen objects 上 37.4%，高于 LAPA（Bridge）31.4%；在 unseen instructions 上只有 28.1%，低于 LAPA（Bridge）35.6%（论文 Table 2）。这说明人类视频带来的更多是物体层面的多样性，而不是指令语义层面的泛化。作者在 Appendix D 用词法匹配统计了预训练数据与下游任务的轨迹数量：Something-Something V2 中 Knock 约 6,655 条、Cover 约 6,824 条，而 BridgeV2 中分别只有 2 条和 898 条；Pick & place 则是 BridgeV2 10,892 条、Open-X 911,166 条、Something-Something V2 只有 3,272 条（论文 Table 4）。这正好解释了为什么人类视频模型在 Knock/Cover 上更好、在 Pick & place 上更差，也说明“人类视频优于 OpenVLA（Bridge）”的对比混合了任务分布差异。人类视频的结果见图 4。

图 4（论文 Fig. 4）：只用人类视频预训练时的结果。SIMPLER 一栏中，LAPA 高于 VPT、UniPi 和 Scratch；真实桌面一栏中，LAPA（Human Videos）高于 OpenVLA（Bridge）但低于 LAPA（Bridge）。两栏共同说明人类视频能带来正迁移，但迁移幅度和任务构成密切相关，不能简单解读为人类视频优于机器人视频；真实桌面的 3.2 个百分点差距也没有给出置信区间。

总体来看，论文的证据支持三个较窄的结论：在 Language Table 和 SIMPLER 上，LAPA 优于无动作标签基线；在真实世界 Bridge/Open-X 设置上，LAPA 的系统级平均成功率高于 OpenVLA；只用人类视频也能得到正迁移。证据不支持更宽的结论：LAPA 在 Language Table 和 SIMPLER 上都低于同骨干的 ActionVLA，在 cross-task unseen 上低于 VPT，在真实世界 Pick & place 上低于 OpenVLA（Open-X）；真实世界每个模型只有 54 次 rollout，没有方差或显著性检验。作者在 §4.6 报告 Open-X 预训练用 8 张 H100 训练 34 小时（272 H100-hours），而 OpenVLA 用 21,500 A100-hours，声称约 30–40 倍效率优势；这个比较混入了骨干差异（LWM 已有视频下一帧预测目标）、epoch 数差异（1 对 30）和批大小差异（128 对 2048），不能全部归因于潜在动作目标。

4.3 机制证据

论文的消融主要证明“规模有用”，而不是“潜在动作这一设计为什么有用”。模型规模从约 30M 增到 300M、数据比例从 10% 增到 100%、潜在动作序列长度从 1 增到 46、词表从 2 增到 38 时，SIMPLER 成功率总体上升（论文 Fig. 5、PDF p. 9）；默认配置是 8^4，即词表 8、序列长度 4（论文 §5.1）。窗口大小在合理范围内比较稳健，窗口过大时性能下降，作者归因于 300M 量化模型难以建模过大的视觉变化（论文 Appendix F、论文 Fig. 15(a)）。微调数据量从少到多时，LAPA 始终高于 Scratch（论文 Fig. 15(b)）。这些结果说明方法可以随规模扩展，但没有隔离“离散潜在动作”相对于其他预训练目标的优势。

潜在动作的语义分析是定性的。Language Table 中，不同潜在动作对应不同方向的移动，且在真实 2D 动作空间中聚类良好（论文 Fig. 12、论文 Fig. 13）；Open-X 多具身数据中，同一个潜在动作在不同机器人/场景下重建出相似的运动趋势（论文 Fig. 6）；人类视频中，潜在动作还会编码相机运动（论文 Fig. 14）。这些观察支持“潜在动作是共享运动抽象”的解释，但没有给出跨具身一致性的定量指标，也没有证明这种一致性是下游迁移的原因。图 5 展示了其中最关键的一组可视化。

图 5（论文 Fig. 6）：潜在动作的语义探测。以同一当前帧为条件，把不同的离散潜在动作送入量化模型解码器，重建出的未来帧呈现不同方向的运动；在 Open-X 的多具身数据上，同一潜在动作在不同机器人或场景中对应相似的运动趋势。该图支持“潜在动作是共享运动抽象”这一解释，但属于定性证据，没有给出跨具身的定量一致性指标，也没有排除“模型只是记住了场景统计”这一替代解释。

闭环推演同样是定性演示。作者只给 LAPA 当前帧和指令 “take the broccoli out of the pot”，让它连续预测潜在动作，再把潜在动作送入解码器生成后续帧；画面中机械臂接近、抓取并移开西兰花，西兰花在机械臂移开后从画面中消失（论文 Fig. 7）。这展示了潜在动作作为世界模型接口的可行性，但论文没有报告推演的成功率、与真实执行的闭环误差，也没有说明推演多长时间后会漂移。图 6 是这组演示的画面。

图 6（论文 Fig. 7）：用 LAPA 预测的潜在动作驱动解码器得到的闭环神经推演。模型只给定当前帧和 “take the broccoli out of the pot” 指令，连续预测潜在动作；解码器据此生成后续帧，画面中机械臂接近、抓取并移开西兰花。它展示的是潜在动作作为世界模型接口的可行性，论文没有报告该推演的定量成功率或与真实执行的闭环误差，因此不能把它当作物理正确性的证据。

更关键的是，论文没有报告以下消融：把交叉注意力换回 GENIE 的加性嵌入会怎样；去掉 NSVQ 或 stop-gradient 会怎样；把潜在动作目标换成像素重建、光流、DINO 特征或真实动作标签，在相同骨干、相同数据、相同计算预算下会怎样。VPT 是最接近的无标签基线，但它的 IDM 是在带动作标签的数据上训练的，所以 LAPA 与 VPT 的差异同时包含“标签来源不同”和“目标空间不同”两个因素。ActionVLA 是最接近的同骨干动作标签基线，但只在 Bridge 和 Language Table 上训练，没有 Open-X 版本。因此，论文能够支持“这套 pipeline 在若干设置下有效”，还不能支持“离散潜在动作是有效的充分原因”，也不能排除数据规模、骨干预训练和训练轮数带来的替代解释。

4.4 成本与适用范围

训练成本方面，论文报告 Open-X 预训练使用 8 张 H100、34 小时、batch size 128，共 272 H100-hours；OpenVLA 为 21,500 A100-hours、batch size 2048、30 个 epoch（论文 §4.6、论文 Appendix C）。量化模型约 300M 参数，VLM 为 7B；论文没有报告量化模型本身的训练成本、动作微调成本或推理时延。作者在 §6 承认实时推理存在延迟问题，但没有给出毫秒数或吞吐量。数据方面，真实世界微调只需 450 条带动作轨迹，SIMPLER 只需 100 条，Language Table 为 1k/7k；预训练阶段不需要机器人动作标签，但仍需要视频-语言配对，Something-Something V2 的指令文本如何构造、如何过滤，论文没有报告。外部依赖包括 LWM-Chat-1M、OpenVLA checkpoint、BridgeV2/Open-X/Something-Something V2 数据集，以及 Franka/WidowX 硬件；没有闭源 API 依赖。

适用范围是桌面操作：2 自由度推块和 7 自由度单臂抓取/放置/覆盖/击倒。论文没有验证导航、自动驾驶、灵巧操作、双臂或全身控制；作者在 §6 明确把非操作视频留作未来工作。方法在细粒度抓取上仍然弱，LAPA（Open-X）在 Pick & place 上低于 OpenVLA（Open-X），作者归因于 150 条微调轨迹不足以学习多样物体的抓取物理特性（论文 §4.4）。真实世界评估只在单一实验室、单一 Franka 上进行，54 次 rollout 的规模也不足以覆盖物体、初始位置和光照的长尾。可复现性方面，官方仓库在 2026-10-17 可访问，采用 MIT License，并提供 LAPA-7B-openx checkpoint；但论文正文和 Appendix A 没有给出量化模型与 VLA 的学习率、优化器、训练轮数、数据过滤规则，§3.1 所称的“Further model and training details are provided in Appendix A”与实际附录内容不完全对应，独立复现仍需要依赖仓库。

5. 最容易受到审稿人质疑的地方

质疑：中心主张“多具身下优于动作预训练”缺少同骨干的 ActionVLA（Open-X）对照

  • 原文依据：论文 §4.2 明确把 ActionVLA 定义为“使用真实动作标签、与 LAPA 共用 VLM 骨干”的上界，但真实世界只训练了 ActionVLA（Bridge）；论文 Table 2 中与 LAPA（Open-X）对比的是 OpenVLA（Open-X），后者使用 Prismatic 骨干、不同的预训练配方和 30 个 epoch。论文没有报告 ActionVLA（Open-X）。
  • 为什么重要：这直接关系到 Q2 和摘要中“超越使用动作标签的 SOTA VLA”的归因。LAPA（Open-X）50.1% 对 OpenVLA（Open-X）43.9% 的差距，可能来自 LWM 骨干的视频预训练、单 epoch 的粗粒度目标、微调方式（全量 LM 对 LoRA）或数据预处理，而不一定来自潜在动作目标本身。没有同骨干、同数据、同预算的 ActionVLA（Open-X），无法把“潜在动作优于动作标签”从系统级观察提升为机制结论。
  • 当前能够得出的判断：证据足以支持“LAPA 这套系统在 Open-X 数据上优于 OpenVLA 这套系统”，不足以支持“潜在动作目标在多具身设置下优于真实动作标签”。这是审稿人判断，不是论文结论。
  • 如何验证或补强：用 LWM 骨干在 Open-X 上训练 ActionVLA，匹配数据、epoch、batch size 和微调协议；同时报告 LAPA 与 ActionVLA 在相同计算预算下的收敛曲线和逐任务结果。若 ActionVLA（Open-X）仍低于 LAPA，才能较干净地支持 Q2。
  • 严重程度：主要问题

质疑：真实世界证据规模小、缺少统计稳定性，平均增益可能被任务异质性掩盖

  • 原文依据：每个模型只有 54 次真实世界 rollout，每个任务 18 次、每种能力 6 次（论文 Appendix B）；论文 Table 2 没有置信区间，论文 Fig. 3 的误差条是 rollout StdErr，不是跨训练种子或跨初始化的方差；评分使用部分成功标准，论文没有报告评分者一致性、盲评或随机化顺序。LAPA（Open-X）50.1% 对 OpenVLA（Open-X）43.9% 的 +6.2 个百分点，主要来自 Knock（52.8% 对 38.9%）和 Cover（51.7% 对 38.6%），而在 Pick & place 上低 8.4 个百分点（45.8% 对 54.2%，论文 Fig. 3）。人类视频的 34.0% 对 30.8% 也只有 3.2 个百分点，且低于 LAPA（Bridge）36.8%（论文 Table 2）。
  • 为什么重要：论文的核心卖点是“真实世界超越 OpenVLA”，但 54 次 rollout、单机器人、单实验室的设置不足以支撑“state-of-the-art”这种强表述。任务级差异说明平均成功率不是一个稳定的能力指标；如果换一组物体或初始位置，排序可能变化。没有方差也意味着无法判断 +6.2 个百分点是否超过噪声。
  • 当前能够得出的判断：方向性结果可信，但效应大小和“超越 SOTA”的结论证据不足；至少需要多 checkpoint、多种子或多实验室重复。论文没有报告这些，因此当前材料无法确认统计显著性。
  • 如何验证或补强：增加每个模型的 rollout 数量（至少数百次），报告 bootstrap 置信区间或贝叶斯区间；使用多个训练种子/checkpoint；在不同实验室、不同机械臂和不同物体集上重复；采用盲评和双人评分并报告一致性；预先注册任务和评分标准。
  • 严重程度：主要问题

质疑：机制没有被隔离，消融只证明规模有用，没有证明离散潜在动作是必要条件

  • 原文依据：论文 §3.1 声称交叉注意力“empirically leads to more semantically meaningful latent actions”，但没有给出交叉注意力对加性嵌入的消融；NSVQ、stop-gradient、码本替换也只有设计说明，没有去除实验。论文 §5.2 和 Appendix E 的潜在动作分析是定性的（论文 Fig. 6、论文 Fig. 12–14）；论文 Fig. 7 的闭环推演没有定量指标。论文没有把潜在动作目标与像素重建、光流、DINO 特征或真实动作标签在相同骨干、相同数据、相同计算预算下比较。VPT 的 IDM 需要动作标签训练，因此 LAPA 与 VPT 的差异同时包含标签来源和目标空间两个变量。
  • 为什么重要：论文的科学主张是“帧间离散潜在动作是一种好的预训练目标”，而不只是“这套工程 pipeline 能跑”。如果增益主要来自 LWM 骨干、数据规模或单 epoch 的正则化效果，那么潜在动作的理论动机就没有得到支持。缺少组件消融也使读者无法判断哪些设计是必要的、哪些只是实现细节。
  • 当前能够得出的判断：现有证据支持“方法有效”的相关性，不支持“潜在动作是原因”的因果结论。作者对“环境中心动作”的解释是合理的假设，但尚未被定量验证。
  • 如何验证或补强：做组件消融（交叉注意力 vs 加性嵌入、NSVQ vs 标准 VQ、stop-gradient 有无）；在相同骨干和数据上比较不同预训练目标（像素、光流、DINO、真实动作、随机离散标签）；用线性探针或跨具身检索定量衡量潜在动作与真实动作/物体运动的对应关系；对闭环推演报告成功率、帧级误差和长时漂移。
  • 严重程度：主要问题

质疑：人类视频的真实世界优势混合了任务分布、骨干和基线选择，不能单独归因于人类视频预训练

  • 原文依据：论文 §4.5 和论文 Fig. 4(b) 中，LAPA（Human Videos）34.0% 对 OpenVLA（Bridge）30.8%，但 LAPA（Bridge）36.8% 更高；论文 Table 4 的词法统计显示，Something-Something V2 中 Knock/Cover 轨迹远多于 BridgeV2，而 Pick & place 远少于 BridgeV2/Open-X；人类视频模型在 Knock/Cover 上更好、在 Pick & place 上更差（论文 Fig. 4(b)、论文 Table 2）。真实世界没有同数据的 VPT（Human Videos）基线，只有 SIMPLER 上有 VPT 人类视频对照（LAPA 52.1% 对 VPT 45.8%，论文 Table 12）。
  • 为什么重要：Q3 和摘要把“只用人类视频也能正迁移”作为通向 web-scale 数据的关键证据。正迁移在 SIMPLER 的同数据对照中成立，但真实世界“超过 OpenVLA（Bridge）”的对比不是同数据、同任务分布、同骨干的比较；它可能主要反映 Something-Something V2 恰好覆盖了 Knock/Cover 任务，而不是人类视频本身的优势。3.2 个百分点的差距也没有置信区间。
  • 当前能够得出的判断：人类视频的正迁移有支持，但“人类视频在真实世界优于机器人视频预训练”没有；论文的表述应限定为“在部分任务上可竞争”，而不是“优于 OpenVLA”。这是审稿人判断。
  • 如何验证或补强：在真实世界加入 VPT（Human Videos）或同骨干的人类视频基线；按任务分布匹配预训练数据（例如对 Sthv2 做任务重采样）；报告逐任务、逐物体的置信区间；在更多人类视频数据集上重复，检验任务覆盖与迁移增益的关系。
  • 严重程度：主要问题

质疑：表格与正文存在内部不一致，关键训练细节缺失，影响可复现性和基线可信度

  • 原文依据：论文 Table 1 中 ActionVLA 在 In-domain 与 Cross-task 两列的数值完全相同（77.0±3.5 / 58.8±6.6）；附录论文 Table 5 与论文 Table 7、论文 Table 6 与论文 Table 8 的 ActionVLA 逐任务数值也逐格相同（76/72/76/70/90 与 62/58/48/44/82），但两者微调数据分别为 1k 和 7k，论文没有解释这是复用同一 checkpoint、表格转录错误还是其他原因。论文 Table 1 的 VPT in-domain seen 为 44.0，而论文 Table 5 为 43.6；UniPi 为 22.0 对 22.4；ActionVLA 为 77.0 对 76.8，口径未说明。论文 §4.5 写 Something-Something V2 有 220K 视频，论文 Table 3 写 200k；v1 的表格写 220k，v2 改为 200k，但正文没有同步。论文 §1 写 “+6.22%”，实际是 6.22 个百分点。论文 §3.1 指向 Appendix A 的 “model and training details”，但 Appendix A 只给出架构和损失，没有学习率、优化器、训练轮数或数据过滤规则。
  • 为什么重要：ActionVLA 是论文最重要的同骨干上界；如果它在两个不同微调设置中使用了同一组结果，cross-task 比较就不是独立的，论文 Table 1 的“上界”也会失去部分意义。其他数字口径不一致会让读者难以判断哪张表是权威结果；训练细节缺失则削弱独立复现，尽管官方仓库和 checkpoint 可以缓解。
  • 当前能够得出的判断：这些不一致目前无法从论文正文确认原因；它们不必然推翻主结论，但会降低对实验表的信任。若 ActionVLA 行确为复制错误，应视为实验报告的主要问题；若只是复用同一 checkpoint，也应明确说明。
  • 如何验证或补强：公开逐次运行日志、checkpoint 和表格生成脚本；说明 ActionVLA 在 1k/7k 两种微调设置下是否分别训练；统一论文 Table 1 与附录表的聚合口径（均值、种子数、StdErr 来源）；在正文和表格中统一 Something-Something V2 的样本数；补充量化模型和 VLA 的优化器、学习率、训练轮数、数据过滤和指令构造细节。
  • 严重程度：次要问题

6. 审稿式总评

作者发现 VLA 的规模受限于遥操作动作标签，而互联网和人类视频虽然充足却没有动作标签，因此提出用帧间离散潜在动作作为中间监督，通过“VQ-VAE 量化—VLM 潜在行为克隆—少量动作微调”把无标签视频转成可迁移的机器人先验，并在 Language Table、SIMPLER 和真实 Franka 桌面任务上验证。实验表明，LAPA 在无动作标签基线中稳定领先，在真实世界 Open-X 设置上以 50.1% 对 43.9% 超过 OpenVLA；其中“无标签视频能带来正迁移”和“真实世界系统级平均成功率更高”证据较强，但“多具身下潜在动作优于动作标签”“人类视频优于机器人视频”“潜在动作是增益的因果原因”仍缺少充分支持。本文最有价值的部分是把潜在动作量化、VLA 预训练和少量动作微调串成一条可运行的 pipeline，并给出跨环境、跨具身和人类视频的完整实验矩阵；最大的审稿风险是缺少同骨干的 ActionVLA（Open-X）对照、真实世界评估规模过小，以及机制消融不足。
