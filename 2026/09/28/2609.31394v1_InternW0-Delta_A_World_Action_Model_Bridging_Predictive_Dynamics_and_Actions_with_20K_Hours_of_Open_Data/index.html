1. 作者发现了什么问题？

1.1 背景与任务

World Action Model（WAM，世界动作模型）是近年通用机器人操作的一条新路线：不再只学”看到什么→做什么”（VLA 范式），而是同时建模视觉世界如何演变与机器人动作如何生成（§1、§2.1）。其动机很直接：互联网规模的视频预训练里包含了大量”场景会怎样随时间变化”的视觉与时间知识，理应能帮到控制。

本文的任务是：在不牺牲推理速度的前提下，把大规模视频预训练、场景语义理解、几何与运动先验这几类互补知识整合进一个统一的动作生成框架，并给出从数据到部署的完整配方。

1.2 已有方法的问题：预测能力≠控制能力

论文明确指出的核心矛盾是（§1 第 1 段）：**”能预测未来观测”并不直接等价于”会控制”。要生成动作，模型还必须能（a）识别与任务相关的场景变化，（b）理解物体几何与运动，（c）把线索锚定到当前指令和场景上。已有 WAM 的关键设计分歧在于：动作推理是否需要先生成未来视频**——DreamZero、Motus、LingBot-VA 2.0 等把视频生成视为动作推理路径的一部分，代价是推理时要跑视频采样；Fast-WAM（Yuan et al., 2026b）则把”未来视频监督”与”动作推理路径”分离，说明视频预测可以只在训练期起作用。InternW0-Δ 选择了后一条路线并把它做完整。

作者在建模层面给出了几个具体、可验证的观察（这些是本文自己的观察，区别于”已有方法不好用”这类笼统说法）：

  1. **T5 语言条件只看懂”话”，看不懂”场景”**（§3.2）：视频专家沿用 Wan2.2 的 T5 文本通路，但 T5 只编码指令的语义内容，”同一条指令在不同视觉状态下可能对应不同动作”，它无法回答现在有哪些物体、它们在哪、任务进行到哪一步。
  2. 密集观测历史是浪费（§3.3）：短期内相近的历史对运动/交互连续性最有用，远期历史只是粗略的全局参考，因此保留完整历史帧属于不必要的计算开销。
  3. 未来信息应该只当”监督信号”，不能当”输入”（§3.4、§3.6）：如果把已实现的未来帧直接喂给动作预测分支，就泄露了推理时拿不到的信息；更好的做法是让模型从当前可获得的观测中学出面向未来的变化表示。
  4. 异构数据的维度语义不一致（§4.1）：不同机器人数据集的关节、夹爪、手部、底盘维度含义各不相同，直接把原生向量混在一起”会让同一维度在不同样本里具有不一致的物理含义”，阻碍跨本体学习。

1.3 证据

这些判断在消融实验里都有对应的量化证据（详见 §3）：单一当前观测不够用（LIBERO-Plus 上 baseline 49.59% → 加 Sparse Memory Context 53.47%）；只靠 T5 语义不足（加 Qwen3.5-2B → 60.37%，换成 RynnBrain1.1-2B → 69.08%，见 §7.4.1 与表 14）；而把未来监督完全挡在推理路径之外的前提下，Causal Imprint 相关目标累计带来约 +7.4 个百分点（69.08% → 76.45%，其中对齐项 Lalign\mathcal{L}_{\text{align}}Lalign​ 单独贡献 5.65 点）。

需要区分的是：论文没有给出”其他 WAM 失败原因”的因果分析，它给出的是一组设计选择及其消融证据；”为什么已有方法会出现这个问题”在本文里止于”未来生成与动作推理耦合会带来在线开销”这一动机层面，更深层的原因作者没有展开，报告也不替作者补充。

2. 作者如何解决？

2.1 核心思路（一句话版）

用一个”有向”的 Mixture-of-Transformers 把视频专家（负责预测性动态）和动作专家（负责动作生成）拼在一起：未来信息只作为训练监督进入视频专家，通过 Causal Imprint 与 4D 蒸馏把”面向未来”的表示压进只依赖当前观测的 token 里，再让动作专家读取这些 token；推理时不做任何未来视频采样。

这句话对应了前面三组问题：场景语义不足→加一个冻结 VLM 提供场景级 token；未来信息不能泄露→用注意力掩码切断”未来帧→动作”的任何前向通路，改用 Causal Imprint 表示来承载预测信息；异构数据难混训→统一 80 维 canonical 状态-动作表示 + 大规模清洗与 Ego2Robot 转换。

2.3 关键设计一：Causal Imprint——用未来监督”刻”出可用的预测表示

这是全文最有辨识度的机制（§3.4、§3.7，图 4）。做法是：向视频专家的自注意力层注入一组可学习的 Causal Imprint token，其空间布局与当前视频潜变量一致，只聚合 recent 与 current 的视觉特征，用来刻画运动、交互与状态转移（即”外观之外”的变化信息）。

训练时（未来视频 latent 加噪之前）构造”相邻潜变量差分”作为显式目标（式 (10)）：

  • 统一表示（§4.1，表 1）：所有动作映射到 80 维共享动作空间，每个槽位绑定固定物理量，而不是沿用原数据集的维度顺序。布局为：双臂关节 [0,7)[0,7)[0,7) 与 [40,47)[40,47)[40,47)（各 7 维）、末端位姿 [7,16)[7,16)[7,16) 与 [47,56)[47,56)[47,56)（各 9 维）、夹爪 [16,17)[16,17)[16,17) 与 [56,57)[56,57)[56,57)、灵巧手 [17,29)[17,29)[17,29) 与 [57,69)[57,69)[57,69)（各 12 维）、躯干 [29,34)[29,34)[29,34)（5 维）、独立升降 [39,40)[39,40)[39,40)、头部 [74,77)[74,77)[74,77)（3 维）、移动底盘 [77,80)[77,80)[77,80)（3 维），另有 [34,39)[34,39)[34,39)、[69,74)[69,74)[69,74) 保留槽。状态保留绝对量（关节位置、绝对 EEF 位姿——3D 位置 + 6D 连续旋转、夹爪开度或手部关节），动作区分关节空间（绝对目标位置）与任务空间（3D 平移增量 + 当前 EEF 局部坐标系的 3D 旋转向量）。
  • 机器人数据：共 15 个数据集（§4.2.1），包括 AgiBotWorld、InternData-A1、RoboMIND/2.0、RW-RL、Dexora、ABC-130K、Galaxea、RoboCOIN、RH20T、RDT-1B、RoboSet、RealSource-World、MolmoAct2-BimanualYAM、HABIT、ActionNet；另有 UMI 数据 Hy-UMI-10K 与 ego 数据 EgoDex、EgoVerse。
  • 清洗流水线（§4.2.2，固定顺序执行）：信号异常与一致性过滤（平滑轨迹偏差检测 + 状态-动作方向一致性，默认阈值 0.65）→ 静态边界裁剪 → 视觉质量过滤（黑帧、模糊、8×8 压缩块效应、时间突变）→ 动作幅度护栏（单步平移 > 0.2 m 或旋转 > 0.5 rad 的样本丢弃）→ LLM 指令正确性筛查 → VLM 视频-指令一致性检查（用夹爪开合事件把 episode 切成动作片段，逐片理解后结合全局抽帧判断行为是否匹配指令、任务是否完成）→ 人工抽检每个数据集-本体对（回放关节轨迹、叠加 EEF 位姿与录像核对坐标系与夹爪约定）。
  • Ego2Robot 转换（§4.3.2、图 6、图 7、算法 1）：腕部姿态当作 EEF，统一到相机坐标系（式 (21)）；夹爪开度由指尖几何估计——拇指尖到食指/中指尖中点的距离，5 cm 映射为全闭、7 cm 映射为全开（式 (22)），动作用相机相对位置增量 + EEF 局部旋转增量 + 下一帧绝对夹爪目标（式 (23)）；运动学对齐把”基座搜索”与”轨迹 IK”耦合起来（在 MuJoCo 中做由粗到细的整段轨迹校验，而不是只查代表帧，算法 1）；视觉对齐用 SAM3 分割人手、ProPainter 擦除，再把按原视角渲染的机器人做深度感知合成（物体掩码约束遮挡、时域迟滞抑制闪烁）。ego 轨迹整体放慢 2 倍以贴近机器人数据速度。
  • 规模（表 2、表 3）：机器人数据由 13,867.71 小时 / 1,370,003 条清洗到 11,302.20 小时 / 1,247,656 条（11.01 亿帧）；ego 数据由 4,640.04 小时保留 4,061.35 小时（4.39 亿帧）；UMI 保留 2,075.42 小时（2.24 亿帧）；Ego2Robot 转换覆盖 1,101.55 小时源视频、产出 5,633.77 robot-hours / 3,730,513 条训练片段（6.08 亿帧）。按我的核算（分析者推断，非论文原文数字）：11,302.20 + 4,061.35 + 2,075.42 + 5,633.77 ≈ 23,073 小时，与摘要”over 20K hours”一致。

2.9 训练与部署配方

  • 预训练（§5.1）：视频专家用 Wan2.2-TI2V-5B 初始化，动作专家为随机初始化的 ActionDiT；数据配比 robot 80% / Ego2Robot 10% / UMI 8% / Ego 2%（按有效起始帧数加权，并有轨迹级均衡防止长片段主导）；样本含 33 帧视频与 32 步动作块，视频:动作频率比 4，recent 帧滞后 32 个动作步，anchor 取 episode 开头。256 张 A800、bf16、batch 16×256 = 全局 4096、AdamW、lr 5×10−55\times10^{-5}5×10−5、5% warmup + cosine；先训 235K 步不用 4D 蒸馏，再续训 10K 步加上蒸馏（每个 GPU mini-batch 16 个样本里只有 1 个带缓存的 Track4World 描述子），共 245K 步、约 14 天（表 4）。
  • 后训练（§5.2、§5.3）：从同一预训练 checkpoint 出发，各 benchmark / 各真机平台只换数据适配器与动作接口（表 5：LIBERO-Plus 用 LIBERO 训练集 + min-max 归一化 + 15 epoch；RoboTwin 2.0 只用 clean 数据训练、z-score + 10 epoch；EBench/RoboDojo 各 3 视角 + 10 epoch）。真机后训练采用 training-time RTC（Black et al., 2025d）：对每个全长样本采样已提交前缀长度 d∼U{0,…,16}d\sim\mathcal{U}\{0,\dots,16\}d∼U{0,…,16}，前 ddd 步真值动作保持”干净”（flow 时间步置 0），其余加噪，损失只算有效后缀 token——让策略学会”在已知前缀条件下续写动作”。
  • 基础设施（§6）：训练侧用统一 Cache Manager 缓存冻结 VAE/VLM 输出（键 key=hash(D,e,k,v,P,M)\mathrm{key}=\mathrm{hash}(D,e,k,v,P,M)key=hash(D,e,k,v,P,M)，式 (25)，避免跨数据/编码器配置误复用），并对 30 层 MoT 做逐层编译（FlexAttention 64-token 块掩码、VLM 上下文 padding 到 640 token、必要时每 3 层做外部非重入 checkpointing）；LIBERO 与 RoboTwin 上端到端训练吞吐分别提速 3.02× / 2.11×，单独用逐层 MoT 优化也有 20–30%。部署侧：单张 RTX 5090（32 GiB）、控制频率 30 Hz、32 步预测视野、每执行 16 步发起一次后台推理请求、前缀长度按近期延迟保守估计并封顶在训练见过的 16 步。

3. 解决得怎么样？

3.1 验证范围

四个仿真基准（LIBERO-Plus 单臂、RoboTwin 2.0 与 RoboDojo 双臂、EBench 移动双臂），外加 4 个真机平台、11 个任务的真实部署（表 6）；对比对象既有 VLA（π0\pi_0π0​、π0.5\pi_{0.5}π0.5​、OpenVLA-OFT、Qwen-RobotManip-Context、X-VLA 等）也有 WAM（Fast-WAM、OpenWAM-α\alphaα、4D-WAM、ST-WAM、JEPA-WAM、Being-H0.7 等），还包括 LLM-as-policy 的 GPT-6 Astra。作者说明 baseline 数值取自各自论文或公开基准结果，采用匹配的评测协议（§7.1），未对评测环境做额外适配。

3.3 消融是否支持作者的解释

组件消融（表 14，全部从零独立训练、同数据同配方；LIBERO-Plus 总成功率）：Baseline 49.59 → +SMC 53.47 → +Qwen3.5-2B 60.37 → +RynnBrain1.1-2B 69.08 → +Causal Imprint 70.80 → +Lalign\mathcal{L}_{\text{align}}Lalign​ 76.45 → +L4D\mathcal{L}_{\text{4D}}L4D​ 78.37。两个值得注意的点：

  • 增益最大的一块来自语义表示与 Causal Imprint 的对齐项（VLM 替换 +8.71、Lalign\mathcal{L}_{\text{align}}Lalign​ +5.65），而 Causal Imprint 自身的 LΔ\mathcal{L}_\DeltaLΔ​ 只带来 +1.72。作者的解释是：LΔ\mathcal{L}_\DeltaLΔ​ 描述”未来轨迹上的时序变化”属于低层信号，Lalign\mathcal{L}_{\text{align}}Lalign​ 才对接到视频专家中间层更丰富的语义/时间表征，两者互补。这个解释与消融顺序一致，但论文没有做”Imprint 表示到底编码了什么”的表征分析（如线性探测/可视化），因此**”性能提升”有证据，”机制被解释清楚”只有间接证据**。
  • 蒸馏设计消融（表 15）：Track4World 78.37% > CoWTracker 76.15% > Pi3X 73.63%，且不做动作注入（77.78%）比注入更好，支持”蒸馏只塑形视频表示、不进推理路径”的设计取向。

数据来源消融（表 16/17）：单用真机数据预训练在 LIBERO-Plus 上把 78.59% 提到 83.73%，RoboTwin Clean2Random 从 4.38% 提到 32.34%；Ego2Robot 转换数据（81.86% / 6.66%）明显好于原始 ego 视频（80.45% / 3.13%）；UMI 数据在 RoboTwin Clean2Random 上贡献 13.90%。作者的结论是”人类数据在观测/动作空间与机器人对齐后才更有效”。作者同时明确写了适用范围：该结论仅限当前数据规模与评测场景（两个基准都以夹爪操作为主），不代表 ego 视频在更大规模或灵巧操作上无益；且只测了下游成功率、没测表示质量。这是论文里少见的、值得肯定的一句自我限定。

3.4 代价与成本

  • 训练：预训练 256×A800 跑 14 天（245K 步，全局 batch 4096），还需要额外一轮带 4D 蒸馏的续训；每个下游目标都要各自后训练（仿真 10–15 epoch，真机 10–100 epoch，见表 5、表 7）。
  • 推理：单张 RTX 5090 上控制器观测的往返时延从 780.5 ms 降到 152.8 ms（5.11×）（表 8，30 Hz 下必须 <533 ms）。表 8 的累计消融显示收益大头依次是进程隔离（2.09×）、复用与编译（3.12×）、上下文缓存（3.59×）、分组执行（4.19×）、CUDA Graph 回放（5.11×）；对应 LIBERO-Plus 成功率保持在 92.23–92.78% 区间，作者以此说明这些优化不改变模型语义。
  • 数据：20K+ 小时语料本身需要跨 15 个数据源的加载器、LLM+VLM 自动过滤与人工抽检，外加 Ego2Robot 的 IK/渲染/合成流水线；这部分工程量在论文中被视为贡献之一，但无法从外部独立验证其清洗质量。
  • 外部依赖：探索性的 GPT 引导策略（§7.5）显示，用 GPT-6 Astra 在 RoboDojo 五个任务上做执行期 EEF 纠正，平均成功率从 10.80% 提到 47.20%（”classify objects” 14%→80%，”general pickup” 36%→76%，两个零成功率任务变为 20%/40%；xhigh 推理档位优于 medium，但也只是”完成全部 5 个被评测 episode”这一量级的证据），提示当前策略在语义推理类任务上仍高度依赖外部大模型兜底；且该探索只在 seed 0 下选出的 5 个任务上进行、每行成功率对应的 episode 数论文未报告。

3.5 仍未解决的问题（论文自述 + 观察）

论文 Limitations（§8）自述两点：其一，ego 人类数据的贡献没有被系统研究（不同来源、转换策略、配比、监督形式的影响都未展开）；其二，agent-assisted control 只是初步探索，未研究 agent 调用策略、长程规划、分层决策以及与 WAM 的更紧耦合。此外可观察到的边界：RoboDojo 的 Gen-Rand/Open 类别与 EBench 绝对成功率仍低；推理时的 NNN（去噪步数）、总参数量论文未报告；LIBERO-Plus 的 “Total” 列并非七类扰动的简单平均（我核算的平均值约 93.2，论文报 92.8），应以官方指标口径理解；§4.2.1 对 InternData-A1 的描述（7,400 小时）与表 2 记录的清洗前 3,528.27 小时不一致，推测本文只用了其中一个子集，但论文未说明。

收尾：作者发现”会预测未来视频”并不等于”会控制”——已有 WAM 要么把视频生成塞进推理路径、要么缺少场景语义与几何先验，于是提出 InternW0-Δ：用有向 MoT 把预训练视频专家与动作专家耦合，以冻结 VLM 补场景语义、以训练期 4D 蒸馏注入几何运动先验、以 Causal Imprint 把未来监督”刻”成推理可用的变化表示，并用 20K+ 小时的统一表示异构语料与两阶段训练配方把这条路线做实；实验表明它在 LIBERO-Plus（92.8%）、RoboTwin 2.0 Clean2Random（71.9%）、EBench（得分 66.0）与 RoboDojo（平均 23.91%，近乎前最强 WAM 的两倍）上领先，并能在 4 个真机上把同一 checkpoint 适配到夹爪与灵巧手接口，推理时延 152.8 ms；但 ego 数据的价值、agent 辅助控制、RoboDojo 上的泛化与开放词汇任务，以及”预测表示为什么有效”的机制层面证据，仍未解决。
