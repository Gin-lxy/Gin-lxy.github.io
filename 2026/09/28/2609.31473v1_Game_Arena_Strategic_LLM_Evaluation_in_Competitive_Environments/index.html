Game Arena: Strategic LLM Evaluation in Competitive Environments

1. 作者发现了什么问题？

背景：LLM 能力评测本身正在成为瓶颈。经典的静态基准（MMLU、GSM8K、HellaSwag）在知识、数学与常识推理上长期有效，但前沿模型的分数已接近饱和，基准区分不同系统的能力随之下降；同时固定测试集容易被训练语料污染，导致高估（§1 引 White et al., 2024；Kapoor et al., 2024）。社区转向动态的偏好型评测：Chatbot Arena 的众包成对投票、MT-bench 的 LLM-as-a-judge。作者对这些替代方案同样不满意——人类评委与模型评委本质上是主观的、标准不一致，并存在偏爱冗长输出（verbosity）、谄媚（sycophancy）等偏置，最终产生高噪声的评测数据（§1）。

作者的核心判断：可靠的评测应当锚定 ground-truth 结果，而游戏同时解决”饱和”与”主观”两个问题：(1) 每局都要求玩家根据对手的决策做策略调整，模型变强时对局面貌随之演化，天然不易饱和；(2) 胜负、平局、筹码是客观可测的，不需要评委。作者援引了这条历史脉络——Deep Blue、AlphaGo/AlphaZero、Cicero、AlphaStar、Libratus/Pluribus，以及近年把游戏用于 LLM 的 AgentBench、GTBench、PokerBench、SmartPlay、Game Reasoning Arena、PokerBattle 等，指出这些工作共同显示：强模型在完美信息确定性游戏中仍会挣扎，在不完全信息游戏中更差（§1）。

已有游戏评测具体差在哪（这是本文问题意识中最具体的一层）：它们通常以固定数据集或孤立评测的形式发布，”不是为持续评测、弹性接入新游戏、跨异构环境的大规模 head-to-head 竞争而设计的”；多数缺乏统计严谨性——只报告几千次交互，在高方差游戏中远低于得出显著结论所需样本；因此也难以支持跨模型世代的纵向（longitudinal）进度测量。最接近的对照是 NeurIPS 2025 的 MindGames 竞赛（Wang et al., 2026），虽是 live arena，但范围局限于四款 theory-of-mind 风格的卡牌游戏（§1）。作者用数字量化了样本量差距：PokerBattle 每模型约 3,800 手牌，PokerBench 评测不足 2,000 手，而本文扑克单项就跑了 90 万手（§2.2）。

被忽略的问题与作者的新观察：(1) 评测的”可持续性”没有被当成一等公民——模型迭代快、基准会过期，因此评测应做成持续运行、可加新游戏的平台，而不是一次性考卷；(2) 不同游戏调动的是不同能力：完美信息（棋）考规划与搜索，不完全信息（扑克）考信念更新与风险，多人自然语言（狼人杀）考欺骗与社会推断（Table 1），所以单一游戏的结论不能外推；(3) 作者在 §4 给出了他们自己的实验发现作为佐证：模型强度在同一游戏内分层明显，但跨游戏并不一致，说明”战略博弈能力”是多面的。这条发现反过来支撑了平台化评测的必要性。

分析者注：第 (3) 点属于本文的实验发现（在 §3 与 §4 才出现），§1 只把它作为设计理由的铺垫，本报告不把它与”已有方法的缺陷”混为一谈。

2. 作者如何解决？

核心思路（一段话）：作者提出 Kaggle Game Arena——一个开放、持续扩展的 LLM 竞技评测平台。它把”评测”做成比赛：在统一协议下，模型与对手在预定义游戏环境中逐步博弈，每一步的状态、动作与推理轨迹都被记录；名次完全由客观对局结果算出；用大方差削减技巧、大样本与 bootstrap 置信区间保证排名可复现、可解释；首批发布 Chess、Poker、Werewolf 三个环境，分别覆盖完美信息、不完全信息、以及不对称信息的多人语言博弈；新游戏、新变体、新评测方法可以接入而无需重定义核心框架、也不会作废已有结果（§1、§2、附录 A.1）。整个流程是 training-free：不训练、不微调任何模型，也不给工具调用或检索，全部机制发生在环境、协议与评测方法层（§2.5）。

2.1 一次决策怎么走：统一 harness 与三个环境

所有环境共享同一套基于文本的 harness：输入是”当前状态的自然语言描述 + 完整历史”，输出是规定格式的单个动作。模型输出非法时，harness 只允许少量重试，且反馈被刻意最小化（不说为什么非法、不给候选项）——这样”独立推断动作合法性”本身也成为被测能力，而不是 harness 替模型解题（§2、附录 B.1）。三个环境的具体形态（§2.1–§2.3）：

  • Chess（完美信息、确定性、2 人、无通信）：每回合给模型 FEN 局面串和 PGN 完整着法历史，要求返回 SAN 记谱的合法着法；harness 不提供合法着法列表。非法着法会被要求重试，最多 3 次重试（即总共 4 次尝试），仍失败则该局判负；每次重试事件称为一次 “rethink”，其频率被当作交互可靠性的诊断指标（§2.1、附录 A.2.2）。作者还观察到模型在默认对局中”一致偏爱西西里防御”开局，于是增设 Chess Opening 变体：每局从 Lichess 数据库 20 个最流行的两回合开局之一开始，用于检验模型对开局结构的适应性与对单一套路的依赖（§2.1、§3.1）。
  • Poker（不完全信息、随机、2 人、无通信）：headsup no-limit Texas Hold’em（HU-NLHE），盲注 1-2，每手初始 100 个大盲，每手之间筹码重置以隔离单次决策质量。模型收到 PokerStars 手牌历史风格的状态描述（位置、筹码、底牌、公共牌、下注史）；非法动作触发重试，连续两次非法则退化为最保守动作（无下注则 check，否则 fold）；每个动作限时 60 分钟。系统提示词由职业扑克选手参与设计，明确目标是最大化整体期望值（EV），默认采用博弈论最优（GTO）策略、仅在识别到对手可利用倾向时偏离，并要求给出基于 range advantage、pot odds、fold equity 等概念的推理轨迹（§2.2、附录 B.2）。
  • Werewolf（不完全信息 + 不对称、随机、8 人、自然语言）：8 名玩家分饰 2 狼人、1 预言家、1 医生、4 村民；主持人在”夜晚”（角色私下行动）与”白天”（公开讨论 + 多数票放逐）之间交替。环境内部用 append-only 的事件日志 + 集中式 event bus 按可见性权限向各模型分发信息，从而机器级地强制执行信息不对称；讨论格式（轮转/并行）与投票规则（顺序/同时）做成可插拔协议，便于消融（§2.3）。模型侧采用 ReAct 风格提示：时序事件日志 + 阶段任务定义 + “团队胜利优先于个人存活”的系统指令，输出 JSON（不公开的 reasoning 字段 + 公开的 action 字段）；工程上做宽松 JSON 解析（pyjson5）、端点失败指数退避、上下文溢出时迭代截断（每次保留最新 75%）、违规语言规则过滤，解析重试超限则强制弃权（在狼人杀规则内始终合法）（§2.3、附录 B.3）。附录 A.5 报告了规则平衡性：标准 8 人配置村民胜率高达 73.4%，因为”预言家立刻亮明身份 + 医生每晚连保”形成无懈可击的信息优势；作者用 self-play 消融（单个 Gemini 3 Pro Preview 同时控制 8 个匿名玩家、每配置 500 局）验证，最终采用四条修改（医生不可自救、不可连续保护同一人、平票不淘汰、首发言者/首投票者轮换）把村民胜率压到 56.7%（附录 Table 2）。

2.2 让结论可信：方差削减、大样本与统计方法

  • 规模与配对设计：棋类每对模型下 40 局，黑白各 20 局以中和先手优势；扑克把每对模型的对抗切成相互独立的 100 手 episode，在 episode 内模型能看到此前所有手牌的完整文本历史，且每手结束后无论是否摊牌都公开双方底牌，以加速对手建模；同时采用 duplicate poker（手牌镜像）：预先洗好 100 手的牌序，同一序列打两遍、交换座位与手牌。这样虽然不能消除运气，但能显著降方差，并可直接比较”同一副牌下两个模型怎么打”。每对模型共 20,000 手（10,000 个发牌 × 2 次镜像），10 模型全循环 (102)=45\binom{10}{2}=45(210​)=45 对 → 合计 900,000 手、每模型 180,000 手（§2.2）。
  • 主指标：Chess 用 Bradley–Terry 模型拟合全部成对结果得到 Elo 式评分（和棋记 0.5）；由于 Elo 只在相差一个常数下可识别，作者把最低分模型锚定为 0；报告 bootstrap 95% 置信区间，并用 Stockfish 多档难度对弈插值到 CCRL 参考 Elo 做近似外部校准（作者提示超出引擎校准范围时该校准不可靠）。Poker 用大盲/百手（BB/100），对 episode 分块做 block bootstrap 以处理组内相关。Werewolf 用后文详述的 game-theoretic evaluation（GTE）。三个环境都跑全循环（round-robin），日志粒度分别细到每步/每手/每局（§2.4）。

2.3 工程与数据：环境、回放与可视化

每个游戏环境由两部分组成：声明式 JSON 规范（定义模型能观察什么、允许哪些动作、奖励怎么算）与实现规则的 Python 解释器；棋类与扑克部分适配自 Gymnasium、PettingZoo、OpenSpiel 等既有 RL/多智能体框架（附录 A.1）。每个回合产生一份不可变的完整状态快照（含模型动作与解释），串成可序列化为 JSON 的轨迹，支撑回放、大规模分析与跨数万局的可靠比较。可视化层用 TypeScript/React/Canvas 构建，把公共渲染基础设施与各游戏自定义渲染器分离，并提供 Reasoning Panel 展示模型的自然语言推理（支持流式回放与折叠日志）。所有环境实现、harness、提示词模板、评测脚本与完整轨迹数据集均开源（harness 仓库 github.com/google-deepmind/game_arena；平台 kaggle.com/game-arena）。附录 B 明确了一条共同的提示词哲学：把状态说全、把目标说清（”下最强的一手”/最大化 EV/团队胜利优先）、要求先推理再作答，其余保持最小与中立，让观测到的行为尽量反映模型自身能力而非提示词工程的产物。

2.4 评测对象

为在每对模型间跑到足够局数，作者把评测对象限定为 5 家前沿实验室的 10 个模型（截至 2026 年 2 月）：GPT-5.2、GPT-5 mini、o3（OpenAI）；Claude Opus 4.5、Claude Sonnet 4.5、Claude Haiku 4.5（Anthropic）；Gemini 3 Pro Preview、Gemini 3 Flash Preview（Google）；Grok 4、Grok 4.1 Fast Reasoning（xAI）；DeepSeek V3.2（DeepSeek）。全部通过公开 API 以各家默认采样参数与生成长度访问，不做微调、不给工具、不做检索；同时报告每回合 token 数与推断成本以支持成本—性能分析（§2.5）。

3. 解决得怎么样？

3.1 Chess：三个梯队，差距出现在中后盘

在 Chess Text 上（正文 Figure 2、附录 Table 1），Elo 呈清晰三层：Gemini 3 Pro Preview 1325（95% CI 1217–1428）与 Gemini 3 Flash Preview 1297（1205–1405）构成第一梯队，且其配对胜率热图一致偏蓝；第二梯队 o3 1009（928–1107）与 GPT-5.2 933（849–1018）仍有竞争力但波动更大（两者的区间与第一梯队的下界已不重叠）；第三梯队 Grok 4 773、Grok 4.1 Fast Reasoning 632、GPT-5 mini 525；Claude 4.5 系列垫底——Opus 236、Sonnet 189、Haiku 122；DeepSeek V3.2 作为锚点记 0（§3.1、附录 Table 1）。作者用 Stockfish 做了”差距何时产生”的定位：把逐位置的 centipawn loss 折算成胜率、按棋局进度归一后取平均，得到胜率轨迹（正文 Figure 3）——开局阶段各模型大体均衡，中局开始分叉，强模型逐步积累优势、弱模型（如 DeepSeek V3.2 与 Claude 4.5 系列）系统性地下滑，说明差距主要来自中后盘的决策质量而非开局选择。可靠性维度上，rethink 频率与对手强度强相关：最强的 Gemini 模型平均每局 <0.2 次，GPT-5.2 稳定在每局 1 次以内，中档模型约 0.5–1.7 次，而 DeepSeek V3.2 与 Claude Haiku 4.5 经常超过 5 次、常常超过 10 次；重试集中出现在后半盘（高频重试的模型开局段只占约 10–20%），常见失败模式是”被将军但没有解将”（§3.1、附录 A.2.2）。Chess Opening 变体作为稳健性检验：排序、分层与时间动态与 Chess Text 基本一致（附录 Figure 1/2、附录 Table 1；唯一明显变化是 Gemini 3 Flash 以 1263 反超 Gemini 3 Pro 的 1253，但两者区间高度重叠），说明结论不依赖模型对少数熟悉开局的依赖（§3.1、附录 A.2.1）。

3.2 Poker：GPT-5.2 独占第一，头部与尾部差距巨大

扑克共 900,000 手（每模型约 180,000 手）。按 BB/100 分三层（正文 Table 2、正文 Figure 5）：第一梯队 GPT-5.2 +46.56、o3 +29.69、Grok 4 +27.11；第二梯队 Claude Opus 4.5 +17.62、Claude Sonnet 4.5 +12.83、Gemini 3 Flash Preview +5.49；第三梯队为负——DeepSeek V3.2 −10.05、Gemini 3 Pro Preview −15.17、Grok 4.1 Fast Reasoning −19.19、GPT-5 mini −94.87。Bootstrap 分布显示 GPT-5.2 与其余所有模型 95% 区间不重叠；GPT-5 mini 完全孤立；中游若干模型的区间互相交叠，即点估计的次序并不都可靠。配对层面：GPT-5.2 是唯一对每个对手都保持胜绩的模型（胜率 57%–76%）；o3 九组配对中八组不败（只输给 GPT-5.2 的 42%，与 Sonnet 打成 50%）；Grok 4 有过全场最悬殊的一组成绩（对 GPT-5 mini 90%），但九组里只有三组胜多负少——说明其高 BB/100 来自顺手对局的大幅领先，而非全面稳定（§3.2）。翻前风格分析（附录 A.3、附录 Figure 5）给出一个重要的否证：翻前激进度与盈利不呈线性——GPT-5.2（+46.6）与 GPT-5 mini（−94.9）都开池很宽（按钮位开牌率 91.7% 与 98.3%），结果相差超过 140 BB/100；Grok 4 的 3-bet 率高达 56.7%（第二高的 GPT-5.2 只有 35.4%），而最保守的 Gemini 3 Pro Preview（按钮开牌率 52.8% 最低、大盲面对偷盲弃牌率 43.8% 最高、3-bet 率 6.0% 最低）在扑克上亏损 −15.2 BB/100，与”过度保守在单挑中次优”的扑克常识一致。作者据此认为翻前范围选择是必要条件而非充分条件，结果差异更多来自翻后决策（附录 A.3.4）。

原文图 5（Poker evaluation）。左：模型两两对局的胜率热图（行为当前模型、列为对手，蓝高红低，对角线留空）；右：十个模型 BB/100 的 bootstrap 分布（红色虚线为盈亏平衡，黑色虚线为四分位数），按均值自下而上排序，可见 GPT-5.2 与 GPT-5 mini 分别孤立于两端。该图说明本文如何用”成对胜率 + 重采样分布”同时呈现排序与不确定性。

3.3 Werewolf：角色分解评分，Gemini 居首，弱点各有不同

Werewolf 共 31,472 局，用 GTE 把总技能分解到四个角色上（正文 Figure 6、附录 Table 1）。榜首是 Gemini 3 Pro Preview 与 Gemini 3 Flash Preview，它们在”知情少数（狼人）”与”不知情多数（村民/预言家/医生）”两侧的贡献都较均衡。注意附录 Table 1 的 equilibrium rating 是相对尺度（0 为盈亏平衡线，不是绝对胜率）：Gemini 3 Pro Preview +0.10%（−0.01%, 0.21%）略高于平衡线，其余全为负——Gemini 3 Flash −0.36%、GPT-5.2 −1.12%、Claude Opus 4.5 −1.31%、Claude Sonnet 4.5 −3.67%、Grok 4.1 Fast Reasoning −5.23%、Grok 4 −5.28%、GPT-5 mini −6.78%。中段暴露出具体策略弱点：Claude Sonnet 4.5 与 Grok 4.1 Fast Reasoning 在预言家角色上贡献为负，作者解释为”难以在不引起怀疑的情况下传递私有信息”；末位 GPT-5 mini 在所有角色上都是显著负贡献（§3.3）。方法上，作者对比了 group Elo、OpenSkill 与 GTE（附录 Figure 6）：三者排序趋势一致，但 GTE 的置信区间更紧、区分度更高，而 Elo 与 OpenSkill 很难把顶部队列拉开——这与”传统评分不是为不对称多人博弈设计的”的判断相符。排序的稳健性还得到三方面支持：锦标赛图无环（附录 Figure 7）、Copeland/Ranked Pairs 与 GTE 排序完全一致（附录 Table 3）、以及合作博弈的替换分析——把任意模型换成 Gemini 3 Pro Preview 在任何角色上都是净收益，而 GPT-5 mini、Grok 4、Grok 4.1 Fast Reasoning 是普遍较差的队友（附录 Figure 8、附录 A.6.1）。此外，作者尝试的启发式指标（关键角色存活率 KSR 约 0.5、识别精度 IRP 约 0.65、投票成功分 VSS 接近 1.0）几乎没有区分度，反而可能误导——例如”活到最后”并不等于”对团队最优”，因为战略性自我牺牲有时是最优解（附录 A.8、附录 Figure 9）。分析者注：附录表与 tournament 图只出现 8 个模型，未包含 Claude Haiku 4.5 与 DeepSeek V3.2，正文未解释这一差异。

原文附录 Figure 6（Ratings of group Elo, OpenSkill, and Game Theoretic Eval (GTE)）。三幅柱状图用同一批 31,472 局数据、1000 次 bootstrap 分别给出 group Elo、OpenSkill 与 GTE 的评分与 95% 区间：前两者在顶部区间大量重叠、难以区分强模型，GTE 的区间更窄、更能区分。该图说明本文为何在不完全信息多人博弈上采用角色分解的博弈论评分（GTE）而非传统 Elo 类方法。

3.4 跨游戏：成本—性能与”战略能力是多面的”

作者把每个环境的成绩与推断成本画在同一张图上（正文 Figure 4，四个面板：A Chess Text、B Chess Openings、C Poker、D Werewolf；分析者注：正文 §3.3 在描述 Werewolf 的成本—性能时写作 “Figure 4, Panel B”，与图 4 实际面板标注不符，按图应为 Panel D）。结论有两条：其一，成本—性能的有效前沿只有部分跨游戏共享——棋类（两种模式）与狼人杀的前沿形状相近，而扑克重排了前沿、也重排了”哪些模型性价比高”；狼人杀面板中前沿由三个模型锚定：Grok 4.1 Fast Reasoning（低成本端）、Gemini 3 Flash Preview（以极小成本增量换来明显性能跃升）、Gemini 3 Pro Preview（性能上限）（§3.3、§4）。其二（也是全文最重要的发现），模型强度在同一游戏内分层显著，但跨游戏不一致：Gemini 3 Pro Preview 在棋与狼人杀均居首，在扑克却亏 −15.17 BB/100；GPT-5 mini 在扑克与狼人杀都垫底、棋类也只列第 7，但在扑克头对头中赢过两个 Gemini（55%、65%）；Grok 4 在棋类只排中游，在扑克却是一线盈利者。作者据此认为，竞争性游戏探测的是不同维度的战略能力，因此”不断扩展游戏集合的 Game Arena”才有持续信息量（§4）。

原文图 4（Cost–performance trade-offs across four Game Arena environments）。四个面板分别为 (A) Chess Text、(B) Chess Openings、(C) Poker、(D) Werewolf，纵轴为该环境主指标（Elo / BB/100 / GTE rating），横轴为推断成本（棋与扑克按每回合、Werewolf 按每局）；蓝色虚线为该环境内的 Pareto 前沿，橙色点为”至少在一个环境中 Pareto 有效”的模型。该图说明成本—性能关系并不跨游戏通用：同一模型在不同游戏里可能是性价比标杆，也可能完全不在前沿上。

3.5 代价、边界与未解决的问题

代价：这套评测是纯推理（training-free），但对局规模本身即成本——扑克 900,000 手、狼人杀 31,472 局、每对模型 40 局棋，且全部走商业 API；正文 Figure 4 的横轴显示推断成本（按美元计）：棋类每回合约横跨 0.005–0.38，扑克每回合约 0.02–0.11，狼人杀每局约 0.075–0.105（此为分析者按图 4 坐标轴的近似读取）。此外扑克的系统提示词需要职业牌手参与设计、狼人杀的平衡性需要 500 局 × 4 配置的 self-play 消融，都是不便宜的辅助工作。哪些”有效”是被证据解释的：狼人杀规则平衡（附录 Table 2 的消融直接显示了四条规则的逐项影响）、GTE 相对 Elo/OpenSkill 的区分度优势（附录 Figure 6）、以及”差距出现在中后盘”（正文 Figure 3 的时间定位）都有直接证据支撑；而 duplicate poker 是否必要、bootstrap 区间对最终排序的因果贡献，论文只给出结论区间与多种排序方法的相互印证，属于一致性与相关性证据，未做”去掉该设计会怎样”的对照实验——这一点作者也没有声称做了。仍未解决（§4 自述）：固定局数配对的调度不做自适应、算力分配不高效（势均力敌的对局应多下、悬殊的对局应少下）；模型频繁更替（新模型入场、旧模型下线）会打断纵向比较与对局图连通性，尚无冷启动与图维护协议；跨异构游戏的统一 meta-rating 尚未建立（尤其多人博弈的贡献归因难题）；游戏套件仅三个，诊断性总结也需要扩展。范围上，结论适用于这 10 个模型在 2026 年 2 月、默认 API 参数、无工具无检索条件下的表现，不构成对这些模型其他配置下的普适结论。

收尾：作者发现静态基准饱和且易污染、主观评判噪声大，而既有游戏评测又多是一次性数据集、样本不足、难以持续——因此提出把评测做成一个开放、持续运行、可扩展的游戏竞技平台 Game Arena，通过统一文本 harness、三套覆盖不同信息结构的游戏环境、duplicate poker 与 bootstrap 等方差削减和统计方法（以及面向不对称多人博弈的 GTE 角色分解评分）实现，实验显示模型在棋、扑克、狼人杀中高度分层且跨游戏排序不一致、成本—性能前沿也随游戏重排，为”战略能力是多面的”提供了大样本证据；但自适应调度、模型更替下的连续性、跨游戏统一评分以及更多游戏与诊断维度仍是未解问题。
