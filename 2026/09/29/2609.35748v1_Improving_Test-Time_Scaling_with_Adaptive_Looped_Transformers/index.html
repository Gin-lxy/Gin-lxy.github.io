0. 一句话结论

论文研究的是：把循环（looped）Transformer 结构通过后训练（post-training）引入预训练 LLM 后，能否在测试时扩展（test-time scaling）中超过非循环基线。作者先建立一个负面观察——既有循环模型（Ouro、Huginn）的精度–算力斜率更陡，但在同等解码算力下精度反而更低，原因是固定深度循环对每个 token 都追加迭代，而多数 token 并不受益；随后提出 TaH2：用在线测得的迭代增益监督一个 token 级 iteration decider，与骨干网络联合后训练，只在受益的 token 上多迭代。在 1.7B 规模、AIME 基准上，TaH2 的斜率比非循环基线高 53%（2.74 vs. 1.79），在同等解码算力下超过基线峰值约 3.4 分，并在 4B/8B 与数学、代码、QA、工具调用多领域保持增益。主要结论在其覆盖的范围内（Qwen3-Base、SFT 蒸馏式后训练、已报告基准）有实验支持，但基线为作者自行改造的实现、训练数据依赖教师模型，且缺少方差与显著性检验，结论外推需谨慎。

1. 论文具体想解决什么问题？

背景与任务。 测试时扩展（test-time scaling）通过在推理阶段投入更多算力提升语言模型推理：一条路线是 token 空间生成更长的思维链，另一条是潜在空间路线——循环 Transformer 对共享层重复施加迭代（§1）。参数共享让模型不加参数就能获得”更大有效深度”，但每次迭代仍产生解码开销（§1）。

现有比较的缺口。 已有的循环 vs 非循环比较都在”匹配参数量”或”匹配每 token FLOPs”的口径下进行（Parcae、Iso-Depth、SMELT 等，§2、Appendix E）。作者指出：这些比较没有回答”当输出 token 预算增长时，循环能否改善精度–算力缩放”（§1）。这是一个此前未被系统研究的评测角度，而非全新的架构问题。

作者发现的新现象。 在”同一 Qwen3-1.7B-Base 检查点、同一后训练数据”的受控条件下，作者后训练了 Standard（非循环，M=1M=1M=1）、Ouro（全栈循环，M=2M=2M=2）与 Huginn（中段 14 层循环，M=3M=3M=3），在 AIME24–26 上以 32 样本/题、输出长度截断 4K–16K 扫描，把精度对解码 FLOPs 的 log⁡2\log_2log2​ 做线性拟合得到”精度–算力斜率”（§3.2，Figure 1(a)）。结果是：固定深度 Ouro、自适应 Ouro、Huginn 的斜率分别为 2.12、2.27、2.26（精度点/算力翻倍），均高于 Standard 的 1.79；但在重叠的算力区间内，三个循环模型的精度全部低于 Standard（§3.2，Figure 1(a)）。论文用一句话概括这个张力：”post-trained looped models gain accuracy faster as test-time compute increases, yet underperform the non-looped baseline at matched compute”。

瓶颈分析与问题归因。 作者在验证集（1,000 条，teacher forcing）上比较第 1 次与最后一次迭代的 next-token loss，发现 loss 下降分布高度集中在 0 附近：Ouro 与 Huginn 分别有 52.3% 与 33.5% 的 token 变化不超过 10−310^{-3}10−3，另有 21.7% 与 15.9% 的 token 反而变差（§3.2，Figure 3；我们核对了图内数字 21.71%/52.27%/26.02% 与 15.94%/33.46%/50.61%，与正文一致）。据此作者认为：固定深度循环把额外迭代浪费在不受益的 token 上。对 Ouro 自适应退出门的失败，作者给出的解释是”骨干只在全深度训练、推理时提前退出，造成训练–推理错配”（§3.2），并提到其 Stage I 在作者的 post-training 设置下会出现 gate collapse（每个 token 第一次迭代就退出，Appendix A.2.1、Appendix E）——这两点属于作者主张，论文没有用单独的隔离实验验证错配就是主因。

核心假设与问题边界。 论文最终要验证的假设是：把深度决策与骨干联合训练、并用当前骨干上实测的迭代增益做在线监督，可以把循环变成”只在受益 token 上加深”，从而在同等测试算力下超过非循环基线（§3.2 末、§4）。论文明确区分了”循环在预训练中有效（Ouro/Huginn 的原始结果）”与”本文观察到的缺陷：循环仅在 post-training 阶段引入时”（§2、§6），问题的定义是收敛的。

2. 创新点是什么？

一句话概括技术增量：TaH2 = 一个共享骨干 + 输入注入 updater + token 级 iteration decider 的循环架构，其 decider 采用 lookahead depth supervision——深度标签在训练过程中由当前骨干上实测的”再来一次迭代的 loss 增益”在线生成，配合覆盖率截断与代价敏感损失，与骨干联合训练；辅助组件（updater、停止概率加权输出、duo-causal 注意力）多为对已有工作的引入或扩展。逐项分析如下。

(5) 研究问题层面的贡献。 提出并实测量化”post-training 引入循环后的精度–算力斜率”这一新问题，并报告了负面结果（现有循环模型斜率更陡但在同等算力下更差）。这是本文最有辨识度的部分，但它属于分析性贡献，其成立依赖 (a) 基线实现的可比性、(b) 后训练条件（见 §5 的质疑）。

原创边界说明：根据本文的 related work 与实验对比，只能确认作者声称的差异（相对于 TaH、Ouro Stage II、MoR、pondering 类方法）；”首次提出”的判断需要更完整的文献检索，本文未给出足够的外部对照。

3. 作者如何解决？

直觉：既然固定深度循环的问题在于”给所有 token 都加迭代”，那就让每个 token 拥有自己的迭代次数，由一个很小的 decider 在线决定；训练这个 decider 的信号不靠人工标注，而直接来自”再来一次迭代是否真的降低了预测 loss”这一可测量的量。因为标签是在当前骨干上实时测的，所以监督目标不会与模型脱节；因为决策规则训练与推理一致，所以不存在 Ouro 式的训练–推理错配。

运行流程（训练与推理共用同一套前向）。

  1. 输入：token 嵌入 et\mathbf{e}_{t}et​（prompt + response，训练序列长 16,384）。第 1 次迭代直接以嵌入为输入。
  2. 迭代执行：第 mmm 次迭代先用 updater 融合 et\mathbf{e}_{t}et​ 与上一轮隐状态 ht(m−1)\mathbf{h}_{t}^{(m-1)}ht(m−1)​（一个小型带归一化的 SwiGLU MLP，Eq. 2、9），再让共享骨干跑完整 LLL 层，得到 ht(m)\mathbf{h}_{t}^{(m)}ht(m)​，LM head 给出 qt(m)\mathbf{q}_{t}^{(m)}qt(m)​（§4.1，Appendix A.2.1）。updater 与 decider 在所有迭代间共享参数、只增约占 2.6% 的参数（1.7B：46.16M，Table 6/7）。
  3. 深度决策：decider 读取 (et,ht(m),TopK⁡(qt(m)))(\mathbf{e}_{t},\mathbf{h}_{t}^{(m)},\operatorname{TopK}(\mathbf{q}_{t}^{(m)}))(et​,ht(m)​,TopK(qt(m)​))，输出继续概率 gt(m)∈(0,1)g_{t}^{(m)}\in(0,1)gt(m)​∈(0,1)（Eq. 3；TopK 取 2048 个概率值）；阈值 τexit=0.5\tau_{\mathrm{exit}}=0.5τexit​=0.5，g<τg<\taug<τ 即在该深度停止，否则跑到上限 MMM（§4.1；停步规则以 LaTeX 源文件为准，HTML 版此处渲染缺失）。
  4. 输出：按停止概率对执行过的各深度预测做加权混合（Eq. 4），最后一次迭代吸收剩余概率质量——这一设计让”深度”以软权重而非硬选择的方式参与语言建模，梯度可回传到更浅的预测。
  5. 监督信号：每个 batch 上用 Eq. 5 计算 δt(m)\delta_{t}^{(m)}δt(m)​（已停止 token 由无梯度 lookahead 补足），按 Eq. 24 求覆盖 99% 正增益总量的截断 δcut\delta_{\mathrm{cut}}δcut​，得到继续/停止标签（Eq. 6）；decider 用代价敏感 BCE（Eq. 7、25、26）训练，αD=0.05\alpha_{D}=0.05αD​=0.05。
  6. 训练：仅 SFT（蒸馏式后训练）：273K prompts（AM-Qwen3-Distilled 数学/代码/QA + Nemotron-Agentic-v1 工具调用），响应由 Qwen3-8B 教师生成，3 epochs、全局 batch 128、lr 4×10−54\times10^{-5}4×10−5、共 3.4B tokens（§5.1；Appendix A.1、B.1）。不需要 RL、不需要人工标注。
  7. 推理：同一 decider、同一阈值；用扩展过的 Mini-SGLang（连续深度批处理，把不同迭代深度的请求放进同一个前向里）做服务（§5.2；Appendix A.3）。

关键机制细节：extended duo-causal attention。 每次迭代持有自己的 KV cache，位置 ttt、深度 mmm 的 query 只能看到位置 s≤ts\leq ts≤t、深度 j≤mj\leq mj≤m 的已执行 KV（§4.1，Appendix A.2.1）。训练时为监督已停止 token，需要一次无梯度 lookahead 迭代；lookahead query 不能看到其它 token 的 lookahead 状态。把所有迭代的 cache 拼接后，该规则变成块结构掩码，使训练与 prefill 仍能整序列并行（Figure 7）。

上图左侧把”逐 token 自适应深度”可视化：横轴是 4 个 token、纵轴是迭代深度，绿色对勾表示 decider 让它继续、红叉表示停止；虚线灰框是训练期才存在的 no-gradient lookahead 迭代——它不改变推理行为，只为给停止的 token 补出”若再迭代一次会得到什么 loss”，从而让监督标签在训练时处处可得（这是本方法能在线生成标签的关键机制）。右侧是训练时的数据流：Embed 的嵌入被 updater 反复注入；LLM 每次迭代后既接 Head（得到 q(m)\mathbf{q}^{(m)}q(m)）又接 Decider（得到 g(m)g^{(m)}g(m)）；g(m)>θg^{(m)}>\thetag(m)>θ 就继续，g(m)<θg^{(m)}<\thetag(m)<θ 就在该深度停止；各深度的预测按停止权重 w(m)w^{(m)}w(m) 乘权后求和成最终分布 q\mathbf{q}q，与交叉熵损失相连；最右的 lookahead 迭代给出 ℓ(4)\ell^{(4)}ℓ(4)，用 δ(3)=ℓ(3)−ℓ(4)\delta^{(3)}=\ell^{(3)}-\ell^{(4)}δ(3)=ℓ(3)−ℓ(4) 构造 decider 的 BCE 监督。图中所有模块”跨迭代共享参数”，因此循环带来的参数量增幅很小。

上图解释了”为什么循环模型还能并行训练”：每个 (token, 深度) 单元是一个 query，它可见的 key 被限制在”位置不超过自己、深度不超过自己”的矩形内（绿色箭头与绿框），这正是 duo-causal 规则；而 lookahead 行（如 (3,3)）只能看到自己的已执行状态、看不到其它 token 的 lookahead，避免把监督用的信息泄漏给生成路径。把各迭代 cache 顺序拼接后，这套约束变成一个块状掩码，因此不需要逐迭代串行训练。这是 TaH2 相对 TaH 的扩展点（TaH 不支持训练期 lookahead）。

4. 解决得怎么样？

4.1 实验设置

  • 模型与基线（§5.1，Appendix A.2）：骨干为 Qwen3-1.7B/4B/8B-Base；主实验在 1.7B（M=2,4,8M=2,4,8M=2,4,8），4B/8B 验证规模迁移（M=2M=2M=2）。基线四类：Standard（单次前向）；TaH2-fixed（同架构但无 decider、每 token 固定跑满 MMM 次迭代、用因果注意力）；Ouro（全栈循环、隐状态直接跨迭代传递、无 updater/decider；按原论文两阶段训练，但 Stage I 被作者简化以避免 gate collapse，Appendix A.2.1）；Huginn（循环第 8–21 层共 14 层，M=3,7M=3,7M=3,7，等效有效深度 56/112 层，与 Ouro M=2,4M=2,4M=2,4 对齐）。所有变体共享同一 Qwen3 初始化和同一后训练配方；作者明确说明 Ouro/Huginn 是”适配到本设置的重实现，而不是复现官方检查点”（Appendix A.2.1）。
  • 训练数据：AM-Qwen3-Distilled（数学/代码/QA prompts）+ Nemotron-Agentic-v1（工具调用）；1.7B 实验用 Qwen3-8B 重新生成的响应（教师选择见 Appendix B.1：8B 教师把学生带到 11.98，高于 32B 的 10.35 与 235B-A22B 的 10.18）；273K prompts、3 epochs、16K 上下文、3.4B tokens、6,402 步（§5.1，Appendix A.1）。4B/8B 用 Qwen3-235B-A22B 的原始响应，训练预算固定为每参数 2 tokens（4B: 8B tokens；8B: 16B tokens）（§5.3，Appendix A.1.2）。
  • 评测（§5.1，Appendix A.3，Table 8）：数学（AIME24–26 avg@32、AMC23 avg@32、MATH500/OlympiadBench/IMO-AnswerBench avg@4）、QA（GPQA-Diamond avg@8、SuperGPQA-Hard avg@4）、代码（HumanEval/MBPP avg@8、LiveCodeBench v6 avg@4）、工具调用（BFCL v3 multi-turn avg@1 greedy）；zero-shot CoT，temperature 0.6、top-p 0.95、top-k 20，默认最大生成长度 32K；decider 阈值 0.5。评测使用统一随机种子（Appendix A.3 原文：All results use the same evaluation seed），未报告多次训练或多次评测的方差。
  • 指标与算力口径：精度外另报”解码 FLOPs/response”（只计矩阵乘，Appendix A.4.1 明确排除了逐元素操作、显存访问与服务开销）、A800-80GB 上的端到端时延与吞吐（Table 2）。斜率定义为精度对 log⁡2\log_2log2​ 解码 FLOPs 的线性拟合（4K–16K 截断、2K 步长，7 个点；拟合 R2R^2R2：Ouro 0.997、Huginn 0.994、Standard 0.955，TaH2 未给）（§3.2，Appendix A.3）。
  • 各部分回答的问题：§5.2 = 1.7B 主结果（深度缩放 + 测试时缩放 + 运行时）；§5.3 = 规模迁移；§5.4 = 设计消融（标签、损失权重、覆盖率、采样、updater、输出）；§5.5 + Appendix C = 机制分析（decider 对齐、token 级深度、跨迭代注意力、并行缩放、逐基准缩放）；Appendix B.2 = 推理深度超出训练上限的外推。

4.2 关键结果

主结果（1.7B，十基准平均，32K 生成，Table 1）。 Standard 平均 37.7；TaH2 M=2M=2M=2 40.6（+2.9）、M=4M=4M=4 40.9（+3.2）、M=8M=8M=8 42.5（+4.8）；TaH2-fixed M=2M=2M=2 39.4、M=4M=4M=4 40.3；Ouro M=2M=2M=2 37.3、M=4M=4M=4 36.4；Huginn M=3M=3M=3 38.2、M=7M=7M=7 38.4。单位算力代价（FLOPs/token，相对 Standard）：TaH2 M=2M=2M=2 仅 1.21×，而 TaH2-fixed M=2M=2M=2 1.99×、Ouro M=2M=2M=2 1.91×、Huginn M=3M=3M=3 1.90×——即 TaH2 用约六成的每 token 解码算力取得明显更高的均值。单基准最大增益出现在 HumanEval（M=8M=8M=8 时 72.6，+9.0）与 OlympiadBench（47.4，+7.0）。

测试时缩放（核心声明）。 在 16K 训练长度内，TaH2 M=2M=2M=2 的斜率为 2.74 精度点/算力翻倍，其他循环模型为 2.12–2.42，Standard 为 1.79（§5.2，Figure 1(a)）——即相对非循环基线 +53%，相对次优循环基线（TaH2-fixed）约 +13%。把评测延长到 32K 后，Standard 在 191.7 TFLOPs/response 处饱和于 12.0%，TaH2 在同一算力下达到 15.4%，高 3.4 分（§5.2，Figure 4(b)，Appendix A.3 的算力估算）。并行轴（多数投票）上 cons@32 为 27.3%（M=2M=2M=2）vs. Standard 21.9%（Appendix C.3）。

上图中四个子图共用同一横纵轴：Standard 曲线在约 191.7 TFLOPs 处走平于 12% 附近，而自适应 TaH2 的曲线在对齐的算力区间内始终更高、且到 32K 截断仍在上升，最终触及约 15.4%——这就是”同等算力下超过基线峰值 3.4 分”的直接来源；固定深度 TaH2 也高于 Standard 但低于自适应版，说明 decider 的深度分配的贡献独立于”循环 + 更多训练算力”。Huginn 与 Ouro 的子图里，曲线在重叠区间处于 Standard 之下或与其相当，这也正是论文负面观察的图形证据。

深度缩放（增大迭代上限）。 验证损失上 Ouro/Huginn 在各上限下不低于 Standard，而 TaH2 随 MMM 增大持续更低，自适应版在 M=8M=8M=8 比 Standard 低 0.0106（§5.2，Figure 4(a)，Appendix C.1）。十基准平均增益从 M=2M=2M=2 的 +2.9 增至 M=8M=8M=8 的 +4.8（Table 1）；AIME24–26 在 16K 截断下从 +2.8（M=2M=2M=2）增至 +3.9（M=8M=8M=8）（Figure 1(b)；注意 +2.9/+4.8 是十基准 32K 口径、+2.8/+3.9 是 AIME 16K 口径，两者条件不同）。

规模迁移（Table 3）。 4B：平均 49.6（+3.2），AIME26 +6.9；8B：平均 58.5（+2.4），AIME24 +4.4。提升较小或没有提升的地方：8B 的平均增益（+2.4）小于 4B（+3.2），其中 Olympiad +1.1、SGPQA +1.2、BFCL +1.4 都较小；1.7B 上 GPQA 是唯一被基线反超的基准——Ouro M=2M=2M=2 拿到全表最高的 34.0、Huginn M=3M=3M=3 为 33.7，而 TaH2 三个深度只有 33.1/33.0/32.0（Table 1）；Huginn 在十基准平均上其实略高于 Standard（38.2/38.4 vs. 37.7），论文正文”stay close to Standard”的表述方向正确但略显含糊。另外 4B/8B 只测了 M=2M=2M=2，深度缩放结论没有在大模型上复验。

运行时（Table 2，AIME26，A800，32K 输出）。 TaH2 每 token 解码 GFLOPs 为 Standard 的 1.22×（8.59 vs. 7.04），端到端时延为 1.34×（batch 1，187.0s vs. 139.8s）与 1.30×（batch 4），吞吐降到 0.71×/0.74×（144.3/376.2 tokens/s）；对照 TaH2-fixed 是 2.00× FLOPs、2.35× 时延。把横轴换成实际时延后（Figure 5），TaH2 的最高可达精度（约 15.5%）明显高于 Standard 的饱和值（约 12%）；但在约 50–60 s 以内的低延迟区间，其曲线与 Standard 相当或略低，优势出现在更高延迟区间——也就是说，FLOPs 口径的 22% 开销在真实服务里放大为约 30–34% 的时延开销。

4.3 机制证据

  • decider–增益对齐（§5.5，Figure 6）。 在验证集上按继续概率分箱，统计”再迭代一次”的平均 loss 下降：概率接近 0 的 token 增益为负或近零，增益随概率单调上升，且在阈值 0.5 处恰好约为零。这支持”decider 指向的正是受益 token”的说法，属于机制证据；但它是对已训练模型的相关性分析（单模型、单验证集、无干预实验），不能排除”decider 只是拟合了 loss 的一阶特征”这类替代解释。

上图是”decider 是否真的在选受益 token”最直接的一张证据：横轴越往右表示 decider 越倾向继续，曲线在左侧（p≈0）对应的 loss 下降为轻微负值——说明这些 token 再迭代一次反而变差，模型选择停止是合理的；曲线在 p≈0.5 附近穿过零点，与推理阈值 τexit=0.5\tau_{\mathrm{exit}}=0.5τexit​=0.5 重合——意味着”继续/停止”的分界线恰好落在”再迭代一次是否改善预测”的分界线上；p 接近 1 的 token 平均可再降低约 0.3 的 loss，即高置信继续的 token 确实是高收益 token。合起来看，学习到的门控行为与训练目标（增益监督）是一致的；局限是这只说明相关性与阈值校准良好，不构成”分配深度导致了性能提升”的因果证据。

  • 设计消融（§5.4，Table 4，1.7B、M=2M=2M=2、32K 评测）。 增益标签→top-1 mismatch −1.1；代价敏感权重→均匀权重 −3.6（最大项）；ρ=0.99\rho=0.99ρ=0.99→ρ=1\rho=1ρ=1 −1.9；确定性阈值→采样决策 −1.3；学习式 updater→top-100 词嵌入加权 −2.1；停止加权输出→仅最终迭代 −1.0。这些消融逐一隔离了 TaH2 的组件贡献，是”设计不可替代”的主要证据；但每项都是单次训练的点估计，1.0–1.3 分的差异是否超过训练噪声，论文未报告方差。
  • token 级深度分配（Appendix C.4，Figure 11）。 三个正确响应样例中，数学表达式与最终代码的平均迭代深度低于前面的自然语言推理（OlympiadBench：2.46→1.29；HumanEval：3.31→1.04），QA 样例则全程较深。这是小样本定性观察（3 个样例），只能说明”深度分配与局部内容相关”，不能支撑统计性结论。
  • 跨迭代注意力（Appendix C.5，Figures 12–13）。 三个注意力头在迭代 8 的 query 上分别偏好首迭代状态、后迭代状态或两者（100 条验证序列，均值±1 标准差）。属于探索性分析，与性能无直接因果链。
  • 训练稳定性（Appendix C.1，Figure 8）。 两个 TaH2 变体的验证损失在训练全程低于 Standard，且自适应版最低——支持”增益不是后期偶然现象”，但不构成对机制的解释。
  • 未能隔离的替代解释。 TaH2 M=2M=2M=2 的训练算力是 Standard 的 1.87×（Table 10），”额外训练量本身带来提升”只被间接排除：TaH2-fixed（2.01×）与 Ouro（2.00×）在相近训练算力下都没有取得 TaH2 的增益；但论文没有做”Standard 用 1.87× 算力训练更久/更大”的直接对照。至于”为什么 Ouro 的自适应门不行”，作者的”训练–推理错配”解释只有定性论证（其门训练时骨干被冻结、Stage I 被简化），没有隔离实验。

4.4 成本与适用范围

训练成本（Appendix A.4.3，Table 10）。 以 1.7B、6,402 步、3 epochs 计，Standard 为 41.8×101841.8\times10^{18}41.8×1018 FLOPs；TaH2 M=2M=2M=2 为 78.1（其中在线标签的 lookahead 占 15.2，约 20–24% 的额外开销），合计 1.87×；M=4M=4M=4 为 2.73×、M=8M=8M=8 为 5.17×。同表对照：TaH2-fixed M=2M=2M=2 2.01×、Ouro M=2M=2M=2 2.00×、Huginn M=3M=3M=3 1.86×——即在 M=2M=2M=2 时 TaH2 的训练开销低于固定深度循环。作者在结论中承认”高于标准 SFT”，并辩称后训练总算力远小于预训练，因此”给已有模型加自适应深度”仍然实用。

推理成本（Table 2、Table 1）。 M=2M=2M=2 时 +22% 解码 FLOPs/token、+30–34% 端到端时延、吞吐 0.71–0.74×；十基准平均的 FLOPs/token 为 1.21×（M=2M=2M=2）、1.47×（M=4M=4M=4）、2.37×（M=8M=8M=8），相比固定深度循环（约 1.9–4.0×）显著更省。真实获益依赖深度批处理服务（连续深度批处理，Appendix A.3）。

其它成本与依赖。 参数增量：1.7B 为 46.16M（2.61%）、4B 为 1.76%、8B 为 2.20%（Table 7）。数据侧依赖外部教师模型（Qwen3-8B 生成响应，Appendix B.1），复现需要能运行该教师；4B/8B 则依赖 Qwen3-235B-A22B 的响应。论文未报告：KV 缓存/显存开销（duo-causal 注意力让每个迭代持有独立 KV cache，推理显存随执行深度增长的代价没有被量化）、多次训练的方差、任何失败率统计。代码/配置/检查点声明”发表后释出”（Reproducibility statement）；arXiv 摘要页给出的仓库是 github.com/thu-nics/TaH——精读时点该页面仍为前作 TaH（Think-at-Hard，ICML’26）的实现，TaH2 的代码尚无法核对。

适用范围与遗留问题。 结论限定在：Qwen3 稠密模型（1.7B–8B）、SFT/蒸馏式后训练（作者把 RL 与 on-policy distillation 列为 future work，§6 Limitations）、数学/代码/QA/工具调用的零样本 CoT 评测。推理深度超出训练上限（Appendix B.2）不会带来增益（M=8M=8M=8 模型把推理上限提到 12，精度不变、平均深度增加 20–27%），而把上限从 8 降到 4 会掉 2.7–3.1 分——即”深度上限”必须与训练一致。未解决的还包括：8B 增益低于 4B 的规模趋势、GPQA 上的基线反超、以及无教师模型时的行为。

5. 最容易受到审稿人质疑的地方

质疑：核心负面结论（既有循环模型在同等算力下不如非循环基线）建立在作者自行改造的 Ouro/Huginn 实现上，而非官方检查点或官方配方

  • 原文依据：Appendix A.2.1 明确写明”Our Ouro and Huginn implementations adapt their architectures to this setting rather than reproduce the released checkpoints”；Ouro 的 Stage I 被简化（去掉 exit gate、改为均匀平均各迭代损失）以避免 gate collapse；Huginn 只循环 14/28 层，且用作者自己的输入适配器实现。三者与 TaH2 共享同一初始化与配方，但 Ouro/Huginn 的超参与结构改动由作者决定。
  • 为什么重要：论文的问题定义（现有循环模型斜率更陡但精度更低）是全文动机的支点；如果该现象部分来自基线实现的欠训练或配方不匹配，”post-trained 循环模型存在系统性缺陷”这一判断的外部效度就会被削弱，TaH2 的对比基准也随之改变。
  • 当前能够得出的判断：这是真实存在的混淆因素，但论文提供了部分对冲证据——TaH2-fixed 与 Ouro 在几乎相同的训练算力（2.01× vs. 2.00×）下前者平均高约 2.1 分，说明差异不能全部归因于算力；不过仍无法排除”官方 Ouro/Huginn 配方 + 更长训练”能缩小差距。
  • 如何验证或补强：用官方发布的 Ouro/Huginn 检查点（若存在同规模开源版本）或严格按原论文配方（含原 Stage I/II 完整流程、原深度超参）重跑对照；至少公开 Ouro/Huginn 基线各自的超参搜索范围与训练损失曲线。
  • 严重程度：主要问题。

质疑：训练数据依赖教师蒸馏，且”同等测试算力”的对照没有排除”更多后训练算力”的替代解释

  • 原文依据：主实验的训练响应全部由 Qwen3-8B 重新生成（§5.1、Appendix A.1.2），且对教师极敏感——同一配方下 8B 教师给学生 11.98 平均，而 32B/235B 教师只有 10.35/10.18（Appendix B.1，Table 11）；同时 TaH2 的训练 FLOPs 是 Standard 的 1.87×（Table 10，M=2M=2M=2）。
  • 为什么重要：两个方向都影响结论归因。其一，若没有强教师，”post-training 循环模型”的收益可能大幅缩水，方法的可迁移性受限于蒸馏数据可获得性；其二，TaH2 相对 Standard 的优势里，有多少来自 decider 机制、多少来自”多花了 87% 训练算力”，论文只通过 TaH2-fixed/Ouro 间接排除（它们训练算力相近却收益更小），没有”Standard 用等算力训练更久”的直接对照。
  • 当前能够得出的判断：证据不足以完全归因于机制；作者也未做数据规模消融（例如换更弱/更强教师时 TaH2 增益是否一致）。
  • 如何验证或补强：补充 (a) 无教师（人类或模型无关数据）条件下 TaH2 vs. Standard 的对照；(b) Standard 以 1.87× 算力（更多 epoch 或更长序列）训练的等算力对照；(c) 更换教师规模的敏感性实验。
  • 严重程度：主要问题。

质疑：主结果与消融缺少统计稳定性证据，且评估样本量小

  • 原文依据：Table 1、Table 3、Table 4 均为单次训练/单次评测点估计，未报告方差、置信区间或显著性检验；Appendix A.3 仅说明”All results use the same evaluation seed”；AIME24–26 每套只有 30 题（Table 8），十基准平均由 10 个基准聚合；Table 4 中多处消融差异在 1.0–1.3 分（如”仅最终迭代”−1.0、”采样决策”−1.3），与 AIME 上 30 题 × 32 采样的采样噪声量级相当接近。
  • 为什么重要：论文最核心的提升（+2.9 均值、+3.4 匹配算力）若建立在 AIME 这类小基准上，读者无法判断其稳定性；消融结论（哪些组件”不可替代”）在小差异上尤其脆弱。
  • 当前能够得出的判断：大方向（十基准平均 +2.9、AIME +53% 斜率）不太可能完全由噪声造成，因为方向在多个基准、多个规模上一致；但个别基准（如 1.7B 的 GPQA 上 TaH2 最高仅 33.1，低于 Ouro 的 34.0 与 Huginn 的 33.7；8B 上 OlympiadBench 仅 +1.1）与小幅消融差异不应被当作可靠结论。
  • 如何验证或补强：报告多次（≥3）训练种子与多种评测种子的均值±标准差；对关键对比给出配对显著性检验或 bootstrap 置信区间；公开每题得分。
  • 严重程度：主要问题。

质疑：headline 数字”匹配算力下超过基线峰值 3.4 分”的比较方式与真实部署收益存在落差

  • 原文依据：该数字来自”Standard 饱和点（191.7 TFLOPs/response）上 TaH2 的精度”（§5.2，Figure 4(b)），是单点比较而非等预算曲线比较；算力口径只计矩阵乘、排除显存访问与调度（Appendix A.4.1）；真实服务中 TaH2 的时延增量为 30–34%，高于 FLOPs 的 22%（Table 2），且 Figure 5 显示低延迟区间（约 50–60 s 以内）TaH2 并不优于 Standard。
  • 为什么重要：这决定读者对”更高效的 test-time scaling”的期望值。若部署场景的延迟预算较小，TaH2 的单位时间收益可能不显著；若延迟预算充裕，收益是真实的。
  • 当前能够得出的判断：论文确实提供了时延口径的 Figure 5 与深度批处理实现，属于坦诚报告；但摘要与引言只强调 FLOPs 口径的 3.4 分/53%，对”低延迟区间无优势、时延开销高于 FLOPs 开销”这一限定条件呈现不足。
  • 如何验证或补强：给出等延迟预算下的精度–预算曲线与 Pareto 前沿（论文已有素材，只需按固定时延截断）；公开不同 batch size/硬件下时延分解（decider 调用、迭代串行化的占比）。
  • 严重程度：次要问题（属于表述与覆盖范围问题，不是方法错误）。

质疑：机制类证据（”迭代分配给受益 token”）以相关性观察和极小样本为主，且对失败原因的解释未被隔离验证

  • 原文依据：Figure 6 是验证集上的分箱相关性；token 级深度分析只基于 3 个抽样正确响应（Appendix C.4，Figure 11）；跨迭代注意力只有 3 个头（Appendix C.5）；”Ouro 门失败源于训练–推理错配”只依赖定性论证与 gate collapse 的旁证（§3.2、Appendix A.2.1/E），没有”在推理期保留全深度执行时门是否仍失效”之类的隔离实验。
  • 为什么重要：论文的核心主张不只是”更快”，而是”因为它把迭代分配给了受益 token 所以更好”。如果 decider 的增益来自其它因素（例如 decider 作为额外容量、或标签机制起的正则化作用），这一因果叙事需要修正；这影响创新点的解释力与后续方法设计的方向。
  • 当前能够得出的判断：现有证据支持”decider 学到的概率与实测增益单调相关”，但不足以证明因果机制；对基线失败原因的解释属于作者主张，证据强度为弱到中等。
  • 如何验证或补强：加入干预实验（例如固定 decider 输出为随机路由，但保持相同平均深度与算力，比较精度）；对 token 深度与增益做更大规模（全验证集而非 3 例）的统计；对 Ouro 门做”全深度训练 vs. 早退推理”的 2×2 隔离对照。
  • 严重程度：次要问题。

6. 审稿式总评

作者发现，把循环结构通过后训练引入 LLM 后，Ouro、Huginn 这类模型的精度–算力斜率比非循环基线更陡，但在同等解码算力下精度更低；token 级分析显示多数 token 并不能从额外迭代中获益（Ouro/Huginn 分别有 52.3%/33.5% 的 token 几乎无变化、21.7%/15.9% 反而变差），因此提出 TaH2：用当前骨干上在线实测的迭代增益监督一个 token 级 decider，与骨干联合后训练，并配合输入注入 updater、停止概率加权输出与扩展 duo-causal 注意力。实验在 Qwen3-1.7B/4B/8B 的蒸馏式 SFT 后训练条件下表明，AIME 上斜率提升 53%、匹配算力下超过基线峰值约 3.4 分、十基准平均从 +2.9（M=2）增至 +4.8（M=8），且 M=2M=2M=2 时每 token 解码算力仅 1.21×；其中在线增益监督与代价敏感损失的作用由消融支持（去掉后分别掉 1.1 与 3.6 分），证据较强，但”现有循环模型为何在 post-training 下失灵”与”decider 的因果机制”仍缺少隔离实验和统计支持。本文最有价值的部分是在受控后训练条件下系统量化了循环模型的测试时扩展行为，并给出一个代价可控的自适应深度方案；最大的审稿风险是 Ouro/Huginn 基线为自行改造实现、训练数据依赖教师蒸馏，以及主结果缺少方差与显著性检验——这三者共同决定了其核心对比的可信边界。

  • 问题定义清晰度：强——把”循环能否改善 test-time scaling”转化为可测量的斜率指标，并明确限定在 post-training 引入循环的设定（§1、§3.2）。
  • 创新性证据：中——在线 lookahead 深度监督与联合训练是相对 TaH/Ouro Stage II 的实质差异并有消融支撑，但 updater、输出混合、duo-causal 注意力均属引入/扩展，整体是”已有组件 + 新监督信号”的组合式创新（§2、§4、Table 4）。
  • 方法可信度：中——方法描述完整、公式与超参齐全、on-policy 设定明确，但核心基线的实现细节由作者自行适配，且 Ouro Stage I 被简化，方法层面的公平性存在未消除的不确定性（Appendix A.2.1）。
  • 实验支持力度：中——十个基准、四个模型族、三个规模、深度/测试时/并行三条缩放轴，覆盖面好；但单种子、无置信区间、教师依赖与 8B 增益回落都限制了结论强度（Table 1–3、Appendix A.3）。
  • 可复现性：中——数据配方、超参、FLOPs 核算与评测协议披露充分，但代码/检查点声明”发表后释出”，且基线不是官方检查点，精读时点无法独立复算（Reproducibility statement、Appendix A.2.1）。
  • 综合阅读价值：高——对关注循环/自适应深度与 test-time scaling 的读者，这篇论文提供了一个干净的负面观察、一个实现代价明确的方案，以及对成本与失败模式的较坦诚报告（Table 2、Table 10、Appendix B.2）。
