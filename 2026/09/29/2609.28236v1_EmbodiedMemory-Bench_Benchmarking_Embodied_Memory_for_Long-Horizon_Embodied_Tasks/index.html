0. 一句话结论

论文指出长程具身交互中 MLLM 难以持续维护、更新与复用世界状态，为此构建了记忆中心的可执行基准 EMem-Bench（2,554 个 episode，四个任务族：被动观察、动态跟踪、交互失败、经验泛化），并给出外部记忆系统 EMem 与其 8B 策略 EMem-8B 作为基线。核心思路是让 agent 先把多模态交互历史写入 scene/spatial/event 三类记忆，再用记忆检索结果指导后续环境动作；证据支持”当前模型在该基准上普遍偏弱、EMem 在固定 GPT-5.4-mini 骨干下平均分最高”，但四个任务族对记忆的因果依赖并不均衡、主 leaderboard 无方差报告，部分结论（如”扩大原始视觉上下文无益”）证据范围有限。

1. 论文具体想解决什么问题？

背景与任务。LLM agent 在数字环境（写代码、在线调研）中的长程任务已证明”长期记忆”是关键能力（§2）。但进入真实 3D 物理世界后，记忆需求发生质变：动作改变环境，动作的后果会揭示视觉上不可见的状态（如柜子被锁、容器不可用），因此 agent 必须保存”观测—动作—反馈”的因果链，而不仅是语言或图像内容（§2，Figure 1）。

现有做法与不足。已有的 agent memory 基准（LoCoMo、LongMemEval、MemoryAgentBench、Evo-Memory、WorldMemArena）面向对话或数字环境，不要求记住的信息去指导后续具身交互；已有的具身基准（EmbodiedBench、FindingDory、LMEE-Bench、SpaMEM、WorldLines）只在单个任务内引入记忆，或只覆盖视觉记忆 / 动态跟踪 / 交互反馈 / 经验泛化中的一部分（§3 与 Table 1 的四维对比表）。

作者的新观察。作者手工检查 Gemini-3-Flash 与 Qwen3-VL-32B 在 EmbodiedBench 的 EB-ALF 与 EB-Hab 上的 100 条失败轨迹，发现四类错误合计占 91%：忘记细粒度视觉线索 35%、忽略环境变化 18%、未记录交互结果揭示的世界状态 31%、未能从既往经验泛化 7%（§2，Figure 2）。这四类被提升为四种”具身记忆能力”，并直接对应基准的四个任务族。需要注意：这是现象层面的经验分类（100 条轨迹、2 个模型、2 个基准子集），论文没有报告标注协议或标注者一致性；”模型失败是因为缺乏具身记忆”这一因果解释主要靠后文的因果控制实验（Appendix D.1）间接支撑，而不是由这次手工分析本身证明。

核心假设。把这四类能力放进一个统一的可执行评测——先给一段离线多模态交互历史 H\mathcal{H}H，再给出目标任务 T\mathcal{T}T，让模型在原环境中继续交互直到完成——能够稳定测出模型在长程记忆中”保留、更新、复用世界状态”的差异，并验证这些任务确实依赖历史信息。形式化定义为：at∼π(⋅∣H,T,o1:te,a1:t−1)a_t\sim\pi(\cdot\mid\mathcal{H},\mathcal{T},o^{e}_{1:t},a_{1:t-1})at​∼π(⋅∣H,T,o1:te​,a1:t−1​)，其中 o1:teo^{e}_{1:t}o1:te​ 是任务执行阶段的观测（§4.1，Eq. 1）。

2. 创新点是什么？

一句话概括：本文的主要增量是一个”记忆中心 + 可执行”的具身记忆基准（含专门的错误复演指标 ERR 与一套因果控制实验），外加一个可复现的强基线记忆系统 EMem / EMem-8B；EMem 本身是常见组件的组合式工程实现，其价值在于把”写什么、查什么、怎么据此动作”这套记忆循环变成了可被监督训练、可被公平比较的对象。

创新点 1：EMem-Bench 基准本身。2,554 个可执行 episode，四个任务族（Passive Observation 1,036、Dynamic Tracking 1,052、Interaction Failure 263、Experience Generalization 203），覆盖 1,118 个场景、125 类可见物体、83 类目标物、33 类容器（§4.4，Table 9）。与最接近的已有工作的差异在于：EmbodiedBench 只做”视觉驱动执行”、FindingDory/LMEE-Bench 面向导航视觉历史、SpaMEM 测空间状态修正、WorldLines 做多日轨迹问答（§3，Table 1）——它们要么是单轮问答，要么不提供离线历史、要求 agent 自行探索。EMem-Bench 的差异点是把”给定历史 → 构建记忆 → 在原环境用记忆完成任务”作为统一评测回路，并且四个族分别对应四类记忆能力。

创新点 2：ERR（Error Recurrence Rate）指标。除终态成功率 SR 外，用固定探针自动检测”执行路径是否重演了历史本可避免的错误”：ERRf=1Nf∑i=1Nfmin⁡(1,Eimax⁡(1,Ki))\mathrm{ERR}_f=\frac{1}{N_f}\sum_{i=1}^{N_f}\min(1,\frac{E_i}{\max(1,K_i)})ERRf​=Nf​1​∑i=1Nf​​min(1,max(1,Ki​)Ei​​)（§4.4，Eq. 2）。其设计意图是让 SR 只回答”终态对不对”，ERR 回答”路径是否复发了本该避免的错误”；在正式发布中每个 episode 只有一个”记忆相关决策点”，即 Ki=1K_i=1Ki​=1，ERR 退化为”是否触发至少一次错误复演”的指示量（Appendix C.2，Eq. 11–12），且”走到错误位置后仍可能完成任务”（C.2）。这是相对同类基准的增量指标，但如上所述其实现已比公式外观（带 KiK_iKi​ 的比值）更简单。

创新点 3：EMem / EMem-8B 基线系统。三类记忆（spatial entity graph、event append-only log + 规则聚合、scene 图像快照）+ 统一读写工具接口 + LoRA SFT 教模型”从当前观测写什么、为目标任务查哪些记忆、如何由检索结果生成动作序列”（§5，Appendix B）。作者自述为 “a simple yet effective embodied memory system”（§2），属于已有组件（实体图 / 事件日志 / 图像描述缓存 / 工具调用）的新组合，而非新学习范式；其不可替代性证据来自消融（Table 4）与多骨干迁移（Table 2）。

创新点 4（未列为 contribution 但实际是最强的差异化证据）：基准有效性的因果控制实验。Appendix D.1 用四种历史条件（correct / current-only / cue-removed / minimal-oracle）在固定 800 episodes 上验证”任务成功确实依赖历史”；这类验证在同期的记忆基准中并不常见，是本文相对”只对比分数”的基准文章的更实质的方法论增量。

原创边界说明：根据本文 related work（§3 与 Appendix A，后者列举了 STARBench、RoboMME、RoboMME-Interference、eMEM-Bench、3DMem-Bench、EgoMemReason、MemCompiler、MEMO 等大量近邻工作）与实验对比，只能确认作者声称的差异；表中对比的”Y”组合是否确为首次，需要更完整的文献检索才能判定。

3. 作者如何解决？

直觉。如果模型失败的原因是”把决定性的历史证据弄丢了或没更新”，那么一个自然的对策是不要求模型把全部历史塞进上下文，而是把历史结构化地写进外部记忆：位置/状态类信息进实体图（可被新证据覆盖），交互与反馈进事件日志（保留失败与纠正），视觉细节进场景快照（防止同名物体混淆）；任务到来时，模型通过查询工具取回与任务相关的少量记录，再据此生成动作（Figure 6）。训练的目标不是让模型记住更多，而是让模型学会”该写什么、该查什么、怎么用”。

运行流程（Appendix B.2–B.3，Algorithm 1）：

  1. 输入：按时间排序的交互历史 H\mathcal{H}H（每步含模型可见 RGB 观测 oiho^h_ioih​、前一动作 ai−1ha^h_{i-1}ai−1h​、反馈 fi−1hf^h_{i-1}fi−1h​、scene scope）；任务到来前，写入阶段不提供未来目标指令（防止答案泄漏）。
  2. 写入记忆：每个历史步，writer 策略 WθW_\thetaWθ​ 允许调用三种写工具（update_object、remember_event、remember_scene，Table 6）；后端只执行 schema 合法的调用：spatial 做”关系族替换”——同一物理位置族内新关系覆盖旧关系，Rt(v)=(Rt−1(v)∖F(r))∪{r}\mathcal{R}_t(v)=(\mathcal{R}_{t-1}(v)\setminus F(r))\cup\{r\}Rt​(v)=(Rt−1​(v)∖F(r))∪{r}（Eq. 4），从而保证实体图记录的是最新状态而不是状态历史；event 追加动作/反馈/成功标志，并在”至少两次相关纠正”或”一次持续性失败”后生成可复用的自然语言规则；scene 保存带 caption 与实体列表的快照，用近重复过滤（余弦阈值 0.995）控制入库量。
  3. 查询与执行：目标指令到达后，模型选择 query_spatial / query_event / query_scene（B.3）；查询必须”不能预设答案”；检索流水线先做结构化约束过滤，再做精确匹配与词法匹配，语义相似度只作兜底；单次最多返回 12 条记录，携带支持性记录 id。
  4. 动作循环：检索结果 + 指令 + 当前 RGB + 当前合法动作列表构成动作上下文，模型一次输出一个有序 action_sequence；执行前逐条校验合法性；动作失败或记忆支持的状态发生显著变化时中断剩余序列，开启新一轮 memory–action turn。任务阶段原始动作预算为 8 步，确定性解码（B.3 末段、C.1）。

基准构建流程（§4.3，Figure 4）：

  1. 选房间：AI2-THOR 只有单房间，作者把不同房型拼成”虚拟住宅”并扩展 LeaveRoom/EnterRoom/MoveToRoom 动作（重进房间时恢复状态）；ProcTHOR 本身是多房间，按连通性、可导航空间、物体可见性与可执行交互过滤。每个环境指定一个”cue room”承载记忆线索，其余连通房间用于无关活动与后续任务。
  2. 构造记忆线索：四个族各有一套构造法——被动观察挑选当前视野内物体作为后续检索目标；动态跟踪在模拟器中改变物体位置/状态；交互失败执行一次失败动作，让反馈揭示视觉不可见状态；经验泛化由 Claude-4.6-Sonnet 接收结构化场景信息，输出包含潜在规律、若干纠正案例与目标任务的结构化经验，再在模拟器里落地执行。
  3. 注入干扰轨迹：用 PDDL planner 基于当前场景与 agent 状态生成线索前后无关轨迹，使线索在 episode 中出现的位置可变，并在线索与目标任务之间插入其它房间与任务；任何触碰关键物体、泄露答案、改变目标任务所需状态或不可执行的轨迹都被丢弃。
  4. 校验与人工审查：自动检查场景可导航、交互可执行、目标任务可完成、决定性证据出现在先前经验中且未被干扰轨迹泄露；通过自动检查的候选全部再由 5 名领域专家做六维人工审查（证据充分性、指令清晰性、无答案/目标泄漏、轨迹合理性、线索-探针一致性、终态判定正确性，Appendix C.6，Figure 11）。构造+审查共拒绝 143 个候选，保留 2,554 个。

训练（EMem-8B）（Appendix B.5）：在 ProcTHOR 训练划分上构造家庭交互课程（导航、找物、状态检查、操作、带纠正的交互），由一名未披露名称的 teacher 模型通过与推理一致的 RGB + 记忆工具 + 动作接口完成，训练与评测场景/轨迹不相交。轨迹被序列化为三类监督 turn：C（context-write，写什么）、M（memory，查什么）、A（action，如何生成可执行序列），共 8,852 条监督 turn（3,930 C + 2,461 M + 2,461 A），来自 93 条轨迹（77 训练 / 8 验证 / 8 留出）。用 LoRA 微调 Qwen3-VL-8B：rank 4、alpha 8、dropout 0、lr 10−410^{-4}10−4、batch 1、梯度累积 4、最大序列长度 8,192、1 epoch 共 1,816 步；系统提示、阶段标签、工具 schema、JSON 格式与采集监督时的确定性解码在推理时保持一致。

对照条件：full_context 基线把完整历史以文本形式（语义动作类型、目标标签与类型、净化后的自然语言动作、成功标志、反馈、观测备注）提供给模型，仅当前观测给图像，每个会话最多 K=80 步（正式版最长会话 78 步，因此文本历史完整保留），并保留最近 8 个模型-环境 turn（C.1，Eq. 6–8）。这解释了为什么”加历史图像”需要一个单独的实验条件（§6.3）——默认基线本来就没有历史图像。

4. 解决得怎么样？

4.1 实验设置

  • 任务与数据：EMem-Bench 全量 2,554 episode（AI2-THOR 352 + ProcTHOR 2,202；Table 9）；四族 episode 数 1,036/1,052/263/203，占比 81.8% 集中在被动观察与动态跟踪两族。历史长度中位数 78–83 步（经验泛化 111 步），线索到目标任务间隔中位数 52–56 步，被动观察线索处平均 11.0 个可见物体（Table 10）。
  • 被测模型：open-source 通用 8 个（Qwen3-VL 4B/8B/32B、InternVL3 8B/38B、Ovis2-16B、Qwen3.6-27B、Mistral-Small-3.1-24B）、具身 MLLM 5 个（RynnBrain-8B、Cambrian-S-7B、RoboBrain2.5-8B-NV、MiMo-Embodied-7B、Robotics-ER 1.5）、闭源通用 4 个（GPT-5.4-mini、GPT-5.4、Gemini-2.5-Pro、Gemini-3-Flash），共 17 行（Table 2）。口径不一致：§2 正文称”16 leading open-source and proprietary MLLMs”，而 Table 2 有 17 个 full-context 模型、Table 8 的轨迹长度统计只覆盖”12 general-purpose full-context MLLMs”；Robotics-ER 1.5 因 API 不稳定只在 10% 子集上评测（Table 2 脚注）。16 的构成无法从正文确认，属分析者无法核实的口径。
  • 记忆系统对比：固定 GPT-5.4-mini 为骨干，比较 MIRIX、MemVerse、TeleMem、MMA 与 EMem，加上 full_context 共 5 个对照（§6.1，Table 2 下半）。论文未报告各系统提示模板如何适配。
  • 指标：每族 SR + 等权平均（防止两个大族支配总分），以及 ERR（§4.4，Eq. 2）；动作序列在模拟器中真实执行，只有终态满足任务才算成功。
  • 协议：任务阶段原始动作预算 8 步、确定性解码、每次请求一个原始动作；full_context 每会话 K=80 步截断、最近 8 turn 记录（C.1）。整体统计显示 12 个通用模型平均输出 3.07–6.77 步，10/12 在 P90 触到 8 步上限（Table 8）。
  • 各实验回答什么：Table 2=主 leaderboard；Table 3/13=视觉上下文扩展；Table 4=三类记忆 leave-one-out 消融；Table 5=跨基准泛化；Figure 7=失败分布；Appendix D.1=历史因果控制（基准有效性）；C.7=任务族排名一致性（Spearman 0.52–0.94）。

4.2 关键结果

当前模型普遍偏弱且不均衡（Table 2）：最强 full-context 模型 Gemini-3-Flash 平均 SR 仅 **64.2%**（ERR 21.3）；Qwen3-VL-32B 在 Dynamic Tracking 上只有 20.3% SR，但在 Experience Generalization 上达 63.1%。具身专用模型并未更好：RynnBrain-8B 平均 3.6%、Cambrian-S-7B 0.8%、RoboBrain2.5-8B-NV 20.0%，均低于通用 Qwen3-VL-8B-Instruct 的 25.4%（§6.2）。

EMem 是其设定下的最优记忆系统（Table 2）：固定 GPT-5.4-mini 骨干时，EMem 平均 SR **58.9%**，比最强替代记忆系统 TeleMem（37.8%）高 21.1 个点，平均 ERR 24.3（比 TeleMem 35.7 低 11.4；比 full_context 38.8 低 14.5）。冻结骨干条件下，EMem 在三个开源骨干上平均 SR 提升 +10.8（Qwen3-VL-8B）、+14.1（Qwen3-VL-32B）、+16.4（Mistral-Small-3.1-24B），在闭源 GPT-5.4-mini 上 +23.6；EMem-8B 平均 46.0%，比 Qwen3-VL-8B 基线高 20.6、比”冻结骨干 + EMem”再高 9.8（§6.2）。

并非全面最优（Table 2，分析者核对）：Dynamic Tracking 上 TeleMem 的 72.0% SR 是全表最高（高于 EMem 的 58.1，也高于 Gemini-3-Flash 的 53.9），但其 Interaction Failure 只有 4.2% 且 ERR 37.3，说明记忆系统的能力剖面差异极大。EMem 在 Interaction Failure 上 SR 提升 +25.1 但 ERR 仅降 0.4（17.5→17.1）；Qwen3-VL-32B + EMem 在 Experience Generalization 上出现唯一负迁移（63.1→59.6，-3.5）；Mistral + EMem 在 Passive Observation 上也微降（58.5→52.1，-6.4），而同族 Qwen3-VL-8B + EMem 仅 +2.7。

扩大视觉上下文会变差（Table 3、Table 13）：同一 800 episode 子集上，GPT-5.4-mini 的 full_context 平均 SR 36.6%，填入”尽可能多的历史 RGB 帧”后降到 26.2%（配对差 -10.4，95% CI [-14.4, -6.5]，D.2），输入 token 从 41,770 增至 206,489（4.9×）、单步延迟 4.1s→39.1s（9.5×），四个历史长度分位全部为负。

消融（Table 4）：去掉任一记忆都掉分——去掉 spatial 47.9、去掉 event 46.9、去掉 scene 47.3（全系统 58.9）；任务族与记忆类型的对应清晰：Dynamic Tracking 最依赖 spatial（58.1→46.1），Interaction Failure 与 Experience Generalization 最依赖 event（44.1→27.4；62.1→45.3），Passive Observation 最依赖 scene（71.2→51.7）。

跨基准（Table 5）：EMem-8B 相对 Qwen3-VL-8B：EB-ALF 18.3→23.3（+5.0）、BLINK 55.6→56.9（+1.3）、MMMU-Pro 44.6→45.1（+0.5）、HallusionBench 66.1→65.8（-0.4）。

失败分布（Figure 7，§6.6，百分比为分析者从图中读取的近似值）：总体约 61% 的失败始于”行为与历史证据冲突”的记忆使用错误（与 §2 的 61.3% 一致）；Dynamic Tracking 中记忆使用错误占比最高（约八成半，几乎无动作错误）；Interaction Failure 相反，约六成失败是”历史就在上下文里但没用对”的语境推理错误；动作错误在四族中都很少（约一成）。作者据此认为瓶颈在动作生成之前。

因果控制（Appendix D.1，Table 12）：固定 800 episode，撤销历史或只撤掉决定性证据都会大幅掉分——Qwen3-VL-8B 的 correct vs cue-removed 为 23.8% vs 12.6%（Δ=11.1，95% CI [8.1, 14.1]），GPT-5.4-mini 为 36.6% vs 15.2%（Δ=21.4，CI [17.8, 25.0]）；只给最短结构化命题的 minimal oracle 达到 58.2% / 69.1%，说明两模型在拿到关键关系后执行能力远好于检索能力。

4.3 机制证据

支持”这些任务确实需要历史”的证据较强，但只到家族混合层面。D.1 的四种历史条件是少见的严格对照：current-only 与 cue-removed 分别排除”当前观测”与”单条线索”的替代解释，paired bootstrap CI 提供了统计量。但把 Table 12 按家族拆开（分析者核对）会看到因果依赖极不均匀：GPT-5.4-mini 的 correct-vs-cue-removed 差值在 Passive Observation 为 47.0（58.0 vs 11.0）、Experience Generalization 为 26.5（41.0 vs 14.5）、Dynamic Tracking 仅 13.5（28.5 vs 15.0）、Interaction Failure 为负（19.0 vs 20.5）；Qwen3-VL-8B 的 Dynamic Tracking 与 Interaction Failure 差值分别为 0.5 与 0.0。也就是说”基准成功确实需要记忆”的宏观结论（Δ=11.1/21.4）主要由 Passive Observation 拉动，而 Dynamic Tracking 与 Interaction Failure 两族的记忆必要性在该实验里没有得到支持。这与 §6.6 的观察一致：Interaction Failure 的失败大多不是记忆问题，而是拿到状态后的推理问题。

Table 3/13 是”效果”证据而非”机制”证据。它证明了”无差别填满历史图像会掉分”这一现象，但并未隔离原因：均匀采样是否保留决定性线索帧、长上下文本身是否伤害推理，两个解释都没有被排除（详见 §5 质疑 2）。

**Table 4 消融支持”三类记忆各自被使用”**，但不构成”为什么有效”的机制证据：没有检索命中率、记忆编辑正确率、写入时机分析等中间量，也没有说明三类记忆的收益是否可加（只做了 leave-one-out，未做只开一类的对照）。

EMem 的收益不能完全归因于记忆循环本身：EMem-8B 与冻结骨干 + EMem 之间还差一次 SFT（+9.8），而记忆系统对比中的 MIRIX/MemVerse/MMA 均未接受对应训练（论文未报告其是否原样使用官方训练权重），因此”EMem 最好”中训练与系统设计的贡献未被隔离。

4.4 成本与适用范围

  • 训练成本（B.5，报告值）：8,852 监督 turn、93 条轨迹、LoRA 1 epoch / 1,816 步，属于极轻量微调；但监督数据由未具名的 teacher 模型生成，其调用成本未报告。
  • 推理成本（部分报告）：Table 3/13 报告了 full_context 与”加满历史图像”两种条件的每 episode 平均输入 token（41,770 vs 206,489）与单步延迟（4.1s vs 39.1s，不含模拟器渲染）；论文未报告主 leaderboard 上 EMem 自身的模型调用次数、token 开销与端到端延迟，因此无法比较”记忆系统 vs full_context”的成本。
  • 人工成本（报告值）：5 名领域专家完成六维人工审查，构造+审查共拒绝 143 个候选（§4.3、C.6）。
  • 适用范围与未解决项：全部实验在 AI2-THOR/ProcTHOR 模拟器中完成；Appendix E 明确承认模拟环境不包含传感器噪声、执行误差、开放世界变化与模糊人类反馈，不能据此推断真机长期记忆性能。EMem 相对 full_context 的大幅提升（+23.6）只在 GPT-5.4-mini 上做了记忆系统对比，其它骨干只验证了 EMem 自身（Table 2 上半），跨骨干的记忆系统排名未验证。经验泛化族规模最小（203 episode、18 类目标物），其结论的外推范围最窄。

5. 最容易受到审稿人质疑的地方

质疑：Interaction Failure 任务族缺少”记忆必要性”的家族级证据，与基准的核心有效性主张相冲突

  • 原文依据：Appendix D.1 的 Table 12 给出四族分列结果：GPT-5.4-mini 在 Interaction Failure 上 Correct history 19.0% vs Cue removed 20.5%（差值为负），Qwen3-VL-8B 为 12.5% vs 12.5%（差值 0.0）；而 Passive Observation 上同条件差值为 47.0 / 29.0。§D.1 正文只报告宏观 Δcue=11.1 与 21.4 并据此宣称 “benchmark success genuinely requires memory”。§6.6 与 Figure 7 又显示该族的失败主要是语境推理错误（约六成），记忆使用错误只占约两成；Table 2 中 EMem 在该族 SR +25.1 而 ERR 仅 -0.4。
  • 为什么重要：基准是否”真的在测记忆”是这类论文的核心效度问题（作者自己也称之为 central validity claim）。若某一族在删除全部历史后成绩不降，该族的分数不能解释为记忆能力，而四族等权平均意味着这一问题会污染总分。
  • 当前能够得出的判断：宏观因果主张成立但被过度概括到每一族；家族级证据（论文自己表格里就有数据）与该主张不一致，且论文未做家族级显著性检验（该族每族仅 200 episode）。
  • 如何验证或补强：给出四族分别的 cue-removal 配对差与 CI；检查该族指令是否暗示了答案（answer leakage 审查只覆盖了人工流程，未报告该族特例）；补充”只保留失败反馈记录”的最小 oracle 条件。
  • 严重程度：主要问题。

质疑：”扩大原始视觉上下文无益”的结论存在帧采样与长上下文两个混杂

  • 原文依据：Table 3、Table 13、§D.2：treatment 用一个确定性采样器把历史 RGB “uniformly across sessions and each session’s timeline” 填入剩余上下文，报告 treatment 对全部 800 episode 都成功填入帧，但未报告决定性线索帧（cue）是否被包含在采样结果里；实验只覆盖 GPT-5.4-mini、800/2,554 episode。
  • 为什么重要：这是摘要与 §6.3 的标题级结论（”cannot be solved by simply enlarging the raw multimodal context”），并被用来论证”有效记忆需要精确检索、无关历史会稀释信号”。
  • 当前能够得出的判断：证据支持”无差别最大化历史帧数量会显著掉分”（-10.4，CI [-14.4, -6.5]，四族一致），但”更多视觉历史本身无益”未与”均匀采样恰好漏掉决定性帧”和”超长上下文导致推理退化”两个替代解释区分开；两个替代解释分别指向采样策略问题与上下文长度问题，而非”记忆检索才是唯一解法”。
  • 如何验证或补强：条件于”线索帧被包含/不包含”分层的 2×2 对照；在固定 token 预算下比较”信息量优先选帧”与”均匀选帧”；增加第二个骨干模型（目前仅 GPT-5.4-mini）。
  • 严重程度：主要问题。

质疑：主 leaderboard 缺少统计稳定性，等族加权放大了小家族的权重

  • 原文依据：Table 2 无方差、置信区间或重复次数；全部 CI 只出现在 Appendix D 的两个配对实验（800 episode 子集）中。聚合上，Interaction Failure（263）与 Experience Generalization（203）合计 18.2% 的 episode 却各占 25% 总分（§4.4 与 Table 9）；Interaction Failure 的目标物仅 18 类、容器仅 5 类（Table 11，Top-5 容器=100%），且其 oracle 轨迹长度为 6 步、显著长于其它族（C.3）；Table 12 中 GPT-5.4-mini 在该族三种历史条件下的分数都在 19.0–20.5% 之间，参考值本身很窄。
  • 为什么重要：论文所有排名性结论（”Gemini-3-Flash 最强 full-context”、”EMem 是最优记忆系统、比 TeleMem 高 21.1”）都依赖单次运行与这一聚合方式；小家族占一半权重意味着总分对它们的波动更敏感，而 Table 2 只给一位小数的点估计、”10% 子集”评测等细节说明部分数字的条件并不统一。
  • 当前能够得出的判断：无法从当前材料判断排名的统计稳定性；等族平均是合理的设计选择（作者给出的理由是两个大族不应支配总分），但缺少 episode 加权版本的敏感性分析与逐 episode 自助抽样 CI。
  • 如何验证或补强：给出全量 leaderboard 的 episode-paired bootstrap CI（或多次运行）；并列报告 episode 加权与等族加权两套总分；对 Robotics-ER 1.5 等部分评测模型明确标注不可比。
  • 严重程度：主要问题。

质疑：四类错误分类的证据基础薄弱，且与基准家族设计互为镜像

  • 原文依据：§2 与 Figure 2：分类来自 100 条失败轨迹，仅两个模型（Gemini-3-Flash、Qwen3-VL-32B）、两个基准子集（EB-ALF、EB-Hab）；未报告标注流程、参与人数或一致性；四类合计 91%，剩余 9% 未说明。基准的四个任务族与四类错误一一对应（§2 与 §4.2）。
  • 为什么重要：论文的第一贡献是”识别四类典型错误”并据此断言当前 MLLM 缺乏具身记忆。若分类不穷尽或不可复现，这一”发现”只能算设计动机；而且基准家族由该分类定义，基准上的模型表现不能反过来验证分类本身的正确性（有循环论证风险）。
  • 当前能够得出的判断：作为基准动机该证据可以接受；作为独立经验发现有明显局限。D.1 的因果实验补上了一部分效度证据，但没有覆盖”分类是否穷尽/可复现”。
  • 如何验证或补强：多方独立标注 + 一致性系数；在更多模型/基准上复现四类分布；解释未归类的 9%；说明分类是否在观察数据前就预先设定。
  • 严重程度：主要问题（针对”发现新现象”这一主张；对基准本身的可用性影响为次要）。

质疑：EMem 的方法增量偏工程，记忆系统对比与成本披露不对称

  • 原文依据：§5 与 Appendix B：三类记忆（实体图 / 事件日志 / 图像快照缓存）与工具调用循环均为已有组件的组合；作者自称 “a simple yet effective … memory system”（§2）。记忆系统对比固定单一骨干 GPT-5.4-mini（§6.1），未报告 MIRIX/MemVerse/TeleMem/MMA 的提示适配或是否加载其训练权重；EMem-8B 的 teacher 模型未具名，训练语料仅 93 条轨迹/8,852 turn（B.5）；Table 3/13 详细报告了”扩大上下文”的 token 与延迟代价，但主 leaderboard 上 EMem 自身的调用/token/延迟未报告。
  • 为什么重要：这关系到”EMem 是最优记忆系统”这一结论的公平性（各系统是否被同等对待、是否都在其设计条件下运行）与成本可比性（论文用成本论证上下文扩展不可取，却不披露自己方法的成本）。
  • 当前能够得出的判断：EMem 的价值更多在于”提供了一个可被监督训练、工具接口统一的强基线”，而非新机制；对比公平性当前无法确认（论文未报告）。由于审稿人无法在不披露适配细节的情况下判断 21.1 个点的优势有多少来自系统设计、多少来自适配差异，结论应限定在”论文报告的实验条件内”。
  • 如何验证或补强：至少换 2 个骨干重复记忆系统对比；公开各系统提示/适配与调用预算；报告 EMem 每 episode 的模型调用次数与 token；补充”只开一类记忆”的正向对照以证明三类记忆的必要组合性。
  • 严重程度：次要问题。

6. 审稿式总评

作者发现长程具身交互中的失败集中在细粒度视觉记忆、动态状态跟踪、交互结果记录与经验泛化四类能力上（§2，Figure 2），因此构建了先给交互历史、再在原环境执行后续任务的可执行基准 EMem-Bench（2,554 episode，四族），提出记忆中心指标 ERR，并给出由 spatial/event/scene 三类记忆与工具循环组成的基线系统 EMem，以及用 8,852 条监督 turn 微调出的 EMem-8B。实验在 17 个 full-context 模型与 5 个记忆系统上表明：最强模型 Gemini-3-Flash 平均 SR 仅 64.2%，EMem 在固定 GPT-5.4-mini 骨干下以 58.9% 成为最优记忆系统并改善 ERR；其中”删除决定性历史证据导致大幅掉分”（Δ=11.1/21.4，带 CI）与”三类记忆消融各自掉分”的证据较强，但家族级因果依赖极不均匀（Dynamic Tracking 与 Interaction Failure 上删除历史几乎不掉分甚至反弹）、主 leaderboard 无方差报告、且”扩大视觉上下文无益”的结论未被帧采样混杂排除。本文最有价值的部分是一个可执行、带因果控制与人工审查的记忆评测回路；最大的审稿风险是四个任务族中至少两族的”记忆必要性”未能被论文自己的控制实验支持，以及主要排名结论缺少统计稳定性。

  • 问题定义清晰度：强。episode 三元组 (H,T,A)(\mathcal{H},\mathcal{T},\mathcal{A})(H,T,A)、四族划分、SR/ERR 定义与评测协议（C.1）都写得可执行、可复现；与已有基准的差异有 Table 1 的逐维对照。
  • 创新性证据：中。基准本身与因果控制实验是实质增量；ERR 的实现比公式外观简化（Ki=1K_i=1Ki​=1）；EMem 是已有组件的新组合，其优越性未经多骨干与同训练条件的对照。
  • 方法可信度：中。记忆读写的确定性后端 + 只允许 schema 合法调用是稳妥设计；但检索质量、写入正确率等中间量未评估，收益无法与检索策略选择分开。
  • 实验支持力度：中。模型覆盖广、附录实验（D.1/D.2、Table 8–13）质量高、有 CI 与 quartile 分析，这些都超出平均水平；但主表缺方差、家族级效度不均、单骨干记忆对比、”更多视觉历史”结论存在未排除的混杂。
  • 可复现性：中。评测协议、prompt 模板（Figures 8–9）、LoRA 超参与工具 schema 均已给出，且有项目页（https://zju-omniai.github.io/EmbodiedMemoryBench/）；但 teacher 模型身份、各基准模型的调用配置、记忆系统适配细节与资源释放情况无法从论文确认。
  • 综合阅读价值：高。对做具身 agent / 长程记忆 / 基准设计的研究者，这是一篇值得精读的论文：它的基准设计与因果控制协议可直接借鉴，而它在家族级效度与统计报告上暴露的问题同样有教学价值。
