0. 一句话结论

在 Qwen3.5-9B/4B/2B 三个规模上，作者发现按领域标签路由的多教师在线策略蒸馏（MOPD）学生既打不过”最强单教师学生”，也学不到数学专家的大部分增益，并测到各领域教师反馈的尺度严重不平衡（首批次中指令遵循反馈的离散度是整体信号的 2.3–4.4 倍，且为初始 4B 学生贡献 94% 的合成梯度）；为此提出 DN-MOPD，保持路由不变、按批次给每个领域一个被裁剪的有界乘子 wd=clip⁡(σall/σd, 0.25, 4)w_d=\operatorname{clip}(\sigma_{\mathrm{all}}/\sigma_d,\,0.25,\,4)wd​=clip(σall​/σd​,0.25,4) 重标定其蒸馏优势。六基准平均分在三个规模、两个评测长度上限、三个学生种子上一致优于 Label 路由（16K 下 +1.17+2.36 pp，8K 下 +2.47+3.08 pp），并恢复大部分丢失的数学增益；但作者自己的控制实验显示增益主要来自”压低 IF 反馈”（固定常数权重即可复现大部分收益），全部非 OPD 基线（SeqKD-SFT、task arithmetic）的总分仍更高，且该收益依赖具体构造（作者早期的 Qwen3-4B 构造上无增益）。因此证据支持”修正了所测 OPD 配方”，尚不支持”反馈尺度标定是普遍必要的整合原则”。

1. 论文具体想解决什么问题？

研究背景与任务。 LLM 后训练越来越按领域分工：数学用可验证奖励的 RL（Shao et al., 2024; DeepSeek-AI et al., 2025），代码用执行反馈（Cui et al., 2025），指令遵循（IF）用约束检查（Lambert et al., 2024; Pyatkin et al., 2025）。这些管线数据、奖励、优化都不同，通常从同一初始化出发各自训练出一个领域专家，而部署需要”一个模型同时具备三域能力”（§1，原文事实）。多教师在线策略蒸馏（MOPD，Ma et al., 2026；Uni-OPD，Hou et al., 2026）在策略空间做整合：学生自己采样回答，每个 prompt 按领域标签路由给对应专家，专家对学生自己的回答逐 token 给出 log-prob，形成稠密的蒸馏信号（Agarwal et al., 2023; Gu et al., 2024）。该配方已被多篇近期前沿模型后训练工作采用（§1 引用 DeepSeek-AI、NVIDIA 等 2026 年报告）。

现有方法如何处理权重。 路由规则只决定”谁教”；每个领域损失/反馈占多大权重，要么手工固定，要么按”剩余 teacher–student gap”或 token 份额设置（Gao et al., 2026 的 Open-MOPD 按领域平均奖励幅度的运行估计分配权重、做 token 分配与域预算）。作者指出：这些权重都不考虑各专家反馈本身的离散程度，而不同 RL 管线训出的专家，其反馈尺度不必可比（§1、§2，作者主张）。

现有方法的失效条件（本文的核心观察）。 在独立训练的 Qwen3.5-9B/4B/2B 三套专家池上，label 路由的 MOPD（表中记作 Label）学生：

  • 在任一个规模上都没有超过”最强单教师学生”（六任务 Total：58.4 vs 58.5；50.3 vs 50.9；26.6 vs 28.8，Table 1–2、Table C.6，原文事实）；
  • 几乎不传递数学专家的增益：8K 评测下只保留数学专家增益的 14–32%；16K 下数学相对初始化没有增益，4B 上甚至显著低于初始化（Table E.1：Label 数学增益 −0.86/−1.98/−0.60 pp，其中 4B 的区间不含 0）。

Fig. 3 解读（上图）： 三个热图为 9B/4B/2B 三个专家池在 16K 下的”相对共享初始化的增益（pp）”，行为专家（Math/Code/IF expert）、列为评测域（Math/Code/IF），每格是该域两个任务的平均；对角线三格加黑框标记”专家在自域”的位置。读法有三点：(i) 每个专家的对角格全为正（如 Math expert 在 9B 数学 +4.5，Code expert 在 2B 代码 +10.3，IF expert 在 2B IF +9.4），说明可迁移能力确实存在；(ii) 非对角格有正有负（IF expert 在数学域 −2.6/−1.5/−1.9，Math expert 在 9B 代码 −1.7），说明单教师迁移也会”带副作用”；(iii) 关键对比是这张图与 Table E.1 的并置——数学专家在 9B 的 +4.5 到了 Label 学生手里只剩 8K 下的不到三成（保留率 14–32%），16K 下不升反降（−0.86），而”数学单教师 OPD”能拿到 +4.09（9B，16K）——由此论文把问题定位为”组合时机的问题”，而非”教师教不动”。

支撑问题判断的证据。 作者在训练信号上直接测到不平衡（§2、§3.2、App. D，原文事实）：

  • 第一个训练批次（与 Label 共享同一初始学生，故也代表 Label 的起点）中，IF 的 log-ratio 离散度比例 σd/σall\sigma_d/\sigma_{\mathrm{all}}σd​/σall​ 为 4.41/2.93/2.32（9B/4B/2B），数学约 0.5（0.57/0.50/0.48），即 IF 离散度是整体信号的 2.3–4.4 倍（Table D.1）；
  • IF 回答很短，只占约 1% 的响应 token，却贡献 51%/21%/19% 的池化 log-ratio 方差（Table D.2、App. D.5）；
  • 在初始 4B 学生上按训练用的 response 级 reduction 计算逐域梯度：IF 梯度范数是数学/代码的 5–15 倍，等权下 IF 损失项贡献 94% 的合成梯度；把损失改为按 token 平均仍不能消除失衡（IF 仍占 88%）（Table D.3、App. D.5）；
  • IF 梯度还是三个域中方向最不一致的：两个不相交 prompt 子集的梯度 cosine 只有 0.41，而数学/代码为 0.89/0.88（Table D.3）。

作者认为的原因与核心假设。 作者主张：路由决定反馈来源，但不校准反馈尺度；由于所有域更新共享的同一套参数，”哪个域的反馈幅度大”就劫持了更新（§1–§2，作者主张）。据此论文验证的核心假设是：把每个领域的反馈按批次测得离散度重标定到共同尺度（有界、保号）即可改善多教师整合，且这一操作不需要改路由、不需要额外教师调用（§1 贡献清单、§2）。

三类问题的区分（审稿人判断）。 （i）”多专家整合”与”OPD 训练-推理失配”是领域早已存在的普遍问题；（ii）本文的新观察是把”反馈尺度/离散度失衡”作为 MOPD 失效的候选原因并用训练信号量化（前述 2.3–4.4 倍、94% 梯度份额等），这是具体、可核对的测量，但注意这是现象与相关测量，不是完整的因果证明——论文自己在 App. D.2 承认”数学放大与数学增益的对应关系不能识别因果”（9B 上代码乘子同样被放大却无代码增益）；（iii）本文实际解决的具体子问题是：在 Qwen3.5 同族、数学/代码/IF 三域、同规模教师-学生的设定下，把 label 路由配方的整合效果提升到超过最强单教师学生，并恢复大部分数学迁移。

2. 创新点是什么？

一段话概括。 真正的技术增量只有一个操作：在 label 路由的 MOPD 训练循环里，每批次用 rollout 阶段已缓存的 teacher–student log-ratio 估计”每个域相对整体批次的离散度比例”，给每个域一个有界乘子 wd=clip⁡(σall/σd, 0.25, 4)w_d=\operatorname{clip}(\sigma_{\mathrm{all}}/\sigma_d,\,0.25,\,4)wd​=clip(σall​/σd​,0.25,4)，乘在将要进入裁剪策略梯度目标的蒸馏优势上（stopgrad 后使用）。它不改变路由、不改变提示配比、不引入 learned router、不额外调用教师；MOPD 就是 wd≡1w_d\equiv 1wd​≡1 的特例。差异在于标定对象：已有工作调节的是”各域损失权重/预算/奖励幅度”，本文调节的是”每个域反馈信号自身的尺度”。

逐项分析（含与最近已有工作的差异）：

  1. 新增机制：有界、保号的域级离散度乘子（§2”Domain normalization”与”Student update”两小节，公式未编号）。 统计量 ri,t=ℓi,tT−ℓi,trollr_{i,t}=\ell^{T}_{i,t}-\ell^{\mathrm{roll}}_{i,t}ri,t​=ℓi,tT​−ℓi,troll​ 按有效 token 池化，σd\sigma_dσd​ 为域内总体标准差，σall\sigma_{\mathrm{all}}σall​ 为跨域池化标准差；乘子对”离散度小的域放大、离散度大的域衰减”，未裁剪时满足恒等式 Std⁡(wdrd)=σall\operatorname{Std}(w_d r_d)=\sigma_{\mathrm{all}}Std(wd​rd​)=σall​。只乘正因子、不减去域均值，保留每个优势的方向语义。与最接近的 Open-MOPD（Gao et al., 2026）相比有三处明确差异（App. D.1）：按离散度而非均值奖励幅度缩放；每批次重估而非运行估计；裁剪区间 [0.25,4][0.25,4][0.25,4] 而非 [0.05,20][0.05,20][0.05,20]。与 PowerOPD（变换采样 token 奖励幅度）、ExOPD（reward/KL 平衡）、DAPO/Dr. GRPO（response/token 级归一化）、多任务学习的梯度范数/不确定性加权、PopArt（值目标归一化）等，作者主张 DN-MOPD 针对的是”多教师反馈尺度”这一未被处理的失衡（§4）。原创边界说明：依据本文 related work 与实验对比，只能确认作者声称的这些差异；是否构成该问题的首次提出，需要更完整的文献检索。
  2. 对应问题的逻辑。 如果”IF 反馈离散度是整体 2.3–4.4 倍、且贡献 94% 初始梯度”成立，那么按离散度把所有域拉到共同尺度，应直接削减这种劫持；wdw_dwd​ 全为 1 时严格回退到 Label，因此任何相对于 Label 的差异只能来自这一操作（Table 3 的对照设计）。该逻辑的实证强度有界限：见 §4.3 与 §5 质疑 1——实验显示”压下 IF”才是有效成分，”放大数学”（离散度匹配的另一半）单独只恢复一半甚至极少，且离散度归一化未验证因果。
  3. 对”不可替代性/有效性”的原文证据。 （i）替换路由的两类变体（Uniform pooling 教师概率平均、Dynamic 按当前回答选教师）在三个规模均无一致增益（Table 3：−0.41/−0.69/+0.30 与 −0.25/+0.28/−0.07），说明”改分配”不够；（ii）保留 Label 路由但只改信号的其他干预（annealed injection 早期模仿）也没有一致增益（−0.24/+1.11/+0.30）；（iii）固定权重控制（App. C.6，Table C.11）给”离散度标定”做减法：只把数学放大到 2（其余为 1）在 4B 只恢复约一半收益（+1.20 vs DN 的 +2.24），2B 几乎没有（+0.27 且区间含 0）；只把 IF 压到 0.25 则恢复大部分（+1.79/+2.19），并把数学域均分抬高 2.76/3.07 pp。这意味着”有效的成分”主要是给高离散域的反馈设上限，而非归一化本身（原文事实+审稿人判断）。
  4. 工程实现性质。 相对已有优势：一次池化标准差 + 每域标准差的计算，复用 rollout 已缓存的 log-prob，无额外教师前向（§2 “Cost and scope”、App. D.1）；相对 Label 只改 advantage 计算，其余（掩码、reduction、clip 界）原样继承（App. D.1）。这是”已有组件（PPO 式裁剪目标 + 优势重标定）在特定统计量上的新组合”，不是全新训练范式。

3. 作者如何解决？

直觉（先讲清”为什么可能有效”）。 把三个教师想成三位口径不同的顾问：数学教师说话”温吞”（log-ratio 幅度小），IF 教师说话”激烈”（幅度大且乱）。学生同时听三个人，虽然每人给的意见都标了方向（正/负号），但音量差了好几倍，结果激进、方向又最不一致的那位主导了学生的每一次修改。DN-MOPD 的做法不是换顾问（不改路由），而是每轮先量一遍各自音量，然后给每人配一个音量旋钮——离散度大就调小（压上限）、小就调大（提增益），旋钮被限定在 4 倍以内以防极端值，并且只调音量、不改意见的正负。教学简化示例：以上”音量旋钮”类比只用于直觉说明，不是论文中的表述，也不是论文实验的一部分。

4. 解决得怎么样？

4.1 实验设置

  • 模型与数据： Qwen3.5-9B/4B/2B 各一套独立训练的数学/代码/IF 专家池；学生与专家同规模、同初始化；主 OPD 比较在同一规模内共享专家、初始化、提示混合与更新预算（§3、App. A.1）。评测：AIME25/AIME26（各 30 题 ×64 采样）、LiveCodeBench v5/v6（167/175 个互不重叠问题 ×6 采样）、IFEval-541 与 IFBench-300（×16 采样，strict prompt-level）；数学用 Math-Verify 取最后一个 boxed 表达式（缺失记错），代码用官方 LCB runner（每题全部测试通过才算对）；评分为 avg@N（先题内平均再跨题平均，估计单答案正确率，非 pass@N）。评测使用 non-thinking 渲染、temperature/top-p 1.0、生成种子 42，同一 checkpoint 在 8K 与 16K 两个回答上限下各评一次（App. A.3）。
  • 基线： 初始学生；三位 RL 专家；三个单教师 OPD 学生；Uniform pooling（教师概率平均）；Dynamic router（按当前学生回答选教师）；Label 路由 MOPD；SeqKD-SFT（对教师固定答案做离线蒸馏，16K cap、84 updates、约 4 遍固定答案）；参数平均与 task arithmetic（λ=1\lambda=1λ=1）合并（Table 1–2）；外加消融型对照：annealed injection、固定权重（数学×2、IF×0.25、首批次权重、全局 2/1/0.25）（Table 3、C.11）。
  • 统计口径： 配对 95% 区间用 10,000 次 question-level bootstrap（种子 20260923），条件在单一学生训练种子与单一专家池上，不覆盖专家重训或学生重训方差（App. A.3）；种子 43/44 只改变 prompt 顺序与 rollout 采样（App. C.5）。”最强单教师学生”按同一 public Total 选择（此选择对比较对象有利，作者明说 “favoring that comparator”）。
  • 方法选择与报告口径（App. A.4，重要背景）： 域缩放操作与裁剪界在早期 Qwen3 开发仪器上选定后原样迁移到 Qwen3.5；主表显示 16K 是检查两个 cap 之后的展示选择（原协议为 8K），作者主动披露为 “presentation amendment, not a preregistered preference”，并保留全部 8K 结果。
  • 附注（透明度）： 论文附 AI use statement，说明作者用 LLM agents 编写训练/评测脚本、起草文字并在作者指导下核对引用与重算数字，人类作者声明对全部结论负责（§AI use statement，原文事实）。

4.3 机制证据

先分开两类证据（审稿人判断）：

效果证据（方法是否有效） 是充分的：主对比固定了教师、初始化、提示与更新预算，只改反馈权重；三规模×两 cap×三种子的方向一致，且第二大 Label 重跑给出噪声量级参照。

机制证据（为什么有效） 分三层，强度递减：

  1. 失衡的存在性有直接测量：首批次 σd/σall\sigma_d/\sigma_{\mathrm{all}}σd​/σall​（Table D.1）、IF 的方差份额与 token 份额错位（Table D.2）、逐域梯度份额 94%→（DN 首批次权重下）64%、数学/代码份额 1%/5%→16%/20%（Table D.3）、IF 梯度方向一致性最差（0.41；Label 训练 80 updates 后降至 −0.07）。这些测量显示”IF 反馈在共享更新中占比失衡”是训练前的既有事实，而非 DN-MOPD 造成。
  2. 操作与结果的对应有正有反：放大数学与数学增益出现同向对应（Fig. 4a/4b/4c：数学乘子全程 1.5–2.2、数学域增益 +3.7~+4.0），但作者自己给出两个反例——(i) 9B 的代码乘子同样被放大到 ≈1.5，代码在 16K 却无增益，故”放大不保证增益”（App. D.2）；(ii) 固定权重控制表明”只压 IF”就恢复大部分增益，说明起作用的主要是限制高离散域的影响，而不是”离散度匹配”这一机制本身（§3.2、App. C.6）。训练 80 updates 后：DN-MOPD 学生的数学/代码 log-ratio 标准差收敛到 0.07/0.12，Label 学生的为 0.20/0.41（初始 0.31/0.68），与”DN-MOPD 学生吸收了更多数学/代码反馈”一致（App. D.5）。
  3. 因果与替代解释的排除不完整：作者明说梯度测量是描述性的（单一 probe 集、policy ratio 为 1、不含裁剪与优化器状态），”不构成能力差异的原因证明”（App. D.5）；对 σ_all 混合域均值差项、token-pooled 统计 vs response 级损失的 reduction 差异都做了说明，但未单独消融统计量选择、裁剪界、域配比（App. D.4 原文承认 “The experiments do not separately vary the clipping bounds, domain proportions or the statistic used to estimate scale”）。此外，唯一被证伪（在 9B 上）的替代解释是”更长的生成”——DN-MOPD 的回答更短、触顶更少（Table 4）。

Fig. 4 解读（机制证据的主图）： 面板 (a) 用对数轴展示各域相对离散度 σd/σall\sigma_d/\sigma_{\mathrm{all}}σd​/σall​ 的中位数与四分位（覆盖含续训的全部记录批次）：数学（橙点）稳定低于 1、代码（蓝方）≈1、IF（紫三角）数倍于整体——这是”失衡持续存在”的证据；面板 (b) 是 DN−Label 的分域增益（16K 点估计）：数学 +4.0/+3.8/+3.7、代码 −0.8/+2.1/+2.9、IF +0.4/+0.8/+0.5——说明优点集中在数学、代码跨规模不稳定、IF 基本持平；面板 (c) 是训练过程中的乘子轨迹（每规模一列，虚线在第 80 update 处）：数学（实线橙）全程约 1.5–2.2，代码（蓝）≈1（9B 略高），IF（紫实线）贴着 1/4 下限、其”裁剪前原始乘子”（点线）低到约 1/8——**该面板直接显示规则对 IF 是”限幅”而非”等化”**，也是”增益主要来自压 IF”这一判断的原始出处。

4.4 成本与适用范围

  • 训练成本： 相对 Label 无额外教师前向、无新增可学参数、无额外模型；每批次多两次标准统计与一次标量乘（§2、App. D.1）。论文未报告 GPU 小时数、墙钟时间、教师池构建总成本（三规模×三专家，各 200–400 GRPO update）以及存储量；因此”低开销”只能理解为算法级增量小，绝对成本无法从原文核验。
  • 推理成本： 无变化（方法不改结构/解码，§2；Table 4 显示推理回答反而更短、触顶更少，但作者提示平均长度不等于时延/成本）。
  • 人工/外部依赖： 无人工标注新增；教师池、提示数据与评测集均为公开或自建数据（App. A.1、Ethics statement：无人类受试与个人数据；代码 judge 在资源受限沙箱运行）。
  • 复现材料： 仓库发布 80 个评测模型的逐题对错、重算全部分数与区间的脚本、DN-MOPD 参考实现与单元测试、训练配方；checkpoints 未发布（Reproducibility statement）。
  • 适用范围（论文自身边界，§5）： 单一模型家族、每规模一个专家池、三域设定；学生种子不覆盖专家重训；方法在 Qwen3 开发仪器上选定（App. A.4）并存在 Qwen3-4B 无增益先例（App. E.2）；标定值依赖域构成与回答长度；裁剪界未按规模调参；收益在 16K 评测上限下收缩；**”收敛后的最终排序未解决”**（§3.3）。得到改善的问题：Qwen3.5 池上 label 路由整合效果逼近/超过最强单教师学生、数学迁移恢复大部分。仍未解决：跨家族/跨池的普适性、per-batch 估计何时值得（只在 2B 检出）、相对更强离线整合方法的差距。

质疑：增益的主要来源是”压下 IF 反馈”，而不是论文标题与摘要主打的”域归一化/离散度匹配”机制，固定常数权重即可复现大部分收益

  • 原文依据： Table 3 与 Table C.11：只压 IF（1/1/0.25）在 4B/2B@16K 相对 Label 为 +1.79/+2.19，与 DN-MOPD 的差仅为 −0.44 [−1.35,+0.48] 与 −0.17 [−0.84,+0.52]；”首批次乘子固定全程”在 9B/4B 与 DN-MOPD 无可测差异；Table D.1 显示 IF 乘子长期贴 0.25 下限（”bounds rather than equalizes”）。
  • 为什么重要： 这决定创新性的定位——若一个训练前测一次即可固定的常数能达到同样效果，那么”每批次用离散度统计做自适应标定”的必要性与其机制解释都被显著削弱（论文自己也承认 per-batch 的增量只在 2B 被检出）。
  • 当前能够得出的判断： “反馈尺度需要标定”这一结论有证据；”离散度归一化是正确机制”只有间接支持且有反例（9B 代码被放大但无增益；σ_all 混有域均值差项）。结论范围应限定为”在测量驱动下给主导域限幅”。
  • 如何验证或补强： 在更多规模/域组合上系统比较 per-batch 与多组固定权重；对裁剪区间 (0.25,4) 做消融；报告”只放大数学”在更大规模是否也失效；给出”何时该相信 per-batch 估计”的判据。
  • 严重程度： 主要问题。

质疑：外部有效性有限——所有正向证据来自 Qwen3.5 一族三规模、每规模单一专家池，作者自己的前身构造无增益

  • 原文依据： §5 limitations：one expert pool per size within one model family；App. E.2：Qwen3-4B 构造 ΔTotal +0.02 [−0.56,+0.59]，各域区间含 0，且该构造下数学乘子中位数是 1.00；App. A.4：方法在早期 Qwen3 开发仪器上选定后迁移；App. A.3：置信区间条件在单一学生种子与专家池上，不覆盖专家重训。
  • 为什么重要： 论文的结论句（”整合专家需要同时决定谁教与反馈多强”）是原则性主张，但证据只是一个家族的三个规模，且存在一个同作者反例；跨模型家族、跨域数、跨专家训练方式的可迁移性无法从前文确认。
  • 当前能够得出的判断： 在 Qwen3.5 三规模（三域）上成立；作为普适原则”无法确认”。作者对这一点披露充分，没有夸大。
  • 如何验证或补强： 在第二、第三个模型家族与不同 RL 配方（如不同 KL/奖励塑形）上复现；重训专家池多份以估计池间方差；扩充到 4 个以上域。
  • 严重程度： 主要问题。

质疑：与更强的离线整合基线相比总分全面落后，缺少 compute-matched 的公平对照

  • 原文依据： Table 1–2：SeqKD-SFT（62.6/55.9/32.9）与 ParamMerge-TA（60.5/53.2/32.7）在三个规模均高于 DN-MOPD（59.6/52.5/29.0）；App. A.2 说明 SeqKD 用 16K cap 的固定教师答案训 84 updates（约 4 遍）、LR 10−510^{-5}10−5，教师答案库复用——与 OPD 的 token/优化预算不同；§3.1 原文：”SeqKD-SFT and task arithmetic retain higher Totals under their own training recipes”。
  • 为什么重要： 读者最关心的问题是”部署时该选哪条路线”；若离线蒸馏在此设置下更便宜且更强（9B 的 SeqKD 学生 62.6 甚至超过所有专家本身的最高 58.9），那么本文”OPD 整合”的价值主张只在”必须与现有 OPD 管线兼容”这一狭窄前提下成立。
  • 当前能够得出的判断： 现有证据只支持”DN-MOPD 改进了 label 路由配方”，不足以支持”OPD 整合优于离线整合”；预算不等使跨路线比较无法定论，但也意味着”DN-MOPD 是更好的整合方法”这类外推不成立。
  • 如何验证或补强： 匹配 token/FLOP 预算的离线蒸馏 vs OPD 对照；报告两种路线在相同教师池上的 scaling 曲线；解释 SeqKD 学生为何能超教师（多域数据协同？），并检查 OPD 学生是否也有该效应。
  • 严重程度： 主要问题（对论文的定位与结论表述），方法本身的增量不受影响（次要）。

质疑：统计效力与稳定性——区间条件于单一种子与单池，关键比较区间含 0，题目规模小

  • 原文依据： App. A.3（区间不覆盖专家/学生重训方差）；App. C.5（种子 43/44 只改 prompt 顺序与采样，非全量独立重复）；Table C.6（DN−single 在 9B@8K、2B@16K 含 0）；AIME 仅各 30 题；Table C.11 的固定权重控制只用单种子。
  • 为什么重要： 论文最强主张是对 Label 的稳定改进（证据较好），次强主张是”超过最强单教师学生”（证据较弱）；若采纳者以”超过单教师学生”为选择依据，2B/16K 的 +0.13 无法支撑。
  • 当前能够得出的判断： 对 Label 的增益在三规模两 cap 三种子方向一致、可视为稳健；”超过最强单教师”目前只在部分单元可分离，属临界结论。
  • 如何验证或补强： 多个独立专家池与完整种子矩阵（含重训专家）；把最强单教师学生也纳入多种子对照；增大 AIME 等题量或增加补充数学基准（已有 MATH-500 可扩样）。
  • 严重程度： 次要问题（对主结论）+ 主要问题（对”超过单教师”这一小节结论）。

质疑：评测协议存在事后自由度——主表 16K 是检查两个 cap 后的展示选择，增益对评测长度敏感

  • 原文依据： App. A.4（原协议 8K，”The choice to show 16K in the main text was made after both caps had been inspected”，作者自述为 presentation amendment）；增益在 8K 更大（+2.47+3.08）而在 16K 收缩（+1.17+2.36），且”允许更长回答对 Label 帮助更大”（§3.3、App. C.3）；MATH-500 在 9B/4B 接近天花板（Table C.12）；Total 为作者自定义的六任务等权平均，会掩盖域内反向变化（如 9B 代码专家在数学域 −1.7，Fig. 3）。
  • 为什么重要： 这类”事后选择展示口径”即使被披露，也会改变读者对效应大小的感知；结论对回答长度预算的敏感性意味着使用场景（生成预算）会成为方法有效性的隐含条件。
  • 当前能够得出的判断： 作者披露充分（含全部 8K 表），未发现选择性隐藏；但”效应大小”应同时读两个 cap，且不应以 16K 的收窄结果反推 8K 也如此。
  • 如何验证或补强： 预注册单一评测协议，或全部 cap 平行报告并预先声明主口径；报告 Total 之外的域级与稳健性摘要（论文已有）。
  • 严重程度： 次要问题。

6. 审稿式总评

作者发现按领域标签路由的多教师在线蒸馏不能把 RL 专家的能力真正整合进一个学生（打不过最强单教师学生、数学几乎不迁移），并把原因落到一个可直接测量的量——各域 teacher–student log-ratio 反馈的尺度失衡（IF 首批次离散度为整体的 2.3–4.4 倍、贡献初始 4B 学生 94% 的合成梯度）；因此提出 DN-MOPD，通过每批次、按域、有界且保号的乘子 wd=clip⁡(σall/σd,0.25,4)w_d=\operatorname{clip}(\sigma_{\mathrm{all}}/\sigma_d,0.25,4)wd​=clip(σall​/σd​,0.25,4) 重标定蒸馏优势，以近乎零的算法增量接入现有 MOPD 管线。实验在 Qwen3.5-9B/4B/2B 的六基准上表明：平均分在两个评测上限与三个种子下一致优于 Label 路由（16K +1.17+2.36 pp，8K +2.47+3.08 pp），并把数学迁移率从 14–32% 提到 61–90%；其中”优于 Label”的证据较强（固定教师/数据/预算的配对设计、完整附录、公开重算脚本），但”机制是离散度归一化”仍缺少充分支持——作者自己的控制实验显示固定常数权重即可复现大部分收益、且增益主要来自压制 IF；”超过最强单教师学生”在 2 个单元仍含 0，”优于离线整合路线”则被 SeqKD/参数合并更高的总分否定。本文最有价值的部分是问题诊断的诚实度与控制实验的完整度（含对自身叙事不利的固定权重与边界构造），最大的审稿风险是创新点与标题叙事（”域归一化”）被自身证据降格为”给高离散域限幅”的工程校准，且外部有效性尚未跨出 Qwen3.5 一族。

  • 问题定义清晰度： 强——失效条件（不超单教师、数学不迁移）与原因测量（离散度、梯度份额）都有明确数字与位置。
  • 创新性证据： 中——机制是单点、简单的组合式改进；自证实验中”每批次自适应”相对固定常数只在 2B 显现，原创边界需更完整文献检索。
  • 方法可信度： 中——公式、实现、恒等式与退化处理都清晰且可复现，但论文对”为什么有效”的机制叙事与自身控制实验存在张力。
  • 实验支持力度： 中——对”优于 Label”强（3 规模×2 cap×3 种子+完整附录+公开记录）；对”超过单教师””跨构造普适”弱（含 0 区间与 Qwen3-4B 反例）。
  • 可复现性： 强——评分级复现材料（逐题记录、重算脚本、参考实现、单元测试、训练配方）已发布；checkpoints 尚未发布使训练级复现暂无法核验。
  • 综合阅读价值： 高——这是一篇诊断先于方法的诚实研究，适合作为”如何用控制实验检验自己机制主张”的案例阅读。
