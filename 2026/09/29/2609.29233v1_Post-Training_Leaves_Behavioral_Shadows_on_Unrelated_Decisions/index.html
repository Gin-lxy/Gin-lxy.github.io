0. 一句话结论

论文研究的问题是：一次私有的后训练更新（post-training）会不会在与目标任务无关的日常行为上留下可观测痕迹，且学习这些痕迹能否把部分目标能力迁移给另一个模型。作者提出 ATD（Active Taskless Distillation）：用公开祖先模型挑选它对两个普通单词”近乎无所谓”（near-tie）的无关提示，每个提示只向私有教师索取 1 个贪心 token，学生从同一祖先出发只在这些”提示–单词”对上学交叉熵。在 Qwen2.5-1.5B 的编码实验里，5,664 条单词级样本使学生在 HumanEval+ 上比精确配对控制高 5.34 pp（95% CI [1.22, 9.60]，Table 1），并跨 7 个任务、5 次独立采集（15/15 为正）方向一致。证据边界：主端点的识别证据较强（执行式评测、多重对照、采集级重复），但机制解释基本是表征相关性，跨模型泛化增益的置信区间包含 0，结论应限定为”已知同源公开祖先、教师有明显且学生可表达的能力提升、提示位于祖先决策边界”这一条件内。

1. 论文具体想解决什么问题？

背景与任务。 post-training（SFT/DPO 等）通常按目标任务行为来评估：代码更新让模型写更好的代码。但更新的影响未必局限在目标任务上——它也可能改变模型在短故事里偏好哪个普通单词（§1）。作者把这类”在任务无关输入上发生的行为变化”称为 behavioral shadow（行为影子），并追问它是否携带与能力相关的信息。由此定义两个具体问题（§1）：

  1. Observability（可观测性）：不接触更新后的参数、也拿不到目标任务回答，仅凭无关输入上的单个决策，能否观测到一次私有的 post-training 更新？
  2. Capability transfer（能力迁移）：从这些决策中学习，能否把教师的一部分目标能力提升迁移到另一个模型？

现有方法怎么处理。 相关工作分四条线（§2）：(a) subliminal learning 证明行为特质/偏好可以通过语义无关的训练数据传递，但主要面向 traits/preferences，且依赖大量教师输出；(b) 经典蒸馏/on-policy 蒸馏需要教师分布或对教师生成内容的监督，黑盒蒸馏仍需教师文本；(c) 主动学习与模型抽取（Knockoff Nets、ActiveThief 等）会用不确定/边界输入做查询，但目标是复刻或指纹识别黑盒模型；(d) task vector 视角把后训练看作参数差 δ=θT−θ0\delta=\theta_T-\theta_0δ=θT​−θ0​。作者的位置是：能力（而非特质）迁移，且每个查询只保留单个 token 的观测。

新观察与假设。 论文的设定是”已知祖先”（§3）：公开模型 M0M_0M0​ 与私有教师 MT=θ0+δM_T=\theta_0+\deltaMT​=θ0​+δ，学生从同一 θ0\theta_0θ0​ 初始化，教师只暴露黑盒接口（每个查询返回全词表贪心 top-1），且查询集必须在看到任何教师响应之前固定。核心假设来自一阶近似：对载体提示 xix_ixi​ 上两个候选词 ai,bia_i,b_iai​,bi​ 的 logit 差

2. 创新点是什么？

一段话概括。 ATD 的实质增量是一个极低带宽的黑盒探针 + 严格的对照构造：把查询主动放在祖先模型的决策边界上（near-tie），每个查询只取教师的 1 个 token 作为监督，学生从同一祖先出发做全词表交叉熵；同时给出一个用整数规划构造的 exact nuisance-matched 控制（受约束二分匹配），把”提示–token 的逐条对应”从词频、难度、翻转率等 nuisance 变量中分离出来。它属于”已有组件的新组合”（主动选样 × 黑盒观测 × 同源蒸馏 × 行为影子现象），并配了一个方法论上更讲究的控制臂，而不是全新的理论或架构。

逐项看：

  1. Near-tie 主动查询选择。 用公开祖先的概率定义 qi=exp⁡z0(bi∣xi)exp⁡z0(ai∣xi)+exp⁡z0(bi∣xi)q_i=\frac{\exp z_0(b_i\mid x_i)}{\exp z_0(a_i\mid x_i)+\exp z_0(b_i\mid x_i)}qi​=expz0​(ai​∣xi​)+expz0​(bi​∣xi​)expz0​(bi​∣xi​)​（Eq. 5），保留 ∣qi−0.5∣≤ϵ|q_i-0.5|\le\epsilon∣qi​−0.5∣≤ϵ（ϵ=0.02\epsilon=0.02ϵ=0.02）且祖先全词表 top-1 必须落在两词中的提示；查询集在看到教师响应前固定。与最接近的已有方法相比：subliminal learning 用教师的大量无关生成文本，这里把观测压到单 token，并把”问哪里”从被动采样改成主动的边界选择。不可替代性有实验：同等查询预算下主动超过被动 +4.27+4.27+4.27 pp [0.30, 8.38]，同等训练行数下 +5.03+5.03+5.03 pp [1.52, 8.84]（Table 3a，§5.4）——说明效应来自查询位置而非查询量/数据量。

对照证据（每个创新点的有效性证据）：near-tie 设计有 active/passive 对照（Table 3a）；单 token 通道有多 token 扩展（Table 5）；exact 控制有对应关系曲线（0%→100% 恢复配对，cosine 单调上升 .399→.460，Spearman ρ=1\rho{=}1ρ=1，Table 7）与分歧破坏实验（Table 8）；”影子”现象本身有源特异性热图与组合实验（Figure 4，Appendix E）与强度分级实验（Appendix G）。

原创边界的说明：根据本文的 related work 和实验对比，只能确认作者声称的差异（单 token、能力而非特质、主动边界选择、exact 匹配控制）；是否构成”首次提出”，还需要更完整的文献检索，本文没有给出与黑盒蒸馏/模型抽取基线在同等查询预算下的横向对比（见 §5 质疑 4）。

3. 作者如何解决？

直觉说明。 一次后训练会给模型参数加上 δ\deltaδ。δ\deltaδ 对目标任务的影响早已被评估；而它在”讲故事时更爱用哪个普通词”这类决策上也有微弱投影。假如随便挑一个提示问教师，祖先本来就有明显偏好，δ\deltaδ 很难翻转它；但如果在祖先”两个词各占 50.4% / 49.6%”这种近平衡点上提问，δ\deltaδ 引入的微小偏好变化就足以改变答案。于是每个”教师选了词 A 还是词 B”都是一比特关于 δ\deltaδ 的观测。把这些观测当作监督信号喂给一个与教师共享祖先的学生，相当于沿着这些决策的梯度方向注入 δ\deltaδ 的一个分量——局部一阶近似下，这可能是能力迁移的机制（Eq. 2–4）。

完整流程（按实际运行顺序）。

  1. 输入与设定：公开祖先 M0M_0M0​（主实验为 Qwen2.5-1.5B-Instruct），私有教师 MT=θ0+δM_T=\theta_0+\deltaMT​=θ0​+δ（主实验为冻结的 rank-16 code-DPO LoRA），学生从同一 M0M_0M0​ 初始化。教师仅通过黑盒接口访问：每个查询返回一个全词表贪心 top-1（§4）。
  2. 载体构造（不使用任何教师信息）：从经过冻结目标词过滤的 128 词安全词表 VsafeV_{\mathrm{safe}}Vsafe​ 中取两个普通单 token 词，放入固定指令模板（“…Choose exactly one of these two words. Reply only with that word.”），上下文是任务无关的短文本（Appendix A 给了一个真实载体：关于”龙虾与心脏如何出现在同一短篇故事”的提示后跟一串普通词，候选 jacket | tie）。用 M0M_0M0​ 计算 qiq_iqi​，保留 ∣qi−0.5∣≤0.02|q_i-0.5|\le 0.02∣qi​−0.5∣≤0.02 且祖先 top-1 在两词之内的提示（Eq. 5，§4）。
  3. 教师查询：每个保留提示查询一次；若教师返回的词不在候选对中，丢弃该例、不重采样。主编码采集共 17,85817{,}85817,858 次近平衡查询，保留 5,6645{,}6645,664 条（保留率 ≈31.7%）；这是训练信号的全部（Appendix B）。例如 Appendix A 中 P(tie)=0.5044P(\texttt{tie})=0.5044P(tie)=0.5044，教师选了 jacket，训练对就是 (prompt, jacket)——提示和标签都不含代码。
  4. 学生训练：全词表交叉熵 LCE(θ)=−1n∑i=1nlog⁡pθ(wiT∣xi)\mathcal{L}_{\text{CE}}(\theta)=-\frac{1}{n}\sum_{i=1}^{n}\log p_\theta(w_i^T\mid x_i)LCE​(θ)=−n1​∑i=1n​logpθ​(wiT​∣xi​)（Eq. 6，只有回应 token 计入损失），rank-16 all-linear LoRA + AdamW、冻结的 157 步计划（Appendix B）。
  5. 控制臂（同构训练，只换标签）：exact nuisance-matched（整数规划，Eq. 9–11）、global teacher-label shuffle、public-label（用祖先自己的 top-1，从不查询教师）、random-marginal（按教师侧边际独立采样）（Table 1，Appendix C）。
  6. 评估：目标基准只在冻结的评估阶段进入，训练/采集阶段从不出现；主端点 HumanEval+ 用 EvalPlus 执行式贪心 pass@1（Appendix B）。

哪些行为由模型决定，哪些由固定流程控制：提示构造、near-tie 过滤、查询预算、丢弃规则、训练步数全部是固定流程；模型决定的是”教师返回哪个 token”（教师侧）与”学生如何最小化 CE”（学生侧）。推理阶段没有特别变化：学生就是被微调后的模型，评估时按各自基准的常规协议解码。

代价与瓶颈（论文报告）：构造 qiq_iqi​ 需要祖先的概率（白盒访问公开 M0M_0M0​ 的输出分布），教师侧只需黑盒；17,85817{,}85817,858 次查询换来 5,6645{,}6645,664 行训练数据，约 2/3 的查询被丢弃。论文没有报告 wall-clock 或算力费用（未报告）。此外 Appendix H 指出通道是”低带宽”的：教师自身增益缩小时可恢复的东西也变小（MBPP+ 端点）。

图注（对应论文 Figure 1）：从左到右四个环节。Near-tie Probes：只用公开祖先 M0M_0M0​ 生成并筛选”对两个普通单词近乎无所谓”的无关提示（图中示意多组候选词对）；Teacher Readout：私有教师 MT=M0+δM_T=M_0+\deltaMT​=M0​+δ 对每个提示只返回 1 个词（图示 1 token/query），凡被更新”翻转”的近平衡点是 1-bit 的行为影子观测；Shadow Distillation：学生从同一 M0M_0M0​ 出发，只在真实”提示–词”配对上学（paired），对照臂沿用同样的词但打乱配对（shuffled），让学生经历相同的词频与预算、仅缺失逐条对应；Target Evaluation：训练时从未出现的目标任务（如 HumanEval+、ScienceQA）上比较 signal 与控制，图中右下示意”不同来源的影子抬升不同能力”（code shadow 抬高代码分、science shadow 抬高科学分）。这个流程的关键在于把”观测成本”压到每提示一个 token，同时用配对控制保证比较公平。

4. 解决得怎么样？

4.1 实验设置

  • 任务与数据：主端点 HumanEval+（164 题，执行式贪心 pass@1，EvalPlus）；数学 GSM8K（1,319 题，exact match）；多选题按选项答案似然评分（无 chain-of-thought）：ScienceQA（文本测试集 2,224）、OpenBookQA（500）、HellaSwag（10,042）、RACE-high（3,498）、CommonsenseQA（1,221）、PIQA（1,838）；次要代码端点 MBPP+（Table 13）。载体是任务无关的近平衡提示（主编码采集 5,664 行、128 词、冻结审计确认无代码/数学/基准/任务词与数字，Appendix B）。
  • 基础模型与教师：主系用 Qwen2.5-1.5B-Instruct 同时作为祖先与学生初始化；编码教师是在其上的 rank-16 code-DPO LoRA（DPO + 少量 chosen-token SFT 辅助），偏好对来自公开语料 KAKA22/CodeRM-UnitTest（revision 98879a4b，Apache-2.0），过滤后 13,607 对、按哈希划分 12,921/686，并预先剔除与 HumanEval+/MBPP+ 重叠的样本（exact prompt、entry point、5-gram Jaccard ≥0.1）。六个多选题教师共用一套配方：Qwen2.5-1.5B 上的任务特定 SFT LoRA（Appendix B）。学生是 rank-16 all-linear LoRA，157 步冻结计划。
  • 基线与对照：exact nuisance-matched、teacher-label shuffle、public-label、random-marginal 四个同构控制（Table 1）；主动 vs 被动采集（Table 3a）；两类 adversarial 教师（记忆答案、注入替换密码，Table 3b）；不兼容祖先教师（Table 12）；weak-gap 端点（Table 13）。探索性扩展：RPM 目标（Eq. 7）与多 token 观测（Eq. 8）。
  • 评价与统计：报”教师差距”（teacher − base）与”迁移”（signal − control）两个量；除非另有说明，所有区间是配对 signal−control 差的 95% bootstrap（100,000 次重采样，跨训练种子与任务）；5 次采集的鲁棒性因子还额外重采样采集轴（§5，§5.2）。
  • 各部分回答什么：§5.1 用多重对照做识别（增益是否来自更新本身）；§5.2 用重造采集/重训教师/换适应制度做鲁棒性；§5.3 做跨任务与跨模型泛化；§5.4 分析信号来源、路由与结构；§5.5 探测边界（大增益不保证迁移）；§6 是工具扩展（RPM、多 token）；附录 D–H 给诊断细节与失败边界。

4.2 关键结果

  • 主结果（Table 1，Qwen2.5-1.5B，HumanEval+ pass@1）：ATD 学生 51.22%，恰好等于教师的聚合分数（教师 gap 为 +7.93，base 43.29）；相对各控制臂：exact nuisance-matched 45.88 → Δ=+5.34\Delta=+5.34Δ=+5.34 pp [1.22, 9.60]（n=4 种子）；shuffle 46.19 → +5.03+5.03+5.03 [0.91, 9.30]；public-label（不查询教师）46.65 → +4.57+4.57+4.57 [0.91, 8.54]；random-marginal 45.12 → +6.71+6.71+6.71（单种子诊断，无区间）。由于 exact 控制臂在完成词多重集与难度分箱上完全一致，unigram 频率与标签边际无法解释这一 gap（§5.1）。
  • 鲁棒性（Figure 2）：5 个独立构造的采集（各自载体种子+私有教师+exact 控制）× 3 个训练种子共 15 个配对，15/15 为正、5/5 采集为正，聚合效应 +4.80+4.80+4.80 pp [1.18, 8.74]，采集间标准差仅 0.83 pp；换适应制度（教师与学生同制度）：LoRA r32 +6.55+6.55+6.55 [2.59, 10.82]、r64 +9.15+9.15+9.15 [4.88, 13.87]、全参数 SFT +4.67+4.67+4.67 [1.22, 8.54]（Figure 2b）。
  • 跨任务（Table 2，7 个任务）：所有学生都超过自己的 shuffle 控制，Δ\DeltaΔ 从 +0.81+0.81+0.81 pp（RACE-high，[0.24, 1.40]）到 +5.03+5.03+5.03 pp（HumanEval+）：ScienceQA +2.53+2.53+2.53 [1.57, 3.52]、HellaSwag +2.90+2.90+2.90 [2.44, 3.36]、OpenBookQA +2.07+2.07+2.07 [0.33, 3.87]、CommonsenseQA +1.94+1.94+1.94 [0.76, 3.19]、PIQA +1.25+1.25+1.25 [0.15, 2.38]。注意增益幅度与教师 gap 并不同比例（HellaSwag 教师 gap 达 +22.31，迁移仅 +2.90）。
  • 跨模型（Figure 3）：Llama-3.2-1B 17.1→17.5、Qwen2.5-1.5B 46.2→51.2、Qwen3-1.7B 56.5→59.5、Qwen3-4B 65.7→68.5（signal 对 shuffle）。论文明确说明：均值全为正，但后三个模型的配对 95% 区间包含 0。

图注（对应论文 Figure 3）：四条模型线按规模排序的 HumanEval+ pass@1，灰色为 teacher-label shuffle 控制、红色为 ATD 学生（柱顶数字为分数）。它支撑”跨世代/规模/家族方向一致”的主张，同时也是限定条件的直接证据：Llama-3.2-1B 的增益只有 +0.4 pp，三条新增模型线的配对区间含 0——这里应读作”方向一致但强度不稳健”。

  • 主动 vs 被动（Table 3a）：同等教师查询预算 +4.27+4.27+4.27 [0.30, 8.38]；同等训练行数 +5.03+5.03+5.03 [1.52, 8.84]——效应来自查询位置（祖先决策边界），不是查询量或数据量。
  • 大增益不保证迁移（Table 3b）：记忆 HumanEval+ 答案的教师（gap +39.02）训练出的学生 56.56 反而低于 base 59.15；注入替换密码的教师（gap ≈97 pp）学生 0.00/0.00。作者据此主张通道里传的是”学生可被引出的能力”而非教师的原始优势（§5.5）。
  • 其它边界：MBPP+ 上教师仅微弱领先（51.85→54.23，+2.38），ATD 迁移近零（+0.33+0.33+0.33 [−2.25, 2.91]，独立采集 +0.53+0.53+0.53 [−1.85, 2.91]，Table 13）；不兼容祖先（Qwen3-Coder-30B-A3B gap +17.68、Coder-7B gap +40.25）均不迁移（Table 12）。
  • 个体题层面（§5.4）：在教师相对祖先修复的 19 个 HumanEval+ 任务（76 个种子–任务格）中，ATD 学生解出 64.47%（49/76），匹配控制 21.05%（16/76）；任务级变化向量与教师的 cosine 为 .701 对 .398。Appendix A 给出可执行案例：HumanEval/158(find_max) 中教师与全部 4 个信号种子采用”按不同字符数排序”的规则，而 base 与对照用”按词长”——该规则从未出现在载体里；HumanEval/18 中教师与全部 4 个信号种子采用重叠计数规则，4 个对照中只有 1 个也是（论文自认这个案例区分度较弱）。
  • 探索性扩展：RPM 在 HumanEval+ 上把 shuffle 对比从 +5.03 提到 +6.30+6.30+6.30 [2.03, 10.98]，但对 public-label 的控制差 +4.47 含零，且在 OpenBookQA 上回退（+1.47，含零）——作者定性为”边界感知的改进而非全面更优”（Table 4）；多 token（K=20K{=}20K=20，Qwen2.5-0.5B）在 GSM8K 上 +6.37+6.37+6.37 [+4.37, +8.42]，HumanEval+ +1.02 与 ScienceQA +0.84 均含零，但 6/6 种子为正（符号检验 p=1/64p=1/64p=1/64）（Table 5）。

4.3 机制证据

这一节区分”方法有效”与”为什么有效”。

  • 源特异性（Figure 4(a)）：在 3 个影子来源 × 3 个端点矩阵中，每个影子的最大正效应都落在自己的匹配端点上（code→HumanEval+ +5.34+5.34+5.34、science→ScienceQA +2.52+2.52+2.52），非对角近零或为负（−0.15、−0.61、−0.17 等）；数学对角 +0.47 是行内最大但很小，作者归因于 1.5B base 在 GSM8K 近饱和。这排除了”通道传的是通用’更用力训练’方向”的解释。
  • 组合性（Figure 4b、Appendix E）：用几乎正交的两个来源（math 与 code 影子，来源间 cosine −0.0002）各 50% 混合训练，学生同时对齐两个方向（alignment advantage +0.046+0.046+0.046 与 +0.062+0.062+0.062，均 3/3 种子为正）——通道承载的是可叠加的混合，而非单一胜者。比例扫描（Figure 6）中 math 系数随混合比例单调上升（Spearman ρ=1\rho{=}1ρ=1，4/4 种子），但 GSM8K 端点上的 100% vs 0% 差只有 +0.28 pp [−0.80, +1.37]，不显著；作者明确说这是”功能性（functional）而非端点性”的证据。
  • 强度分级（Table 11、Appendix G）：沿教师的训练轨迹取检查点（code：80/160/240/320；SciQ：20/40/80/160），学生恢复的方向投影与教师强度同序（Spearman ρ=1\rho{=}1ρ=1，3/3 种子；单轨迹置换检验 p=1/24p=1/24p=1/24，两轨迹合并 1/5761/5761/576），甚至复现了 code 轨迹的非单调反转（320 虽训练更久但教师实际更弱）；但同样的恢复在可执行端点上做不到——端点太噪，无法排序检查点。即强度分级只是”恢复出的功能方向”的属性。
  • 对应关系定位（Appendix D）：固定完成词多重集、只改变恢复配对的比例（0%→100%），学生方向与教师方向的 cosine 严格单调上升（.399→.460，Spearman ρ=1\rho{=}1ρ=1，3 种子）；破坏实验中，抹掉教师–祖先分歧最大的 20% 状态代价最大（cosine 损失 .022，是随机破坏的 1.56 倍、最不分歧破坏的 2.86 倍），但 top-20% 破坏后仍有 .437，高于全打乱底线 .395——信息集中在高分歧状态但不仅限于此。
  • 早期对齐（Table 10、Appendix F）：训练过程中，对照消减后的教师方向功能对比在 step 4 起稳定为正（4/4 种子），step 16 时已达 .216；而可执行端点在 step 80 才第一次显著超过控制（+4.27），157 步达到 +5.34。作者明确写这是”suggestive“，不声称方向先于能力获得（两个轴的统计功效不同）。
  • 总体判断：这些证据说明信号**(a) 与教师更新的方向相关、(b) 特异于来源、(c) 不与词频/难度混淆；但它们是表征相关性**——没有证明从载体决策到目标任务提升的因果链。论文自己在 Discussion 中承认分不清失败场景是”观测里信息太少”还是”学习过程没能用足信息”（§5.5 Discussion）。

图注（对应论文 Figure 4(a)，代码/科学/数学三个来源 × HumanEval+/ScienceQA/GSM8K 三个端点的 signal−control 差值热图，黑框为对角线）：对角线为每个影子在自己的目标端点上的效应，非对角是”交叉迁移”。读法上它回答的是”通道是否只是一个通用方向”：若如此，同一行应处处为正；实际上非对角接近零或为负，说明影子携带的是来源特异信息。数学行整体偏弱需结合正文解释（1.5B 在 GSM8K 近饱和）。

4.4 成本与适用范围

  • 成本（论文报告）：主编码采集 17,85817{,}85817,858 次教师查询（每次返回 1 个 token），保留 5,6645{,}6645,664 条训练行（≈31.7%）；学生只需 157 步 rank-16 LoRA 训练（Appendix B）。查询与训练都很便宜，但论文未报告 wall-clock、GPU 时长或任何金额化的成本；也未报告查询预算的 scaling 曲线（更多查询能否带来更多迁移，未报告）。
  • 依赖与系统复杂度：需要白盒访问公开祖先 M0M_0M0​ 的概率（构造 qiq_iqi​），教师只需黑盒 top-1；教师语料与基准都是公开资源，不依赖闭源服务；代码已开源（github.com/myboker/ATD）。额外的复杂度主要在控制臂的整数规划构造与冻结审计（Appendix B、C）。
  • 得到的改善：证明了”能力相关信息可以经任务无关的单 token 通道被部分恢复”，且给出了比常见 shuffle 更严格的控制设计；主端点的效应可重复（15/15）。
  • 仍未解决的：
    • 传输并非普遍成功：MBPP+ 弱 gap 端点近零（Table 13）；不兼容祖先失败（Table 12）；非可表达教师失败（Table 3b）；跨模型/规模的均值增益区间含 0（Figure 3）。
    • 通道带宽受限：作者把 MBPP+ 的近零结果解释为低带宽通道的自然表现（Appendix H），这只是合理假设，未单独验证。
    • 机制未闭环：功能方向与可执行端点之间存在缺口（强度分级和组合扫描在端点上都失效）。
    • 适用条件：已知同源公开祖先；教师有明显且学生能表达的目标能力提升；能构造祖先的近平衡载体。超过这个范围（例如想窃取一个未知祖先的私有模型能力）论文没有提供可行性的证据。

5. 最容易受到审稿人质疑的地方

质疑：核心效应量的统计稳定性偏弱，”泛化”主张超出区间支持的强度

  • 原文依据：主结果 +5.34+5.34+5.34 pp 的 95% CI 是 [1.22, 9.60]（Table 1，n=4 种子）；跨模型三条新增模型线的配对区间均含 0（Figure 3 图注原文承认）；多 token 扩展的两个非算术端点区间也含 0（Table 5）。
  • 为什么重要：论文摘要级别的表述（”positive mean gains across additional model generations, sizes, and families”）读起来像泛化结论，但区间层面的证据只能支持”方向为正”。HumanEval+ 只有 164 题，5 pp 约合 8~9 道题，噪声不小。
  • 当前能够得出的判断：主端点（HumanEval+）在采集级重复下确实稳健（15/15、采集间 SD 0.83 pp），这一点证据较强；但”跨模型泛化”属于证据不足而非被证伪——目前只能作为方向性信息。
  • 如何验证或补强：在 Qwen3-1.7B/4B、Llama-3.2-1B 各增加独立采集与种子数、报采集级重复；对主要结论做多重比较校正；给关键端点报告方差分解（种子 vs 采集 vs 任务）。
  • 严重程度：主要问题。

质疑：机制解释只有相关性，没有从”载体决策”到”能力提升”的因果链

  • 原文依据：所有机制分析（correspondence curve、destruction analysis、graded recovery、early alignment）都基于同一套表征诊断（teacher-direction cosine / projection，Appendix D/F/G）；论文的因果框架（Eq. 3 一阶近似）只是局部解释；作者自己在 Discussion（§5.5 后）写道无法区分”观测信息太少”还是”学习没用足”；早期对齐被作者自己标注为 suggestive。
  • 为什么重要：标题与摘要的核心主张是”影子携带能力相关信息并可迁移”，但”影子为何有效”决定了它是否可推广（比如能否设计更好的问题选择或目标函数）。若机制只是”与教师方向表征对齐”，它与直接的行为克隆在原理上的区别需要更清楚。
  • 当前能够得出的判断：证据足以支撑”恢复了与教师更新相关的方向性信号”，不足以支撑”该信号就是能力迁移的载体”这一更强命题；论文对此基本诚实，但摘要的语气强于证据。
  • 如何验证或补强：如对载体集合做受控扰动（在保持词多重集与难度下改变不同状态的选择性）观察端点变化；检验功能对比与端点增益在个体端点/任务级上的相关性；给出”把功能对比当筛选器”后能否预测哪些任务会增益。
  • 严重程度：主要问题。

质疑：适用条件的收窄与”可观测性”叙事之间的张力

  • 原文依据：需要已知且同源的公开祖先（§3；不兼容祖先直接失败，Table 12）；需要教师增益明显（MBPP+ 弱 gap 近零，Table 13）；需要学生”可表达”该能力（记忆答案与密文教师均失败，Table 3b）；需要构造任务无关的近平衡载体（作者自建，Appendix B）。Discussion 也承认”relies on actively constructed carriers and a known public ancestor”。
  • 为什么重要：论文的动机叙述涉及”私有更新的可观测性”（隐私含义）。但设定中学生本身就是相同祖先的另一份拷贝——对”攻击者只有 API、不知道祖先”的现实问题，本文不提供证据；标题”Post-Training Leaves Behavioral Shadows on Unrelated Decisions”是成立的，但”shadow 泄露能力”的适用范围比叙事暗示的窄。
  • 当前能够得出的判断：属于”设定内在限制 + 表述可能被误读”的问题；论文在 Discussion 与 Appendix H 有披露，但摘要没有同样清晰的限定。
  • 如何验证或补强：在”祖先未知”或”祖先相似但不相同”（同家族相邻检查点）设定下做实验；给出失败模式的边界条件（tokenizer/家族/规模各自贡献多少）。
  • 严重程度：主要问题。

质疑：新颖性边界含混，缺少与最近邻方法在同等预算下的横向对比

  • 原文依据：§2 自述与 subliminal learning（[1]–[7]）、模型抽取/主动学习（[16]–[21]）、黑盒/on-policy 蒸馏（[13]–[15]）的关系；实验里只做了三类对照：打乱标签、public-label、被动采样（Table 1、3a）。没有把”同一查询预算下用教师做常规黑盒蒸馏（例如多 token 回答）”作为基线一并比较（多 token 扩展只在小模型 0.5B 上做，且对照是自己的 exact 控制而非单 token 主实验）。
  • 为什么重要：读者会问：单 token 通道相比”问教师要更长回答”的收益是什么？如果多 token 观测在同等查询数下更强（Table 5 在 GSM8K 上 +6.37），那么”单 token 即可”的主张需要与”单 token 与多 token 的等价/增益对比”配套。
  • 当前能够得出的判断：本文的贡献更像”已有组件的新组合 + 更严格的对照工具”；单 token 与多 token、主动与被动之间的比较不完整，属于当前材料无法完全确认的部分。
  • 如何验证或补强：在同等查询预算下比较单 token ATD、K=20K{=}20K=20 ATD、以及经典黑盒蒸馏（教师长回答 CE）；报告各自在 7 个端点上的效应量。
  • 严重程度：次要问题（偏主要）。

质疑：探索性结果内部不一致，控制臂波动即可改变结论方向；成本与复现细节披露不完整

  • 原文依据：RPM 在 HumanEval+ 上对 shuffle 更强（+6.30）但对 public-label 的区间含零（+4.47，[−0.61, 9.76]，Table 4）；ScienceQA 上”RPM 更大的 shuffle 相对差来自更低的 shuffle 基线，而不是更强的学生”（§6.1 原文）；Figure 6 的端点剂量响应在 GSM8K 上不显著（+0.28 pp）；多 token 在 0.5B 上非算术端点近 +1 pp。论文未报告任何 wall-clock/算力成本；载体”冻结过滤词表”、审计脚本与 50% 一致约束的可实行性依赖代码仓库与 MILP 求解器（Appendix C 说”数秒返回可行见证”，无更多细节）。
  • 为什么重要：小端点（500 题的 OpenBookQA、1,221 题的 CommonsenseQA）上 shuffle 基线的随机波动就能翻转”谁更好”的结论；探索性扩展没有多重比较校正；成本与复现细节缺失影响可复现性评估。
  • 当前能够得出的判断：论文对 RPM 的定性（”不全面占优”）是诚实的；但这也意味着 §6 的结论应被当作假设生成而非可依赖的发现。复现性中等——主实验流程描述详细且代码公开，但控制构造与审计的完全复现依赖仓库状态。
  • 如何验证或补强：对 RPM/multi-token 增加采集级重复与校正；公开载体全列表、审计脚本和 MILP 实例；报告训练与查询成本。
  • 严重程度：次要问题。

6. 审稿式总评

作者发现后训练会在任务无关输入上留下可观测的行为变化（behavioral shadow），因此提出 ATD：用公开祖先挑选近平衡提示、每个提示只取教师一个 token，把”私有的后训练更新”变成数千个 1-bit 观测来训练同源学生；通过配套的 exact nuisance-matched 控制与执行式评测，实验在 Qwen2.5-1.5B 编码端点上表明学生比精确匹配控制高 5.34 pp、且在独立重造采集下 15/15 为正，主动放置查询的价值（+4.27/+5.03 pp）与源特异性（对角线最大）证据较强；但”影子携带能力”的机制证据停留在表征相关性、跨模型增益的置信区间含 0、适用条件（已知同源祖先、明显且可表达的教师增益、可构造近平衡载体）比摘要语气所暗示的更窄。本文最有价值的部分是问题设定 + 严格的控制构造（把黑盒观测的”提示–token 对应”从词频/难度中干净地分离出来），最大的审稿风险是把方向一致的弱证据表述成泛化结论，以及机制叙事领先于机制证据。

  • 问题定义清晰度：强——可观测性与能力迁移两个问题、已知祖先设定、预注册式查询约束都写得明确（§1、§3）。
  • 创新性证据：中——组合式创新，且 exact 控制与主动/被动对照提供了设计不可替代性的实验（Table 1、3a）；但与最近邻方法的横向比较不足，首次性主张只能按 related work 自述接受。
  • 方法可信度：中——流程简单、可审计、代码公开；但依赖一阶近似解释、依赖祖先概率与近平衡选择，论文自己承认机制未闭环。
  • 实验支持力度：中——主端点识别证据强（多重控制+采集级重复+执行式评测），泛化与扩展证据弱（跨模型区间含 0、端点剂量响应不显著）。
  • 可复现性：中——主流程、语料、超参与统计协议披露详细且代码公开，但载体构造/审计与 MILP 控制臂的完全复现依赖仓库，成本未报告。
  • 综合阅读价值：高——对”后训练影响的外溢””隐式蒸馏/黑盒信息泄露”方向是设计较严谨的实证工作，其控制构造思路（精确匹配的标签置换）可迁移到其他”训练数据携带隐藏信号”的研究。
