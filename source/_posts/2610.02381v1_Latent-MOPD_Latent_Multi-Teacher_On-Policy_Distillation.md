## 0. 一句话结论

论文在"按域路由的多教师 on-policy 蒸馏（MOPD 式 token 监督）"之上加入同一位路由教师的隐状态对齐目标（同家族对齐最后 3 层、跨规模用共享线性映射对齐最后一层），并用按教师各自计步的 crossfade 把隐状态监督逐步过渡到 token 预测，同时按域组织纯批更新。在论文报告的 1.5B 同家族教师面板上，验证了该校学生在 9 个数学/代码/逻辑基准上超过 token-only、representation-only 与均匀平均三类基线、并在 5 个基准上超过逐基准最佳教师；跨 7B 教师面板与参数合并初始化下方向一致但绝对增益更小。核心结论在论文自己的控制实验内自洽，但其"超过 token-only 多教师蒸馏"的对外比较基准是自实现的变体而非已发表 MOPD 系统，且主流结果缺少多种子方差，这两点限制了结论强度。

## 1. 论文要解决什么问题

**背景与任务**（原文事实，§1）。RL 后训练已经产出大量"各有所长"的领域专家（数学、代码、逻辑推理），但把若干专家整合进一个可部署模型仍是问题。多教师 on-policy 蒸馏（MOPD，Ma et al., 2026）的思路是：学生自己采样回答，按 prompt 的领域标签路由到对应教师，由该教师对学生的 token 打分，学生在自己的 rollout 上学习教师的输出分布。这条路线下，监督完全定义在输出层——学生学"教师预测什么"。

**现有方法的局限**（原文事实 + 作者主张）。输出分布是教师内部计算的末端产物；可解释性研究（Lindsey et al., 2025；Gurnee et al., 2026）表明隐表示携带中间推理信息并因果影响后续计算，即隐状态还携带"教师怎么算"。representation-level 的 OPD 方法（LastOPD、OPRD；Yang et al., 2026a/b）已证明在合理选层与调度下，隐状态监督可以优于纯 token 蒸馏，但这些工作都只研究**单教师**。多教师场景下，多个教师的不同表示目标要联合训练同一个学生骨干，"如何选择表示目标、如何组织它们的监督"没有被研究过（作者主张，§1 的核心问题陈述）。

**本文的两个新观察**（原文事实，Fig. 3a/b、Fig. 3c；审稿人判断：这是本文问题动机中最扎实的部分）：

1. 训练前教师与基础学生之间的 native linear CKA 呈现两种模式：同家族面板在多数层保持高相似（块 1–25 均值 0.987–0.992），只在靠近输出的最后三块下降（0.945–0.962，最后一块 0.886–0.930）；跨家族面板（1.5B 对 7B）在中层出现明显"低谷"（最低在块 13，0.116–0.124），到块 21 后回升，最后一块再次下降（0.536–0.635）。这说明"逐层一一对应"的假设在不同模型关系下不成立，选层要依据教师—学生的表示关系。
2. 在"同家族、全 28 层、纯表示监督"的控制实验中，按域打包的更新（domain-pure blocks of 32）可以稳定训练 62 步，而把三个域的样本混进同一个优化器更新（interleaved）会在 20 步内崩溃：MATH-500 从基础 84.1 掉到 22.8（第 20 步）、9.8（第 30 步），第 62 步仍只有 43.2；GYM-200 同期为 4.1、0.9、12.8。论文报告了 4 组 interleaved 复现实验，均重现早期崩溃特征（Appendix F）。

**原因解释的边界**（审稿人判断）。论文对崩溃给出的解释是"若干教师的表示目标在同一个参数更新里相互冲突"，但没有给出梯度冲突、参数漂移或损失几何的直接证据，只报告了表示损失上升（约 $7.9\times10^{-5}$ → $2.8\times10^{-4}$）且无 NaN / 梯度溢出（Appendix F）。因此这是"观察到了现象，但因果解释尚未验证"。同样，CKA 只被作者用作"候选选层"的几何依据，论文自己也承认 CKA 不能决定哪些层对迁移最优（Appendix E）。

**论文验证的核心假设**：把路由教师的隐状态目标（经选层、投影、按教师计步的 crossfade、域纯批组织）加进 MOPD 式 token 蒸馏，能让一个学生同时吸收多个专家的能力，且优于 token-only、表示-only、均匀平均等所有单通道或朴素组合基线（§1、§3–5）。

## 2. 核心创新点

**一句话概括技术增量**：本文不是提出新的蒸馏算法框架，而是把已有的三块组件——MOPD 的按域路由 token 蒸馏、LastOPD/OPRD 的隐状态对齐与 crossfade、以及"域纯批"这一更新组织方式——在**多教师路由**场景下重新设计并组合：表示目标改为取自与 token 通道同一位路由教师的隐状态；选层按教师—学生关系分面板决定；crossfade 改成"每个教师各自计步"的时钟；并首次（作者主张）系统报告了批组织对表示监督稳定性的影响。逐项如下（每项给出"与最接近已有方法的具体差异"和"移除后的证据"）：

**创新点 1：representation-level 多教师 OPD 本身**（原文事实，§3、Fig. 2c）。token 通道与表示通道使用同一个按域路由的教师：math prompt 同时收到 math 教师的 token 分布和 math 教师的隐状态目标。相对 MOPD（只有输出分布）和 OPRD/LastOPD（有隐状态但没有多教师路由），这是新的组合方式；相对离线的多教师特征蒸馏（You et al., 2017；Formont et al., 2026）则新增了 on-policy 与路由两个维度（Appendix I 的 Table 4 按 Multi-t. / Pre-head / On-policy 三列定位，作者列出同时具备三者的只有本文方法）。**移除证据**（原文事实）：把该通道关掉就是 Table 1 的 MOPD-style 一行（Norm 0.90）；联合但恒定权重（Latent-MOPD constant）Norm 0.94；加 crossfade 后 1.05。即表示通道本身带来约 +0.04 Norm，调度再带来 +0.11。

**创新点 2：随面板变化的选层策略 + 宽度桥接投影**（原文事实，§3、Fig. 3a/b、Table 1–2）。同家族：对齐最后 3 层、映射取恒等（因为共享血统与宽度）；跨家族：只对齐最后一层（宽度 1536→3584），用**所有路由教师与所选出层共享**的一个无偏置可训练线性映射，且用闭式 ridge 拟合初始化（42 条 rollout、134,843 个路由状态对、90/10 划分、$\lambda_r=10^{-3}d_S$，Appendix A）。与 OPRD 按相对深度配对 + 冻结低秩投影、LastOPD 只对齐最后一层的做法不同，本文的关键差异是"选层依据 CKA 给出的教师—学生关系、并让投影在教师间共享"。**移除证据**：同家族 last-3 vs last-1 在 8/9 基准上胜出（Norm 1.05 vs 0.99）；跨家族 last-1（0.26）与 last-3（0.25）几乎持平、胜负 3:3，所以跨家族默认反而只用一层——这与"多层更好"的直觉相反，说明选层结论确实是面板相关的（这篇论文比较诚实地呈现了这一点）。投影形式的消融显示线性 vs 两层 MLP 在六个基准上 3:3 打平（Norm 0.26 vs 0.27），且该对比同时改变了结构与初始化（MLP 随机初始化、线性 ridge 初始化），投影形式本身是否重要无法从这组对比确认（审稿人判断）。

**创新点 3：按教师各自计步的 crossfade 调度**（原文事实，§3、式(3)）。$\alpha(u)=\min(1,u/T_w)$ 随该教师的已完成更新数 $u$ 线性升高 token 权重，$\beta(u)=\max(0,1-u/T_w)$ 衰减表示权重；同家族 $T_w=10$、跨家族 7（对应 62 个全局步中表示项活跃于第 1–30 / 1–21 步，此后纯 token 更新）。这与 LastOPD 的 crossfade 同形，新意在于多教师轮转下的"每教师时钟"（每个教师进入自己的窗口时都经历同样的权重序列）。**移除证据**：与恒权控制（Latent-MOPD constant）相比 8/9 基准提升，Norm 0.94→1.05；反向例外是 AIME25（37.5 vs 36.9，恒权更高）（Table 1）。值得注意的是论文自己引用的 LastOPD 结论：在其单教师同血统设置中，**持续**保留 latent 项比 crossfade 在 MATH-500 上更高（Appendix C）；作者选择从 crossfade 起步并靠本文的多教师控制实验（Table 1）支持该选择——这是作者知情下的一个领域差异判断，而非无意识忽略。

**创新点 4：域纯批组织**（原文事实，Fig. 3c、Appendix F）。路由只决定"每条 prompt 归哪个教师"，不决定"一个优化器步里可否混多个域"；本文报告后者是表示监督稳定性的关键变量（见 §1 第 2 条观察）。这条更接近"被忽略的工程事实的发现"，而不是新算法；其证据强度见 §4.2 与 §5"域纯批组织"一条质疑。

**原创边界说明**（审稿人判断）：根据本文 related work 和实验对比，只能确认作者声称的差异；"首个 representation-level 多教师 OPD"的表述属于作者主张（原文："to our knowledge the first"），是否构成首次提出需要更完整的文献检索，本文未做穷尽的系统检索。

## 3. 方法

**直觉**：把"多教师"看作学生已有的一条 token 监督流水线，在其每个训练样本上再挂一条来自**同一位域教师**的隐状态对齐损失；由于不同教师的隐状态目标可能互相冲突、且并非训练全程都需要，作者用三个约束驯服它——只在教师—学生关系支持的层上对齐、只在每个教师进入训练的最初若干步施加、且每个优化器步只装一个域的样本。学生推理时完全不带教师和投影，部署成本与普通微调模型相同（原文事实，§3 末段）。

**运行流程**（原文事实，§3 + Appendix A/C）：

1. **输入**：prompt $x$ 带固定领域标签 $d\in\{$math, code, logic$\}$；训练池 17,856 条（每域 5,952，来自 DAPO-Math-17k、OpenCodeReasoning、Reasoning Gym 的 prompt）；数据集自带解答**不**作为模仿目标，也没有 verifier reward。
2. **学生 rollout**：学生（DeepSeek-R1-Distill-Qwen-1.5B）对每条 prompt 采样 4 条回答（温度 1.0，长度上限 16,384 token，chat template `enable_thinking=False`），回答路由到领域教师 $\pi_{T_d}$。
3. **token 通道**（式(1)）：教师与学生都在全词表上归一化打分；取学生 top-$k$（$k=16$）候选 $V_{k,t}$，候选权重 $w_{t,v}=\bar p_t(v)/\sum_{v'\in V_{k,t}}\bar p_t(v')$ 在支撑集内归一化，奖励 $r_{t,v}=-w_{t,v}[\log\bar p_t(v)-\log p_{T,t}(v)]$ 反映"教师相对学生有多看好该 token"；按域内掩码标准差缩放成固定优势 $A_{t,v}=r_{t,v}/\sigma_d$（不减均值），损失

$$\mathcal{L}_{\mathrm{OPD}}^{\mathrm{route}}=-\frac{1}{|M|}\sum_{t\in M}\sum_{v\in V_{k,t}}\mathrm{sg}[A_{t,v}]\,\log p_{\theta,t}(v).\qquad(1)$$

梯度只流经 $p_{\theta,t}$，等价于一次不含 critic 的 policy-gradient 更新。**注意**：这一估计器是作者为公平对比而统一使用的自实现形式，与已发表 MOPD 的默认 reverse-KL 估计器不同（Appendix A，见 §5"MOPD-style 基线是自实现变体"一条质疑）。

4. **表示通道**（式(2)）：在教师 LM head 之前的隐状态 $z^S_t$（学生）、$z^{T_d}_t$（教师）上做逐位置 $\ell_2$ 归一化 $\nu(\cdot)$ 后的平方距离，教师侧 stop-gradient：

$$\ell^{\mathrm{route}}_{\mathrm{rep},t}=\frac{\lambda}{d_T}\left\|\nu\!\left(g_\psi(z^S_t)\right)-\mathrm{sg}\!\left[\nu(z^{T_d}_t)\right]\right\|_2^2,\qquad(2)$$

其中 $g_\psi$ 同家族取恒等、跨家族取共享的无偏置线性映射（ridge 初始化，训练后丢弃）。同家族对齐最后 3 层、全部回答位置；跨家族对齐最后一层、每条回答最后 $\min(2000, |M_b|)$ 个有效位置。多层惩罚先对位置求掩码平均、再对层等权平均（式(4)），因此对齐 3 层不会把表示损失权重放大 3 倍。$\lambda$ 同家族取 1、跨家族取 2000，全程固定、无运行时损失份额归一化。

图 2（下）展示了三条监督设计并存的学生前缀对齐关系：它回答"为什么需要两个通道用同一教师"——只有同一教师同时提供 token 与隐状态目标，隐状态吸收的"how"才与输出学到的"what"来自同一计算路径。

*图 2（论文 Fig. 2）：三种监督设计在学生自生成前缀上的对比。(a) 均匀平均把三个教师的 token 概率等权平均；(b) MOPD 式把 token 监督路由到单个冻结教师；(c) Latent-MOPD 在 (b) 之上叠加同一教师的隐状态目标（$g_\psi(z^S)\to z^{T_d}$，经 LM head 前后读取）。图中柱状分布为示意，PG 表示来自输出的 policy-gradient token 更新。*

5. **选层依据**（Fig. 3a/b，见 §1）：同家族因共享结构、只在末层差异大，故对齐末三块；跨家族中层 CKA 低谷说明"逐层对应"不成立，于是选择在所有模型中有共同功能角色的对象——直接馈入 LM head 的末层状态。

![表示相似性与批组织稳定性：(a) 同家族 CKA、(b) 跨家族 CKA（中层低谷）、(c) 域纯批 vs 交错批的训练稳定性](/images/dailypaper/2026-10-06/2610.02381v1_fig3.png)

*图 3（论文 Fig. 3）：(a) 同家族教师与基础学生在深度匹配块上的 native linear CKA（纵轴放大），末层差异最大；(b) 跨家族 CKA 在块 13 附近出现明显低谷（约 0.12），块 21 后回升；(c) 同家族全层表示-only 控制中，域纯批更新（红）稳定收敛到 91.7（MATH-500），交错批（紫）在 20 步内崩溃到 22.8、30 步 9.8，62 步后仍只有 43.2（虚线为基础学生 84.1）。*

6. **crossfade 调度**（式(3)）：对第 $s$ 个全局步，令 $u$ 为该（当前活跃）教师已完成的更新数：

$$\mathcal{L}^{(s)}=\alpha(u)\,\mathcal{L}_{\mathrm{OPD}}^{\mathrm{route}}+\beta(u)\,\mathcal{L}_{\mathrm{rep}}^{\mathrm{route}},\quad \alpha(u)=\min\!\Big(1,\tfrac{u}{T_w}\Big),\quad \beta(u)=\max\!\Big(0,1-\tfrac{u}{T_w}\Big).\qquad(3)$$

每个域纯优化器步用一对固定权重，只有活跃教师的计数器前进；前 3 个全局步 $\alpha=0,\beta=1$（纯隐状态起步），同家族表示项在第 30 步后归零、跨家族在第 21 步后归零。此外，**训练流程固定**的部分还包括：域纯 blocks of 32、按 math–code–logic 不洗牌轮转共 62 步（1,984 次 prompt 呈现、7,936 条回答，与 LastOPD 的 on-policy 预算一致）、8 worker、每 worker 局部 minibatch 16 条回答、恒定学习率 $10^{-5}$ AdamW。**由模型决定**的只有学生自己的回答内容与 top-16 候选的选择；教师、路由、调度、批组织都是固定流程。

7. **训练的部分与推理**：更新学生权重；跨家族时还联合更新投影 $g_\psi$（每 worker 一份、教师间共享），教师全部冻结；训练完成后投影被丢弃，推理只用学生（representation matching 仅训练期使用）。

**可选的初始化变体**（§3 末、§4.4）：学生也可以先取三个同家族教师的均匀权重平均（"model soup"）再跑 62 步蒸馏，用于检验蒸馏能否在合并权重之上继续改进。

## 4. 解决得怎么样

#### 4.1 实验设计与主要结果

**设置**（原文事实，§4.1 + Appendix A/B）：学生为 DeepSeek-R1-Distill-Qwen-1.5B；同家族面板为三个同血统 1.5B RL 检查点（JustRL-DeepSeek-1.5B=math、Archer2.0-Code-1.5B-Preview=code、Nemotron-Research-Reasoning-Qwen-1.5B family 的 ProRL=logic，revision v2）；跨家族面板为三个 7B 教师（Skywork-OR1-Math-7B=math、AceReason-Nemotron-7B=code、DeepSeek-R1-Distill-Qwen-7B=logic，隐宽 3,584）。评测：9 个同家族基准覆盖 math（AIME24/AIME25/Minerva）、code（MBPP、MBPP+、LiveCodeBench-easy）、logic（BBH、MuSR、Reasoning Gym 冻结 925 题集）；跨家族与合并实验用 6 个（去 MuSR/LCB/Minerva）。生成默认温度 0.7 / top-p 0.95，AIME 系列 16 采样、Minerva 4、LCB-e 4、BBH/MuSR/GYM 各 1；只评测最终检查点、从不挑中间检查点；训练与评测问题实例无重叠（训练前检查）。基线：均匀平均、MOPD-style（token-only，路由）、OPRD-style（全 28 层表示-only）、Rep-only（last 1 / last 3，恒定表示目标全程）、以及若干 Latent-MOPD 自身的消融行。聚合指标 Norm 为"相对基础的提升 / 基础到逐基准最佳教师的差距"加权和（式(5)），基础=0、最佳教师包络=1。

#### 4.2 消融与机理分析

**crossfade 是联合方法内部最大的单项增益来源**（原文事实，Table 1、§4.2）：恒权联合控制（Latent-MOPD constant，Norm 0.94）→ 默认 crossfade（1.05），8/9 基准提升；AIME25 是唯一反向（36.9 vs 37.5）。同样，默认配置相对"全层 + 双通道恒权"的 Latent-MOPD（OPRD-style）在 8/9 基准上占优（1.05 vs 0.94），说明"选层 + 调度"这套组合贡献大于"把表示通道拉到全层全时段"。

**分层预算的消融呈现面板依赖性**（原文事实，§5）：同家族 last-3 优于 last-1（8/9 基准，1.05 vs 0.99）；跨家族 last-1 与 last-3 几乎持平（0.26 vs 0.25，胜负 3:3），默认取更省的一层。表示-only 的独立对照倾向一致的结论（同家族 last-3 对 last-1 与 all-layers 各胜 7/9，0.73 vs 0.64）——即"三层偏好"在表示-only 与联合监督下都出现，减少了单路径巧合的可能（审稿人判断：这是本文较扎实的一组消融）。

**训练动态与目标收敛**（原文事实，Fig. 5）：同家族默认配置在 500 题 MATH-500（每题 8 采样）上从基础 84.1 升到第 20 步 90.3、第 62 步 92.0；跨家族 86.2 / 87.7，两者都稳定高于基础且 token-only 阶段不回退。表示损失按域归一化后在第 10 次更新/域时降到首值的 0.30（math）、0.38（code）、0.39（logic），最终 0.13/0.19/0.15；该曲线排除了 $\beta$ 因子，所以下降不是调度的机械产物——这是"表示目标确实在训练中被拟合"的直接证据（原文事实，Fig. 5c）。GYM-200 上同家族 37.94→62.56、跨家族→41.19（Appendix D，Fig. 8c）。

*图 5（论文 Fig. 5）：(a) 同家族/跨家族配置在 MATH-500 上的训练动态（基础 84.1，同家族到 92.0）；(b) 训练分布外的 ARC-C / HellaSwag / WinoGrande 上单字面保留（ARC-C 32.8→33.9、HSwag 44.7→44.2、WinoG 54.5→55.2，均在 1.1 分以内）；(c) 三个域的表示损失按各自首值归一化后持续下降（阴影为 crossfade 的每域 10 次更新窗口），排除 $\beta$ 权重因子。*

**批组织稳定性**（原文事实，Fig. 3c、Appendix F）：域纯批的表示-only 全层控制在 62 步内稳定（MATH-500 91.7 / GYM-200 56.7）；交错批在 10 步内就低于基础（79.8/32.6）、20 步崩溃（22.8/4.1）、30 步 9.8/0.9、62 步仍远低（43.2/12.8）。把交错训练预算加倍到 120 步后，MATH-500 才回到 84.50（基础 84.12）、GYM-200 到 41.56（基础 37.94），且末期曲线基本走平——"多数额外更新只是抵消崩溃"（原文事实，Fig. 10）。这是本文最有信息量的观察之一。

**机制证据：教师匹配**（原文事实，Fig. 6、Appendix G）：在同一批诊断前缀上比较 MOPD-style 与 Latent-MOPD 的最终学生与三个教师的输出分布余弦——MOPD-style 的 math 行最大值落在 code 教师（0.966 > 0.938），Latent-MOPD 的 math 行最大值回到 math 教师（0.969 > 0.933）；code、logic 行两者都匹配各自教师。以"匹配教师相似度 − 最接近的替代教师相似度"定义的 margin，math 行从 −0.0282 提升到 +0.0366，配对 bootstrap 95% 区间为 $[0.0184, 0.1324]$（selected positions）与 $[0.0077, 0.0659]$（all positions）；code（+0.0094）与 logic（+0.0013）的区间跨 0，即只有 math 一行的变化统计上可辨（原文事实）。按 readout 深度的扩展分析（Fig. 11）显示 math margin 在 native head 上增加 0.0655 $[0.0196,0.1257]$，且该变化来自"向 math 教师靠拢 + 与 code/logic 教师略远"。

#### 4.3 局限性

**论文自报的范围限制**（原文事实，Appendix J、§4.1、Appendix A）：

- "跨家族"在本研究中定义为**不同规模与不同后训练**，而非不同架构：四个模型全部是 Qwen 骨干、28 个块、共享 tokenizer；且跨家族面板中 Skywork-OR1-Math-7B 与 AceReason-Nemotron-7B 本身就是 DeepSeek-R1-Distill-Qwen-7B 的 RL 微调（脚注 2）。作者列出"更异构的教师、学习式路由、不同 tokenizer 支持"为扩展方向。
- 领域标签固定、非学习得到；表示损失尺度 $\lambda$ 按设置人工固定。
- MOPD-style 基线**不是已发表 MOPD 系统的复现**（估计器、教师规模与领域混合均不同，见 §5 第一条质疑）。
- 图 5c 的表示损失是在不断演化的 on-policy rollout 上测量，只描述域内训练轨迹、不能跨教师比较绝对误差尺度。
- 表示状态存储的 0.28 GiB 示例是解析计数而非实测峰值显存（论文明确说明学生仍需对全骨干反传、materialize 全层隐状态的实现可能保有完整瞬时分配）。
- CKA 只是"候选选层"依据，不能决定哪层对迁移最优（Appendix E 自述）。

**论文未报告、也无法从文中确认的内容**（无法确认）：训练总算力（GPU 型号/数量/时长的报告缺失，仅有 8 worker、62 步、7,936 条回答、16k token 上限等预算描述）；每种配置的训练随机种子数与多次运行的方差；$\lambda$（1 与 2000）与 $T_w$（10 与 7）的敏感性扫描；联合方法在交错批下是否会崩溃（交错崩溃只在表示-only 控制中测过）；推理阶段对无领域标签输入的领域无关行为变化；失败案例统计。

**审稿人判断**：结论的适用边界应表述为"在 1.5B 学生、同血统/同骨干教师、固定域标签、62 步预算下，路由隐状态目标 + crossfade + 域纯批相对于单通道基线有一致的内部增益"；跨家族面板的增益方向一致但幅度小（Norm 0.16→0.26），且远未达到教师水平，不宜外推为"一个学生能普遍吸收异构专家的能力"。

#### 4.4 与相关工作的对比

- **MOPD（Ma et al., 2026，arXiv:2606.30406）**：本文的直接前身，路由式 token 蒸馏；本文在保留其路由与 on-policy 打分的前提下叠加同教师的隐状态目标。差异是真实的（隐状态通道），但对外比较用的是自实现 token 基线（见 §5 第一条质疑），与已发表系统的对比只能说是"同思路方向的扩展"。
- **LastOPD / OPRD（Yang et al., 2026a/b）**：单教师表示级蒸馏。本文复用 LastOPD 的末层 + crossfade 形式、OPRD 的"分层配对 + 投影"思想，新增多教师路由下的选层（面板相关）、共享投影与每教师时钟。论文披露 LastOPD 在其可比设置中"持续 latent 项优于 crossfade"，本文在 62 步预算下选择 crossfade 并以恒权控制作为对照（Table 1）——两文的结论差异说明调度选择可能依赖教师数量与预算，尚无统一定论（审稿人判断）。
- **离策略多教师蒸馏与特征 KD（You et al., 2017；Yuan et al., 2021；Formont et al., 2026）与 FuseLLM（Wan et al., 2024）**：在固定数据上融合输出或特征；本文的 on-policy + 路由设定增加了"学生自生成轨迹"和"按域选择教师"两个维度，但也因此受限于教师共享 tokenizer 的假设（Appendix I 明确提到 tokenizer 不同需专门处理，Niu et al., 2026）。
- **模型合并（Wortsman et al., 2022；Ilharco et al., 2022）**：零训练即可组合兼容权重，但 Table 3 显示合并（0.87）仍偏斜于各域教师、蒸馏可在其上再提升（1.03）；本文用"参数合并初始化"把其作为起点而非替代。
- **同批次多教师 OPD 工作**（D3-MOPD 的域调度、MT-SDPO 的答案验证教师选择、Open-MOPD 的能力失衡分析、UI-MOPD、CA-OPD 等，均在 related work 提及但**未作实验对比**）：它们关注"选哪个输出目标"，本文关注"输出目标之外的隐状态目标与更新组织"，两者互补；缺少与其输出侧方法的组合实验（审稿人判断）。

## 5. 审稿人质疑

#### 质疑："MOPD-style" 基线是自实现变体而非已发表 MOPD 系统，头号对外对比（超过 token-only 多教师蒸馏）的证据强度无法确认

- **原文依据**：Appendix A "Baseline implementation" 明确写道：本文基线"is not a replication of the published system (Ma et al., 2026)"——已发表系统训练同血统教师、规模更大、领域混合不同、默认使用 policy-gradient reverse-KL 估计器，其 top-$k$ 变体用 teacher-selected support 与截断校正；本文 token 通道用 student-selected support、全词表 log-prob 比值与学生归一化候选权重。Uniform averaging 也是朴素基线（Table 1 中 GYM 仅 40.7）。
- **为什么重要**：论文摘要与结论的第一卖点是"outperforms token-only (MOPD-style) baseline"，这是方法能否成立的外部参照系；如果自定义 token 估计器恰好弱于已发表实现，Norm 0.90→1.05 的对比就会部分来自估计器差异而非隐状态通道本身。此外，MT-SDPO、D3-MOPD、Open-MOPD 等同期多教师 OPD 方法只在 related work 出现，未进入实验对比。
- **当前能够得出的判断**：内部消融是干净的（各臂共享同一 token 估计器、数据、批与优化器，表示通道是唯一变量），可支持"在**本文的**token 估计器之上，隐状态通道 + 调度有增益"；但不能确认"超过已发表的 MOPD 系统"。
- **如何验证或补强**：以已发表 MOPD 的默认估计器（reverse-KL、teacher-selected top-$k$ + 截断校正）与本文方法在相同预算下重跑对照；或至少在附录提供两种估计器下基线分数的敏感性范围；补充与 MT-SDPO/Open-MOPD 的适配对比。
- **严重程度**：主要问题。

#### 质疑：主流基准缺少统计稳定性证据，若干"全胜"结论可能落在采样噪声内

- **原文依据**：Table 1–3 每个训练臂只给最终检查点的一个数值，全文未报告训练种子或多次运行的方差（无法确认：论文未报告）；部分基准每题只采样 1 次（BBH、MuSR、GYM，Appendix A），AIME24/25 仅 30 题（16 采样）；论文自报的若干胜负差距很小：默认 vs MOPD-style 在 MuSR 为 52.4 vs 50.7、Table 2 中 AIME25 差距 1.5、crossfade 对恒权的提升多在 +0.5~3.5 分，且 AIME25 反向（36.9 vs 37.5）、last-1 变体在 AIME24 反向（51.0 vs 50.8）、Table 3 中 Rep-only 的 AIME24 更高（54.6 vs 53.8）。Norm 由原始求和构成，没有不确定性区间。
- **为什么重要**：这直接影响"在全部九/六个基准上超过基线"这类断言的可重复性；在 1 采样基准上 1–2 分的差异在温度 0.7 的生成式评测里通常并不稳定。一个单臂单次训练 + 单次评测的表格，无法区分"方法增益"与"这次抽样的运气"。
- **当前能够得出的判断**：差距较大且方向一致的项（如 92.0 vs 84.1 的 in-loop 曲线、Minerva +2.8、GYM 跨家族 +4.9、崩溃实验 22.8 vs 91.7）可信度较高；"逐基准全胜"级别的边际胜利（如 52.4 vs 51.8）当前证据不足以排除噪声。
- **如何验证或补强**：每臂至少 3 个训练种子并报告均值±标准差；对每题多次采样的基准报告自助法区间；把评测采样数与方差写入主表；对 1 采样基准上调采样数或改用 pass@k 风格的稳定估计。
- **严重程度**：主要问题。

#### 质疑："跨家族"实为同骨干、同 tokenizer 的相邻谱系，结论外推到异构专家缺乏依据

- **原文依据**：§4.1 "all four models have 28 blocks and use a Qwen backbone"；Appendix A 脚注 2：Skywork-OR1-Math-7B 与 AceReason-Nemotron-7B 是 DeepSeek-R1-Distill-Qwen-7B 的 RL 微调；Appendix J："All teachers share the student's tokenizer… support for different tokenizers would extend the setting studied here"。
- **为什么重要**：摘要中的 "larger, separately developed cross-family teachers" 容易被读成架构级异构验证；实际上隐宽桥接（1536→3584）与末层对齐之所以可行，依赖共享的词表、骨干与"末层状态直接喂 LM head"的共同功能角色。真正的异构（不同架构、不同 tokenizer、不同深度）下，式(2) 的对齐对象与 ridge 初始化的前提都可能失效。
- **当前能够得出的判断**：论文结论的合理范围是"同谱系、同 tokenizer、不同规模/后训练教师"；"跨家族"一词在本实验中是被作者明确定义过的（§4.1），但对外表述存在过度联想的空间。跨家族表 2 的绝对增益也较小（Norm 0.26），本身已说明难度。
- **如何验证或补强**：加入异构教师（如 Llama/Gemma 系、不同深度、不同 tokenizer 需先做 token 级对齐）；至少做一组"不同骨干 + 共享 tokenizer"的中间难度实验，检验选层与投影策略是否仍成立。
- **严重程度**：主要问题。

#### 质疑：机制叙事（隐状态传递"教师怎么算"）与其最核心的因果证据不匹配，案例研究仅为精选轶事

- **原文依据**：摘要与 §1 把卖点建立在 "hidden states carry information about how a teacher computes"（引 Lindsey et al., 2025；Gurnee et al., 2026 的可解释性结论，作者主张）；但本文自身的机制证据（Fig. 6、Appendix G）只有 math 一行的匹配 margin 显著（code +0.0094、logic +0.0013，区间跨 0），且它测量的是**输出分布余弦**、并非隐状态内容；案例研究（Appendix H）是 3 个示例，没有对"计算结构正确率"的规模化测量；Appendix J 也承认"测量训练目标的更新方向有助于把几何与增益联系起来"（尚未做）。
- **为什么重要**：如果增益实际来自"隐状态目标起到了正则化/课程作用"而非"学生习得了教师的内部计算过程"，方法的设计直觉（同教师双通道、末层对齐、crossfade）就缺少必然性；这也是审稿人判断"创新是组件组合"与作者主张"what+how 双通道整合"分歧的焦点。
- **当前能够得出的判断**：可以确认"表示目标被实际拟合"（Fig. 5c 损失下降）且"学生输出向 math 教师靠拢"（Fig. 6c），但"隐状态监督使学生学到了可迁移的计算过程"这一因果链当前材料不足以确认。
- **如何验证或补强**：在留出集上系统测量约束/不变量保持率（把案例研究扩展成统计指标并做盲评）；对表示目标做 probing（教师隐状态中哪些信息被转移）；对比"对齐教师隐状态"与"对齐随机/打乱目标"的同预算控制，以分离"内容"与"正则化"两种解释。
- **严重程度**：主要问题。

#### 质疑：域纯批组织被列为三大设计支柱之一，但其必要性只在表示-only 控制中得到验证，且崩溃原因未查明

- **原文依据**：Fig. 3c / Appendix F 的崩溃实验用的是"同家族、全 28 层、表示-only、$\lambda=2000$"控制，而 Latent-MOPD 的联合方法（token+latent、末三/末层）从未在交错批下训练；摘要仍将"domain-pure updates stabilize"作为并列贡献陈述。崩溃被解释为多教师表示目标在同一次更新中冲突，但论文只报告损失上升与无 NaN，没有梯度冲突或参数几何的证据（作者承认这是观察）。
- **为什么重要**：这决定"按域组批"是否为方法的必要组件，还是仅为表示-only 全层配置的一个特例修复；也影响复现者能否安全地与其他训练组织（如按 token 数均衡的批）组合。
- **当前能够得出的判断**：现象真实且可复现（4 组交错运行重现早期崩溃特征），但其对**完整方法**的适用性是外推而非实证；"崩溃原因=教师目标冲突"目前是假设。
- **如何验证或补强**：对默认联合配置加入交错批对照（同家族与跨家族各一组）；记录梯度余弦相似度 / 参数漂移等诊断以定位冲突来源；检验在 token 通道占主导（crossfade 结束后）时交错批是否仍然有害。
- **严重程度**：次要问题（作者对结论的表述有"under the tested configuration"的自我限定，但抽象层次上仍略显拔高）。

## 6. 审稿式总评与六维评分

作者观察到多教师表示级蒸馏的三个问题面——表示目标的选择依赖教师—学生关系、多教师表示监督在同一次更新内混域会崩溃、持续表示监督在跨规模时反而有害——因此提出 Latent-MOPD：在 MOPD 式路由 token 蒸馏之上，叠加同教师、选层、经共享投影（跨家族）的隐状态对齐，并用每教师时钟的 crossfade 与域纯批组织其监督。在 1.5B 同家族面板 62 步预算下，实验表明默认配置在 9 个基准上超过三类单通道基线与均匀平均、在 5 个基准上超过逐基准最佳教师（Norm 1.05）；其中**内部消融的证据较强**（crossfade vs 恒权 8/9、选层面板依赖性、表示损失随训练收敛、崩溃复现实验），但**对外比较与机制解释仍缺充分支持**（token 基线非已发表 MOPD 实现、无多种子方差、跨"家族"实为同骨干谱系、教师匹配证据仅 math 一行显著）。本文最有价值的部分是"表示监督的批组织影响训练稳定性"这一可复现的稳定性发现，以及把隐状态通道系统性引入多教师 OPD 的完整工程配方；最大的审稿风险是核心对外对比与统计强度的不足，使"超过 token-only 多教师蒸馏"的结论停留在**本文实现内部**成立。

**六维评分**：

- **创新性：6/10**（中）。组件层面是已有工作的多教师化组合（MOPD 路由 + LastOPD 末层 crossfade + OPRD 投影），新意集中在"每教师时钟""面板相关选层"和域纯批的稳定性发现；"首个表示级多教师 OPD"为作者主张，尚未经穷尽检索验证。
- **技术严谨性：7/10**（中偏强）。各臂同预算、同数据、只评最终检查点，控制变量意识好，并主动披露基线非复现、存储计数非实测等边界；扣分在于 token 估计器自实现、$\lambda$ 与 $T_w$ 无敏感性分析、交错崩溃实验缺少因果诊断。
- **实验充分性：6/10**（中）。15 个基准 × 3 种设置（同家族/跨家族/合并初始化）+ 多层消融覆盖面不错，但每臂单次训练、无方差报告，部分基准单采样，且缺少与已发表 MOPD 及同期多教师 OPD 变体的对比。
- **清晰度：8/10**（强）。问题—设计—证据的对应关系清楚，附录把实现细节（ridge 初始化、损失归约、评测协议）写得很具体；扣分在表格密集、Table 2 默认变体与 Norm 高亮变体（MLP）不一致容易误读。
- **可复现性：8/10**（强）。所有教师均为公开检查点（含 HF 链接与 revision）、代码仓库公开、环境 pin（torch 2.8.0 / vllm 0.11.0 / transformers 4.57.3 / EvalPlus 0.3.1 / reasoning-gym 0.1.19、冻结生成器）；扣分在训练种子与算力未报告、MOPD-style 基线依赖作者自实现细节。
- **影响力：5/10**（中偏弱）。多专家整合是热门方向且"批组织稳定性"对同领域实践者有直接参考价值；但当前证据限于 1.5B、同骨干教师的小规模面板，能否推广到更大模型与真正异构教师尚不可知。

**总分：40/60（约 6.7/10）**。录用建议式判断：**边际接受（borderline accept）**——方法配方完整、内部消融可信、工程可复现，适合作为多教师蒸馏方向的重要实证与配方参考；若按正式会议审稿标准，应在补充训练种子方差、并与已发表 MOPD/同期多教师 OPD 基线在统一预算下直接对比之后，才有条件提升为明确接受。
