## 0. 一句话结论

在 Qwen3.5-9B/4B/2B 三个规模上，作者发现按领域标签路由的多教师在线策略蒸馏（MOPD）学生既打不过"最强单教师学生"，也学不到数学专家的大部分增益，并测到各领域教师反馈的尺度严重不平衡（首批次中指令遵循反馈的离散度是整体信号的 2.3–4.4 倍，且为初始 4B 学生贡献 94% 的合成梯度）；为此提出 DN-MOPD，保持路由不变、按批次给每个领域一个被裁剪的有界乘子 $w_d=\operatorname{clip}(\sigma_{\mathrm{all}}/\sigma_d,\,0.25,\,4)$ 重标定其蒸馏优势。六基准平均分在三个规模、两个评测长度上限、三个学生种子上一致优于 Label 路由（16K 下 +1.17~+2.36 pp，8K 下 +2.47~+3.08 pp），并恢复大部分丢失的数学增益；但作者自己的控制实验显示增益主要来自"压低 IF 反馈"（固定常数权重即可复现大部分收益），全部非 OPD 基线（SeqKD-SFT、task arithmetic）的总分仍更高，且该收益依赖具体构造（作者早期的 Qwen3-4B 构造上无增益）。因此证据支持"修正了所测 OPD 配方"，尚不支持"反馈尺度标定是普遍必要的整合原则"。

## 1. 论文具体想解决什么问题？

**研究背景与任务。** LLM 后训练越来越按领域分工：数学用可验证奖励的 RL（Shao et al., 2024; DeepSeek-AI et al., 2025），代码用执行反馈（Cui et al., 2025），指令遵循（IF）用约束检查（Lambert et al., 2024; Pyatkin et al., 2025）。这些管线数据、奖励、优化都不同，通常从同一初始化出发各自训练出一个领域专家，而部署需要"一个模型同时具备三域能力"（§1，原文事实）。多教师在线策略蒸馏（MOPD，Ma et al., 2026；Uni-OPD，Hou et al., 2026）在策略空间做整合：学生自己采样回答，每个 prompt 按领域标签路由给对应专家，专家对**学生自己的回答**逐 token 给出 log-prob，形成稠密的蒸馏信号（Agarwal et al., 2023; Gu et al., 2024）。该配方已被多篇近期前沿模型后训练工作采用（§1 引用 DeepSeek-AI、NVIDIA 等 2026 年报告）。

**现有方法如何处理权重。** 路由规则只决定"谁教"；每个领域损失/反馈占多大权重，要么手工固定，要么按"剩余 teacher–student gap"或 token 份额设置（Gao et al., 2026 的 Open-MOPD 按领域平均奖励幅度的运行估计分配权重、做 token 分配与域预算）。作者指出：**这些权重都不考虑各专家反馈本身的离散程度**，而不同 RL 管线训出的专家，其反馈尺度不必可比（§1、§2，作者主张）。

**现有方法的失效条件（本文的核心观察）。** 在独立训练的 Qwen3.5-9B/4B/2B 三套专家池上，label 路由的 MOPD（表中记作 Label）学生：

- 在任一个规模上都没有超过"最强单教师学生"（六任务 Total：58.4 vs 58.5；50.3 vs 50.9；26.6 vs 28.8，Table 1–2、Table C.6，原文事实）；
- 几乎不传递数学专家的增益：8K 评测下只保留数学专家增益的 14–32%；16K 下数学相对初始化没有增益，4B 上甚至显著低于初始化（Table E.1：Label 数学增益 −0.86/−1.98/−0.60 pp，其中 4B 的区间不含 0）。

![专家跨域画像:每个专家的增益分布](/images/dailypaper/2026-09-29/2609.35347_fig3.svg)

**Fig. 3 解读（上图）：** 三个热图为 9B/4B/2B 三个专家池在 16K 下的"相对共享初始化的增益（pp）"，行为专家（Math/Code/IF expert）、列为评测域（Math/Code/IF），每格是该域两个任务的平均；对角线三格加黑框标记"专家在自域"的位置。读法有三点：(i) 每个专家的对角格全为正（如 Math expert 在 9B 数学 +4.5，Code expert 在 2B 代码 +10.3，IF expert 在 2B IF +9.4），说明**可迁移能力确实存在**；(ii) 非对角格有正有负（IF expert 在数学域 −2.6/−1.5/−1.9，Math expert 在 9B 代码 −1.7），说明单教师迁移也会"带副作用"；(iii) 关键对比是这张图与 Table E.1 的并置——数学专家在 9B 的 +4.5 到了 Label 学生手里只剩 8K 下的不到三成（保留率 14–32%），16K 下不升反降（−0.86），而"数学单教师 OPD"能拿到 +4.09（9B，16K）——由此论文把问题定位为"组合时机的问题"，而非"教师教不动"。

**支撑问题判断的证据。** 作者在训练信号上直接测到不平衡（§2、§3.2、App. D，原文事实）：

- 第一个训练批次（与 Label 共享同一初始学生，故也代表 Label 的起点）中，IF 的 log-ratio 离散度比例 $\sigma_d/\sigma_{\mathrm{all}}$ 为 4.41/2.93/2.32（9B/4B/2B），数学约 0.5（0.57/0.50/0.48），即 IF 离散度是整体信号的 2.3–4.4 倍（Table D.1）；
- IF 回答很短，只占约 1% 的响应 token，却贡献 51%/21%/19% 的池化 log-ratio 方差（Table D.2、App. D.5）；
- 在初始 4B 学生上按训练用的 response 级 reduction 计算逐域梯度：IF 梯度范数是数学/代码的 5–15 倍，等权下 IF 损失项贡献 94% 的合成梯度；把损失改为按 token 平均仍不能消除失衡（IF 仍占 88%）（Table D.3、App. D.5）；
- IF 梯度还是三个域中方向最不一致的：两个不相交 prompt 子集的梯度 cosine 只有 0.41，而数学/代码为 0.89/0.88（Table D.3）。

**作者认为的原因与核心假设。** 作者主张：路由决定反馈来源，但不校准反馈尺度；由于所有域更新共享的同一套参数，"哪个域的反馈幅度大"就劫持了更新（§1–§2，作者主张）。据此论文验证的核心假设是：**把每个领域的反馈按批次测得离散度重标定到共同尺度（有界、保号）即可改善多教师整合**，且这一操作不需要改路由、不需要额外教师调用（§1 贡献清单、§2）。

**三类问题的区分（审稿人判断）。** （i）"多专家整合"与"OPD 训练-推理失配"是领域早已存在的普遍问题；（ii）本文的新观察是**把"反馈尺度/离散度失衡"作为 MOPD 失效的候选原因并用训练信号量化**（前述 2.3–4.4 倍、94% 梯度份额等），这是具体、可核对的测量，但注意这是**现象与相关测量，不是完整的因果证明**——论文自己在 App. D.2 承认"数学放大与数学增益的对应关系不能识别因果"（9B 上代码乘子同样被放大却无代码增益）；（iii）本文实际解决的具体子问题是：在 Qwen3.5 同族、数学/代码/IF 三域、同规模教师-学生的设定下，把 label 路由配方的整合效果提升到超过最强单教师学生，并恢复大部分数学迁移。

## 2. 创新点是什么？

**一段话概括。** 真正的技术增量只有一个操作：在 label 路由的 MOPD 训练循环里，**每批次**用 rollout 阶段已缓存的 teacher–student log-ratio 估计"每个域相对整体批次的离散度比例"，给每个域一个**有界乘子** $w_d=\operatorname{clip}(\sigma_{\mathrm{all}}/\sigma_d,\,0.25,\,4)$，乘在将要进入裁剪策略梯度目标的蒸馏优势上（`stopgrad` 后使用）。它不改变路由、不改变提示配比、不引入 learned router、不额外调用教师；MOPD 就是 $w_d\equiv 1$ 的特例。差异在于**标定对象**：已有工作调节的是"各域损失权重/预算/奖励幅度"，本文调节的是"每个域反馈信号自身的尺度"。

**逐项分析（含与最近已有工作的差异）：**

1. **新增机制：有界、保号的域级离散度乘子（§2"Domain normalization"与"Student update"两小节，公式未编号）。** 统计量 $r_{i,t}=\ell^{T}_{i,t}-\ell^{\mathrm{roll}}_{i,t}$ 按有效 token 池化，$\sigma_d$ 为域内总体标准差，$\sigma_{\mathrm{all}}$ 为跨域池化标准差；乘子对"离散度小的域放大、离散度大的域衰减"，未裁剪时满足恒等式 $\operatorname{Std}(w_d r_d)=\sigma_{\mathrm{all}}$。只乘正因子、不减去域均值，**保留每个优势的方向语义**。与最接近的 Open-MOPD（Gao et al., 2026）相比有三处明确差异（App. D.1）：按**离散度**而非均值奖励幅度缩放；**每批次重估**而非运行估计；裁剪区间 $[0.25,4]$ 而非 $[0.05,20]$。与 PowerOPD（变换采样 token 奖励幅度）、ExOPD（reward/KL 平衡）、DAPO/Dr. GRPO（response/token 级归一化）、多任务学习的梯度范数/不确定性加权、PopArt（值目标归一化）等，作者主张 DN-MOPD 针对的是"多教师反馈尺度"这一未被处理的失衡（§4）。**原创边界说明：依据本文 related work 与实验对比，只能确认作者声称的这些差异；是否构成该问题的首次提出，需要更完整的文献检索。**
2. **对应问题的逻辑。** 如果"IF 反馈离散度是整体 2.3–4.4 倍、且贡献 94% 初始梯度"成立，那么按离散度把所有域拉到共同尺度，应直接削减这种劫持；$w_d$ 全为 1 时严格回退到 Label，因此任何相对于 Label 的差异只能来自这一操作（Table 3 的对照设计）。**该逻辑的实证强度有界限**：见 §4.3 与 §5 质疑 1——实验显示"压下 IF"才是有效成分，"放大数学"（离散度匹配的另一半）单独只恢复一半甚至极少，且离散度归一化未验证因果。
3. **对"不可替代性/有效性"的原文证据。** （i）替换路由的两类变体（Uniform pooling 教师概率平均、Dynamic 按当前回答选教师）在三个规模均无一致增益（Table 3：−0.41/−0.69/+0.30 与 −0.25/+0.28/−0.07），说明"改分配"不够；（ii）保留 Label 路由但只改信号的其他干预（annealed injection 早期模仿）也没有一致增益（−0.24/+1.11/+0.30）；（iii）固定权重控制（App. C.6，Table C.11）给"离散度标定"做减法：只把数学放大到 2（其余为 1）在 4B 只恢复约一半收益（+1.20 vs DN 的 +2.24），2B 几乎没有（+0.27 且区间含 0）；只把 IF 压到 0.25 则恢复大部分（+1.79/+2.19），并把数学域均分抬高 2.76/3.07 pp。**这意味着"有效的成分"主要是给高离散域的反馈设上限，而非归一化本身**（原文事实+审稿人判断）。
4. **工程实现性质。** 相对已有优势：一次池化标准差 + 每域标准差的计算，复用 rollout 已缓存的 log-prob，**无额外教师前向**（§2 "Cost and scope"、App. D.1）；相对 Label 只改 advantage 计算，其余（掩码、reduction、clip 界）原样继承（App. D.1）。这是"已有组件（PPO 式裁剪目标 + 优势重标定）在特定统计量上的新组合"，不是全新训练范式。

## 3. 作者如何解决？

**直觉（先讲清"为什么可能有效"）。** 把三个教师想成三位口径不同的顾问：数学教师说话"温吞"（log-ratio 幅度小），IF 教师说话"激烈"（幅度大且乱）。学生同时听三个人，虽然每人给的意见都标了方向（正/负号），但音量差了好几倍，结果激进、方向又最不一致的那位主导了学生的每一次修改。DN-MOPD 的做法不是换顾问（不改路由），而是**每轮先量一遍各自音量，然后给每人配一个音量旋钮**——离散度大就调小（压上限）、小就调大（提增益），旋钮被限定在 4 倍以内以防极端值，并且只调音量、不改意见的正负。**教学简化示例：以上"音量旋钮"类比只用于直觉说明，不是论文中的表述，也不是论文实验的一部分。**

**整体流程（Fig. 2 的四个步骤，正文与图注一致）：**

1. **学生滚动采样（Student rollout）。**
   输入是带领域标签的提示 $(x,d)$（$d\in\{\text{math},\text{code},\text{IF}\}$），学生 $\pi_u$ 对提示自己生成回答 $y=(y_1,\dots,y_n)\sim\pi_u(\cdot\mid x)$。这一步同时缓存 rollout 服务的逐 token log-prob $\ell^{\mathrm{roll}}$，并做一次 **actor 重评估**：训练器在更新前重新计算 $\ell^{\mathrm{actor}}$。两套 log-prob 用途不同（App. D.1，原文事实）：$\ell^{\mathrm{roll}}$ 只进尺度估计（$r=\ell^{T}-\ell^{\mathrm{roll}}$），$\ell^{\mathrm{actor}}$ 进优势与策略比分母（$A=\ell^{T}-\ell^{\mathrm{actor}}$）。
2. **领域教师打分（Domain teacher）。**
   按标签路由到**冻结**的对应专家（$T_{\mathrm{math}}/T_{\mathrm{code}}/T_{\mathrm{IF}}$，图中用锁形图标表示冻结；每个规模一个专家池、每个回答只由本域专家打分），专家对学生的同一回答逐 token 给出 log-prob $\ell^{T}$，与 $\ell^{\mathrm{roll}}$ 一起形成"打分批次"。
3. **域归一化（Domain normalization，DN-MOPD 的核心，§2）。**
   在每个训练批次内：对每个域计算 $\sigma_d$（该域全部有效回答 token 上 $r$ 的总体标准差），以及跨域池化的 $\sigma_{\mathrm{all}}$；然后
   $$w_d=\operatorname{clip}\!\left(\frac{\sigma_{\mathrm{all}}}{\sigma_d},\,0.25,\,4\right),\qquad \widetilde{A}_t=w_d\,A_t.$$
   未裁剪且非退化时 $\operatorname{Std}(w_d r_d)=\sigma_{\mathrm{all}}$，即"把该域的 rollout 信号拉到整体尺度"；若任一标准差为 0 或观测少于 2，取 $w_d=1$。注意两个刻意的实现细节：统计量按 **token 池化**，而损失按 **response 平均**（先组内平均再跨组平均），作者在 App. D.3 明确指出二者 reduction 不同，且 $\sigma_{\mathrm{all}}$ 本身混合了域间均值差项（方差分解 $\sigma_{\mathrm{all}}^{2}=\sum_d p_d\left[\sigma_d^{2}+(\mu_d-\mu_{\mathrm{all}})^{2}\right]$），所以这**不是**"每个域独立归一化到单位方差"。
4. **学生更新（Student update，§2；对应 Algorithm 1 第 11–13 行）。**
   重算的 actor 优势 $A_{i,t}=\ell^{T}_{i,t}-\ell^{\mathrm{actor}}_{i,t}$ 与乘子结合 $\widetilde{A}_{i,t}=\operatorname{stopgrad}(w_{d_i}A_{i,t})$，进入与 Label 相同的裁剪策略梯度 token 损失
   $$\mathcal{L}_{i,t}(\theta)=-\min\left\{\rho_{i,t}(\theta)\widetilde{A}_{i,t},\ \operatorname{clip}\bigl(\rho_{i,t}(\theta),\,1-\eta_-,\,1+\eta_+\bigr)\widetilde{A}_{i,t}\right\},\qquad \rho_{i,t}(\theta)=\frac{\pi_\theta(y_{i,t}\mid h_{i,t})}{\exp(\ell^{\mathrm{actor}}_{i,t})},$$
   裁剪界 $\eta_-=\eta_+=0.2$；不参与更新的 prompt/padding 位置走原有掩码。Algorithm 1 汇总了整轮迭代（采样→打分→统计→应用→更新）。

**哪些行为由模型决定、哪些由固定流程控制（审稿人整理）：** 路由完全由数据标签固定；乘子由批统计确定性地计算（非学习、无新参数）；教师的打分与学生的生成行为分别由冻结专家与当前策略决定；只有学生参数被更新。**推理由此阶段无任何变化**（方法只改训练期 advantage，不改模型结构、不改解码），最终产物就是一个同时具备三域能力的学生 checkpoint。

**Fig. 2 解读（上图的四个环节）：** 环节 1（左）显示输入是带标签提示（Math/Code/IF 三色标签）与学生自采样回答，并同时产生两条关键信息流——回答本身（给出题教师打分）和缓存的 $\ell^{\mathrm{roll}}$（供环节 3 估尺度）；"Actor re-evaluation 重算 $\ell^{\mathrm{actor}}$" 分支说明**同一回答会被打分两次**（一次给尺度、一次给优势），这是实现细节中最容易误读的一处。环节 2 显示按标签路由到三个冻结专家，教师只读学生回答、不生成新答案，保证"同一条回答"上可比。环节 3 是 DN-MOPD 相对 MOPD 唯一新增的盒子：上框估尺度（$\sigma_d$、$\sigma_{\mathrm{all}}$、$w_d$ 公式），下框把乘子只乘进 actor 侧优势并 detach（"Positive scaling preserves signs"）。环节 4 输出裁剪 OPD 目标、更新学生，并回连到下一迭代。图中"锁"表示教师冻结、"stopgrad"表示乘子不参与求导、"Next iteration"回路表示该方法在**每个批次**重估乘子——这三点正是方法"无新参数、可插拔到现有 MOPD 管线"的直观来源。

![标签路由与 DN-MOPD 的对比示意及增益](/images/dailypaper/2026-09-29/2609.35347_fig1.svg)

**Fig. 1 解读（上图三格）：** (a) 显示三个域在同一轴上的 teacher–student log-ratio 分布示意——"同样路由、不同尺度"（Math 点稀、IF 点带长尾），且下方标注 "Same routing, different scales"；(b) 是方法直觉：DN-MOPD 对数学"放大（Amplify）"、代码"复位（Rescale）"、IF"衰减（Attenuate）"，重标定后三域信号幅度可比再进入共享学生，标注 "Bounded scaling; signs preserved" 强调有界与保号；(c) 是六任务平均增益的条形图（青=8K 评测、深蓝=16K 评测）：9B +2.47/+1.17、4B +3.08/+2.24、2B +2.92/+2.36——同一张图直观反映论文两个反复出现的边界：**增益在各规模一致为正，但更短的 8K 评测上限下增益更大**。

**论文实际测得的方法行为（§2 "What the rule does in practice"、Table D.1/D.2，原文事实）：** 在 Qwen3.5 运行中，数学乘子的中位数约 1.54/2.03/2.06（9B/4B/2B），代码约 1.57/0.98/0.89（仅 9B 被放大），IF 因离散度过大**在大多数批次被压到 0.25 下限**（触底批次：115/115、99/134、135/160）。作者据此明说：规则对 IF 是"给反馈设上限"而非"完全均衡离散度"。此外，三个 Label 种子运行中**记录但不应用**的"本应乘子"在数学上稳定在 1.49–1.93、IF 在 0.25–0.34，跨种子几乎不变（Table D.2），说明这种失衡是系统性的、不依赖 DN-MOPD 训练。

**训练配置（App. A.1，原文事实）：** 每个规模从同一初始模型出发（专家与学生同源），三专家用 GRPO（temperature 1.0、prompt ≤2,048 token、回答 ≤8,192 token、最多 400 update，实际 checkpoint update 数 200–400 不等，Table A.1）；学生训练用固定混合 2,700 条提示（900/域；数学来自 DeepMath-103K，代码来自 Eurus，IF 为生成提示），每批 64 prompts × 8 responses = 512 responses，学习率 $10^{-6}$、80 updates、种子 42（43/44 见 App. C.5）。**成本：** 相对 Label 无额外教师调用与模型，只多一次统计计算；乘子轨迹被记录进运行审计。

## 4. 解决得怎么样？

#### 4.1 实验设置

- **模型与数据：** Qwen3.5-9B/4B/2B 各一套独立训练的数学/代码/IF 专家池；学生与专家同规模、同初始化；主 OPD 比较在**同一规模内共享专家、初始化、提示混合与更新预算**（§3、App. A.1）。评测：AIME25/AIME26（各 30 题 ×64 采样）、LiveCodeBench v5/v6（167/175 个互不重叠问题 ×6 采样）、IFEval-541 与 IFBench-300（×16 采样，strict prompt-level）；数学用 Math-Verify 取最后一个 boxed 表达式（缺失记错），代码用官方 LCB runner（每题全部测试通过才算对）；评分为 avg@N（先题内平均再跨题平均，估计单答案正确率，非 pass@N）。评测使用 non-thinking 渲染、temperature/top-p 1.0、生成种子 42，同一 checkpoint 在 8K 与 16K 两个回答上限下各评一次（App. A.3）。
- **基线：** 初始学生；三位 RL 专家；三个单教师 OPD 学生；Uniform pooling（教师概率平均）；Dynamic router（按当前学生回答选教师）；Label 路由 MOPD；SeqKD-SFT（对教师固定答案做离线蒸馏，16K cap、84 updates、约 4 遍固定答案）；参数平均与 task arithmetic（$\lambda=1$）合并（Table 1–2）；外加消融型对照：annealed injection、固定权重（数学×2、IF×0.25、首批次权重、全局 2/1/0.25）（Table 3、C.11）。
- **统计口径：** 配对 95% 区间用 10,000 次 question-level bootstrap（种子 20260923），**条件在单一学生训练种子与单一专家池上**，不覆盖专家重训或学生重训方差（App. A.3）；种子 43/44 只改变 prompt 顺序与 rollout 采样（App. C.5）。"最强单教师学生"按同一 public Total 选择（此选择对比较对象有利，作者明说 "favoring that comparator"）。
- **方法选择与报告口径（App. A.4，重要背景）：** 域缩放操作与裁剪界在**早期 Qwen3 开发仪器**上选定后原样迁移到 Qwen3.5；主表显示 16K 是检查两个 cap 之后的**展示选择**（原协议为 8K），作者主动披露为 "presentation amendment, not a preregistered preference"，并保留全部 8K 结果。
- **附注（透明度）：** 论文附 AI use statement，说明作者用 LLM agents 编写训练/评测脚本、起草文字并在作者指导下核对引用与重算数字，人类作者声明对全部结论负责（§AI use statement，原文事实）。

#### 4.2 关键结果

**主对比（DN-MOPD vs Label，六任务平均 Total，pp）：** 16K：+1.17 [+0.28,+2.03]（9B）、+2.24 [+1.30,+3.20]（4B）、+2.36 [+1.58,+3.17]（2B）（Table C.4）；8K：+2.47 [+1.65,+3.27]、+3.08 [+2.12,+4.06]、+2.92 [+2.02,+3.85]（Table C.5），所有配对区间在种子 42 上均高于 0；三个学生种子（42/43/44）的均值差 +1.12/+1.97/+2.34（16K，两级 bootstrap 区间不含 0，Table C.10），9 个"逐种子配对"全部倾向 DN-MOPD。作为噪声参照：第二个种子 42 Label 重跑与原运行差 −0.32/+0.62/+0.19（区间全含 0），小于主增益量级（App. C.5）。续表（Table 1–2，16K）：Total 从 Label 的 58.4/50.3/26.6 提到 59.6/52.5/29.0。

**vs 最强单教师学生（Table C.6、C.7）：** Label 在全部 6 个（规模×cap）单元都不超过最强单教师学生（其中 4 个单元显著为负）；DN-MOPD 全部为正，但仅 4/6 单元可分离——**9B@8K +0.78 [−0.13,+1.68] 与 2B@16K +0.13 [−0.68,+0.93] 的区间含 0**。9B@16K 为 +1.08 [+0.20,+1.98]；把 9B 代码教师学生续训到 160 updates 后它不再提升（160−80 差 −0.34，区间含 0），DN-MOPD 的领先扩大到 +2.57 [+1.65,+3.46]（Table C.7，原文事实）。

**分域结果（Table C.8，16K，80 updates，DN−Label）：** 数学是主导：+3.98 [+2.32,+5.68]、+3.75 [+1.95,+5.60]、+3.72 [+2.03,+5.52]，全部区间高于 0；代码混合：9B 为 −0.82 [−2.78,+1.06]（16K，含 0；同规模 8K 为 +2.51 [+0.78,+4.22]），4B/2B 为正；IF 变化小（+0.36/+0.82/+0.47，部分含 0）。数学迁移率（App. E.1）：8K 下 DN-MOPD 保留数学专家增益的 61–90%，Label 仅 14–32%；16K 下 Label 三规模数学增益均 ≤0（4B 显著为负 −1.98 [−3.78,−0.18]），DN-MOPD 为 +3.12/+1.77/+3.12（区间均含 0 之上）。补充数学基准 MATH-500（Table C.12，不在 Total 内）：DN−Label 为 +0.74、+1.25、+5.95（区间均高于 0），其中 2B 差距大（初始 76.91 → DN 83.16）；9B/4B 接近天花板（初始 95.84/94.46），绝对差值小属预期。**长度/截断（Table 4、C.9）：** 数学提分伴随**更短**回答与更少触顶，且两个 cap 下方向一致（16K：9B 数学均值 token 7,032 vs Label 8,637，触顶率 5.2% vs 9.8%；4B 6,146 vs 8,653，5.3% vs 12.4%；2B 7,444 vs 10,246，13.5% vs 20.2%。8K：9B 5,712 vs 6,071，25.7% vs 31.4%；4B 5,642 vs 6,318，26.4% vs 36.2%；2B 6,700 vs 7,443，34.5% vs 45.4%）。

**控制实验（Table 3、C.6、C.11）：** 改路由的 Uniform/Dynamic、改信号的 annealed injection 都无一致增益；固定权重拆解显示：**"只压 IF 到 0.25"在 4B/2B 恢复 DN-MOPD 的大部分增益（相对 Label +1.79/+2.19，且对 DN 的差为 −0.44/−0.17，区间含 0），并单独把数学抬高约 3 pp；"只放大数学到 2"仅恢复 4B 的一半（+1.20）、2B 几乎没有（+0.27）。** 用"首批次测得乘子"固定全程：9B/4B 与 DN-MOPD 无可测差异（+0.12/+0.10，含 0），2B 显著落后（−1.10 [−1.74,−0.47]）；全局常数 (2,1,0.25)：9B/4B@16K 可观、4B@8K 甚至更好（+0.85 [+0.21,+1.50]）、2B@8K 较差（−0.64 [−1.14,−0.12]）。**即：每批次统计重估相对"一次性固定权重"的增量只在 2B 被检出**（作者在 §5 也如此总结）。**训练时长（Table 5、C.2/C.3）：** 160 updates 后差距缩小（4B：Label 51.6 vs DN 53.1；2B：28.3 vs 30.0），8K 下 Label@160 仍达不到 DN@80（差 1.93/1.95/1.71，区间全高于 0），16K 下差距收窄到 +0.18~+0.94、区间含 0 或贴 0——**收敛后的最终排序未定**（§3.3 原文承认）。

**明确的负结果/边界（不得被平均分掩盖）：** （i）9B 代码在 16K 下不加反微降（−0.82，含 0），作者明说"不能据此确立代码代价"但也未确立收益；（ii）IF 域增益普遍在 ±1 pp 内；（iii）相对最强单教师学生在 2 个单元区间含 0；（iv）**SeqKD-SFT 与 task arithmetic 的总分在每个规模都高于 DN-MOPD**（9B：62.6/60.5 vs 59.6；4B：55.9/53.2 vs 52.5；2B：32.9/32.7 vs 29.0，Table 1–2），作者用"各自配方不同（token 暴露与 compute 不同）"解释，但也明说"最清晰的证据是改进了 label 路由配方"（§3.1）；（v）**早期 Qwen3-4B 构造上无清晰增益**（Table E.2：ΔTotal +0.02 [−0.56,+0.59]，全部域区间含 0；该构造下数学乘子中位数仅 1.00，因 Label 本身已迁移了数学能力）。

#### 4.3 机制证据

先分开两类证据（审稿人判断）：

**效果证据（方法是否有效）** 是充分的：主对比固定了教师、初始化、提示与更新预算，只改反馈权重；三规模×两 cap×三种子的方向一致，且第二大 Label 重跑给出噪声量级参照。

**机制证据（为什么有效）** 分三层，强度递减：

1. **失衡的存在性**有直接测量：首批次 $\sigma_d/\sigma_{\mathrm{all}}$（Table D.1）、IF 的方差份额与 token 份额错位（Table D.2）、逐域梯度份额 94%→（DN 首批次权重下）64%、数学/代码份额 1%/5%→16%/20%（Table D.3）、IF 梯度方向一致性最差（0.41；Label 训练 80 updates 后降至 −0.07）。这些测量显示"IF 反馈在共享更新中占比失衡"是训练前的既有事实，而非 DN-MOPD 造成。
2. **操作与结果的对应**有正有反：放大数学与数学增益出现同向对应（Fig. 4a/4b/4c：数学乘子全程 1.5–2.2、数学域增益 +3.7~+4.0），**但作者自己给出两个反例**——(i) 9B 的代码乘子同样被放大到 ≈1.5，代码在 16K 却无增益，故"放大不保证增益"（App. D.2）；(ii) 固定权重控制表明"只压 IF"就恢复大部分增益，说明起作用的主要是**限制高离散域的影响**，而不是"离散度匹配"这一机制本身（§3.2、App. C.6）。训练 80 updates 后：DN-MOPD 学生的数学/代码 log-ratio 标准差收敛到 0.07/0.12，Label 学生的为 0.20/0.41（初始 0.31/0.68），与"DN-MOPD 学生吸收了更多数学/代码反馈"一致（App. D.5）。
3. **因果与替代解释的排除**不完整：作者明说梯度测量是描述性的（单一 probe 集、policy ratio 为 1、不含裁剪与优化器状态），"不构成能力差异的原因证明"（App. D.5）；对 σ_all 混合域均值差项、token-pooled 统计 vs response 级损失的 reduction 差异都做了说明，但**未单独消融统计量选择、裁剪界、域配比**（App. D.4 原文承认 "The experiments do not separately vary the clipping bounds, domain proportions or the statistic used to estimate scale"）。此外，唯一被证伪（在 9B 上）的替代解释是"更长的生成"——DN-MOPD 的回答更短、触顶更少（Table 4）。

![反馈尺度、域增益与训练乘子](/images/dailypaper/2026-09-29/2609.35347_fig4.svg)

**Fig. 4 解读（机制证据的主图）：** 面板 (a) 用对数轴展示各域相对离散度 $\sigma_d/\sigma_{\mathrm{all}}$ 的中位数与四分位（覆盖含续训的全部记录批次）：数学（橙点）稳定低于 1、代码（蓝方）≈1、IF（紫三角）数倍于整体——这是"失衡持续存在"的证据；面板 (b) 是 DN−Label 的分域增益（16K 点估计）：数学 +4.0/+3.8/+3.7、代码 −0.8/+2.1/+2.9、IF +0.4/+0.8/+0.5——说明优点集中在数学、代码跨规模不稳定、IF 基本持平；面板 (c) 是训练过程中的乘子轨迹（每规模一列，虚线在第 80 update 处）：数学（实线橙）全程约 1.5–2.2，代码（蓝）≈1（9B 略高），IF（紫实线）贴着 1/4 下限、其"裁剪前原始乘子"（点线）低到约 1/8——**该面板直接显示规则对 IF 是"限幅"而非"等化"**，也是"增益主要来自压 IF"这一判断的原始出处。

#### 4.4 成本与适用范围

- **训练成本：** 相对 Label 无额外教师前向、无新增可学参数、无额外模型；每批次多两次标准统计与一次标量乘（§2、App. D.1）。**论文未报告** GPU 小时数、墙钟时间、教师池构建总成本（三规模×三专家，各 200–400 GRPO update）以及存储量；因此"低开销"只能理解为算法级增量小，绝对成本无法从原文核验。
- **推理成本：** 无变化（方法不改结构/解码，§2；Table 4 显示推理回答反而更短、触顶更少，但作者提示平均长度不等于时延/成本）。
- **人工/外部依赖：** 无人工标注新增；教师池、提示数据与评测集均为公开或自建数据（App. A.1、Ethics statement：无人类受试与个人数据；代码 judge 在资源受限沙箱运行）。
- **复现材料：** 仓库发布 80 个评测模型的逐题对错、重算全部分数与区间的脚本、DN-MOPD 参考实现与单元测试、训练配方；**checkpoints 未发布**（Reproducibility statement）。
- **适用范围（论文自身边界，§5）：** 单一模型家族、每规模一个专家池、三域设定；学生种子不覆盖专家重训；方法在 Qwen3 开发仪器上选定（App. A.4）并存在 Qwen3-4B 无增益先例（App. E.2）；标定值依赖域构成与回答长度；裁剪界未按规模调参；收益在 16K 评测上限下收缩；**"收敛后的最终排序未解决"**（§3.3）。得到改善的问题：Qwen3.5 池上 label 路由整合效果逼近/超过最强单教师学生、数学迁移恢复大部分。仍未解决：跨家族/跨池的普适性、per-batch 估计何时值得（只在 2B 检出）、相对更强离线整合方法的差距。

## 5. 最容易受到审稿人质疑的地方

#### 质疑：增益的主要来源是"压下 IF 反馈"，而不是论文标题与摘要主打的"域归一化/离散度匹配"机制，固定常数权重即可复现大部分收益

- **原文依据：** Table 3 与 Table C.11：只压 IF（1/1/0.25）在 4B/2B@16K 相对 Label 为 +1.79/+2.19，与 DN-MOPD 的差仅为 −0.44 [−1.35,+0.48] 与 −0.17 [−0.84,+0.52]；"首批次乘子固定全程"在 9B/4B 与 DN-MOPD 无可测差异；Table D.1 显示 IF 乘子长期贴 0.25 下限（"bounds rather than equalizes"）。
- **为什么重要：** 这决定创新性的定位——若一个训练前测一次即可固定的常数能达到同样效果，那么"每批次用离散度统计做自适应标定"的必要性与其机制解释都被显著削弱（论文自己也承认 per-batch 的增量只在 2B 被检出）。
- **当前能够得出的判断：** "反馈尺度需要标定"这一结论有证据；"离散度归一化是正确机制"只有间接支持且有反例（9B 代码被放大但无增益；σ_all 混有域均值差项）。结论范围应限定为"在测量驱动下给主导域限幅"。
- **如何验证或补强：** 在更多规模/域组合上系统比较 per-batch 与多组固定权重；对裁剪区间 (0.25,4) 做消融；报告"只放大数学"在更大规模是否也失效；给出"何时该相信 per-batch 估计"的判据。
- **严重程度：** 主要问题。

#### 质疑：外部有效性有限——所有正向证据来自 Qwen3.5 一族三规模、每规模单一专家池，作者自己的前身构造无增益

- **原文依据：** §5 limitations：one expert pool per size within one model family；App. E.2：Qwen3-4B 构造 ΔTotal +0.02 [−0.56,+0.59]，各域区间含 0，且该构造下数学乘子中位数是 1.00；App. A.4：方法在早期 Qwen3 开发仪器上选定后迁移；App. A.3：置信区间条件在单一学生种子与专家池上，不覆盖专家重训。
- **为什么重要：** 论文的结论句（"整合专家需要同时决定谁教与反馈多强"）是原则性主张，但证据只是一个家族的三个规模，且存在一个同作者反例；跨模型家族、跨域数、跨专家训练方式的可迁移性无法从前文确认。
- **当前能够得出的判断：** 在 Qwen3.5 三规模（三域）上成立；作为普适原则"无法确认"。作者对这一点披露充分，没有夸大。
- **如何验证或补强：** 在第二、第三个模型家族与不同 RL 配方（如不同 KL/奖励塑形）上复现；重训专家池多份以估计池间方差；扩充到 4 个以上域。
- **严重程度：** 主要问题。

#### 质疑：与更强的离线整合基线相比总分全面落后，缺少 compute-matched 的公平对照

- **原文依据：** Table 1–2：SeqKD-SFT（62.6/55.9/32.9）与 ParamMerge-TA（60.5/53.2/32.7）在三个规模均高于 DN-MOPD（59.6/52.5/29.0）；App. A.2 说明 SeqKD 用 16K cap 的固定教师答案训 84 updates（约 4 遍）、LR $10^{-5}$，教师答案库复用——与 OPD 的 token/优化预算不同；§3.1 原文："SeqKD-SFT and task arithmetic retain higher Totals under their own training recipes"。
- **为什么重要：** 读者最关心的问题是"部署时该选哪条路线"；若离线蒸馏在此设置下更便宜且更强（9B 的 SeqKD 学生 62.6 甚至超过所有专家本身的最高 58.9），那么本文"OPD 整合"的价值主张只在"必须与现有 OPD 管线兼容"这一狭窄前提下成立。
- **当前能够得出的判断：** 现有证据只支持"DN-MOPD 改进了 label 路由配方"，不足以支持"OPD 整合优于离线整合"；预算不等使跨路线比较无法定论，但也意味着"DN-MOPD 是更好的整合方法"这类外推不成立。
- **如何验证或补强：** 匹配 token/FLOP 预算的离线蒸馏 vs OPD 对照；报告两种路线在相同教师池上的 scaling 曲线；解释 SeqKD 学生为何能超教师（多域数据协同？），并检查 OPD 学生是否也有该效应。
- **严重程度：** 主要问题（对论文的定位与结论表述），方法本身的增量不受影响（次要）。

#### 质疑：统计效力与稳定性——区间条件于单一种子与单池，关键比较区间含 0，题目规模小

- **原文依据：** App. A.3（区间不覆盖专家/学生重训方差）；App. C.5（种子 43/44 只改 prompt 顺序与采样，非全量独立重复）；Table C.6（DN−single 在 9B@8K、2B@16K 含 0）；AIME 仅各 30 题；Table C.11 的固定权重控制只用单种子。
- **为什么重要：** 论文最强主张是对 Label 的稳定改进（证据较好），次强主张是"超过最强单教师学生"（证据较弱）；若采纳者以"超过单教师学生"为选择依据，2B/16K 的 +0.13 无法支撑。
- **当前能够得出的判断：** 对 Label 的增益在三规模两 cap 三种子方向一致、可视为稳健；"超过最强单教师"目前只在部分单元可分离，属临界结论。
- **如何验证或补强：** 多个独立专家池与完整种子矩阵（含重训专家）；把最强单教师学生也纳入多种子对照；增大 AIME 等题量或增加补充数学基准（已有 MATH-500 可扩样）。
- **严重程度：** 次要问题（对主结论）+ 主要问题（对"超过单教师"这一小节结论）。

#### 质疑：评测协议存在事后自由度——主表 16K 是检查两个 cap 后的展示选择，增益对评测长度敏感

- **原文依据：** App. A.4（原协议 8K，"The choice to show 16K in the main text was made after both caps had been inspected"，作者自述为 presentation amendment）；增益在 8K 更大（+2.47~+3.08）而在 16K 收缩（+1.17~+2.36），且"允许更长回答对 Label 帮助更大"（§3.3、App. C.3）；MATH-500 在 9B/4B 接近天花板（Table C.12）；Total 为作者自定义的六任务等权平均，会掩盖域内反向变化（如 9B 代码专家在数学域 −1.7，Fig. 3）。
- **为什么重要：** 这类"事后选择展示口径"即使被披露，也会改变读者对效应大小的感知；结论对回答长度预算的敏感性意味着使用场景（生成预算）会成为方法有效性的隐含条件。
- **当前能够得出的判断：** 作者披露充分（含全部 8K 表），未发现选择性隐藏；但"效应大小"应同时读两个 cap，且不应以 16K 的收窄结果反推 8K 也如此。
- **如何验证或补强：** 预注册单一评测协议，或全部 cap 平行报告并预先声明主口径；报告 Total 之外的域级与稳健性摘要（论文已有）。
- **严重程度：** 次要问题。

## 6. 审稿式总评

> 作者发现按领域标签路由的多教师在线蒸馏不能把 RL 专家的能力真正整合进一个学生（打不过最强单教师学生、数学几乎不迁移），并把原因落到一个可直接测量的量——各域 teacher–student log-ratio 反馈的尺度失衡（IF 首批次离散度为整体的 2.3–4.4 倍、贡献初始 4B 学生 94% 的合成梯度）；因此提出 DN-MOPD，通过每批次、按域、有界且保号的乘子 $w_d=\operatorname{clip}(\sigma_{\mathrm{all}}/\sigma_d,0.25,4)$ 重标定蒸馏优势，以近乎零的算法增量接入现有 MOPD 管线。实验在 Qwen3.5-9B/4B/2B 的六基准上表明：平均分在两个评测上限与三个种子下一致优于 Label 路由（16K +1.17~+2.36 pp，8K +2.47~+3.08 pp），并把数学迁移率从 14–32% 提到 61–90%；其中"优于 Label"的证据较强（固定教师/数据/预算的配对设计、完整附录、公开重算脚本），但"机制是离散度归一化"仍缺少充分支持——作者自己的控制实验显示固定常数权重即可复现大部分收益、且增益主要来自压制 IF；"超过最强单教师学生"在 2 个单元仍含 0，"优于离线整合路线"则被 SeqKD/参数合并更高的总分否定。本文最有价值的部分是问题诊断的诚实度与控制实验的完整度（含对自身叙事不利的固定权重与边界构造），最大的审稿风险是创新点与标题叙事（"域归一化"）被自身证据降格为"给高离散域限幅"的工程校准，且外部有效性尚未跨出 Qwen3.5 一族。

- **问题定义清晰度：** 强——失效条件（不超单教师、数学不迁移）与原因测量（离散度、梯度份额）都有明确数字与位置。
- **创新性证据：** 中——机制是单点、简单的组合式改进；自证实验中"每批次自适应"相对固定常数只在 2B 显现，原创边界需更完整文献检索。
- **方法可信度：** 中——公式、实现、恒等式与退化处理都清晰且可复现，但论文对"为什么有效"的机制叙事与自身控制实验存在张力。
- **实验支持力度：** 中——对"优于 Label"强（3 规模×2 cap×3 种子+完整附录+公开记录）；对"超过单教师""跨构造普适"弱（含 0 区间与 Qwen3-4B 反例）。
- **可复现性：** 强——评分级复现材料（逐题记录、重算脚本、参考实现、单元测试、训练配方）已发布；checkpoints 尚未发布使训练级复现暂无法核验。
- **综合阅读价值：** 高——这是一篇诊断先于方法的诚实研究，适合作为"如何用控制实验检验自己机制主张"的案例阅读。
