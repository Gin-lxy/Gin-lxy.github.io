## 0. 一句话结论

LayerEditor 把「按指令编辑一张图」与「输出 N 个有序 RGBA 图层」合并为一次联合生成：源图、指令和层数进入同一个多模态扩散 Transformer（MMDiT），编辑画布与每层 RGB/Alpha 作为同一 token 序列共同去噪；再用冻结的原始编辑器作教师，在学生自己的去噪轨迹上同时监督直接画布与图层重合成结果（组合式编辑先验蒸馏，C-EPD）。论文在自建的 Crello-Testset/ScaleEdit-Testset 上报告 Composite SSIM 0.8351/0.8839、Alpha IoU 0.6074/0.6802，均优于 Seedream5-Pro (Joint) 等基线；但评测基准与训练数据共享源数据集和构造管线、参考层部分由模型流水线构造、评分主要依赖单一视觉语言模型（VLM），证据目前支持「论文构建的分层设计分布内有效」，还不足以证明通用真实设计场景中的可复用性。

## 1. 论文具体想解决什么问题？

先把任务定义说清楚。输入是源图 $I^{\mathrm{src}}$、编辑指令 $u$ 和请求层数 $N$；输出包括一张直接生成的编辑画布 $\mathcal{D}$ 与一组从后到前的有序 RGBA 图层 $\mathcal{S}=\{\mathcal{L}_i=(R_i,A_i)\}_{i=0}^{N-1}$，其中 $R_i$ 是该层的 RGB 外观，$A_i$ 是连续透明度。把所有层按 alpha-over（按透明度从前到后覆盖）规则合成得到 $\mathcal{C}=\operatorname{Comp}(\mathcal{S})$，它应尽量接近编辑目标；$\mathcal{D}$ 是辅助画布，不属于图层栈。指令还可以逐层指定内容，例如「文字单独一层、每只鸟一层、背景一层」。因此这不是单纯的图像分解，而是「指令编辑 + 结构化分层 + 层内容控制」的联合任务；I2L（image-to-layer decomposition，图像到图层分解）只是把指令换成「保持原图」时的特例。图 1 给出这个任务的具体形态。

![图 1：LayerEditor 的任务形态](/images/dailypaper/2026-10-23/layeredit_fig1.png)

**图 1**（论文 Fig. 1）：这张图先交代任务的输入输出，而不是模型结构。左侧是源海报与「替换照片、生成 6 个 RGBA 图层」的指令，中间是编辑后的画布，右侧把同一结果拆成按前后顺序排列的层（背景、外框、物体、标题、文字、装饰），最右展示两件下游操作：只翻译文字层、只给背景层换色。它说明 LayerEditor 的目标不是「先编辑、再抠图」，而是在一次生成里同时交付画布和可独立操作的层；层的内容由指令指定，层数也可变。读图时要抓住两个约束：所有层必须能重新合成回编辑结果，且每层要尽量只包含一类可复用内容。

研究背景是：现有编辑模型通常输出一张扁平画布，文字、物体和背景融合在一起；下游设计（电商、广告、海报）若要移动文字、换背景或复用某个元素，只能重新生成或手工抠图。分层生成与分解方法能恢复层，但编辑和分解往往分开优化：编辑模型不关心层结构，分解模型不知道用户的编辑意图；级联流程会把编辑误差带进分解，层不完整或组织混乱时又要重试。Agent Banana 这类系统把分层工作流代理化，但仍然是级联。LaDe 已经能联合生成设计画布与 RGBA 层，UniWorld-Design 支持分层生成与提示控制的分解，不过它们更偏向从文本/布局生成或事后分解，而不是「对一张已有扁平图执行编辑并输出其编辑后的层栈」；论文据此定位自己的差异（§1、§2.2）。

作者还报告了一个具体现象：把预训练编辑模型直接适配成分层输出（分层 SFT）会让原来的编辑能力退化，出现文字损坏、结构扭曲、周围内容被意外改变（§3.2；原文此处写 Figure 3，但按图题对应的是 Figure 7）。这不是「编辑模型本身不行」，而是「分层适配把编辑先验挤掉」的解释。支撑现象的直接证据是 Table 3 的 w/o C-EPD 行：编辑一致性从 6.14 降到 4.67，图层分割从 6.83 降到 5.01，RGBA L1 从 0.0350 升到 0.0482；Fig. 7 给出可见的文字/结构失败。需要注意，这是作者对原因的解释；论文没有做表征层面的因果分析。

作者用以说明「编辑与分解分离会损失重合成质量」的证据主要来自 Table 1：在 Crello-Testset 上，FR+QIL 的 Composite SSIM 只有 0.5584，FR+QIL-Decomp-FT（在 LayerEditor-100K 上微调分解器）为 0.6343，而 LayerEditor 为 0.8351。这个对比说明级联与联合建模之间存在明显差距，但它混合了编辑画布质量、分解器微调、基础模型和训练数据等变量，不能单独证明差距只来自「编辑与分解分离」。

论文要验证的核心假设是：把 Direct 画布与 N 组 RGB/Alpha 放进同一 token 序列联合去噪，并用冻结的原始编辑器在学生的去噪轨迹上同时约束 Direct 与图层合成结果，可以在输出可复用层的同时保住编辑保真度；层数和层内容可以由文本条件控制。它包含三个子问题：(1) 联合建模是否优于「先编辑再分解」的级联；(2) C-EPD 是否真的保住编辑先验；(3) 方法能否迁移到纯分解、不同层数和不同指令。论文对 (1)(3) 给出较多结果，对 (2) 的机制证据较弱。

需要区分三层：领域一般问题是「编辑结果难以复用、编辑与分解分离」；本文新提出的是「联合 token 建模 + 组合式 on-policy 蒸馏（on-policy distillation，同策略蒸馏）」这一具体配方，以及「分层适配会损伤编辑先验」这一观察；本文实际解决的是「在自建的 2–10 层设计类数据上，同时生成编辑画布与 RGBA 层，并支持层数/内容控制」。论文没有证明它在任意真实照片、复杂透明度或超过 10 层的场景中成立。

## 2. 创新点是什么？

真正的技术增量不是新的扩散架构，而是「联合 token 表示 + 组合式 on-policy 蒸馏 + 配套数据与评测」的组合，针对的分别是「编辑与分层分离」「分层适配丢编辑先验」「缺少成对监督」三个问题。

第一，In-Context RGB–Alpha Token Modeling（上下文 RGB–Alpha token 建模）。它把 Direct 画布和 N 组 RGB/Alpha 作为同一序列的字段共同去噪，用层感知 3D RoPE 区分字段身份与堆叠顺序，并用独立 Alpha 解码器恢复连续透明度。与 Qwen-Image-Layered 这类序列化分层生成相比，差别在于输入是扁平源图 + 编辑指令，画布与层在同一次生成中产生；与「先编辑再分解」相比，差别在于没有两阶段误差传递。这属于新的任务形式与架构适配，不是新的扩散算法；证据见 §3.1、Fig. 2，Alpha 解码器的作用见 Table 3。

第二，C-EPD（compositional edit-prior distillation，组合式编辑先验蒸馏）。它用冻结的原始编辑器作教师，在学生自己的去噪状态上同时监督 Direct 速度与「由预测层合成出的图像」，梯度穿过可微的 alpha 合成回到 RGB/Alpha 分支。与 Flow-OPD/DiffusionOPD 只在图像速度上蒸馏不同，本文把编辑先验传到分层输出；这是全文最有辨识度的技术点。证据见 §3.2、Table 3、Fig. 7，但机制隔离不足（见 §5）。

第三，LayerEditor-100K 与两个测试集。100K 对、2–10 层、两条构造路线（原生分层设计；扁平编辑对 + 模型分解候选）、训练/测试源文档不相交、层数与指令控制、I2L 设置。这是实质性的数据与评测资源，不只是「用了更多数据」；证据见 §3.4、Appendix B、Tables 1/2/6。

创新边界：LaDe 已经做画布 + RGBA 的联合生成，UniWorld-Design 支持分层生成与提示控制分解，Agent Banana 已经做分层编辑工作流；本文的差异是「以扁平源图为输入、把编辑与图层生成放进同一个去噪序列，并用合成结果做蒸馏」。按本文的相关工作与实验，只能确认这些差异，不能确认「首次」；论文也没有与这些最接近的方法做定量比较。

## 3. 作者如何解决？

整体直觉是：不要让模型「先画一张编辑图，再想办法把它拆开」，而是把每层的颜色和透明度当成额外的输出字段，与编辑画布一起从噪声中去噪；这样层不是事后拟合的，而是和画布在同一次生成中互相约束。问题在于，模型学会输出层之后可能「忘了怎么编辑」，于是作者让未适配的原始编辑器在学生的去噪轨迹上当老师，既告诉它画布应该长什么样，也通过可微合成告诉它「你分的这些层叠起来应该长什么样」。图 2 给出完整管线。

![图 2：LayerEditor 的联合去噪与 C-EPD 管线](/images/dailypaper/2026-10-23/layeredit_fig2.png)

**图 2**（论文 Fig. 2）：左半部分从源图、指令和层数 N 出发，文本编码器与 VAE 编码器提供冻结条件；输出字段包括一张 Direct 画布和 N 组 RGB/Alpha 潜变量，它们被拼成一个序列送入 MMDiT，用层感知的 3D RoPE 坐标 $(s,x,y)$ 区分「这是第几层、是颜色还是透明度、在画布什么位置」。去噪后 RGB 与 Alpha 分别由两个解码器还原，再按从后到前的顺序做 alpha 合成。右半部分是 C-EPD：在学生的去噪轨迹上选若干噪声状态，冻结教师只在 Direct 潜变量上预测速度；教师预测经解码得到目标图，学生的层预测经可微解码与合成得到重合成图，二者分别约束 Direct 速度与合成像素。图中还标出了高/中/低噪声查询点与 10 节点 rollout；推理时没有教师，只有左侧的一条去噪轨迹。

**输入与联合表示。** 模型从高斯噪声初始化所有输出字段，并在同一个序列中联合去噪：$Z_t=[z_t^{\mathcal{D}}, z_t^{R_0}, z_t^{A_0}, \ldots, z_t^{R_{N-1}}, z_t^{A_{N-1}}]$。文本编码器与 VAE 编码器提供冻结条件；共享注意力让 Direct 与各层互相看到；层感知 RoPE 用 $(s,x,y)$ 区分字段：源图 $s=-1$、Direct $s=0$、第 $i$ 层 RGB $s=2i+1$、Alpha $s=2i+2$，$(x,y)$ 保持空间对齐。序列长度随 $N$ 变化，因此同一套权重可以处理 2–10 层。这里的「in-context」指源图与指令作为同一序列的条件，而不是外挂一个分层适配器。

**基础模型与 Alpha 解码器。** 骨干是 FireRed-Image-Edit-1.1 的 MMDiT，用 rank-256 LoRA 适配 DiT；文本/图像编码器和预训练 RGB 解码器冻结。Alpha 解码器从 RGB 解码器初始化，改成单通道 alpha logit 头（零权重、bias −3.5），单独训练后冻结；训练时把 alpha 图复制成三通道、缩放到 [−1,1] 送入冻结 VAE，解码只用 alpha latent，不依赖 RGB 特征或 bbox。它的损失由区域 alpha 误差、support/boundary/area/multiscale、黑白背景渲染、composition、LPIPS 与 PatchGAN 对抗项组成，分三阶段（单层重建、全文档监督、latent-noise adaptation，3/5/2 epochs；8 GPU，有效 batch 32；Appendix A.2、Table 5）。分离解码器的作用是保留预训练 RGB 通路，同时专门处理细结构和半透明边界；代价是模型多了一套解码器，且 Alpha 解码器训练与骨干解耦。

**训练目标。** 训练分两段：先用流匹配（flow matching）在完整联合序列上训练 2 epochs，再加 C-EPD 联合训练 3 epochs（Table 4）。流匹配把干净目标 $Z^*$ 加噪为 $Z_t=(1-\sigma_t)Z^*+\sigma_t\epsilon$，目标速度 $v_t^*=\epsilon-Z^*$，损失是全部字段的速度 MSE；C-EPD 在此之上加教师约束，总损失为 $\mathcal{L}_\theta=\mathcal{L}_{\mathrm{flow}}+\lambda_C(k)\mathcal{L}_{\mathrm{C\text{-}EPD}}$。$k$ 是 post-training 的 optimizer update 计数，C-EPD 每 5 次更新启用一次，$\lambda_C(k)=0.1\min(k/500,1)$，$\lambda_S=0.05$。

**C-EPD 的运行方式。** 为什么用 on-policy：教师在学生自己走到的噪声状态上被查询，而不是只拿教师生成的干净样本做离线蒸馏；这能减少教师训练分布与学生当前状态分布的错位（§2.3 引用 OPD 的动机）。具体流程是：在 detached 的学生轨迹上取查询状态 $\bar{Z}_q$（10 个节点从 30 步 sigma 网格中采，按高/中/低噪声 0.2/0.5/0.3 选 2 个查询）；学生在 $\bar{Z}_q$ 上带梯度重算 Direct、RGB、Alpha 的速度；教师接收同一个 Direct latent、源图、指令和 $\sigma_q$，只预测 Direct 速度 $v_{q,T}^{\mathcal{D}}$。对每个层字段 $X\in\{R_i,A_i\}$，学生用 $\hat z_{0|q}^{X}=\bar z_q^{X}-\sigma_q v_{q,S}^{X}$ 估计局部干净潜变量，冻结解码器得到 $\hat R_i,\hat A_i$；从白底 $B$ 开始按从后到前合成：

$$
\hat{\mathcal{C}}_i = \hat{A}_i \odot \hat{R}_i + (1-\hat{A}_i)\odot \hat{\mathcal{C}}_{i-1}, \qquad \hat{\mathcal{C}} = \hat{\mathcal{C}}_{N-1}, \quad \hat{\mathcal{C}}_{-1}=B
$$

其中 $\hat A_i$ 控制第 $i$ 层的可见度，$\hat{\mathcal{C}}_S$ 是学生层的重合成图。教师目标 $\mathcal{I}_T=\operatorname{sg}[\mathcal{D}_R(\bar z_q^{\mathcal{D}}-\sigma_q v_{q,T}^{\mathcal{D}})]$ 是教师 Direct 局部干净估计经 RGB 解码器解码后的图，$\operatorname{sg}$ 表示 stop-gradient。C-EPD 损失为：

$$
\mathcal{L}_{\mathrm{C\text{-}EPD}} = \mathbb{E}_{q\sim\mathcal{Q}}\left[\frac{1}{d_{\mathcal{D}}}\left\|v_{q,S}^{\mathcal{D}}-\operatorname{sg}(v_{q,T}^{\mathcal{D}})\right\|_2^2 + \frac{\lambda_{\mathcal{S}}}{d_{\mathcal{C}}}\left\|\hat{\mathcal{C}}_S-\operatorname{sg}\left(\mathcal{D}_R(\bar{z}_q^{\mathcal{D}}-\sigma_q v_{q,T}^{\mathcal{D}})\right)\right\|_2^2\right]
$$

第一项匹配 Direct 速度；第二项把学生的重合成图拉向教师目标，$d_{\mathcal{D}}$、$d_{\mathcal{C}}$ 分别按元素数归一。关键是第二项：梯度穿过冻结解码器（冻结参数不等于冻结输入梯度）和 alpha 合成，回传到 RGB 与 Alpha 预测，因此「层怎么分、透明度多少」会受到「合成后像不像教师编辑结果」的约束；完全被遮挡的内容仍由逐层 flow matching 监督。教师就是未适配的原始编辑器，不是更大的模型，因此这里的蒸馏更像「保留原始编辑先验」的自蒸馏，而不是从更强教师学新能力。教师只在训练时使用，推理没有额外调用。

**数据构造。** 数据是 LayerEditor-100K：100,000 对，来自 Crello、PrismLayersPro、ScaleEdit；48,329 条文本编辑、36,858 条物体编辑、14,813 条海报级外观编辑；每例 2–10 层。两条构造路线：(A) 原生分层设计——保留 Crello/PrismLayersPro 的层结构，规划编辑，布局变化/移动/删除用确定性操作，文字重绘、物体替换、外观修改用生成式编辑，再与保留的 RGBA 层合成目标栈；(B) 扁平编辑对——对 ScaleEdit 的源–目标对做质量筛选，规划器提出层角色与粒度，用 QIL 与 Seedream5-Pro 生成分解候选，标准化为带完整背景的全画布 RGBA，最多两轮局部修补，整栈复查；严重失败丢弃，修补只有在改善时才保留，修补后的合成只有在独立验证指令执行和内容保持后才成为目标。共享质检包括结构、语义、层 QA、重合成和去重；每层有 index、role、content、edit status、bbox，语义描述进入训练 prompt，几何元数据用于离线验证。图 3 把两条路线和统一质检画在一起。

![图 3：LayerEditor-100K 的两条构造路线](/images/dailypaper/2026-10-23/layeredit_fig3.png)

**图 3**（论文 Fig. 8）：上半部分是 Route A：从 Crello/PrismLayersPro 的原生分层设计收集资产，规范化画布与层语义，规划编辑（文字、物体、外观），渲染出带 2–10 层 RGBA 的目标；下半部分是 Route B：从 ScaleEdit 的扁平源–目标对出发，先做质量筛选与图层规划，再用 QIL/Seedream5-Pro 生成多个分解候选，排序选优后得到目标层栈。底部统一检查把指令执行、层隔离、RGBA 有效性、边界质量和视觉复查串起来，只有通过检查的记录才进入 LayerEditor-100K。读图时应注意到：Route B 的「参考层」是模型候选经筛选/修补得到的，而不是人工从零标注；这会影响后续评测的 ground-truth 强度。

**评测集。** 评测集与训练源文档不相交，派生编辑/层组织与源文档同 split。Crello-Testset 有 2,994 个文档（原生 Crello/PrismLayersPro 设计）；ScaleEdit-Testset 有 1,000 个（扁平编辑对 + 恢复的目标层）。层数控制把 3,994 个源文档重新组织成 2–10 层的不同粒度（每文档通常 2–4 种，分数先在文档内平均再跨文档平均）；指令控制会同步修改编辑目标与参考层栈（Table 6）。I2L 用 1,171 张 held-out 原始 Crello 图（≤10 层），这些原始 Crello 文档不参与训练数据构造。评测时目标像素和参考 RGBA 从不作为生成输入；层内容描述由标注流水线生成并人工筛查（Appendix A.1、B.3）。

**推理。** 给定 $I^{\mathrm{src}}$、$u$、$N$（和可选层描述），一条 30 步去噪轨迹、CFG 4.0，同时输出 Direct 和 N 组 RGB/Alpha；RGB/Alpha 解码后按从后到前合成，白底；没有教师调用，也没有逐层后处理或参考引导。输出的层可以直接单独移动、换色、翻译文字等（Fig. 1、Fig. 5 展示），但论文没有量化这些下游操作后的重合成质量。

**为什么这样设计，代价是什么。** 设计依据可以连成一条因果链：联合序列让画布与层共享注意力，层不是事后拟合；层感知 RoPE 解决同一空间位置多字段的歧义；独立 Alpha 解码器解决透明度细结构；C-EPD 解决分层适配的编辑退化；组合监督直接优化用户最终看到的合成图，而不是只优化每层数组。代价是：一次生成要输出 $1+2N$ 个字段，序列更长；训练要额外跑教师前向；层数上限受序列长度和显存限制（论文只做 ≤10 层，Appendix E）。

## 4. 解决得怎么样？

### 4.1 实验设置

主实验是指令驱动的分层编辑：Crello-Testset（2,994 文档）与 ScaleEdit-Testset（1,000 文档），指标以重合成图 $\mathcal{C}$ 为主，Direct 画布 $\mathcal{D}$ 作为辅助诊断。另有层数控制（3,994 源文档，每文档 2–4 种 2–10 层组织）、指令控制（Table 6）、I2L（1,171 张 held-out Crello 图，≤10 层）。所有 SSIM/Alpha IoU 越高越好，FID/RGBA L1 越低越好；FID 只在同一 benchmark 内解释，不跨数据集比较。

模型是 FireRed-Image-Edit-1.1 + rank-256 LoRA + 独立 Alpha 解码器；2 epochs flow warm-up + 3 epochs joint（Table 4）；1024×1024 像素预算；推理 30 步、CFG 4.0。基线包括 Seedream5-Pro Seq（两次 API：先编辑再分解）与 Joint（一次 API 同时请求编辑 + 分层）；FR+QIL、FR+QIL-Control、FR+QIL-Decomp-FT（QIL 在 LayerEditor-100K 上按官方分解流程微调）、QIL-Edit-SFT（QIL 在同一监督下直接学联合编辑 + 分层）、RevealLayer；I2L 另比 LayerD。除 Seedream 外均为作者自己跑；FR 级联共享同一编辑画布；QIL、QIL-Decomp-FT、RevealLayer 只给层数，QIL-Control、QIL-Edit-SFT、Seedream、LayerEditor 还给有序层内容描述（§4.1、Appendix C.1）。

指标包括 Direct/Composite SSIM 与 FID、RGBA L1、连续 Alpha IoU、五维 VLM rubric（编辑一致性、视觉质量、图层分割、图层合成、Alpha 准确度，1–10 分，单一 Gemini-3.1-Pro 评分），以及时间。RGBA L1 先用匈牙利匹配按 Alpha support IoU（阈值 0.05）建立一一对应，剩余层按原堆叠顺序配对，按参考层数归一；空层诊断中 LayerEditor 为 1.02%，Seedream5-Pro (Seq.) 为 10.37%（Appendix C.2）。

公平性要单独说明：论文明确称这是 system-level 比较，不能隔离「联合建模」与「编辑数据适配」；多数基线是 zero-shot/级联，LayerEditor 与 QIL-Edit-SFT/QIL-Decomp-FT 见过同一批数据；Seedream 是闭源 API，Joint 不导出 Direct 画布，Crello 有 5 个文档因 API 拒绝被排除（指标在 2,989 个可用文档上算）。论文没有报告训练种子方差、置信区间或显著性检验。主实验回答重合成与层质量；层数/指令控制回答可控性；I2L 回答纯分解迁移；Table 3 回答组件消融。

### 4.2 关键结果

先看主表。Table 1 的 Crello-Testset 上，LayerEditor 的 Composite SSIM 0.8351、Composite FID 33.86、Alpha IoU 0.6074、RGBA L1 0.0350；Seedream5-Pro (Joint) 分别为 0.7902、55.33、0.5139、0.1344。按相对值算，Composite SSIM 高 5.7%，Composite FID 低 38.8%（§4.2 的原文也是这两个百分比）。五维 rubric 均值 6.00，Seedream5-Pro (Joint) 4.50；图层分割 6.83 vs 5.22（+1.61），图层合成 5.64 vs FR+QIL-Decomp-FT 4.35（+1.29）。Direct 画布则不是全面领先：Direct SSIM 0.8530 略低于 Seedream5-Pro (Seq.) 的 0.8586，但 Direct FID 30.15 优于 33.04。也就是说，优势主要在「从层重新合成」和层质量上，而不是直接画布本身。

ScaleEdit-Testset 上，Composite SSIM 0.8839 vs Seedream5-Pro (Joint) 0.8365，Composite FID 39.48 vs 59.62，Alpha IoU 0.6802 vs 0.6583，RGBA L1 0.0515 vs 0.0552。论文还报告了一个有用的诊断：Direct→Composite 的 SSIM 损失，LayerEditor 从 0.8925 降到 0.8839（相对 1.0%），Seedream5-Pro (Seq.) 从 0.8933 降到 0.7901（11.6%）。这说明 LayerEditor 的层栈确实能重建编辑结果，而不是只有 Direct 画布好看。

同数据训练的基线也值得看。QIL-Edit-SFT 在 Crello 上 Composite SSIM 0.7285、Alpha IoU 0.3171；FR+QIL-Decomp-FT 为 0.6343、0.2047；LayerEditor 为 0.8351、0.6074。QIL-Edit-SFT 用的是 QIL 骨干，和 FireRed 不同，因此这组差距同时包含骨干先验、联合 token 建模和 C-EPD 的贡献，不能单独归因。

层数控制（Table 2；正文把这张表写成 Table 4.3，按表题应为 Table 2）：LayerEditor 的 Alpha IoU 0.6196 vs Seedream5-Pro (Joint) 0.5703，semantic grouping 6.88 vs 5.91，RGBA L1 0.0460 vs 0.1028；时间是 41.5 s/sample vs 250.0，但论文明确说硬件/服务开销未控制，不能当作严格的速度排名。指令控制（Table 6）：LayerEditor 的 Composite SSIM 0.8765、Alpha IoU 0.5823、RGBA L1 0.0344；edit consistency 5.54 vs Seedream5-Pro (Joint) 3.32，layer segmentation 6.33 vs FR+QIL-Control 5.11，layer composition 5.68 vs FR+QIL-Decomp-FT 4.34。FR 级联的 Direct SSIM 只有 0.6113，LayerEditor 为 0.9018；这说明改指令后 LayerEditor 的编辑响应也更好，但 FR 本来就没有做分层适配，仍是 system-level 比较。

I2L（Fig. 6）：LayerEditor 在不做 I2L 专用微调的情况下，Composite SSIM 0.8761 vs QIL 0.7963，Alpha IoU 0.6343，layer semantic 6.39；四张子图中 LayerEditor 的柱子都处于最优侧。这个设置用原始 Crello 的层作为参考，比 ScaleEdit 的模型恢复层更接近独立真值。需要注意 LayerD 是通过反复分解组装层栈，粒度和对应关系与 count-controlled 比较不同；论文自己说不要把 LayerD 的层分数当作直接受控排名（Appendix C.2）。图 4 把四个指标并排展示。

### 4.3 机制证据

效果证据与机制证据要分开。Table 1/2/6/Fig. 6 说明「在这个设置下有效」；Table 3/Fig. 7 才试图说明「为什么有效」。

C-EPD 消融（Table 3，Crello-Testset，matched backbone steps）：完整模型 6.14/6.35/6.83/0.0350（edit/visual/layer seg/RGBA L1）；w/o C-EPD 4.67/5.12/5.01/0.0482；w/o Direct OPD 5.01/4.19/4.83/0.0513；w/o Comp. OPD 4.98/4.33/4.97/0.0492；w/o Alpha Dec. 5.12/5.30/5.67/0.0578；Base Model 3.93/4.13/3.77/0.0735。原文事实是 C-EPD 整体带来大幅提升；审稿人判断是：单个监督项反而在 visual quality 和 layer segmentation 上低于 w/o C-EPD，只有两项合用才全面提升。作者说这「支持联合使用」，但没有解释为什么单项会伤害图层质量；这更像经验配方，而不是可验证的因果机制。Fig. 7 给出可见证据：去掉 C-EPD 时文字被破坏或出现明显伪影；去掉任一单项也不稳定。注意原文 §3.2 和 §4.5 把这张图写成 Figure 3，但按图题「Effect of C-EPD on recomposed outputs」对应的是 Fig. 7；Figure 3 实际是数据集概览。这个交叉引用错位不影响结论，但读原文时要小心。

**图 5**（论文 Fig. 7）：两行例子分别要求把「13500」改成「14000」、把「CHAMPION」改成「BEST」。左起是源图与指令、完整 LayerEditor、只保留合成监督（w/o Comp. OPD）、只保留 Direct 监督（w/o Direct OPD）、完全去掉 C-EPD。完整模型能保留字体、结构与周围内容；去掉 C-EPD 时文字被破坏或出现明显伪影；去掉任一单项也不稳定。这张图把 Table 3 的 rubric 分数落到可见缺陷上，说明 C-EPD 的两个约束是在「编辑保真」和「可重合成」之间共同起作用。它仍然是精选案例，不能说明失败率。

### 4.4 成本与适用范围

训练成本：100K 对、2+3 epochs、batch 64、rank-256 LoRA；Alpha decoder 用 8 GPU、有效 batch 32、3/5/2 epochs；C-EPD 每 5 次更新查教师，每次 2 个查询，教师前向的额外开销未量化。论文未报告 backbone 的 GPU 型号/数量、GPU 小时、总 token 数、墙钟时间与费用；未报告基础设施失败率、重试率（除 Seedream 评估的 5 次调用上限）。推理成本：30 步、CFG 4.0；Table 2 的 41.5 s/sample 是无控硬件下的观测值，不能当作与 Seedream（250.0）/QIL（104.2）的严格速度对比。

数据与外部依赖：LayerEditor-100K 由 Crello/PrismLayersPro/ScaleEdit 构造；Route B 用 QIL 与 Seedream5-Pro 生成分解候选；评测也使用 Seedream API。没有人工标注时长的报告；benchmark 的层内容描述经过人工筛查。可复现性：论文给出详细的架构、超参、数据构造和评测协议，但未提供代码/项目页，也未说明数据集是否公开；当前材料无法确认 LayerEditor-100K 与两个 benchmark 的发布状态。没有训练种子、方差、置信区间。

适用范围：≤10 层；文本仍是栅格，不是可编辑字体/矢量；细结构、复杂透明度、半透明边界仍可能出错；没有系统测试「移动/改色/换背景后再合成」的质量；没有真实照片或 >10 层；没有与人类评分对齐。论文自己承认这些（Appendix E）。结论边界是：在论文构建的设计类分层编辑数据上，LayerEditor 能同时给出较高质量的重合成图与图层，并在层数/指令控制、纯分解迁移上优于所选基线；但不能据此说它在任意真实图像、任意层数或下游复用流程中都可替代人工分层。

## 5. 最容易受到审稿人质疑的地方

#### 质疑：「可复用」是标题承诺，但评测只测静态重合成，没有测图层被真正复用后的结果

- **原文依据**：标题与 §1 把「reusable RGBA layers」作为核心；§4.1 与 Appendix C.2 的指标只有 Composite SSIM/FID、RGBA L1、Alpha IoU 和 rubric，均是对当前参考层/当前画布的比较；Appendix E 明确写「We do not systematically test reconstruction after layer manipulation or validate VLM scores against human judgments」；Fig. 1、Fig. 5 只给示意性操作。
- **为什么重要**：任务定义的核心是复用。一个层可以在当前画布上 Alpha IoU 很高，但一旦移动、缩放、改色或换背景，就可能暴露被遮挡内容缺失、颜色溢出、阴影/光泽被烘焙进 RGB、边界断裂等问题。只测静态重合成，等于只验证了「层能拼回原图」，没有验证「层能拿去别处用」；这直接影响论文的核心主张，而不只是外围指标。
- **当前能够得出的判断**：现有证据支持「层栈能重建当前编辑结果」，不支持「层在后续操作中可复用」。这是当前材料无法确认的部分，不是作者已经证明的结论。
- **如何验证或补强**：建立下游操作 benchmark：移动/改色/删除/翻译某一层、替换背景、把层拖到新画布；测量重合成后的伪影率、被遮挡内容补全、颜色溢出、边界质量；加入人类偏好或设计师可用性评分；同时报告 2–10 层每一档以及 >10 层的结果。
- **严重程度**：主要问题。

#### 质疑：评测参考层与训练数据同源，部分参考层由被比较的模型生成，不能当作独立 ground truth

- **原文依据**：§3.4 说两个 benchmark「constructed independently from the training data」，但这是源文档级不相交；Appendix B.1 的 Route B 明确用 QIL 与 Seedream5-Pro 生成分解候选，再筛选/修补；Appendix B.2 的质检是结构、语义、层 QA、重合成和去重；Table 1 的参考层来自这套流程；Fig. 4 又把参考列标成「Ground Truth」。Crello-Testset 使用原生 Crello/PrismLayersPro 层，可信度更高；ScaleEdit-Testset 的目标层是模型恢复层，独立真值强度更弱。
- **为什么重要**：如果参考层由同一批模型（QIL、Seedream）生成或修补，而这些模型又是基线，那么「LayerEditor 更接近参考」可能部分反映「它学会了这套流水线的层风格」，而不是通用层质量。训练集 Route B 与 ScaleEdit-Testset 共享构造管线，也会让分布匹配偏向 LayerEditor；这影响所有层指标和主结论。
- **当前能够得出的判断**：Crello-Testset 的原生层较可信，ScaleEdit-Testset 的参考层不是独立人工 ground truth；论文没有外部人工标注的分层编辑 benchmark，也没有报告参考层的人工一致性。这个混杂的方向明确，但影响大小无法从当前材料量化。
- **如何验证或补强**：发布 benchmark 并给出人工标注子集与多标注者一致性；在未参与构造的真实设计文件（PSD/设计稿）上评测；用不同来源的分解器生成参考层做敏感性分析；分别报告 Route A-only 与 Route A+B 训练的模型；给出每个 benchmark、每个层数的分项结果。
- **严重程度**：主要问题。

#### 质疑：C-EPD 的机制没有被隔离，无法说明 on-policy 与组合监督各自的因果作用

- **原文依据**：Table 3 只有 Crello 上的 4 个指标（3 个 rubric 维度 + RGBA L1），没有 Composite SSIM/FID/Alpha IoU；w/o Direct OPD 与 w/o Comp. OPD 在 visual quality 和 layer segmentation 上反而低于 w/o C-EPD（4.19/4.83、4.33/4.97 vs 5.12/5.01），只有两项合用才全面提升；Appendix C.2 明确说「These ablations also do not separate on-policy query selection from teacher supervision, as no matched off-policy control is included」；Appendix E 说编辑先验保留只在构建的 benchmark 上评估。
- **为什么重要**：C-EPD 是本文最主要的技术增量。如果收益只是「加了一个教师正则」或「优化更充分」，那么「on-policy」「compositional」的叙事就被夸大；单项监督的非单调结果也提示两个损失之间存在优化干扰，而不是干净的机制。缺少独立通用编辑测试，则「保住预训练编辑先验」这一说法只在自建分布上成立。
- **当前能够得出的判断**：证据支持「C-EPD 作为一个整体，在当前训练设置下提升 rubric 与 RGBA L1」；不支持「on-policy 查询是必要的」「组合监督各自贡献可分离」「编辑先验在通用编辑上被保留」。这是证据不足，不是作者结论被直接推翻。
- **如何验证或补强**：加入 matched off-policy 蒸馏对照（同样的教师、查询预算，但在教师生成的状态上）；加入 teacher-free 的合成一致性损失（对 ground-truth 目标做合成约束）；加入 on-policy 但不做合成、只做 Direct 的对照；报告所有消融变体的 Composite SSIM/FID/Alpha IoU，而不只是 rubric；在独立通用编辑 benchmark 上测 Direct 画布的编辑能力；用 3–5 个训练种子报告均值与方差。
- **严重程度**：主要问题。

#### 质疑：主评分依赖单一 VLM judge，未与人类评分校准；Table 3 消融又主要用这个评分

- **原文依据**：Appendix C.3 写明「A single Gemini-3.1-Pro evaluator」；Appendix E 写明「We do not ... validate VLM scores against human judgments」；Table 3 只报告 edit consistency/visual quality/layer segmentation 三个 rubric 维度和 RGBA L1，没有 Table 1 的完整指标；Fig. 11 只展示评分锚点的示例，不验证与人类的一致性。
- **为什么重要**：rubric 均值 6.00 vs 4.50 是摘要级卖点之一，C-EPD 消融也主要靠这三个分数；单一闭源 judge 可能有风格偏好、位置偏好或对「像不像参考层」的过度敏感。没有多judge、重复评分或人工校准，分数的可重复性和效度都不清楚。参考指标（SSIM/FID/Alpha IoU）独立支持主结果，但这不能补救消融表缺少这些指标的问题。
- **当前能够得出的判断**：主结果有 reference-based 指标支撑，rubric 是补充证据；C-EPD 的消融结论更依赖未校准的 VLM 评分，因此机制证据偏软。当前材料无法确认 rubric 与人类判断的一致性。
- **如何验证或补强**：用多名标注者做盲评，报告 inter-rater agreement 和与 VLM 的相关性；用多个 VLM judge/多次采样，报告方差；在 Table 3 中补全 Composite SSIM/FID/Alpha IoU；释放评分 prompt、模型版本与全部输出，便于复评。
- **严重程度**：主要问题。

#### 质疑：比较公平性与复现材料不足，最接近的分层编辑方法没有定量比较

- **原文依据**：§4.1 与 Appendix C.1 承认 FR 级联是 pretrained，而 LayerEditor 经过分层编辑适配，属于 system-level 比较，不能隔离联合建模与数据适配；QIL-Edit-SFT 虽是同数据训练，但骨干是较弱的 QIL；Seedream 是闭源 API，Crello 少 5 个文档，Joint 不导出 Direct；§2.2 提到 LaDe、UniWorld-Design、Agent Banana，但没有 Table 1 中的数值比较；论文未提供代码/项目页，也未报告 GPU 小时、训练种子与方差。
- **为什么重要**：主表混合了模型规模、训练数据、推理预算和系统设计；最接近的「画布 + RGBA 联合生成」方法没有对照，读者无法判断 LayerEditor 相对同代方法是领先还是只是比所选基线好。缺少代码、数据发布与成本信息，则独立复现和公平重跑都受限。
- **当前能够得出的判断**：证据支持「LayerEditor 在论文选择的基线与设置下更好」；不支持「它优于所有最接近方法」或「可独立复现」。论文对 system-level 比较有明确交代，这缓解了夸大，但没有消除混杂。
- **如何验证或补强**：加入同骨干的 FireRed 分层 SFT 基线并报告完整指标（w/o C-EPD 已接近，但 Table 3 缺主表指标）；在可运行的情况下加入 LaDe、UniWorld-Design、Agent Banana；统一 API 调用数、采样步数与训练预算；发布代码、LayerEditor-100K、两个 benchmark 与检查点；报告多 seed 均值/方差和 GPU 小时。
- **严重程度**：次要问题。

## 6. 审稿式总评

作者发现现有编辑模型只给扁平画布、分解模型又与编辑目标分离，而且把编辑模型适配到分层输出会损伤原有编辑能力；因此提出 LayerEditor，把 Direct 画布与 N 组 RGB/Alpha 放进同一 token 序列联合去噪，并用冻结的原编辑器在学生的去噪轨迹上同时监督 Direct 速度与图层重合成结果（C-EPD），再配套 LayerEditor-100K 与两个测试集。实验在 Crello/ScaleEdit、层数控制、指令控制和 I2L 上表明，LayerEditor 的重合成 SSIM/FID、Alpha IoU 与层 rubric 均优于所选基线；其中「重合成损失小」「层数/指令可控」「纯分解可迁移」证据较强，但「可复用性」「C-EPD 的因果机制」「独立 ground truth 与人类评分」仍缺少充分支持。本文最有价值的是把「编辑 + 分层」定义成一个可训练、可评测的联合任务，并给出完整的 token 布局、Alpha 解码器和组合蒸馏配方；最大的审稿风险是评测闭环太自洽，核心的「reusable」承诺没有被下游操作直接验证。

- **问题定义清晰度**：强。§1 与 §3.1 把输入、输出、Direct 画布与图层栈、层数/内容条件都定义清楚，§3.4 还给出可操作的评测设置；扣分点是「reusable」在指标上没有操作化。
- **创新性证据**：中。联合 token 建模、合成级 on-policy 蒸馏和 100K 数据资源是有价值的组合；但组件建立在 Qwen-Image-Layered 式序列建模、DiffusionOPD 与 LoRA 之上，最接近的 LaDe/UniWorld-Design/Agent Banana 没有定量比较，「首次」未被证明。
- **方法可信度**：中。§3 的管线、超参和 Alpha 解码器细节完整，消融也覆盖了主要组件；但 C-EPD 的 on-policy 必要性、单项监督的非单调性、Alpha 解码器的架构/训练混杂都没有被隔离，见 §4.3 与 §5。
- **实验支持力度**：中。两个 benchmark、层数/指令控制、I2L 和多个指标给出了一致的正向结果，重合成损失也提供了有说服力的诊断；但评测是自建分布内、单一 VLM judge、无方差/显著性，且没有下游复用测试，见 §4.2、§4.3 与 §5。
- **可复现性**：弱。论文给出详细架构与超参，但没有代码/项目页，未说明数据集是否公开，Route B 依赖闭源 Seedream API，训练 GPU 小时与种子方差未报告，见 §4.4。
- **综合阅读价值**：高。它把「图像编辑 → 可复用 RGBA 图层」的任务、token 布局、Alpha 解码、组合蒸馏和评测协议讲得完整，且作者在 Appendix E 对限制有一定诚实交代；适合作为分层图像编辑与蒸馏方向的入门与批判性阅读材料，但不应把其效果数字直接当作真实设计场景的可用性结论。
