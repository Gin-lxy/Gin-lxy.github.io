## 0. 一句话结论

论文把 representation autoencoder（RAE）里"用哪些编码器层拼出共享 latent"这一固定选择，改成训练时对随机层子集做归一化融合的正则化（FuseReg），使同一个 decoder 在全层、稀疏、单层三种融合下都能工作，并在 ImageNet-256 + 冻结 DINOv3-L 上仅替换 decoder 就把未引导 gFID 从 3.01 降到 2.21。证据边界很明确：所有实验只覆盖 ImageNet-256、DINOv3-L、DiT-Base/XL 与 16/40 epochs 的受控预算，收益在 guided 设置下基本消失，最优 drop rate 依赖模型规模、指标与是否使用 guidance，理论刻画只适用于齐次线性预测器加平方损失。

## 1. 论文具体想解决什么问题？

**研究背景与任务。** RAE 用冻结的预训练视觉编码器（本文为 DINOv3-L）特征作为扩散模型的 latent，再另训一个 decoder 把特征还原成像素（Zheng et al., 2025；§1）。一个 ViT 编码器输出的是逐层变化的特征堆：越浅的层越贴近像素细节，越深的层越语义化。于是 RAE 必须回答一个接口层面的问题——**把哪些层、以什么方式合成那个唯一的共享 latent**，本文称之为 layer fusion。这个融合同时被两个消费者读取：generator（DiT，建模 latent 分布）与 pixel decoder（把 latent 变回图像）。

**现有方法如何处理。** RAEv2（Singh et al., 2026）固定地把最后 $k$ 层相加，并报告 $k$ 控制着重建与生成之间的 Pareto 前沿；DRoRAE 与 attentive multi-layer probing 则学习一组输入无关的确定性融合权重（§2、§A.3）。

**现有方法在哪些条件下不好。** 作者给出的核心证据是 $k$ 这个旋钮把两个偏好不同的阶段绑在一起（§1，原文事实）：在 DINOv3-L + ImageNet-256 下，把融合集合从 $k{=}7$（层 $\{\ell_{11},\ell_{13},\dots,\ell_{23}\}$）扩到 $k{=}23$（全部 23 层），重建 PSNR 从 $22.58$ 升到 $27.04$ dB，但 unguided gFID 从 $1.65$ 恶化到 $3.01$、guided gFID 从 $1.06$ 到 $1.25$。作者的解释是：浅层像素对齐特征会被 $\ell_2$、LPIPS 这类重建损失"廉价地"奖励，而扩散生成更偏好深层语义特征，因此**重建最优点与生成最优点不是同一个融合**，这就是本文命名的 reconstruction–generation gap。

**本文的新观察（超出"复述 RAEv2 折中"的部分）。**

1. **把融合交给优化器学也不行。** 作者在 DINOv3 各层上放了一个可学习的 softmax gate（全局、输入无关），训练后权重塌缩到最浅层、深层权重衰减到 $0$，且 GAN 损失打开后塌缩加速（Figure 1；该图仅存图注，按图注文字与 §3.1、§A.3 转述）。$k$ 的搜索空间因此被限制在"固定子集"内。
2. **下游模型对训练时见过的那个融合依赖极强。** Table 1（§5.1）：RAEv2$_{K=23}$ 在自己训练过的 $k{=}23$ 上有 $27.04$ dB、rFID $0.18$，换到 $k{=}7$ 或单层 $\ell_{11}$ 立刻跌到 $12.51$、$14.31$ dB（rFID 涨到 $16.10$、$11.21$）；RAEv2$_{K=7}$ 同样只在自己训练过的融合上有效。
3. **单点融合上的成功不能保证邻近子集也成功。** 附录 Proposition 4（§E.3）构造了一个 $K{=}2$ 的标量反例：两层噪声可以互相抵消，使一个 decoder 在"全层融合"上损失为零，却在去掉一层后的单层子集上损失任意大。

**作者认为的原因与核心假设。** 作者的判断是：瓶颈不是"还没找到更好的那一个固定融合"，而是下游模型只会读一种层组合；因此不应继续搜索或学习单一融合，而应把层组合当作**训练分布**来训，让 decoder 与 DiT 在整个融合族上都可用（§3 首段："FuseReg targets dependence on a fixed fusion rather than searching for a different fixed fusion"）。需要说明的是，这是作者的解释框架：论文用"门控塌缩 + off-fusion 崩溃 + $K{=}2$ 反例"三类现象支持该判断，但没有做干预实验来排除其他解释（例如"训练数据/容量不足"或"层间特征量纲差异"），因此属于**有现象支撑、因果未完全验证**的诊断。

**三类问题的区分。** 领域一般问题：语义表示与像素保真度之间的张力（§A.1 引用的 Prism Hypothesis、PS-VAE 等）以及"有用信息分布在不同深度"这一共识（§A.3 引用的 deep supervision、DRoRAE）。本文新观察：全局可学门控会塌缩到浅层；下游模型 off-fusion 大幅退化；固定融合成功不能外推到相邻子集。本文实际解决的子问题：在编码器冻结、pipeline 不变的条件下，让 decoder 与 DiT 对层子集融合鲁棒——并未改变 latent 的语义目标，也未改变编码器。

## 2. 创新点是什么？

**一段话概括。** 真正的技术增量不是"加了一个模块"，而是三步组合：(i) 把"训练时每个样本随机保留一部分编码器层、并按保留层数归一化"作为融合接口上的训练分布（Eq. (2)）；(ii) 证明这种归一化随机融合在期望上等于全层均值、只沿"层间分歧方向"注入方差（Lemma 1，Eq. (6)），从而在线性平方损失下等价于显式的分歧惩罚（Proposition 1，Eq. (7)(8)），并与任何输入无关的确定性融合在权重二阶矩上不可匹配（Proposition 2，Eq. (9)）；(iii) 因为 decoder 与 DiT 解的是两个不同的预测问题，给两个阶段各设一个 drop rate $p_{\mathrm{dec}}$、$p_{\mathrm{dit}}$（§3.3）。

**创新点 1：归一化随机子集融合（layer-fusion regularization）。**

- 新增机制：训练时对每个样本独立采一个非空 Bernoulli 掩码 $m$，构造 $z_{m}=\sum_{k}m_{k}h_{k}/\sum_{k}m_{k}$；decoder 从这个子集融合重建像素，DiT 把它作为带噪 flow-matching 输入、回归全层目标 $z_{\mathrm{full}}=K^{-1}\sum_{k}h_{k}$（Eq. (2)(3)，§3.2、§3.3）。
- 与最接近方法的不同：RAEv2 是固定前缀求和；DRoRAE / attentive probing 学一个输入无关的确定权重；dropout、nested dropout、stochastic depth、LayerDrop、Matryoshka 使用同一类随机化，但作用在单元、残差块或表示维度上，且目标是推理效率或有序列基（§2、§A.3）。
- 属于哪一类：**已有组件迁移到新轴 + 新的分析**，不是全新网络或全新训练范式；作者自己在 §A.3 承认机制上与 dropout 家族相关。
- 对应前面哪个问题：针对"下游模型只读一种层组合"（§1 观察 2、3），用覆盖所有非空子集的训练分布替代单点训练；Corollary 1（Eq. (36)）给出 $\ell_{S_{0}}(f)\leq \mathcal{L}_{p}(f)/\pi_{p}(S_{0})$ 的覆盖界，常见子集被约束得更紧、罕见子集较松。
- 效果证据：Table 1 与 Figure 2、Figure 5；移除该设计即 $p_{\mathrm{dec}}{=}0$，对应 Table 4 首行的复现基线（$k{=}23$ 上 $27.10$ dB / rFID $0.189$，off-fusion 跌到 $12.54$ dB / rFID $16.108$）。

**创新点 2：两个阶段各自的 drop rate 与"分歧惩罚"论证。**

- 新增内容：$p_{\mathrm{dec}}$ 与 $p_{\mathrm{dit}}$ 两个独立超参（§3.3）；精确的采样恒等式 Lemma 1（不假设线性）；线性代理下的目标分解 Proposition 1、闭式共识预测器与增益 $\lambda/(\lambda+c_{K}(p)\gamma+\sigma_{t}^{2})$（Proposition 3，Eq. (29)(30)）；与确定性融合的二阶分离 Proposition 2；覆盖率界 Corollary 1；$K{=}2$ 反例 Proposition 4。实现上 $(p_{\mathrm{dec}},p_{\mathrm{dit}})$ 只是 §E.5 中 $2K$ 维逐层 rate 松弛的一个对称二维切片。
- 与已有工作的差异：这些结论刻画的是"随机化相对固定融合多了什么"，而不是"哪一种融合更好"。
- 证据强度：**采样恒等式、覆盖界与 §E.5 的顶点/解析性是精确结论；分解与闭式解假设齐次线性预测器加平方损失**，作者在 §E.6 明确写出该分析"既不预测两个 rate 对比的符号，也不证明超可加性"。因此创新点 2 的理论部分是机制直觉，不是对实际 ViT/DiT 的定量预测。

**什么不算本文的创新。** 用更强的 DiT（DiT-Base/XL）不构成创新，只是评测规模；ImageNet-256、FID/IS 等是既有基准与指标；"把 dropout 放到层维度"如果单独拿出来，机制极薄，本文的增量主要在于均值保持的归一化设计、覆盖性论证与两阶段 rate 的分离；论文使用了 "We introduce / We prove" 的强表述，但没有声称 "first"。根据本文 related work 与实验对比，只能确认作者声称的差异；随机层 dropout 用于 RAE 融合接口是否构成首次提出，还需要更完整的文献检索。

## 3. 作者如何解决？

**直觉。** 不改变 RAE 的架构和推理路径，只在训练阶段把"固定取某几层"换成"每个样本随机取一个层子集，并按层数归一化"。归一化是关键：随机子集的等权平均在期望上就等于全层平均（Lemma 1），所以这个随机化**不移动部署时的 latent**，只改变围绕它的波动幅度——而由 Eq. (6) 与 Eq. (15) 可见，波动完全落在"各层彼此不一致"的方向上。部署时默认保留所有层，推理公式与标准 RAE 完全相同（§3.2）。这正好针对两个失败模式：decoder 无法处理没见过的融合（Table 1 的 off-fusion 崩溃），以及 learned gate 只会退到浅层捷径（Figure 1）。

**实际运行流程。**

1. **输入。** 图像 $x$ 送入冻结的 DINOv3-L，候选池为 $K{=}23$ 个 transformer 层；每层取 patch token 特征并做 LayerNorm，得到 $h_{k}=\mathrm{LN}(E_{l_{k}}(x))\in\mathbb{R}^{N\times d}$（$N$ 个 token，维度 $d$）（§3.1、§B.1）。
2. **把固定融合写成统一形式。** 任何归一化融合为权重线性组合，$z_{a}=\sum_{k=1}^{K}a_{k}h_{k}$，$\mathbf{1}^{\top}a=1$（Eq. (1)）。固定前缀求和、单层选择与全局门控都只是不同的固定 $a$。
3. **训练时的随机化。** 采独立 Bernoulli 掩码并条件在非空上：$\widetilde{m}_{k}\sim\mathrm{Bernoulli}(1-p)$，$m\sim\mathcal{M}_{p}:=\operatorname{Law}(\widetilde{m}\mid \mathbf{1}^{\top}\widetilde{m}>0)$，子集融合为 $z_{m}=\sum_{k}m_{k}h_{k}/\sum_{k}m_{k}$（Eq. (2)）；等价权重 $a_{k}=m_{k}/\sum_{j}m_{j}$。$0<p<1$ 时全部 $2^{K}-1$ 个非空子集都有正概率。
4. **decoder 路径（$p_{\mathrm{dec}}$）。** ViT decoder 重建 $\hat{x}=D(z_{m})$，损失沿用 RAEv2 的像素 + 感知 + 对抗 + classifier surrogate：$\mathcal{L}_{\mathrm{dec}}=\lVert\hat{x}-x\rVert_{2}+\lambda_{\mathrm{p}}\mathcal{L}_{\mathrm{LPIPS}}(\hat{x},x)+\lambda_{\mathrm{g}}\mathcal{L}_{\mathrm{GAN}}(\hat{x})$（§3.3）。
5. **DiT 路径（$p_{\mathrm{dit}}$）。** 用 flow-matching 插值 $z_{t}=tz_{m}+(1-t)\epsilon$（$m\sim\mathcal{M}_{p_{\mathrm{dit}}}$，$\epsilon\sim\mathcal{N}(0,I)$，$t\sim\nu$ 为 shifted logit-normal，方向约定为 noise-to-data，$c$ 为类别标签），让 DiT 回归**全层聚合**目标：

$$\mathcal{L}_{\mathrm{DiT}}=\mathbb{E}_{(x,c),m,t,\epsilon}\ \rho(t)\bigl\lVert x_{\theta}(z_{t},t,c)-z_{\mathrm{full}}\bigr\rVert_{2}^{2},\qquad \rho(t)=\max(1-t,0.05)^{-2}. \tag{3}$$

也就是说：DiT 的输入永远是"某个随机子集构造出的带噪 latent"，预测目标永远是同一个全层融合；$p_{\mathrm{dit}}{=}0$ 退化为标准全层融合目标，与 RAEv2 的 velocity-space 损失的等价关系见 §E.2 的 Eq. (25)(26)。**两个 rate 分开，是因为两个阶段解的是不同的预测问题**：decoder 是对像素目标求不变性，DiT 是从带噪子集输入预测全层共识，其惩罚还带有 $t^{2}\rho(t)$ 的时间权重（Eq. (8)）。
6. **哪些是模型决定的、哪些是固定流程。** 编码器完全冻结；decoder 是标准 ViT decoder；生成器是 RAEv2 的 DiT（含 REPA head 与 internal guidance）；优化器、损失项、采样器全部沿用 RAEv2。FuseReg 唯一新增的是训练时的子集采样与两个 drop rate。论文未使用 RL、agent 或外部工具。
7. **训练与输出。** 需要训练的是 decoder 与 DiT 两部分（各自从零训练，见 §4.1）。推理阶段无任何改动、无额外结构或算力：默认全层融合，得到 $z=\bar{h}=K^{-1}\sum_{k}h_{k}$，其余流程与 RAEv2 一致。

**关键公式的直觉。** 设 $R=|S|$、$\bar{h}$ 为全层均值、$V(x)=K^{-1}\sum_{k}e_{k}e_{k}^{\top}$ 为层间偏差协方差（Eq. (4)），则

$$\mathbb{E}_{S}[z_{S}\mid x]=\bar{h},\qquad \mathbb{E}_{S}\!\left[(z_{S}-\bar{h})(z_{S}-\bar{h})^{\top}\mid x\right]=c_{K}(p)\,V(x),\qquad c_{K}(p)=\mathbb{E}\!\left[\frac{K-R}{R(K-1)}\right] \tag{6}$$

即：均值不变，方差为 $c_{K}(p)$ 倍的"分歧协方差"；$c_{K}(0)=0$、$c_{K}(p)\to 1$（$p\to 1$），是唯一一个只调"分歧方差"、不动"均值信号"的旋钮（§E.1 Remark 1）。把该扰动放进线性 + 平方损失的消费者里，就得到 decoder 与 DiT 各自的目标分解（Eq. (7)(8)）：原目标加上 $c_{K}(p)\operatorname{tr}(D\Gamma D^{\top})$（decoder）或 $\rho(t)t^{2}c_{K}(p)\operatorname{tr}(W\Gamma W^{\top})$（DiT，固定 $t$），其中 $\Gamma=\mathbb{E}_{x}[V(x)]$。这解释了 §5.3 强调的一点：$p_{\mathrm{dec}}{=}0.95$ 不等于"95% 的信号被毁"，而是把"预测随层间分歧而变"的代价放大到 $c_{K}(p)$ 倍。

**教学简化示例（分析者构造，非论文实验）。** 若 $K{=}2$，一层偏纹理、一层偏语义，那么只取单层得到的 $z_{S}$ 与 $\bar{h}$ 之差必然沿着 $h_{1}-h_{2}$ 这条"层间分歧"轴，不可能落在两层的公共成分上；这直观说明为什么归一化随机化只惩罚分歧方向。论文自己的对应物是附录 Proposition 4 的 $K{=}2$ 反例（两层噪声互相抵消）。

**图 2 的作用（正文图 2）。** 图中每一格是 decoder 中间层特征在某个 query patch（星号）上的 patch 级 cosine 相似度图，横排三种输入融合（$K{=}23$、$K{=}7$、单层 $\ell_{11}$），上排 FuseReg、下排 RAEv2，最右列是重建结果。这张图要证明的不是 PSNR 数字，而是**表征结构是否还在**：FuseReg 在三种融合下都保持干净、物体对齐的空间结构，RAEv2 一旦离开它的 $K{=}23$ 训练融合，相似度图的结构就崩掉，重建也随之损坏（§5.1、Figure 2）。

## 4. 解决得怎么样？

### 4.1 实验设置

- **任务与数据**：全部实验在 ImageNet-256（$256\times256$）、冻结 DINOv3-L、$K{=}23$ 个 transformer 层池上进行（§B.1）。三种评测融合：全层 $k{=}23$、$k{=}7$（层 $\{\ell_{11},\ell_{13},\dots,\ell_{23}\}$）与单层 $\ell_{11}$。
- **指标**：重建用 PSNR、SSIM、rFID（50k 张图像）；生成用 gFID、IS（50k 个类别条件样本，50 步 Euler 采样）；guided 设置用 RAEv2 官方 internal guidance，scale $1.78$（§5、§B.1、Table 5 图注）。
- **基线**：Table 1 用官方 RAEv2 的 $k{=}7$ / $k{=}23$ 固定融合 checkpoint；rate sweep 用作者在各自协议下复现的 $p{=}0$ 基线（§B.3）。同一表内作比较，跨表不可直接比。
- **控制条件**：decoder 变体在架构、参数量、优化超参和训练步数上对齐；DiT sweep 在每个规模内做同样的控制（§5、§B.2）。decoder-swap 实验固定 DiT 与采样出的同一批 50k latent，只换 decoder，因此图像变化只可能来自 decoder（§5.2）。
- **训练预算**（§B.2、Table 3）：decoder 从零训练 16 epochs，扫 $p_{\mathrm{dec}}\in\{0,0.05,0.1,0.3,0.5,0.7,0.9,0.95\}$；DiT-Base 与 DiT-XL 各 40 epochs，DiT-XL hidden size 为 1440，$p_{\mathrm{dit}}$ 的扫描档位见 Table 3。
- **三个实验分别回答什么**：§5.1 / Table 1 回答"一个 decoder 能否在任意融合下重建"（隔离 decoder 读出）；§5.2 / Figure 3 / Table 5 回答"decoder 变好能否改善生成"（隔离 decoder，其它全固定）；§5.3 / Table 2 回答"联合正则两个阶段是否互补、能否扩展"（DiT-Base 与 DiT-XL）。附录 §C 是重建补充（rate sweep、定性、层依赖诊断），§D 是生成补充（完整表与 guided rate 偏好），§E 是证明。
- **论文未报告的部分**：硬件型号与数量、训练时长/GPU 小时、优化器与学习率的具体数值、随机种子与方差/置信区间、以及用于挑选 drop rate 的验证集划分。所有表格数字都是点估计（§B.3 原文："Reported grid entries are point estimates"）。

### 4.2 关键结果

**(1) 一个 decoder 服务任意融合（Table 1，§5.1）。** FuseReg（$p_{\mathrm{dec}}{=}0.95$）在 $k{=}7$ / $k{=}23$ / $\ell_{11}$ 三种输入上分别为 $23.77$ / $27.52$ / $25.13$ dB，rFID 为 $0.60$ / $0.42$ / $0.45$（原文正文写 "rFID below 0.6"，但表中 $k{=}7$ 一列为 $0.60$）。对照的专用 decoder 只在自己训练过的融合上有效：RAEv2$_{K=23}$ 在 $k{=}23$ 为 $27.04$ dB / rFID $0.18$，在 $k{=}7$、$\ell_{11}$ 跌到 $12.51$、$14.31$ dB；RAEv2$_{K=7}$ 在自家融合 $22.58$ dB / rFID $0.30$，off-fusion 为 $18.37$、$17.50$ dB。**需要一并注意的负面细节**：FuseReg 在三种融合上 PSNR 都超过对应专用 decoder，但在两个**原生融合**上的 rFID 反而略差（$k{=}23$：$0.42$ vs $0.18$；$k{=}7$：$0.60$ vs $0.30$），摘要中的"higher PSNR"限定在 PSNR，不是全指标胜出。

**(2) 固定 generator、只换 decoder（Table 5 / Figure 3，§5.2）。** native $k{=}23$ 上，unguided gFID 从 $3.01$ 降到 $2.21$（$p_{\mathrm{dec}}{=}0.95$，约 $-27\%$），IS 从 $206.8$ 升到 $218.5$；**同一实验的 guided 设置没有净收益**：$1.25\to1.25$（gFID 持平），IS 从 $263.8$ 略降到 $260.7$，且中间 rate 会先回退（guided 在 $p_{\mathrm{dec}}{=}0.1$ 达 $1.49$；unguided 在 $0.05$/$0.1$ 为 $3.15$/$3.16$，均差于基线 $3.01$）。偏移到 $k{=}7$ 融合空间后增益很大：unguided $27.73\to1.92$、guided $16.35\to1.42$、IS 从 $97.7$/$148.7$ 升到 $221.8$/$250.5$——但这一栏本身是"decoder 与 latent 融合不匹配"的失败场景，收益幅度不宜与 native 栏并列解读。

![固定 generator、替换 decoder 时的 gFID 与 IS](/images/dailypaper/2026-09-28/2609.31620_fig3.png)

*原文 Figure 3：同一个 RAEv2 DiT（$p_{\mathrm{dit}}{=}0$）采出一组固定的 latent，横轴是替换上去的 decoder 的训练 rate $p_{\mathrm{dec}}$（橙：gFID，左轴；蓝：IS，右轴）。$p_{\mathrm{dec}}{=}0$ 即原始 RAEv2 decoder，因此曲线变化只来自 decoder 替换；四个面板依次为 $k{=}23$ 无引导、$k{=}7$ 无引导、$k{=}23$ 引导 $1.78$、$k{=}7$ 引导 $1.78$，$k{=}7$ 面板的 gFID 用对数坐标。*

**(3) 联合正则与扩展性（Table 2，§5.3）。** DiT-Base 基线（$0,0$）unguided gFID 为 $13.96$：只正则 decoder（$p_{\mathrm{dec}}{=}0.9$）得 $12.96$，只正则 generator（$p_{\mathrm{dit}}{=}0.7$）得 $12.09$，联合（$0.9,0.7$）得 $9.93$（约 $-29\%$），IS 从 $107.5$ 升到 $125.7$。§D.2 给出更细的账：两条单轴增益为 $1.00$ 与 $1.87$（加和 $2.87$），联合增益 $4.03$，超出加和 $1.16$；作者称这是互补性，同时声明这只是选定配置下的四点比较、**不是统计交互检验**。扩到 DiT-XL（基线 gFID $2.91$）后结论变成"指标依赖"：gFID 上单独正则 generator 无效甚至变差（$p_{\mathrm{dit}}{=}0.9,p_{\mathrm{dec}}{=}0\to3.09$），需要配合强 decoder 正则才到 $2.38$（$0,0.95$）；IS 则偏好两个 rate 都大（$0.9,0.95$ 处 $221.1$）。guided 版本（Table 6）里最好 guided gFID 是 $(0.9,0)$ 的 $1.50$（基线 $1.57$），但最高 IS 仍在 $(0,0)$ 的 $262.6$。

**(4) rate 扫描显示的是取舍而非单调改进（Table 4，§C.1）。** 全融合 PSNR 在 $p_{\mathrm{dec}}{=}0.05$ 达峰值 $28.59$ dB，此后单调下滑到 $p_{\mathrm{dec}}{=}0.95$ 的 $27.52$ dB；而全融合 rFID 从复现基线的 $0.189$ 单调恶化到 $0.421$。也就是说，稳健性（$k{=}7$ 从 $12.54$ 升到 $23.77$ dB、$\ell_{11}$ 从 $15.81$ 升到 $25.13$ dB）是用原生融合上的保真度换来的，Table 1 选的正是取舍端的 $p_{\mathrm{dec}}{=}0.95$。

**(5) 定性证据（Figure 5，§C.2）。** $k{=}7$ 输入下，RAEv2$_{K=23}$ 塌成低对比度、近乎均匀的输出（$10.8$–$14.4$ dB），FuseReg（$19.6$–$22.4$ dB）略高于专为该融合训练的 RAEv2$_{K=7}$（$18.9$–$21.9$ dB）；$\ell_{11}$ 输入下两个固定融合基线都跌到 $14.5$–$17.2$ dB，同一个 FuseReg decoder 保持在 $20.2$–$23.3$ dB。

**哪些地方提升小或没有提升（汇总）**：guided、native $k{=}23$ 的 decoder-swap 完全没有净提升（gFID 持平、IS 略降）；DiT-XL 上单独正则 generator 对 gFID 无益；低 rate（$0.05$/$0.1$）在 DiT-Base 上反而显著变差（$17.28$/$17.26$，差于 $13.96$ 基线）；原生融合上的 rFID 始终不如专用 decoder；所有比较都是单一数据集、单一编码器下的点估计，论文没有给出方差或显著性检验。

### 4.3 机制证据

**效果证据（较强）。** (i) off-fusion 稳健性是直接的实验事实（Table 1、Table 4、Figure 5）；(ii) decoder-swap 实验把 DiT 与 latent 完全固定，只换 decoder，这构成对"生成改善来自 decoder"的较强隔离（§5.2）；(iii) 联合正则在 DiT-Base 上的增益超过两条单轴加和（§D.2），但作者自己限定为四点比较。

**机制证据（较弱，且作者自己划了边界）。** 采样恒等式 Lemma 1 是精确结论（不假设线性下游）；但"随机化等价于分歧惩罚"的分解（Eq. (7)(8)）与闭式预测器（Eq. (29)(30)）只对**齐次线性预测器 + 平方损失**成立，实际系统用的是 ViT decoder（像素 + LPIPS + GAN + classifier surrogate 混合损失）与非线性 DiT。作者在 §E.6 明确写下：对非线性消费者，"latent 均值保持"不蕴含"预测均值保持"或精确的分歧惩罚，该分析**既不预测两个 rate 对比的符号，也不证明超可加性**。因此摘要与 §5.3 中"互补增益"的措辞强于理论所能支持的范围。

**诊断性证据（相关性）。** Figure 4 与 §C.3 的 Figure 6 在同一批 10,000 张 held-out 图像、同一固定 $\ell_{23}$ token-mean 代理特征上比较两个 decoder：FuseReg 的 leave-one-out PSNR 下降更平坦（浅层尤甚）、单层输入本身重建更强、子集规模增大带来的边际收益更早饱和（PSNR 与 MSE 两种尺度上都成立），而各层的 Shapley 排序大体保留（Figure 6(b)）。由于编码器冻结，这些变化在逻辑上只能来自 decoder 的**读出方式**，这支持"训练改善了对固定表示的读取"的解释；但"信息本来就分布在层间、只是之前读不出来"这一更强的机制断言仍是解释而非被检验的假设，替代解释（例如 drop rate 提供的隐式集成/有效容量效应、正则强度本身带来的平滑）没有被对照排除。

![移除单层与单层输入的重建诊断](/images/dailypaper/2026-09-28/2609.31620_fig4.png)

*原文 Figure 4：FuseReg（$p_{\mathrm{dec}}{=}0.95$）与 RAEv2 decoder 在同一批 10,000 张 ImageNet-256 图像、同一固定 $\ell_{23}$ 代理特征上的对照。左：逐层 leave-one-out 的 PSNR 下降（RAEv2 在浅层 1–5 处掉约 1–3 dB，FuseReg 普遍在 0.5 dB 以内）；右：用单层特征直接重建的 solo PSNR 随层号变化，虚线是各自的全融合 PSNR（图中标注 FuseReg 27.93 dB、RAEv2 27.36 dB）。*

**替代解释的排除情况。** decoder-swap 设计排除了"生成器变化"与"latent 分布变化"；DiT 网格在架构/参数量/步数上受控，排除了容量差异；但**数据量没变、算力每步只多一次掩码采样**，所以"更多训练算力"不是解释；未被排除的是指标噪声与 rate 选取的乐观偏差（无验证集划分、无多 seed）。

### 4.4 成本与适用范围

**推理成本。** 无额外开销：模型结构不变，默认全层融合，采样流程与 RAEv2 一致（§3.2、§7）。训练时每步只多一次子集掩码采样与归一化平均，论文未量化这一开销。

**训练与调参成本（论文报告 + 分析者推断）。** 论文给的是预算而非总计算量：decoder 16 epochs × 8 个 rate，DiT-Base 40 epochs × 7 个 $p_{\mathrm{dit}}$，DiT-XL 40 epochs × 4 个 $p_{\mathrm{dit}}$（§B.2、Table 3）；每个训练好的 DiT 再用整套 decoder-rate 网格评测。按"每个 $p_{\mathrm{dit}}$ 训一个 DiT"读表（这是分析者推断，论文未直接给出训练次数总计），总训练量约为 19 次完整训练（8 decoder + 7 DiT-Base + 4 DiT-XL）对 3 次基线训练。**论文未报告 GPU 型号、数量、时长，也未报告推理时延的任何改动。** 其它成本项：不增加人工标注；不依赖外部模型或闭源服务（论文未使用 RL、agent 或工具调用）；系统复杂度只增加"训练采样 + 两个超参"，部署栈与 RAEv2 相同；唯一隐性成本是调参所需的多轮训练与评测。

**适用范围与未解决问题。** (i) 只验证了 ImageNet-256 + DINOv3-L + DiT-Base/XL 一种组合，其他编码器层级结构、分辨率、数据域与更长训练未测（§7）；(ii) 最优 $p_{\mathrm{dit}}$ 随模型规模、指标（gFID vs IS）与是否使用 guidance 变化，换新设置必须重新标定两个 rate（§7、Table 2、Table 6）；(iii) 理论只覆盖线性预测器与平方损失，混合重建损失与完整引导采样轨迹未被刻画（§E.6、§7）；(iv) 实现只用了"各层同概率"的对角切片，并非任意逐层子集分布（§E.5）；(v) internal guidance 与融合正则之间存在耦合（§6 给出的引导公式为 $\hat{x}_{\mathrm{guided}}=\hat{x}_{\mathrm{full}}+w\,(\hat{x}_{\mathrm{full}}-\hat{x}_{\mathrm{repa}})$，其中 $\hat{x}_{\mathrm{repa}}$ 来自中间 REPA 头；引导项是两者之差，单个预测更稳不等于二者之差更稳），二者的联合标定被留作后续工作。

**可复现性相关事实。** Reproducibility Statement 称将公开全部代码、权重与复现脚本，并称其他研究者在独立环境中验证过表格数字——这是**作者主张**，论文未附第三方报告；分析者核验了论文给出的三个链接在 2026-09-28 均可访问。

## 5. 最容易受到审稿人质疑的地方

#### 质疑 1：收益依赖指标、规模与 guidance，"27% 提升"是在单一设置下选出的最优点；方法需要按设置重扫 rate 网格，实用门槛被低估

- **原文依据**：DiT-XL 上单独正则 generator 对 gFID 无益（$2.91\to3.09$，Table 2(c)）；guided native $k{=}23$ 无净收益（gFID $1.25\to1.25$、IS $263.8\to260.7$，Table 5），且最高 guided IS 仍在 $(0,0)$（Table 6）；低 rate 反而变差（$17.28$/$17.26$ vs $13.96$，Table 2(a)）；§7 明确承认 rate 依赖规模、指标与 guidance；§B.3 说明所有网格数字是点估计。
- **为什么重要**：直接影响"FuseReg mitigates the reconstruction–generation gap"这一主张的强度与适用范围，也影响读者对方法可用性的判断：如果最优 rate 必须逐设置网格搜索，那么方法更像"一套需要调参的训练配方"，而不是开箱即用的改进。
- **当前能够得出的判断**：证据支持"在该受控 pipeline 内、经调参后可获得显著收益"，不支持"普遍或默认生效"；guided 场景下收益基本消失，属于结论被部分夸大（摘要只报了最有利的两个数字）。
- **如何验证或补强**：多 seed 重复并报告方差；用独立验证集选 rate 再在固定测试集上报数；给出 rate 选择成本与自动化流程；在更长训练与更大规模上复现。
- **严重程度**：主要问题。

#### 质疑 2：缺少与最接近方法的实证对比；"与确定性融合的二阶分离"是权重层面的性质，不等于性能上的不可替代

- **原文依据**：§2 与 §A.3 讨论 DRoRAE（Zhu et al., 2026）与 attentive multi-layer probing（Ciernik et al., 2026），但实验对比对象只有 RAEv2 固定融合（官方 checkpoint 与复现的 $p{=}0$ 基线，§B.3），没有任何 learned-fusion / learned-gate 基线进入表格；Figure 1 的门控塌缩是作者自建诊断，只有一张图、没有进入任何量化表格；Proposition 2 与其后的比较**限定在输入无关的融合规则**，§E.4 末尾明确声明不含 input-dependent router，且分离是否传导到目标函数取决于特征矩。
- **为什么重要**：论文的核心主张是"不应搜索或学习一个更好的固定融合"，这是一个相对性主张，必须至少有一个同类方法（学融合的 DRoRAE、学权重的 gate）在相同协议下对照，否则无法判断增益来自"随机化"还是"只是多训了一个更强的 decoder"。
- **当前能够得出的判断**：目前只能确认作者声称的差异与理论上的权重矩分离；"学出来的融合在本文设置下必然更差"这一普适结论证据不足，Figure 1 作为单点诊断也不足以支撑。
- **如何验证或补强**：在相同 decoder/DiT 协议下加入 DRoRAE 或全局 gate 基线（含把 gate 与 FuseReg 结合）；对输入相关 router 做实验；报告 Figure 1 的实验细节（损失项、训练配置、是否联合训练）。
- **严重程度**：主要问题。

#### 质疑 3：机制解释建立在线性代理之上，但正文与摘要的措辞（"complementary gains""confirming"）强于理论所能支持的范围

- **原文依据**：§E.6 原文明确：对非线性消费者，latent 均值保持不蕴含预测均值保持或精确分歧惩罚，该分析"neither predicts the sign of the two-rate contrast nor establishes super-additivity"；§D.2 也声明四点比较不是统计交互检验；而 §5.3 正文写"confirming that stage-specific drop rates act complementarily"，§6 用线性代理解释 guidance 耦合。
- **为什么重要**：这是"结论略超证据"的类型——不是结论错误，而是机制主张（互补性、分歧惩罚是收益来源）缺少因果证据；把机制解释当成已证明的结论会误导读者对方法迁移性的预期。
- **当前能够得出的判断**：机制证据不足；$\Omega(W)$ 的分解与 $c_{K}(p)$ 的非单调曲线只能作为定性佐证；收益是否真来自"分歧惩罚"没有被隔离（例如没有"随机扰动不归一化"或"等方差高斯扰动"这类控制变量的对照）。
- **如何验证或补强**：加入破坏关键设计的消融（去掉归一化、用固定层数随机子集、加等幅随机噪声），看稳健性与生成指标是否同步退化；用多 rate 点与多 seed 检验超可加性。
- **严重程度**：主要问题。

#### 质疑 4：单一数据域、单一编码器、受控但偏短的训练预算，结论外推范围有限

- **原文依据**：§7 的 limitations 首句即承认只覆盖 ImageNet-256 + DINOv3-L + DiT-Base/XL 与 matched budgets；§B.2 给出 16/40 epochs；DiT-Base 与 DiT-XL 的基线水平差距巨大（$13.96$ vs $2.91$ gFID），提示 base 规模或预算受限，在弱基线上的相对提升未必迁移。
- **为什么重要**：涉及结论可推广性（其他编码器层级、分辨率、数据域）与实验公平性（基线是否已充分收敛）。
- **当前能够得出的判断**：当前证据支持"在该设置内"的结论；"narrows the reconstruction–generation gap"作为一般性主张超出实验覆盖。
- **如何验证或补强**：替换为 SigLIP/DINOv2 等其他编码器、提高分辨率、换数据域；延长训练到基线收敛并报告收敛曲线。
- **严重程度**：次要问题。

#### 质疑 5：可复现细节与统计稳定性披露不足；Figure 1 的图形资源在官方 HTML 中缺失

- **原文依据**：§B 只给出 epochs 与 rate 网格，未给硬件、训练时长、优化器与学习率数值；§B.3 承认网格数字是点估计，全文没有 seed、方差或置信区间；FID/IS 对采样实现与 batch 统计敏感；Figure 1（门控塌缩）在 arXiv HTML 中只有图注、无图形资源（分析者核验），门控实验的配置也未在附录说明。

- **当前能够得出的判断**：代码/权重/项目页链接已公开且可访问（分析者核验），部分缓解；但论文本身未披露统计稳定性，无法判断 $0.1$–$0.3$ dB 级别的差异（如 $27.52$ vs $27.04$）是否超出噪声。
- **如何验证或补强**：补一份训练配置表（硬件、优化器、学习率、batch）、多 seed 方差、采样实现说明，以及 Figure 1 的完整实验设置。

## 6. 审稿式总评

> 作者发现 RAE 的 layer fusion 被固定启发式绑死：浅层利于重建、深层利于生成，全局可学门控会塌缩到浅层，且下游模型一旦离开训练时的融合就严重退化（Table 1、Figure 1、Prop. 4）；因此提出 FuseReg，把融合从"一个固定选择"改为"归一化随机子集上的训练分布"，并用均值保持与分歧协方差刻画其作用（Lemma 1、Prop. 1–3），为 decoder 与 DiT 各设一个 drop rate。实验在 ImageNet-256 + 冻结 DINOv3-L 的受控设置下表明：一个 decoder 可在全层、稀疏与单层融合间通用并在三种输入上都超过专用 decoder 的 PSNR，仅替换 decoder 可把 native $k{=}23$ 的 unguided gFID 从 $3.01$ 降到 $2.21$、两阶段联合正则把 DiT-Base 的 gFID 从 $13.96$ 降到 $9.93$；其中"decoder-swap 隔离实验"与"off-fusion 稳健性"证据较强，但 guided 设置下的收益、DiT-XL 上 generator 一侧的收益、以及"互补性/分歧惩罚"的机制主张仍缺少充分支持，理论只在齐次线性 + 平方损失下成立，且缺少与 learned-fusion 方法的实证对照。本文最有价值的部分是"用归一化把随机化约束在不改变期望 latent 的分歧方向上"这一可迁移的设计直觉，以及坦诚的负面结果（低 rate 变差、guided 无增益、rate 依赖设置）；最大的审稿风险是把一个需要逐设置调参的训练配方表述为对 reconstruction–generation gap 的普遍缓解。

- **问题定义清晰度**：强。（问题被操作化为"层融合作为 generator/decoder 共享接口"，并有 $22.58/27.04$ dB 与 $1.65/3.01$ gFID 的具体数字支撑 §1；不过"gap"这一命名现象与 RAEv2 已报告的 Pareto 前沿有部分重叠，本文的增量在于把它归因到接口的固定性。）
- **创新性证据**：中。（机制属于 dropout/随机深度家族迁移到新轴（§A.3 自述），真正的增量是均值保持的归一化设计、覆盖率界与二阶段 rate；缺少与 learned-fusion 方法的实证对比。）
- **方法可信度**：中。（设计简单、无推理开销、控制变量清楚（同一 50k latent、匹配预算）；但最优 rate 依赖规模/指标/guidance，需要网格搜索，且线性代理理论不能预测 rate 对比的符号（§E.6）。）
- **实验支持力度**：中。（decoder-swap 是强隔离实验；但均为单数据集/单编码器点估计，无方差或显著性检验，guided 与 DiT-XL generator 一侧缺少净收益。）
- **可复现性**：中。（论文给出 epochs、rate 网格与协议，代码/权重/项目页链接公开且可访问（分析者核验）；但未报告硬件、优化器数值、seed 与方差，Figure 1 图形资源在 HTML 中缺失。）
- **综合阅读价值**：中。（对研究 latent diffusion / RAE 接口设计的学生，值得读的是问题构造方式、归一化随机化的分析思路，以及作者公开的失败与边界；不适合作为"即插即用提升 gFID"的方法来读。）
