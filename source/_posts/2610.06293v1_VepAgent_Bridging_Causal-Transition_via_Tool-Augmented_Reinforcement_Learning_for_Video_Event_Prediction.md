## 0. 一句话结论

VepAgent 针对视频事件预测（video event prediction，VEP）中"多模态大模型（multimodal large language model，MLLM）只会回溯总结历史、无法桥接观测末端与未来事件之间不可见的因果转移"这一问题，在 Qwen3-VL-4B 上用合成四步因果思维链做监督微调（supervised fine-tuning，SFT），再用带诊断工具库的 GRPO（group relative policy optimization）训练并加入因果间隙与"反先验"复合奖励（composite reward）。论文在 FutureBench 与 NEPBench 上报告 AVG 81.44% 与 Overall 70.20%（较同尺寸骨干分别 +22.35、+28.03 个百分点），消融显示工具、动态选择与奖励项均有贡献。但基线数字全部照搬其他论文、工具使模型获得超出 32 帧的额外视觉证据与外部 VLM 证据通道、且全表无方差与显著性检验，因此证据只支持"在该两基准、作者自定协议下该流程显著优于所引报告数字"，不足以支持"通用解决 VEP"或"反先验奖励确实压制了语言捷径"的更强结论。

## 1. 论文具体想解决什么问题？

**研究背景与任务。** VEP 要求基于部分观测的视频证据预测最可能的未来事件（§1）。形式化设定为：输入部分观测视频 $V$、查询 $Q$ 与 $K$ 个候选未来事件选项 $\mathcal{O}=\{o_k\}_{k=1}^{K}$，输出预测 $y\in\mathcal{O}$（§3.1）。该能力被作者列为主动式机器人、自动驾驶、智能监控等应用的基础（§1）。与普通视频理解任务（描述已发生内容）不同，VEP 需要向前的外推式因果理解。

**现有方法通常如何处理。** 早期路线来自 NLP 的脚本事件归纳与动作预期（Granroth-Wilding and Clark 2016；Girdhar and Grauman 2021），数据集如 VidSitu、EPIC-Kitchens、VLEP；近期 VidEvent、EventFormer 用节点图注意力建模事件演化；FutureBench 用现代 MLLM 评测未来事件推理（§2，§B.1）。工具增强方向已有 FAST、MVoT（多模态思维链）、LLaVA-Plus/VPD（工具使用训练）、TACO、PyVision（工具 + RL）、VITAL（长视频按需获取视觉证据的 tool-augmented RL）（§2，§B.3）。

**作者认为现有方法在哪些条件下表现不好。** 论文在 §1 提出三个失败模式（均以 Fig. 1 的一个"抹黄油"示例与文献引用为佐证）：❶ 因果逻辑间隙（Causal-Logic Gap）：MLLM 能重建历史事件链，但"回溯式摘要"能力不外推未来轨迹，观测末端与未来事件之间存在需要结构化桥接的未观测中间状态转移；❷ 语言先验捷径（Language-Prior Shortcut）：模型倾向选择与问题文本最相似的选项，而非基于视频状态作答；❸ 视觉证据缺失（Visual-Evidence Omission）：遮挡、快速运动或均匀抽帧截断关键时空线索，模型没有动态找回缺失证据的机制。

**本文的新观察。** 需要区分：VEP 任务本身、语言先验问题、抽帧漏信息都是领域早已存在的问题（论文也承认来自先前文献，如 Chen et al. 2025c 关于推理增强模型仍欠利用视觉信息的观察、Chen et al. 2026b 关于语言先验的观察）。本文相对新的部分是**把 VEP 的困难重新形式化为"末端观测状态（terminal observed state）$S_{\text{final}}$ → 未完成动作（ongoing action）$A_{\text{ongoing}}$ → 不可观测的因果间隙 → 未来事件"的四段结构**（§3.1），并据此主张训练数据、工具与奖励都应围绕该结构设计。这是作者的问题框定（作者主张），论文并未在基准上给出捷径发生率或因果间隙存在性的量化诊断实验——对三个失败模式的支撑目前是示例式的（Fig. 1）与引用式的，属于"论文观察到了现象并引用文献佐证，但没有以新实验验证因果解释"。

**支撑问题判断的证据。** Fig. 1 用同一道选择题展示四种推理模式的差异：(a) 朴素 VLM 只对已见动作做粗糙延续；(b) 选项驱动的推理被文本先验带偏、提前断言烹饪阶段；(c) 无工具的因果间隙推理抓住了"+进行中的抹黄油"却漏掉细粒度视觉状态而选错；(d) 加入工具证据后识别出"还有一片没抹"，从而正确预测下一步（Fig. 1 caption）。另有 §3.3 的一个预实验观察：不做 SFT 直接 RL 时工具调用频率在训练中持续下降，作者将其归因于"工具增强视觉特征与模型预训练分布的目标域分布差异"（§3.3）——这是作者解释，论文未进一步验证该因果归因。

**论文要验证的核心假设。** 显式建模"末端状态→未完成动作→状态演化→未来事件"的推理结构（体现在数据与提示词模板中）、在推理时选择性调用诊断工具补证、并用复合奖励抑制浅层文本作答，三者结合可以显著提升 VEP 准确率。该假设由 Table 3–5 的消融部分检验（见 §4.3）。

**本文实际解决的具体子问题。** 在 FutureBench 与 NEPBench 两个封闭选项基准上，用 4B 规模的开源模型（Qwen3-VL-4B-Instruct）+ 合成的 CoT 数据 + 工具增强 GRPO，提高选项预测准确率；不涉及开放式生成、多轮规划或真实机器人闭环。

## 2. 创新点是什么？

**总括。** 本文的技术增量是"已有组件在 VEP 上的领域化组合 + 两处相对较新的设计"：把（i）强模型采样蒸馏的四步因果 CoT 数据、（ii）四个固定诊断工具与"单轮选择 + 一次执行 + 二次推理"的两轮 agent 流程、（iii）带过程项与捷径抑制项的 GRPO 复合奖励，串成一条面向 VEP 的训练管线。其中较新的设计是面向 VEP 的"末端状态/未完成动作/因果间隙"四步推理结构与相应过程奖励（Eq. 8–9）、按"正确选项文本相似度排名"给分的反先验奖励项（Eq. 6）。论文没有提出新网络结构、新学习范式或新的基础模型训练目标；4B 骨干比对照的 30B/72B 模型更小，不是"换更大模型"式贡献。

**1) futurebench-4K 的因果转移 CoT 数据构造管线（§3.2，Fig. 2 左）。** 用 Qwen3-VL-32B 对基础 VEP 训练集每个样本做 8 次独立 rollout 采样多样因果推理路径，"至少一次与真值匹配"才算可解（排除纯语言先验猜中），再由 Qwen-VL-Max 按"观测状态事实正确性、因果桥接逻辑一致性、无捷径行为"过滤，得到约 4,000 条 SFT 推理链（futurebench-4K），其余约 5,000 条有效轨迹用于 RL，且只取自训练划分以避免泄漏（§3.2，§A.1）。相对普通 CoT 蒸馏，它强调四步因果结构与"可解性"筛选，但仍属已有做法（强模型采样＋过滤＋蒸馏）的领域化改版——论文没有做"普通 CoT 数据 vs 四步结构数据"的对照消融（审稿人判断）。它对应 §1 的"因果逻辑间隙"；证据指向 §4.3（Table 3 (b)）。

**2) 诊断工具库与两轮 agent 工作流（§3.1，Fig. 2/Fig. 3，Appendix C/D）。** 四个工具的固定库——状态转移追踪器（State Transition Tracker，STT）、聚焦证据检索器（Focused Evidence Retriever，FRE）、区域聚焦放大镜（Region Focus Magnifier，RFM）、视觉细节提取器（Visual Detail Extractor，VDE）：策略只做一次工具选择（对四工具逐一 yes/no），选中工具执行一次后证据并入上下文再推理，所有工具只访问已观测片段，杜绝未来帧泄漏（Appendix C "Tool Execution Protocol"）。与 VITAL（长视频一般性按需取证）、TACO/PyVision（图像工具链）不同，它的工具目标落在 VEP 特有的"确认末端状态与未完成动作"，且选择是单轮一次性的；属已有组件（工具＋RL、两轮 agent）的新组合与领域化设计。它对应 §1 的"视觉证据缺失与细粒度状态歧义"；证据指向 §4.3（Table 3 (e)–(h)、Table 4、Table 5），论文未与 VITAL 等最接近方法做同基准数值对照。

**3) 复合奖励，特别是因果间隙奖励与反先验奖励（§3.4，Eq. 6–9）。** 总奖励 $R(\tau)=R_{\text{format}}\cdot(0.65R_{\text{acc}}+0.20R_{\text{cau}}+0.15R_{\text{ant}})$（Eq. 7）：格式奖励作硬门控，准确率奖励二值，因果间隙奖励用 MiniLM 句向量余弦相似度把生成的末端状态、状态演化与参考文本比对（权重 0.45/0.55）并按预测对错分层给分（Eq. 8–9），反先验奖励按"正确选项相对查询的文本相似度排名 $k$"给 $(k-1)/(K-1)$ 的连续分（Eq. 6）。过程奖励与可验证奖励属 RLVR 常规做法，反先验的"按排名给分"在论文引用的相关工作里未见直接对应，相对较新；但该奖励只依赖样本静态属性 $k$、组内不随轨迹行为变化，机制解释与实现存在落差（§5 质疑 2）。它同时对应 §1 的"语言先验捷径"与"因果桥接质量"；证据指向 §4.3（Table 3 (i)–(l)）。

**原创边界说明。** 根据本文 related work 与实验对比，只能确认作者声称的差异（VEP 专用因果转移结构、VEP 诊断工具、反先验奖励项）；是否属于"首次提出"，需要更完整的文献检索，且缺少与最接近的工具增强 RL 方法（VITAL、Video-R1、TACO 等）的同基准数值比较来支撑"不可替代"。

## 3. 作者如何解决？

**直觉。** 把"猜接下来会发生什么"改造成"先确认视频停在哪一步、哪件事做到一半，再推断下一步"：推理时模型自己判断证据够不够，不够就从已观测视频里取回缺失证据（更密的帧、放大的局部、结构化的状态序列、文本化的可见事实），训练时用两阶段（先模仿合成推理链，再用 RL 把"何时取证"与"如何作答"固化为策略），奖励里加入鼓励因果桥接与"不要按文本相似度作答"的项。

**整体范式。** 这是 training-based（需要训练）的框架：训练只更新策略模型 Qwen3-VL-4B-Instruct 一个模块，所有工具与外部服务全部冻结；训练分 SFT 与 GRPO 强化学习两阶段，推理时按"两轮"运行（先选工具、再带证据推理）。任务输入是部分观测视频 $V$、查询 $Q$ 与 $K$ 个候选未来事件选项 $\mathcal{O}=\{o_k\}_{k=1}^{K}$，最终输出是选项字母 $y\in\mathcal{O}$（§3.1）。整条管线的四个阶段（数据构造 → SFT → RL → 评测）及其数据流如图 1（论文 Fig. 2）所示。

![图 1：VepAgent 总体流水线](/images/dailypaper/2026-10-08/2610.06293v1_fig2_pipeline.png)

**图 1**（论文 Fig. 2）：这张总览图从左到右画出完整闭环——左侧 "Data Construction" 是训练材料的产出（视频＋问题经 Qwen3-VL-32B 教师做工具使用分析与因果推理，对每个样本跑 8 次 rollout，再由 Qwen-VL-Max 质检状态正确性、因果一致性与有效预测，产出 4K SFT 数据与 5K RL 数据）；中间 "Supervised Fine-Tuning" 展示模型要学的两轮回复格式（第一轮含思维链分析与工具请求字段，第二轮含 Terminal state → Unfinished action → State evolution → future event 的四步结构）；右侧 "Reinforcement Learning" 展示 GRPO 采样后由因果间隙奖励、反先验奖励、准确率奖励合成 $R=r_{fmt}(0.65r_{acc}+0.20r_{gap}+0.15r_{ap})$ 的格式门控流程；最右 "Evaluation" 是以"视频＋问题＋工具→推理与答案"的两轮推理完成评测。读图时把四段当作同一条链的四环：缺"数据从哪来"就没有可模仿的推理模板，缺 SFT 冷启动则 RL 阶段工具调用会退化（§3.3），缺 RL 奖励设计则模型不会学"何时取证"，缺两轮评测就看不到推理过程——正文每一步都可以在这张图上定位。

**数据从哪来（§3.2，对应 §2 创新点 1）。** 现有 MLLM 缺少"因果转移推理链"这种训练素材，第一步是合成它。生成流程在论文里是三步（§3.2 "Generating Pipeline"）：先识别末端观测状态 $S_{\text{final}}$ 与仍在进行、尚未完成的动作 $A_{\text{ongoing}}$；若关键状态转移存在歧义，条件性地引入诊断工具（如 STT 或 FRE）找回缺失的时间证据；最后桥接因果间隙——推演未完成动作如何演进到下一个物理上合理的状态，并给出未来事件预测。执行者是 Qwen3-VL-32B 教师模型：对每个部分观测视频做 8 次独立 rollout，得到多样的推理路径；一个样本被判为可解（solvable）的标准是"至少有一次 rollout 在同一匹配协议下与真值一致"，用以保证预测来自真实视觉状态而非语言先验猜中。质量把关由 Qwen-VL-Max 以专家校验器身份完成：观测状态事实错误、因果桥接逻辑不一致、或存在语言先验捷径行为的推理链被丢弃；约 4,000 条留下来的推理链用于 SFT（即 futurebench-4K），其余被确认有效但未入选的轨迹（约 5,000 条）用于 RL。所有数据只从 VEP 训练划分构建，论文声明以此避免数据泄漏（§3.2）。为什么需要数据先于 RL：论文模仿 R1-Zero 直接做 RL 的预实验发现 rollout 中工具调用频率持续下降，作者把它归因于"工具增强视觉特征与模型预训练分布之间的目标域分布差异"（§3.3）——这是作者解释，论文未进一步验证该因果归因；由此改为"SFT 冷启动 → RL"两阶段。

**输入与第一轮：Observation & Tool Selection（§3.1 Stage 1；Appendix D Round 1，由策略模型决定）。** 每次预测的输入是默认约 32 帧的部分观测视频、查询与 $K$ 个候选选项。第一轮里策略网络 $\pi_{\theta}$ 只做一次判断，输出两块内容：[1] 2–3 句视频情境分析（人物、关键动作变化与进行方向）；[2] 一个"预测关键但尚未观测清楚"的不确定性（末端状态 / 事件顺序 / 小区域 / 细节），随后对四个工具逐一给出 yes/no，得到选择子集 $C\subseteq\mathcal{T}$。提示词的固定规则是：若已可见内容不存在真实不确定性则全部答 no；每个请求只写一条针对"已观测内容"的检查目标；选项只作为待验证的假设、不当作视觉证据（Appendix D Round 1）。哪些由模型决定、哪些固定：选哪些工具与不确定性怎么写由模型决定；工具集合、yes/no 输出格式、每轮回复必须含 `<thinking>`/`<answer>` 标签均为固定约束。为什么只选一轮：论文的设计是单轮选择，模型没有多轮试错的权限——论文未比较多轮方案，这是控制调用与流程稳定性的设计取舍（审稿人判断）。

**工具执行：固定协议与混合后端（Appendix C，Table 6）。** 无论选中几个工具都只执行一次，之后不再进行第二轮工具选择（"No additional tool-selection round is performed"）。四个工具各对应一类信息缺失，其输入输出与示例见图 2（论文 Fig. 3）。

![图 2：四个诊断工具及其输入输出](/images/dailypaper/2026-10-08/2610.06293v1_fig3_tools.png)

**图 2**（论文 Fig. 3）：左上 FRE 以输入视频和指定时间窗抽取密集帧（图中为连续帧网格），找回均匀抽帧漏掉的瞬时动作（例：临近结束时手仍握着还是已松开）；右上 RFM 以预测的空间框裁剪放大局部（图中红框为手部区域），确认接触、朝向等微观状态；左下 STT 输出 "timeline" 式事件链与末端状态文本（示例：站姿→弯腰→取盘→举起到嘴边→咬下，final state 为"举着盘子进食"）；右下 VDE 输出对象、属性、动作等 "readouts" 文本事实（示例 person/sandwich/open doorway）。右侧 "Qwen API" 表明 STT/VDE 的文本化由外部托管 VLM 完成——两个工具的能力上限不在 4B 策略模型内。读图时注意两点：每个工具针对一种特定的"看不见"（时序遗漏、局部模糊、顺序歧义、细粒度事实被忽略），且所有工具只作用于已观测片段（图注），这是防止未来信息泄漏的关键设计。失败回退同样固定（Table 6）：STT 回退全局视频描述，FRE/RFM 遇非法输入直接忽略，VDE 回退原查询。实现上 FRE/RFM 是 OpenCV/Pillow 的确定性图像算子，STT/VDE 调用 DashScope 托管的 VLM（型号未披露）——四个工具在训练中全部冻结，模型学的是"何时调用与如何使用返回结果"，不是工具本身。

**第二轮：Causal Bridging → 预测（§3.1 Stage 2；Appendix D Round 2，由策略模型决定）。** 把原始视频与工具返回的证据拼入上下文后，模型按四步输出结构化推理："last observed state → unfinished action → how the state evolves → most plausible next event and why"，最后给出 `<answer>`。论文把最终预测形式化为：

$$p(y|V\oplus V_{\text{aug}},Q\oplus E_{\text{aug}})=\pi_{\theta}(V\oplus V_{\text{aug}},Q\oplus E_{\text{aug}})$$

其中 $\oplus$ 表示模态特定拼接，$V_{\text{aug}}$、$E_{\text{aug}}$ 分别为工具返回的增强视觉与文本证据，$\pi_{\theta}$ 是 MLLM 策略网络（Eq. 1）。工具输出不是简单拼接：论文强调 STT 澄清动作序列、FRE 找回瞬时动作、RFM/VDE 解决细粒度歧义（如手是否已松开物体），它们分别服务于四步推理中"末端状态判断是否正确""动作是否真的未完成"这两个前提（§3.1 Stage 2）。

**训练了什么（§3.3–3.4，对应 §2 创新点 3 的训练侧）。** 训练只更新策略模型本身（Qwen3-VL-4B-Instruct，全参还是 LoRA 论文未说明）；工具与外部服务冻结。SFT 在 futurebench-4K 上训练 1 epoch、有效 batch 16、学习率 $5\times10^{-6}$：每个样本的推理过程与最终答案拼成完整助手回复，按标准自回归负对数似然整体优化：

$$\mathcal{L}_{\text{SFT}}=-\mathbb{E}_{\mathcal{W}\sim\mathcal{D}}\left[\sum_{t=1}^{L}\log p_{\theta}(\tilde{z}_{t}\mid\mathcal{X},\mathcal{Y},\tilde{z}_{<t})\right]$$

（Eq. 2）——推理 token 与 `<answer>` 一起学，模型由此获得两轮回复格式与"先桥接因果再作答"的行为模板。RL 用 GRPO 优化 250 步、学习率 $1\times10^{-6}$：对每个查询采 $G$ 条轨迹，组内奖励归一化得到优势 $A_{i}=(r_{i}-\mathrm{mean})/\mathrm{std}$，带 KL 约束（$\beta=0.04$）与裁剪（$\epsilon_{\text{low}}=0.2$，$\epsilon_{\text{high}}=0.3$）（Eq. 3–5）。

**奖励如何计算（§3.4、§A.2，对应 §2 创新点 3）。** 总奖励为

$$R(\tau)=R_{\text{format}}(\tau)\cdot(0.65R_{\text{acc}}(\tau)+0.20R_{\text{cau}}(\tau)+0.15R_{\text{ant}}(\tau))$$

（Eq. 7）。$R_{\text{format}}$ 是硬门控：轨迹必须严格含合法的 `<thinking>` 与 `<answer>` 标签才得 1，否则整条轨迹得 0，防止牺牲格式换分数。$R_{\text{acc}}$ 是二值准确率：预测与真值未来事件语义匹配为 1，否则 0。$R_{\text{cau}}$（因果间隙奖励）量化"推理是否真的桥接了未观测的中间转移，而不是直接猜未来"：用 MiniLM 句向量余弦相似度，把生成的末端状态描述 $s_{1}$ 与状态演化部分 $s_{34}$（第 3、4 步拼接）分别与参考末端状态 $r_{1}$、参考因果转移 $r_{4}$ 比对，加权得 $g_{\text{raw}}=(0.45\,\mathrm{sim}(s_{1},r_{1})+0.55\,\mathrm{sim}(s_{34},r_{4}))/(0.45+0.55)$（Eq. 8），再按预测对错分层：$R_{\text{cau}}=\min(1,0.20+0.80g_{\text{raw}})$（预测正确）或 $\min(0.35,0.20g_{\text{raw}})$（预测错误）——错误预测的过程分被封顶在 0.35，防止"论证精彩但猜错"拿到过多过程奖励（Eq. 9）。$R_{\text{ant}}$（反先验奖励）针对语言捷径：用句向量计算查询与各选项的文本相似度并排名，记正确选项的排名为 $k$，则 $R_{\text{ant}}=(k-1)/(K-1)$（仅当预测正确且 $K>1$，否则 0；Eq. 6）——"文本上最像答案"的样本得 0 分、"最不像"的得 1 分，是连续给分而非二值。

**推理阶段发生了什么。** 训练完成后不再更新参数；与零样本相比，每次预测增加"第一轮选择 + 工具执行 + 第二轮推理"的开销，工具调用平均 1.13 次（Table 4，G=4 模型）。哪些是固定流程：工具集合与执行次数（一次）、失败回退规则、`<answer>` 的字母输出格式、奖励计算公式全部固定；哪些由模型决定：选哪些工具、不确定性如何表述、四步推理怎么写。

**最终输出。** 候选选项中的未来事件（选项字母）。

**回到 §1 的三个失败模式，图 3（论文 Fig. 1）在同一个"抹黄油"样本上给出四联对照**：四个子图共用同一道含 A–E 选项的问题与同一段部分观测视频，区别只在推理方式。

![图 3：四种推理模式对比](/images/dailypaper/2026-10-08/2610.06293v1_fig1_key_insight.png)

**图 3**（论文 Fig. 1）：(a) 朴素 VLM 推理只做已见动作的粗糙延续，标为"弱因果推理"；(b) 选项驱动推理的 thinking 明显在比较文本相似度（"选项 B 最匹配下一步"），被标为"文本先验捷径"；(c) 无工具的因果间隙推理虽然写对了"仍在抹黄油、动作未完成"，但不掌握"还剩一片没抹"这一细粒度视觉状态，仍选错；(d) 增加工具后，模型先用 RegionFocusMagnifier 锁定待验证区域（图中以 FOI 框标注待检对象），再看 thinking："一片已抹、另一片仍未抹"，据此推对下一步。这张图是论文问题动机的主要视觉证据——它展示了三个失败模式分别长什么样、工具究竟补了哪一块证据；但本质上是一个精选示例，不是覆盖率统计。

**瓶颈与开销（§3 层面）。** 推理侧：每次预测至少两次生成（选择轮 + 推理轮），外加至多 4 个工具的一次执行；FRE 增加视觉帧数、STT/VDE 走外部 API。训练侧：SFT 1 epoch（约 4K 样本）、GRPO 250 步（约 5K 样本、每样本 8 条 rollout），硬件为 8×NVIDIA RTX A5000（24GB）。数据侧：每个基础训练样本 8 次 32B 教师模型 rollout + 强校验模型评审。论文未报告任何一项的墙钟时间、token 数或 API 费用（见 §4.4）。

**教学简化示例（非论文实验）。** 假设视频停在"手拿杯子悬在桌上"，四步模板的期望推理是：末端状态=杯子仍在手中且未接触桌面；未完成动作=放下杯子；状态演化=手下降、杯子将接触桌面；下一步=放下杯子。这个例子只用于说明模板各步的作用，不代表论文实验数据。

**组件归属（区分本文提出 vs 直接使用）。** 本文提出的：futurebench-4K 构造管线、四个工具及其执行/回退协议、两轮推理提示词模板、复合奖励（含因果间隙与反先验项）。直接使用的：Qwen3-VL-4B-Instruct（策略骨干）、Qwen3-VL-32B（数据生成者）、Qwen-VL-Max（数据校验者）、DashScope 托管 VLM（STT/VDE 后端）、MiniLM（文本相似度）、GRPO 算法、OpenCV/Pillow、FutureBench 与 NEPBench 基准及其评测协议。

## 4. 解决得怎么样？

#### 4.1 实验设置

- **任务与数据集**：FutureBench（Wang et al. 2026a），按推理深度报告 1-Hop、2-Hop、3-Hop、Interp.（插值）与总体 AVG 准确率；NEPBench（Lei et al. 2020），报告 Overall 及 Charades、VidSitu、YouCook2 三个子集（§4 "Dataset and Metrics"）。两者都是候选选项选择题，预测只有在"与真值未来事件语义匹配"时判对；匹配协议细节论文未展开。**两个基准的测试集规模论文均未报告。**
- **基础模型与训练配置**：Qwen3-VL-4B-Instruct；SFT 用约 4K 条 futurebench-4K 轨迹训练 1 epoch（有效 batch 16，lr $5\times10^{-6}$）；RL 用约 5K 条验证轨迹训练 250 步 GRPO（lr $1\times10^{-6}$，最终模型 $G=8$，$\beta=0.04$，clip 0.2/0.3）；组件消融统一 $G=4$；硬件 8×RTX A5000 24GB（§4 "Implementation Details"，§A.1）。SFT/RL 数据均只取自训练划分（§3.2）。

#### 4.3 机制证据

**只说明"方法有效"的部分。** Table 1/2 的总体提升只能说明整套流程（合成数据 + SFT + 工具增强 RL + 复合奖励）相对所引基线数字更好，不能拆分归因。

**进一步支持"为什么有效"的部分。** 消融链条相对完整：Table 3 (a)–(d) 隔离了训练阶段增量（SFT 贡献约 12.5pp，无工具 RL 约 +3.5pp，工具再 +3.7pp，均为 G=4 单次）；Table 3 (e)–(h) 隔离每个工具（STT 贡献最大）；Table 4 隔离"选择策略"——动态选择好于随机好于全量静态好于无工具，且动态调用次数最少，这一组对照是全文对机制最好的支持；Table 5 隔离时间/空间工具维度；Table 3 (i)–(l) 隔离奖励项。

**对 §2 创新点逐一核对。** 数据构造、工具与两轮流程、复合奖励三类创新中：数据构造只有 Table 3 (b) 的阶段证据、没有"普通 CoT 数据 vs 四步结构数据"的对照；工具与选择流程有逐工具移除（Table 3 (e)–(h)）与策略替换（Table 4、Table 5）对照；复合奖励只有单项加减（Table 3 (i)–(l)），因果间隙与反先验两项的"不可替代性"与行为机制均未被单独隔离。

**无法由现有证据排除的替代解释。**
1. **帧数与证据量混杂**：FRE 在窗口内加密抽帧、RFM 放大局部、STT/VDE 注入外部 VLM 文本，VepAgent 的有效输入信息量大于 32 帧基线；没有"等帧数/等 token 但不加工具"或"随机抽等量额外帧"的对照，工具增益中"针对性取证"与"单纯多给视觉 token"无法分离（Table 4 的随机工具对照部分缓解了选择策略问题，但没有对齐证据总量）。
2. **反先验奖励机制未获测量**：Eq. 6 的 $R_{\text{ant}}$ 只依赖样本静态属性——正确选项相对查询的文本相似度排名 $k$（§A.2），在 GRPO 组内所有正确轨迹取同一值（Eq. 5 的组内归一化下，它更接近"给文本不可猜的样本加权"，而非在轨迹层面惩罚捷径行为）。论文没有报告任何捷径诊断指标（如按正确选项文本排名分层的准确率、预测选项的文本相似度分布、baseline 捷径发生率），因此"anti-prior 奖励压制了语言先验"仍是未验证的机制主张；Table 3 (k) 的 +1.7pp 只是性能相关性。
3. **外部 VLM 的贡献未知**：STT/VDE 由 DashScope 托管 VLM（型号未披露）完成文本化，若该模型本身强于 4B 策略，部分增益可能来自"外挂更强模型"，而非策略学会了取证；没有"固定提示词 + 直接把工具证据给零样本 Qwen3-VL-4B"的对照。
4. **因果间隙奖励的语义相似度代理**：$R_{\text{cau}}$ 用 MiniLM 比对生成文本与 Qwen3-VL-32B 生成的参考答案（Eq. 8），奖励的是"与参考措辞语义接近"，论文未验证它确实奖励了因果桥接而非表述风格。

**结论**：论文的消融能较好支撑"工具与动态选择有贡献"；对"训练阶段的组织方式有效"有中等支撑；对"反先验/因果间隙奖励通过改变模型行为实现增益"仅有效果证据、没有机制证据。

#### 4.4 成本与适用范围

- **训练成本**：8×RTX A5000（24GB）×（SFT 1 epoch ≈4K 样本 + GRPO 250 步、每步组大小 8、数据池 ≈5K）。硬件规模不大，但**训练时长、GPU 时、token 数、FLOPs 均未报告**。
- **推理时延与调用**：两轮生成 + 至多 4 个工具单次执行；动态策略平均 1.13 次工具调用（Table 4，G=4 模型）。**延迟、token 数、工具失败/回退率未报告**。
- **外部依赖**：数据构造依赖 Qwen3-VL-32B 与 Qwen-VL-Max（闭源托管服务），推理依赖 DashScope 托管 VLM（型号与版本未披露），文本相似度依赖 MiniLM，图像算子依赖 OpenCV/Pillow——复现与成本评估都受闭源服务约束；**API 费用未报告**。
- **人工标注**：论文未报告人工标注或人工抽检；数据质量由 AI 校验器（Qwen-VL-Max）把关（§3.2，AI 使用声明）。
- **适用范围**：结论仅覆盖 FutureBench、NEPBench 两个封闭选项基准（§5 自述"Broader video understanding settings remain untested"）。改进最小处是 3-Hop（+4.0pp 相对最强基线）与 VidSitu 子集（+1.72pp）；开放性预测、多轮交互、真实部署闭环、跨域迁移（作者注明 NEPBench 为跨域场景但未量化域差）均未验证。失败率、错误分布与负迁移场景未报告。

## 5. 最容易受到审稿人质疑的地方

#### 质疑：基线与本文方法并非同一协议：基线数字照搬其他论文，而 VepAgent 额外获得工具证据、加密帧与外部 VLM 通道，"same evaluation protocols / 32-frame budget"的比较公平性无法成立

- **原文依据**：§4.1 明确写"against the MLLMs reported in that table"；Table 1 中所有方法 Frames=32，VepAgent 亦标 32；但 Appendix C.2 的 FRE 在时间窗内密集抽帧、C.3 的 RFM 放大局部、C "Implementation Backends" 的 STT/VDE 调用 DashScope VLM，均使 VepAgent 的视觉/外部模型输入超过基线的 32 帧纯端到端推理。
- **为什么重要**：全文核心主张（"significantly outperforming larger MLLMs"，+14.58/+22.70pp）建立在与这些数字的对比上；若协议、提示模板、视觉预算不一致，提升幅度无法归因于方法本身。
- **当前能够得出的判断**：可以确认 VepAgent 与所引基线的运行条件不同（工具、额外帧、外部模型证据），论文没有提供对齐实验或证明基线不能使用同样工具预算；同骨干对比（59.09→81.44、42.17→70.20）是内部一致的证据，但基线侧的 59.09/42.17 同样来自照搬数字。
- **如何验证或补强**：在同一评测脚本下复跑全部基线；报告每方法 token/帧/调用预算；增设"基线 + 同等工具证据"或"基线 + 等量随机帧"对照；公开判对协议（语义匹配的具体实现）。
- **严重程度**：主要问题

#### 质疑：反先验奖励的公式无法实现其声称的机制——它只依赖正确选项的文本可猜度排名 k（样本静态属性），组内不随轨迹行为变化，且论文没有报告任何捷径测量

- **原文依据**：Eq. 6 与 §A.2 的 $R_{\text{ant}}=(k-1)/(K-1)$，其中 $k$ 由 MiniLM 计算查询与选项的文本相似度排名得出，与模型行为无关；Eq. 5 的组内优势归一化使同一查询的所有正确轨迹取相同 $R_{\text{ant}}$；论文声称该奖励"penalizes language-shortcut behaviors"（§1 Contribution 2、§3.4），但全文未报告捷径发生率、按 $k$ 分层的准确率或推理文本的捷径模式统计。
- **为什么重要**：这是三大贡献之一；若该奖励实际只是"对文本不可猜样本加权"，则"反捷径"的机制解释不成立，创新点表述需要修正。
- **当前能够得出的判断**：实现与描述之间存在明确落差（可对照公式直接确认）；Table 3 (k) 的 +1.7pp 只提供效果相关性，不构成机制证据；即便有效，也无法区分它是在鼓励视觉接地还是在重新加权训练分布。
- **如何验证或补强**：报告 baseline 与各消融模型的"按正确选项文本排名分层的准确率"或"预测选项与查询的相似度分布"；设计轨迹级捷径惩罚（如惩罚推理文本抄选项）；提供 $R_{\text{ant}}$ 去掉后同预算对照的多次运行。
- **严重程度**：主要问题

#### 质疑：训练数据的教师蒸馏效应未被隔离，且教师/校验模型与基准同属 Qwen 系列，测试集泄漏风险未被讨论

- **原文依据**：§3.2 数据由 Qwen3-VL-32B 8 次 rollout 生成、Qwen-VL-Max 校验；§4.2 Table 3 (b) 显示仅 SFT 就把 AVG 从 59.09 提到 71.59；论文只声明"训练数据只取自训练划分"（§3.2），未讨论教师模型预训练语料可能覆盖基准测试视频（FutureBench/NEPBench 的测试素材多为公开视频数据集的二次组织），也未做"不用教师、由人工或弱模型产数据"的对照。
- **为什么重要**：若增益主要来自"用更强模型蒸馏数据"，则"tool-augmented RL + 因果结构"的贡献被高估；若存在测试集泄漏，主结果全部失效。
- **当前能够得出的判断**：无法确认泄漏是否发生（论文未报告任何泄漏检查），但结构与数据来源使该风险真实存在；教师蒸馏贡献未被单独界定这一混杂是当前材料可确认的。
- **如何验证或补强**：对训练/测试视频做近重复与来源重叠检查；增加"同等规模普通 CoT 蒸馏"与"无教师、仅人工 CoT"对照；报告未来基准测试集的构建时间与教师模型版本的先后关系。
- **严重程度**：主要问题

#### 质疑：全部结果为单次运行、无方差/置信区间/显著性检验，若干关键对比的差异处于噪声级，个别结论（如工具有效性、动态选择最优）可能被波动翻转

- **原文依据**：Table 1–5 无任何 std/CI/seed 信息；具体噪声级差异包括：移除 RFM 仅 -0.48pp（Table 3 (e)–(h)）、Intepolated VidSitu 上仅 +1.72pp（Table 2）、随机工具 3-Hop 反超动态选择（77.61 vs 76.12，Table 4）、Num=2 的 1-Hop 高于 Num=8（84.39 vs 82.08，Table 3 (m)(p)）、无工具 RL 的 3-Hop 低于 SFT-only（71.14 vs 75.62，Table 3 (b)(c)）。

## 6. 审稿式总评

作者发现 MLLM 在 VEP 上倾向于做"回溯式摘要"而非"向前因果外推"，并将其归纳为因果逻辑间隙、语言先验捷径与视觉证据缺失三类失败模式（§1，Fig. 1），因此提出 VepAgent：用 Qwen3-VL-32B 采样 + Qwen-VL-Max 校验构造四步因果转移 CoT 数据（futurebench-4K）做 SFT，再用带四个诊断工具（STT/FRE/RFM/VDE）与"格式门 × (准确率 + 因果间隙 + 反先验)"复合奖励的 GRPO 做两轮 agent 式训练与推理（§3，Fig. 2/3，Eq. 1–9）。实验在两个基准上报告了大幅提升（FutureBench AVG 81.44%、NEPBench Overall 70.20%），消融链条较完整地支持"工具、动态选择、复合奖励都有贡献"（Table 3–5）；其中证据较强的是"动态工具选择优于随机/静态/无工具"这组对照与同骨干对比的内部一致性；但基线数字照搬、工具带来超出 32 帧预算的额外证据与外部 VLM 通道、单次运行无统计检验，使"显著超越更大模型"的幅度归属不清；反先验奖励的公式与"压制捷径"的机制解释存在明确落差。本文最有价值的部分是一套可迁移的 agentic RL 配方（合成因果 CoT + 工具增强 GRPO + 复合奖励）与其在 VEP 上的工程化细节；最大的审稿风险是核心增益的协议公平性与蒸馏效应未隔离。

- **问题定义清晰度**：强——§1 三类失败模式与 §3.1 的形式化（$S_{\text{final}}$、$A_{\text{ongoing}}$、因果间隙）界定明确，任务输入输出与评测指标清晰；仅失败模式的量化诊断缺席，属于证据层而非定义层问题。
- **创新性证据**：中——四步因果结构、VEP 专用工具库、反先验奖励构成领域化组合，其中反先验公式与状态分解相对新；但无与最接近工具增强 RL 方法（VITAL 等）的同基准对比，"不可替代性"证据薄弱（§2）。
- **方法可信度**：中——流程、提示词、奖励公式与回退协议披露较全（Appendix C/D, Eq. 1–9），但外部 VLM 型号未披露、反先验机制与实现不符（§5 质疑 2），使机制层可信度打折。
- **实验支持力度**：中——两个基准、五组消融（Table 3–5）与三个案例（Fig. 4–6）覆盖了组件验证；但基线照搬未复跑、无方差/显著性、无失败分析（§4.2–4.4），大大限制结论强度。
- **可复现性**：中——超参与数据构造流程报告完整，但代码为不可验证的匿名链接、工具后端为未披露的闭源服务、futurebench-4K 未说明公开计划（§5 质疑 5）。
- **综合阅读价值**：中——对研究 agentic RL、工具增强视频推理的读者，这是一份结构完整、可借鉴配方细节（数据构造、工具协议、奖励设计）的工程化案例，但引用其结论时需带上"基线未复跑、机制未验证"的边界。
