## 0. 一句话结论

SGF+ 针对自回归视频扩散中"上下文写入"（context writing）与"去噪"（denoising）两个角色共享同一套参数、导致二者梯度系统性负对齐（平均夹角超过 90°，512/512 配对余弦为负）的问题，把两个角色拆成独立的参数集而仍通过因果注意力前向耦合，并在原始 DMD 目标下联合训练。在论文自己报告的 VBench 评测（5s/60s/240s，framewise 与 chunkwise 两种粒度）上，SGF+ 相对 SF 与 SGF 在多数质量与一致性指标上方向一致地小幅提升；但该提升没有参数量匹配的对照，相对最近基线 SGF 的幅度普遍只有 0.2–0.5 分（百分制），个别指标反而下降，因此"解耦梯度流带来提升"这一因果结论目前只是可支持的假设，而非已被排除替代解释的结论。

## 1. 论文具体想解决什么问题？

**研究背景与具体任务。** 自回归视频扩散模型（autoregressive video diffusion model）逐块（block）顺序生成视频：对第 $i$ 块，去噪器读取历史的 key-value（KV）缓存，把含噪 latent $z_i^t$ 映射为干净估计 $\tilde{x}_i$；随后一次"上下文写入"调用把该估计编码进供后续块使用的记忆，即 $\text{KV}_i = C_\theta(\tilde{x}_i, t_{\text{ctx}} \mid \text{KV}_{<i})$，$t_{\text{ctx}}=0$（Eq. 1）。同一套 DiT 参数 $\theta$ 承担了两个角色：**去噪**（生成当前内容）与**上下文写入**（把内容表示为未来可用的 KV）。任务目标是让这种顺序生成在远超训练时长的推理 horizon 上仍保持视觉质量与时间一致性。

**现有方法如何处理。** 论文用 Fig. 2 给出一条方法谱系：Teacher Forcing（教师强制）用真值历史训练，存在训练-测试历史不匹配；Self Forcing（SF）改用自生成 rollout 缓解暴露偏差（exposure bias），但为了可行性把历史 KV 缓存当作**冻结的 rollout 状态**，于是未来的生成损失只能监督"含噪目标 token 如何读取历史"，不能监督"更早生成的 latent 如何被写成有用的 K/V"——这一缺失的监督路径被称为历史上下文梯度鸿沟（historical context-gradient gap，该观察来自 SGF [52]，不是本文首创）；Self Gradient Forcing（SGF）用两趟（two-pass）训练修复它：第一趟做无梯度自 rollout，第二趟并行重建上下文表示与目标预测，采样 latent 保持 detached，但重建出的 KV 路径可微。

**现有方法在哪些条件下表现不好。** 作者报告 SGF 仍存在两个具体缺陷（§1）：长序列上有残余退化；在少数生成视频中**首帧**的视觉质量甚至低于 SF。由于首帧没有前置视频上下文，作者把它当作去噪质量的一个探针——这意味着共享参数下"去噪"这一侧本身被拖累了。

**作者发现了什么新现象。** 这是本文真正的观察（§3.2）：在 SGF 的第二趟计算内部按角色把 token 划分开，共享线性权重 $W$ 的梯度可分解为 $g_C = \Delta_C^{\top} H_C$（上下文写入贡献）与 $g_D = \Delta_D^{\top} H_D$（去噪贡献），且 $g_W = g_C + g_D$（Eq. 3）；用余弦相似度 $s(g_C,g_D) = \langle g_C,g_D\rangle /(\lVert g_C\rVert_2 \lVert g_D\rVert_2)$ 衡量方向对齐（Eq. 4）。在 128 条 prompt × 4 个去噪时间步上，作者发现：两类角色梯度在 Attention 与 FFN 中都呈现分离的分布；平均梯度方向的夹角为 **104.2°（Attention）与 106.3°（FFN）**，均超过 90°；**全部 512 对配对余弦相似度在两个模块家族中均为负**（Fig. 3）。由于 $g_W = g_C + g_D$，两个来源在共享权重上会部分抵消。更重要的是，这一冲突**在 Teacher Forcing 初始化阶段、尚未做 SGF 训练时就已存在**（Fig. 6 显示扩散时间步索引 0→1 出现梯度方向突变；Fig. 7 / Appendix C 给出 95.1° 与 105.1° 的平均夹角，绝大多数配对余弦为负）。

**支撑问题判断的证据。** 上述梯度统计（Fig. 3、Fig. 6、Fig. 7、Appendix C），加上 Appendix E 的逐层 t-SNE 与 silhouette 分数，以及 Table 1/Table 4 中长期生成时 SF 与 SGF 的可测退化。

**作者认为问题产生的原因。** §4.4 给出解释性讨论：标准自回归语言模型在一个前向里编码离散 token、写 KV、预测下一个 token，历史表示同样会收到未来损失的梯度；而自回归视频扩散在**干净上下文编码**（$t=0$）与**含噪 latent 去噪**（$t>0$）两种输入条件之间交替，输入条件与计算角色的差异"可能有助于解释"观察到的梯度差异。措辞是 "may help explain"——**论文观察到了现象，但没有充分验证这一因果解释**；尤其"梯度的方向冲突必然导致最终生成的次优"这一步没有被独立验证，只由 Appendix G 的局部一阶分析提供条件性支持。

**论文最终要验证的核心假设。** 在相同的自生成 rollout、相同的可微 KV 重建、相同的 DMD 生成目标下，仅为两个角色分配独立参数（不改任何其它组件）就能减少相互干扰，从而同时改善视觉质量与长时一致性，并带来"原生长 horizon 外推"（native long-horizon extrapolation，即在有限时序训练窗口内学到的持续生成能力）。

**三类问题的区分。**（i）领域早已存在的一般问题：暴露偏差、训练-测试历史不匹配、长视频退化——SF、LongLive、Self-Forcing++ 等已在处理。（ii）本文继承的观察：历史上下文的梯度路径缺失——属于 SGF [52] 的贡献，且 SGF 与本文作者高度重叠（SGF 的作者 Junhao Zhuang、Yaowei Li、Weiyang Jin、Songchun Zhang、Haoran Li、Haoyang Huang、Zeyue Xue、Nan Duan 均出现在本文作者列表中），本文是同一团队对自身方法谱系的直接续作。（iii）本文实际解决的具体子问题：在 SGF 的两趟框架内，阻止两个角色的更新在共享权重上相互抵消。

## 2. 创新点是什么？

**总括。** 真正的技术增量只有一句话：把 SGF 两趟训练管线中那**同一个 DiT** 拆成 上下文写入器（context writer）$C_{\theta_c}$ 与 去噪器（denoiser）$D_{\theta_d}$ 两套参数，二者从同一个预训练自回归扩散模型初始化，前向仍通过因果注意力的 KV 状态耦合，反向各自从同一个 $\mathcal{L}_{\text{DMD}}$ 目标接收梯度，不加任何辅助损失、不做梯度投影（§3.3，Eq. 5）。配套的是两项支撑性工作：把"两角色梯度冲突"显式测量出来的诊断证据（Fig. 3、Fig. 6、Fig. 7），以及 Appendix G 的局部优化分析。论文自身也承认这是"最简单、最直接"的做法（"the simplest and most direct way"）。

**创新点 A：梯度冲突的分解与测量（诊断性贡献）。**

- 新增了什么：在 SGF 的 Pass-2 计算内按角色分区 token，得到 $g_C$、$g_D$ 两个可比较的梯度量，并用余弦相似度（Eq. 4）与角距离 t-SNE 判据给出"冲突"的操作性定义（$s<0$，即夹角大于 90°）。
- 与最接近已有方法的差异：SGF [52] 只论证了"梯度路径缺失"，从未分析同一权重上两个来源的方向关系；SF 相关后续工作（Causal Forcing、Resampling Forcing、Rolling Forcing 等）关注的是历史构造与监督方式，也不涉及这一分解。
- 属于哪一类：**新的分析视角**，不是新机制。它本身不改变任何模型行为。
- 如何对应问题：它把"共享参数是否合理"从猜测变成可测量量，是 SGF+ 的唯一动机来源。
- 原文证据：Fig. 3（104.2°/106.3°，512/512 负余弦）、Fig. 6（TF 初始化下 0→1 的方向突变）、Fig. 7 / Appendix C（95.1°/105.1°）、Appendix E（逐层 silhouette）。
- 证据强度上的保留（审稿人判断）：Appendix E 报告的逐层 silhouette 分数只有 0.014–0.143（如 Block 0 为 0.035、Block 29 为 0.118、Block 28 最高 0.143），属于**弱聚类**；Block 29 在全部 512 对上上下文写入梯度为零，论文未解释原因。也就是说，"分离"是统计上可测的，但强度有限，且并非在所有层一致成立。

**创新点 B：角色专属参数化（核心机制贡献）。**

- 新增了什么：Pass-2 的重建公式从 SGF 的"同一 $\theta$"改为 $M_{\theta_c} = C_{\theta_c}(\mathrm{sg}(X), t_{\text{ctx}} \mid M_{\text{rec}})$、$\hat{X}_{\text{tar}} = D_{\theta_d}(Z^{\star}, t^{\star} \mid M_{\theta_c}, M_{\text{rec}})$、$L = \mathcal{L}_{\text{DMD}}(\hat{X}_{\text{tar}})$（Eq. 5）。未来生成目标经可微 KV 状态 $M_{\theta_c}$ 到达 $\theta_c$，经目标去噪到达 $\theta_d$。
- 与最接近已有方法（SGF）的具体差异：**只差"参数是否共享"这一项**。Pass-1 的无梯度 rollout、detached 的集合 $X$ 与 $Z^{\star}$、掩码 $M_{\text{rec}}$、更新调度全部沿用。
- 属于哪一类：**已有组件的新组合**。它由 SGF 的两趟管线 + "角色/任务专家参数分离"这一常见思路（论文引用 MoE 系列 [7,9,19,21] 与 model merging [18,39,41,45] 作为同族思路）组合而成。作者明确讨论并否定了把冲突解决寄托于"只在 FFN 放角色专家"的做法（§4.3），并说明**没有**引入任何新的损失、数据或训练阶段。因此按规范标准，这属于"解释清楚的组件组合 + 工程实现改进"，而不是新的研究范式。
- 如何对应问题：直接消除 $g_W = g_C + g_D$ 这一求和式。分离后两个角色的更新不再累加到同一批权重上。
- 原文证据：Table 1（60s/240s 两种粒度的对比）、Table 2（消融）、Table 3（成本）。
- 移除后变化：见下段消融。

**创新点 C：局部优化分析（Appendix G）。**

- 新增了什么：固定 rollout latent、采样退出时刻与 DMD 监督，得到代理目标 $F(\theta_c,\theta_d)$（Eq. 6），在其上比较"分离更新空间"与"绑定更新空间"的最大一阶下降。Proposition G.1 给出 $D_{\text{split}}(r) = r\sqrt{\lVert g_C\rVert^2+\lVert g_D\rVert^2}$ 与 $D_{\text{shared}}(r) = \frac{r}{\sqrt{2}}\lVert g_C+g_D\rVert$，平方差为 $\frac{r^2}{2}\lVert g_C-g_D\rVert^2$（Eq. 9–11）；$g_C=g_D$ 时两者相等。Eq. 13 定义 $\Gamma = \frac{1}{2} - \frac{\langle g_C,g_D\rangle}{E}\in[0,1]$ 作为"共享参数造成的下降受限程度"，与"负对齐"是两个不同的量（作者用 $g_C=(2,1)$、$g_D=(2,-1)$ 举例：余弦为 $3/5$ 但 $\Gamma=1/5>0$）。Corollary G.1 说明**精确抵消** $g_C=-g_D\neq0$ 时 $\theta$ 会是绑定目标的驻点，而分离参数下不是；Corollary G.2 与 Proposition G.2 分别给出共同预算与共同学习率下的有限步/单步优势。
- 属于哪一类：对既有优化直觉（"梯度冲突时拆参数更好"）的局部形式化，用于支撑"分离不小于共享"，但它不针对 SGF+ 的具体架构，也不预测收敛后的泛化差异。
- 局限（Appendix 自己承认）：minibatch 情形需要**聚合梯度**负对齐，而 Fig. 3 测的是 per-prompt 配对相似度，两者不等价（§G.5）；该预算"匹配参数位移，不匹配参数量或计算成本"（§G.1）；Corollary G.1 的驻点结论需要精确抵消这一强条件。

**创新点 D（附带观察，非机制）：冲突在 TF 初始化阶段就存在（§4.4，Fig. 6）。** 这一发现本身不改进 SGF+（因为 SGF+ 仍从 TF 权重初始化后做 SGF 风格训练），它是指向未来工作的证据——作者据此提出可以把角色参数化提前到 teacher forcing 阶段，并推广到 world action models（WAM）（Appendix H）。

**不属于创新的部分。** 基础模型（学生 Wan2.1-T2V-1.3B、教师 Wan2.1-T2V-14B、假分数网络同由 Wan2.1-T2V-1.3B 初始化）、DMD 目标、Causal Forcing 提供的 TF 初始化权重、VBench 评测协议与 MovieGen-128 prompt 集全部沿用；论文没有新数据集、新指标或更长训练；"24 小时生成"是同一模型执行更长的自回归 rollout，本身不构成新的训练方法。

**消融证据的正确读法。** Table 2 只分离 Attention（95.37/95.43/99.30/97.40/93.41/58.49/68.18）或只分离 FFN（97.43/96.48/98.33/98.27/65.37/63.49/70.41）都低于全分离（98.48/97.41/99.35/98.69/63.93/66.63/71.51）。但把 Table 2 与该表的严格对照（Table 1 的 60s chunkwise SGF：98.17/97.12/98.94/98.53/64.16/65.38/71.06）并排看会发现一个论文没有点破的事实：**两种部分分离甚至都不如完全不分离的 SGF**（Attention-only 的 Subject Consistency 95.37 比 SGF 的 98.17 低了 2.8 分）。若"冲突导致次优"是主因，那么在夹角最大（104.2°）的 Attention 上单独做分离不应出现如此显著的崩塌。这个非单调性提示"分离带来的收益"与"参数配置的整体平衡"纠缠在一起，论文没有给出解释。

## 3. 作者如何解决？

**直觉。** 把两个角色想象成同一条流水线上被同一个 KPI 打分的两个人：一个负责"把历史整理成后人好用的笔记"（在 $t=0$ 编码干净上下文），另一个负责"把当前这团噪声画清楚"（在 $t>0$ 去噪）。论文发现他们的偏好方向系统性相反（夹角超过 90°），而两人的手感共用同一份参数，于是每一步更新都会部分抵消（$g_W=g_C+g_D$）。SGF+ 的做法是给两人各一套参数，但要求他们必须实时交接（KV 通过因果注意力传给后续块），并且只用一个目标（生成质量）打分，不额外规定"笔记要长什么样"。这样既打断了抵消，又不引入新的监督信号。

![Figure 4：SGF 与 SGF+ 的训练管线。上方是 Pass 1：无梯度自 rollout，去噪器在 timestep>0 去噪、上下文写入器在 timestep=0 写 KV，滚动保存 detached 的干净 latent 集合 X 与退出步含噪 latent 集合 Z*。下方左侧是 Pass 2 的 SGF：X 与 Z* 进入同一份共享模型 θ，上下文与去噪的梯度累加到同一批权重上并相互冲突；右侧是 Pass 2 的 SGF+：上下文由 C(θc) 写、目标由 D(θd) 去噪，两条梯度路径分别落到各自参数上。图中"Differentiable KV"是关键的枢纽——只有它把未来的 DMD 监督送回上下文写入参数，而 X 与 Z* 本身始终 detached，从而避免对整个 rollout 反传。](/images/dailypaper/2026-10-08/2610.10429v1_fig4_training_pipeline.png)

**运行流程。**

1. **输入。** 文本 prompt（来自 VidProM [37] 的过滤与扩写版本），长度 5s 的训练窗口；学生模型是以 Wan2.1-T2V-1.3B 为基础的因果视频扩散模型，用 Causal Forcing [51] 释放的 Teacher Forcing 权重初始化；冻结的 Wan2.1-T2V-14B 教师与单独训练的假分数网络（fake-score network，从 Wan2.1-T2V-1.3B 初始化）提供 $\mathcal{L}_{\text{DMD}}$ 的分布匹配监督（§4.1）。

2. **Pass 1：无梯度自 rollout。** 模型执行普通的串行自回归 rollout，**不保留 autograd 图**。每个自回归步采样一个去噪退出时刻 $t^{\star}$，记录该步的含噪退出 latent $z^{\star}_i$ 与其干净估计 $\tilde{x}_i$；干净估计在 $t_{\text{ctx}}=0$ 被处理以更新后续块使用的串行 KV cache。产出集合 $Z^{\star}=\{z^{\star}_i\}_i$ 与 $X=\{\tilde{x}_i\}_i$，二者都与采样轨迹**脱离（detached）**（§3.1，Fig. 4 上方）。这一趟的作用是让训练看到"推理时真实会遇到的上下文"，但它不产生梯度。

3. **Pass 2：并行上下文梯度重建。** 在单个并行前向里重建"采样退出时刻"的计算，使用因果重建掩码 $M_{\text{rec}}$。$X$ 中的 latent 保持 stop-gradient 输入，但上下文隐状态与其 KV 投影被**重新以可追踪梯度的方式计算**：
   - SGF（对照）：$M_\theta = C_\theta(\mathrm{sg}(X), t_{\text{ctx}} \mid M_{\text{rec}})$，$\hat{X}_{\text{tar}} = D_\theta(Z^{\star}, t^{\star} \mid M_\theta, M_{\text{rec}})$，$L = \mathcal{L}_{\text{DMD}}(\hat{X}_{\text{tar}})$（Eq. 2）。
   - SGF+（本文）：$M_{\theta_c} = C_{\theta_c}(\mathrm{sg}(X), t_{\text{ctx}} \mid M_{\text{rec}})$，$\hat{X}_{\text{tar}} = D_{\theta_d}(Z^{\star}, t^{\star} \mid M_{\theta_c}, M_{\text{rec}})$，$L = \mathcal{L}_{\text{DMD}}(\hat{X}_{\text{tar}})$（Eq. 5）。
   于是未来生成损失同时监督两件事：含噪目标 token **如何读取**历史，以及干净上下文 token **如何写入**历史。采样 latent 与 cache 轨迹保持 detached，**只有 Pass-2 的重建是可微的**——这个边界既恢复了上下文写入的梯度路径，又不必对整个自回归 rollout 反传（§3.1）。

4. **哪些由模型决定、哪些由固定流程控制。** 由**模型**决定的是生成内容本身：去噪轨迹、退出时刻的采样、每个 prompt 下视频的样子。由**固定流程**控制的是两阶段的边界与工程细节：哪里 stop-gradient、掩码 $M_{\text{rec}}$ 的形状、上下文策略（sink + FIFO：framewise 用 4 个 sink latent + 16 个最近 latent + 1 个当前 latent = 窗口 21，chunkwise 用 3 + 6 + 3 = 窗口 12）、以及优化器设置（Appendix B）。
   优化超参（Appendix B）：AdamW，$\beta_1=0$、$\beta_2=0.999$；生成器学习率 $2\times10^{-6}$、critic 学习率 $4\times10^{-7}$；每 5 次 critic 更新做 1 次生成器更新；生成用 4 步去噪。

5. **训练哪些部分。** 生成器的**全部参数被复制成两份**，分别作为 $C_{\theta_c}$ 与 $D_{\theta_d}$，两份都从同一份 TF 权重初始化，并通过同一个 $\mathcal{L}_{\text{DMD}}$ 端到端联合训练；教师与假分数网络冻结。论文说明 SGF+ 可以用两个 LoRA 适配器或两个完整参数集实现，**本文使用后者**（§4.1），因此生成器参数量从 1.4B 翻倍到 2.8B。除此之外没有新的可训练模块，没有辅助损失，没有梯度投影，也没有模型合并（§3.3 把 model merging 留给未来工作）。

6. **推理阶段发生了什么变化。** 调用时序完全不变（每块仍是一次去噪调用 + 一次写 KV 调用），只是每次调用只使用属于自己角色的那份参数；由于每个 token 在一次前向里只走自己角色的参数，作者论证**计算量不翻倍**（§4.4）。实测（Table 3）：81 帧推理时间 4.969s versus SGF 4.962s，几乎不变；推理显存从 24.85 GB 上升到 27.96 GB。

7. **最终输出。** 可流式、可交互的自回归长视频。训练只用 5s rollout（60s 与 240s 评测相当于训练窗口的 12 倍与 48 倍），论文展示最长 24 小时的连续生成（Fig. 1、Fig. 8、Appendix D）。

**瓶颈与额外开销。** 训练侧：峰值显存 97.83 → 98.15 GB，稳定显存 70.06 → 73.60 GB，每步时间 11.79 → 12.76 s（约 +8.2%）（Table 3，对照 SGF）；作为参照，SF 为 86.36/86.19 GB、10.02 s/step。推理侧：显存 +3.11 GB，时延基本持平。主要代价是**参数存储翻倍**，其次是训练显存与每步时间的小幅上升。

## 4. 解决得怎么样？

#### 4.1 实验设置

- **任务与数据。** 文本到长视频生成，分 framewise（逐帧）与 chunkwise（按块）两种生成粒度。训练统一在 **5s 视频窗口**上，prompt 来自 VidProM [37] 的过滤与扩写集合。评测三档：5s 用标准 VBench [16]（Appendix A）；60s 用 VBench-Long prompts [17]；240s 用 128 条 MovieGen prompts [28]（§4.1，Table 1）。60s 与 240s 因此是训练窗口的 12 倍与 48 倍，用来测"原生外推"。
- **基础模型与系统配置。** 学生为基于 Wan2.1-T2V-1.3B [35] 的因果视频扩散模型；教师为冻结的 Wan2.1-T2V-14B；假分数网络单独训练、由 Wan2.1-T2V-1.3B 初始化；TF 初始化权重来自 Causal Forcing [51]。上下文策略为 sink + FIFO（Appendix B）。
- **基线。** 只有两个：Self Forcing（SF，[15]）与 Self Gradient Forcing（SGF，[52]）。SGF 与本文作者高度重叠，因此这是"同一谱系内的前两代"；§2.1 与 §2.3 讨论过的其它长视频方法（Rolling Forcing、LongLive、Self-Forcing++、Causal Forcing++、FreqForcing、MemRoPE）**没有进入定量对比**。
- **指标。** VBench 七项 ×100（Subject Consistency、Background Consistency、Temporal Flickering、Motion Smoothness、Dynamic Degree、Aesthetic Quality、Imaging Quality），越高越好；Appendix A 另给 8 项任务级分数（Object、Multiple、Action、Color、Spatial、Scene、Appearance、Temporal）。
- **预算公平性。** Table 1 caption 明确：每种设置下所有方法共享同一初始化、同一 prompt 集与同一随机种子。但论文**未报告**各方法的训练步数是否相同、总计算量是否相同；SGF+ 的生成器参数量是 1.4B→2.8B（Table 3），**没有参数量匹配的共享参数对照**。
- **各实验回答什么。** 主实验（Table 1、Fig. 5）回答"长 horizon 外推是否更好"；消融（Table 2）回答"分离哪些模块重要"；附录 A（Table 4）回答"在训练窗口内（5s）是否也不退化"；附录 G 回答"为什么分离在局部一阶意义下更优"；Appendix C/E 回答"冲突的统计结构如何"；Appendix D/F 提供 24 小时与更多场景的定性证据。

- **消融的非单调性未被讨论。** Table 2（60s chunkwise）中 Attention-only 95.37/95.43/99.30/97.40/93.41/58.49/68.18 与 FFN-only 97.43/96.48/98.33/98.27/65.37/63.49/70.41 都低于全分离 98.48/97.41/99.35/98.69/63.93/66.63/71.51；与 Table 1 的 SGF 行（98.17/97.12/98.94/98.53/64.16/65.38/71.06）相比，**两种部分分离甚至低于完全不分离**。尤其 Attention-only 的 Subject Consistency 比 SGF 低 2.8 分，而 Attention 恰是夹角最大（104.2°）的模块家族。论文只写"两个部分分离变体都弱于全模型"，未解释这一非单调性。

#### 4.3 机制证据

**"方法有效"的证据是充分的。** Table 1 与 Table 4 在 5s/60s/240s、两种生成粒度上给出了方向一致的提升；Table 2 说明全体分离优于部分分离；Fig. 1 与 Fig. 5 给出定性对照（金矿小镇、盐漠、仓库花朵三个场景中 SF 的背景扭曲、SGF 的绿色条状伪影与花朵形变）；Fig. 8 给出 24 小时的四例连续生成。

**"为什么有效"的证据要弱一层，必须与上一段分开评价。**

- 论文提供的机制证据是 **Appendix G 的局部一阶分析**。它证明的是：在固定 rollout 的代理目标 $F$ 上，分离更新空间能取得的最大一阶下降不小于绑定空间，且平方差恰为 $\frac{r^2}{2}\lVert g_C-g_D\rVert^2$（Eq. 11）；$\Gamma$（Eq. 13）量化"共享参数排除了多少梯度分量"。这是一个**几何事实 + 条件性优势**（Corollary G.1 需要 $g_C=-g_D$ 的精确抵消；Prop. G.2 需要负对齐与足够小的步长），它不描述训练动力学，也不预测收敛后的泛化与长时外推。
- **冲突测量与优化现实之间存在缺口。** Fig. 3 测的是 per-prompt 的配对余弦，而实际更新使用 minibatch 聚合梯度；Appendix G.5 自己写明"the proposition requires negative alignment of the aggregated gradients. Negative alignment of individual samples or selected modules does not establish this condition for the full gradient"。论文最关键的动机数字（512/512 全负）因此不能被直接转译为"聚合梯度负对齐"。
- **逐层统计只支持"弱分离"。** Appendix E 的 silhouette 分数范围 0.014–0.143；Block 29 在全部 512 对上上下文写入梯度为零（作者因此未给出该块的 t-SNE），论文未解释这一现象。这说明冲突并非在所有层同样强烈。
- **替代解释没有被排除。** Table 3 可以排除"SGF+ 靠更省/更快的工程优势取胜"（它更贵），但**不能排除"参数容量翻倍本身带来收益"**：没有 2.8B 共享参数基线，也没有把 SGF+ 做成 LoRA（参数量接近 SGF）的对照。论文 §4.1 提到两种实现方式存在，并选择了两套完整参数集，却未做二者的对比。
- **结论。** 目前证据链的形状是"诊断（相关性）→ 设计（对应该相关性）→ 性能提升"，缺少把中间机制单独隔离出来的对照实验。性能提升不能自动当作"梯度冲突被消除因而更好"的证明。

#### 4.4 成本与适用范围

**论文实际报告的成本：**

- **训练成本。** 生成器参数 1.4B → 2.8B（翻倍）；训练峰值显存 97.83 → 98.15 GB；稳定显存 70.06 → 73.60 GB；每步时间 11.79 → 12.76 s，约 +8.2%（Table 3，对照 SGF；SF 为 86.36/86.19 GB、10.02 s/step）。**训练总步数、总 GPU 小时、数据吞吐论文未报告。**

- **Token / 调用次数 / 工具调用。** 不适用（视频扩散，无 agent 工具调用）；推理调用调度与 SGF 完全一致（§4.4）。

- **外部依赖。** Wan2.1-T2V-1.3B 与 Wan2.1-T2V-14B 权重、Causal Forcing [51] 释放的 TF 初始化权重、单独训练的假分数网络、VidProM 的过滤与扩写 prompt 流程、VBench/VBench-Long 评测协议。这些都不是本文贡献，但复现链条依赖它们。

## 5. 最容易受到审稿人质疑的地方

#### 质疑：SGF+ 的生成器参数从 1.4B 翻倍到 2.8B，却没有参数量匹配的对照，"收益来自角色分离而非更大容量"这一核心因果归因未被建立。

- **原文依据**：§4.1 说明 SGF+ 可用两个 LoRA 或两个完整参数集实现，"In this work, we use the latter"；Table 3 显示生成器参数 1.4B → 2.8B；Table 2 的消融只覆盖"分离哪些模块"（Attention only / FFN only / full），没有任何"参数量翻倍但参数仍共享"或"参数量接近 SGF 的分离"的对照。
- **为什么重要**：论文的核心主张是"角色专属参数化"这一**机制**有效。在扩散模型上单纯增加参数容量通常就会提升 VBench 类指标。缺少等参数对照时，观察到的提升无法在"解耦"与"容量"之间分配。这一缺口直接决定论文的贡献是"一个机制"还是"一个更贵的模型"。
- **当前能够得出的判断**：存在未排除的混杂因素。Appendix G 的理论只说明"分离空间的可行下降不小于共享空间"，这是优化几何性质，不能替代经验对照；Table 3 反而证明 SGF+ 更慢更占显存，说明收益并非来自效率。
- **如何验证或补强**：把 SGF 的骨干扩到约 2.8B（加宽 hidden 或增加层）作为等参数共享基线；或训练 SGF+ 的 LoRA 版本（参数量与 SGF 接近）并比较；或对 $\theta_c$ 与 $\theta_d$ 施加权重平均/部分共享并观察退化速度。
- **严重程度**：主要问题

#### 质疑：相对最近基线 SGF 的提升幅度普遍只有 0.2–0.5 分（百分制）且无方差或显著性检验，个别指标还出现下降。

- **原文依据**：Table 1（60s framewise Imaging Quality：SGF 71.52 vs SGF+ 71.11；240s framewise Imaging 70.89 vs 70.90）、Table 4（5s framewise Imaging：SGF 71.41 vs SGF+ 70.88）、Appendix A 任务级（5s framewise Action：SGF+ 94.40 < SF 95.80；Color：SGF+ 87.12 < SGF 87.87）；Table 1 caption 说明每种设置仅用一个随机种子，全文未给方差、置信区间或显著性检验。
- **为什么重要**：如果与最接近的方法只差零点几分且没有不确定性估计，"有效"的论证就完全依赖"提升方向在多数指标上一致"这一较弱形式。审稿人无法判断这些差距是否超出种子噪声，尤其在有明确反例（两处 Imaging Quality）的情况下。这直接影响实验支持力度与结论措辞的强度。
- **当前能够得出的判断**：证据显示提升方向大体一致（240s framewise 的 Subject/Background/Flickering 差距最大且方向稳定），但幅度与稳健性证据不足；论文对反超失败与落后项没有任何讨论。
- **如何验证或补强**：多种子（≥3）重复训练与评测，报告均值±标准差或配对检验；明确列出 SGF+ 不占优的指标与幅度；若单种子是既有限制，应在正文而非仅 caption 中说明。
- **严重程度**：主要问题

#### 质疑："梯度冲突 ⇒ 共享参数次优"这条因果链没有被独立验证：冲突测量是 per-prompt 配对余弦，理论分析是固定 rollout 的局部一阶代理，两者都到不了"训练动态"这一层。

- **原文依据**：§3.2 与 Fig. 3(c) 在 128 prompts × 4 个去噪时间步上计算同一 prompt 内两个角色的配对余弦，512 对全负；Appendix G.5 明确写出 "the proposition requires negative alignment of the aggregated gradients. Negative alignment of individual samples or selected modules does not establish this condition for the full gradient"；§G.1 说明代理目标固定了 detached rollout、退出时刻与前向随机性，且其预算 "does not match parameter count or computational cost"；Corollary G.1 的驻点分离需要 $g_C=-g_D$ 的精确抵消；Appendix E 的 silhouette 分数仅 0.014–0.143，Block 29 在 512 对上上下文梯度为零。
- **为什么重要**：论文的第一条贡献就是"识别出冲突的梯度"，整篇论文的叙事建立在这一诊断之上。若聚合梯度并不负对齐（各 prompt 方向互异导致聚合后相互抵消），或分离度本就微弱（silhouette 接近 0），那么"SGF+ 的收益来自消除冲突"的解释就缺少支撑，剩下的是"分离参数恰好在这个设置下更好"的经验事实。
- **当前能够得出的判断**：论文对局限是自知的（在附录中主动写明 per-sample 与聚合的差别），但正文的动机表述强于附录证据；逐层统计还提示冲突并非处处成立（Block 29）。此外，没有与梯度手术类基线（如 PCGrad 式投影）的对照，无法判断"分离参数"是否是消除冲突的**唯一或最优**实现。
- **如何验证或补强**：报告 minibatch 聚合梯度层面的夹角/余弦随训练步数与 batch size 的变化曲线；报告 silhouette 的均值与置信区间并解释弱分离层的含义；增加梯度投影/PCGrad 对照实验；补充训练过程中的实测指标（$g_W$ 与 $\lVert g_C\rVert+\lVert g_D\rVert$ 的比值）以证明冲突确实在训练中被缓解。
- **严重程度**：主要问题

#### 质疑：定量对比只包含同谱系的前两代方法（SF、SGF），§2.2 与 §2.3 讨论的同期长视频方法没有进入同一设置的比较，削弱了"更好的长时一致性"这一对外主张。

- **原文依据**：§4.1 与 Table 1 的对比对象只有 SF 与 SGF；§2.2 列出 Causal Forcing、Causal Forcing++、Resampling Forcing、Rolling Forcing、Data-Forcing Distillation、One-Forcing、Reward Forcing、DuoMatching、Video-Mirai、Next Forcing，§2.3 列出 LongLive、Self-Forcing++、FreqForcing、MemRoPE，均未参与 Table 1；SGF [52] 与本文共享至少 8 位作者。
- **为什么重要**：论文摘要写的是 "improves visual quality and long-horizon consistency over the evaluated baselines"，措辞尚准确；但 24 小时外推与"native long-horizon extrapolation"的定位必然会被拿去与 LongLive、Self-Forcing++ 等专攻长视频的方法比较。同时，把最接近的基线选为同团队的前作，虽然合理（它是唯一共享全部训练设定的方法），也使对比缺少外部独立性验证。
- **当前能够得出的判断**：在"隔离角色参数共享这一设计维度"的意义上，锁定同一骨干、同一初始化的 SF/SGF 对比是正确的实验设计；但论文的结论边界应被明确限制在这三个方法之间，目前正文在强调"24 小时外推"时并未给出这一限制。
- **如何验证或补强**：在同一骨干与同一 5s 训练预算下复现至少一个外部长视频方法（如 Self-Forcing++ 或一个 training-free 的 FreqForcing/MemRoPE 组合）作为额外基线；若不可行，则在正文明确声明比较范围与原因。
- **严重程度**：次要问题

#### 质疑："24 小时原生外推"只有单方法定性样例，Dynamic Degree 的系统性劣势只有事后归因。

- **原文依据**：Fig. 1 底栏与 Fig. 8（Appendix D）展示 4 例 24 小时生成，均为定性图，且只有 SGF+ 一列；所有定量评测最长到 240s（Table 1）；论文未报告 24 小时下的任何指标、失败率或用例筛选方式。§4.2 用"场景跳变、物体形变、主体消失、多出人物"解释 SGF+ 的 Dynamic Degree 偏低，但没有配套的伪影检测或人工评估；Table 3 的效率数据只覆盖 81 帧推理。
- **为什么重要**：24 小时是本论文最醒目的标题级主张，若只有选择性定性样例，读者无法判断长时退化的速率、失败模式与是否需要人工干预。Dynamic Degree 又是唯一被显式承认的劣势维度，只给归因不给度量使该解释无法被证伪；如果实际原因是 SGF+ 生成的动作更少，那么"视觉质量更好"的结论就需要重新权衡（VBench 静态质量与动态性存在张力）。
- **当前能够得出的判断**：在此材料下 24 小时外推无法验证，属于存在性演示而非可比较证据；Dynamic Degree 的解释合理但未被验证。
- **如何验证或补强**：在 24h（或至少 10/30 分钟）上给出按时间采样分桶的 VBench 类统计与失败率，并报告显存/吞吐随生成时长的变化；补充人工偏好或伪影检测来验证 Dynamic Degree 的解释；说明 Fig. 8 的四例是随机抽取还是优选。
- **严重程度**：次要问题

## 6. 审稿式总评

作者发现，在 SGF 的两趟训练框架内，同一个 DiT 承担"上下文写入"与"去噪"两个角色时，二者在共享权重上的梯度贡献呈系统性负对齐（Attention 平均夹角 104.2°、FFN 106.3°，512/512 配对余弦为负，且这一现象在 Teacher Forcing 初始化阶段即已出现），因此提出 SGF+：把两个角色拆成独立的参数集 $C_{\theta_c}$ 与 $D_{\theta_d}$，保留 SGF 的无梯度 rollout 与可微 KV 重建，让同一个 $\mathcal{L}_{\text{DMD}}$ 经可微 KV 状态监督写入、经目标去噪监督生成，不加辅助损失、不用新数据、不延长训练。实验以 Wan2.1-T2V-1.3B 学生 + Causal Forcing 初始化为统一设置，在 VBench 的 5s/60s/240s 与 framewise/chunkwise 两种粒度上表明 SGF+ 在多数质量与一致性指标上优于 SF 与 SGF，训练仅用 5s 窗口；其中"梯度冲突确实存在、且在两个模块家族与两个训练阶段稳定出现"这一证据相对较强，Table 3 也清楚地披露了代价（参数翻倍、每步 +8.2%、推理显存 +3.1 GB）。但"参数分离是性能提升的原因"仍缺少充分支持：没有参数量匹配的对照，相对 SGF 的增益普遍只有 0.2–0.5 分且无方差或显著性检验，部分指标（framewise Imaging Quality、5s framewise Action）还低于基线，消融呈现论文未解释的非单调性（部分分离甚至不如不分离），冲突是在 per-prompt 层面而非聚合梯度层面被测得的，24 小时外推只有单方法定性样例。本文最有价值的部分是提出并验证了一个**简单、推理开销几乎为零、且与上下文管理类方法正交**的设计维度——"角色专属参数化"，并用 Appendix G 给出配套的局部优化刻画；最大的审稿风险是把 2× 参数容量带来的收益误归因于梯度解耦。

- **问题定义清晰度**：强。两个角色的划分、方法谱系（Fig. 2）与研究问题的边界都很清楚，而且作者明确说明 SGF+ 作用的是"参数共享"这一与历史构造不同的设计维度（§1、§2.3）。
- **创新性证据**：中。梯度冲突的诊断证据（Fig. 3、Fig. 6、Fig. 7）是新的、可复核的；但机制本身是"已有两趟管线 + 参数拆分"的组合，作者自述为"最简单最直接"的做法，且最接近的前作来自同一团队，外部独立性验证有限（§2、§3.3）。
- **方法可信度**：中。两趟训练流程、梯度路径、超参与上下文策略都写得足够具体（§3.1、§3.3、Appendix B）；但"每 token 只用自己角色的参数因而计算不翻倍"这一关键论证只给出 81 帧单点数据，且缺少参数量匹配对照来隔离机制（§4.4、Table 3、§5 质疑一）。
- **实验支持力度**：中。覆盖 5s/60s/240s、两种粒度、部分分离消融、逐层统计与效率测量，广度达标；但无方差/显著性检验、SGF+ 在若干指标上不占优未加讨论、Dynamic Degree 劣势只有定性归因、24 小时主张只有定性样例（Table 1–4、§4.2、Fig. 8）。
- **可复现性**：中。论文正文只给项目主页，该主页指向 Apache-2.0 的代码仓库（含 train.py、inference.py、trainer、model、gradient_conflict）与 Hugging Face 模型页，核查时均可访问；但复现链条依赖 Causal Forcing 权重、Wan2.1-T2V-1.3B/14B 与假分数网络，且论文未报告训练步数、总计算量与种子细节。
- **综合阅读价值**：中。"角色专属参数化"是一个廉价、可迁移、与上下文管理正交的设计直觉，Appendix G 的局部分析也提供了有用的形式化视角；但由于增益幅度小、机制归因未被隔离、24 小时主张缺乏定量支撑，本文更适合作为"设计原则与诊断工具"来阅读引用，而不是把其性能结论当作已确立的结论。
