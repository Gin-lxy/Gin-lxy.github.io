## 1. 作者发现了什么问题？

### 1.1 背景与任务

World Action Model（WAM，世界动作模型）是近年通用机器人操作的一条新路线：不再只学"看到什么→做什么"（VLA 范式），而是**同时建模视觉世界如何演变与机器人动作如何生成**（§1、§2.1）。其动机很直接：互联网规模的视频预训练里包含了大量"场景会怎样随时间变化"的视觉与时间知识，理应能帮到控制。

本文的任务是：在**不牺牲推理速度**的前提下，把大规模视频预训练、场景语义理解、几何与运动先验这几类互补知识整合进一个统一的动作生成框架，并给出从数据到部署的完整配方。

### 1.2 已有方法的问题：预测能力≠控制能力

论文明确指出的核心矛盾是（§1 第 1 段）：**"能预测未来观测"并不直接等价于"会控制"**。要生成动作，模型还必须能（a）识别与任务相关的场景变化，（b）理解物体几何与运动，（c）把线索锚定到当前指令和场景上。已有 WAM 的关键设计分歧在于：**动作推理是否需要先生成未来视频**——DreamZero、Motus、LingBot-VA 2.0 等把视频生成视为动作推理路径的一部分，代价是推理时要跑视频采样；Fast-WAM（Yuan et al., 2026b）则把"未来视频监督"与"动作推理路径"分离，说明视频预测可以只在训练期起作用。InternW0-Δ 选择了后一条路线并把它做完整。

作者在建模层面给出了几个**具体、可验证的观察**（这些是本文自己的观察，区别于"已有方法不好用"这类笼统说法）：

1. **T5 语言条件只看懂"话"，看不懂"场景"**（§3.2）：视频专家沿用 Wan2.2 的 T5 文本通路，但 T5 只编码指令的语义内容，"同一条指令在不同视觉状态下可能对应不同动作"，它无法回答现在有哪些物体、它们在哪、任务进行到哪一步。
2. **密集观测历史是浪费**（§3.3）：短期内相近的历史对运动/交互连续性最有用，远期历史只是粗略的全局参考，因此保留完整历史帧属于不必要的计算开销。
3. **未来信息应该只当"监督信号"，不能当"输入"**（§3.4、§3.6）：如果把已实现的未来帧直接喂给动作预测分支，就泄露了推理时拿不到的信息；更好的做法是让模型从**当前可获得的观测**中学出面向未来的变化表示。
4. **异构数据的维度语义不一致**（§4.1）：不同机器人数据集的关节、夹爪、手部、底盘维度含义各不相同，直接把原生向量混在一起"会让同一维度在不同样本里具有不一致的物理含义"，阻碍跨本体学习。

### 1.3 证据

这些判断在消融实验里都有对应的量化证据（详见 §3）：单一当前观测不够用（LIBERO-Plus 上 baseline 49.59% → 加 Sparse Memory Context 53.47%）；只靠 T5 语义不足（加 Qwen3.5-2B → 60.37%，换成 RynnBrain1.1-2B → 69.08%，见 §7.4.1 与表 14）；而把未来监督完全挡在推理路径之外的前提下，Causal Imprint 相关目标累计带来约 +7.4 个百分点（69.08% → 76.45%，其中对齐项 $\mathcal{L}_{\text{align}}$ 单独贡献 5.65 点）。

需要区分的是：论文**没有**给出"其他 WAM 失败原因"的因果分析，它给出的是一组设计选择及其消融证据；"为什么已有方法会出现这个问题"在本文里止于"未来生成与动作推理耦合会带来在线开销"这一动机层面，更深层的原因作者没有展开，报告也不替作者补充。

## 2. 作者如何解决？

### 2.1 核心思路（一句话版）

**用一个"有向"的 Mixture-of-Transformers 把视频专家（负责预测性动态）和动作专家（负责动作生成）拼在一起：未来信息只作为训练监督进入视频专家，通过 Causal Imprint 与 4D 蒸馏把"面向未来"的表示压进只依赖当前观测的 token 里，再让动作专家读取这些 token；推理时不做任何未来视频采样。**

这句话对应了前面三组问题：场景语义不足→加一个冻结 VLM 提供场景级 token；未来信息不能泄露→用注意力掩码切断"未来帧→动作"的任何前向通路，改用 Causal Imprint 表示来承载预测信息；异构数据难混训→统一 80 维 canonical 状态-动作表示 + 大规模清洗与 Ego2Robot 转换。

### 2.2 整体架构与输入输出

![InternW0-Δ 总体架构：冻结 VAE 编码稀疏视觉记忆，视频专家与动作专家通过 30 层有向 MoT 耦合，Causal Imprint 提供面向变化表示的通道](/images/dailypaper/2026-09-28/2609.31394_fig1.png)

*原文图 1（Architecture overview，§3.1）。该图说明 A/R/C 三帧观测经 Wan VAE 编码后进入视频专家，T5 指令条件进视频流、冻结 VLM 的场景语义进动作流，Causal Imprint 与 noisy action token 各自成组，输出端同时给出预测的 Causal Imprint、未来世界（仅训练监督）与 action chunk。*

- **输入**：时刻 $\tau$ 的最多 $K$ 路相机图像 $o_\tau^{(k)}$（按本体相关的组合算子 $\Pi$ 拼进统一画布，式 (1)）、当前本体状态 $s_t$（统一表示，见下）、语言指令 $\ell$、以及稀疏视觉记忆。预训练时图像画布为 $384\times256$。
- **表示与编码**（§3.2）：冻结的 Wan VAE 编码得视觉潜变量 $z_\tau=E_{\mathrm{VAE}}(x_\tau)$（式 (2)）；本体状态用**两个独立的单层线性投影**分别进入视频专家与动作专家 $e_t^v=E_s^v(s_t)，e_t^a=E_s^a(s_t)$（式 (3)）；动作块 $A_t\in\mathbb{R}^{H_a\times D_a}$，$H_a=32$、$D_a=80$，另有有效性掩码 $M_A$（式 (4)，无效维度不参与损失）。
- **两条语言/语义通路**（式 (6)–(8)）：视频侧条件 $C_t^v=[E_{\mathrm{T5}}(\ell);e_t^v]$ 保留 Wan2.2 预训练学到的语言-视频接口；动作侧条件 $C_t^a=[H_t^{\mathrm{VLM}};e_t^a]$，其中 $H_t^{\mathrm{VLM}}$ 由**冻结**的 RynnBrain1.1-2B VLM 联合处理"所有有效当前视图 + 视角身份 + 指令"得到（式 (7)）。
- **稀疏视觉记忆**（式 (9)）：$\mathcal{X}_t=\{x_a,\,x_{t-H_c},\,x_t\}$，即 episode 起始 anchor（A）、上一动作块之前的 recent（R）、当前帧（C）三个观测。**推理时不做未来 rollout，蒸馏分支也不加载**，最终一步到位输出 32 步动作块。

### 2.3 关键设计一：Causal Imprint——用未来监督"刻"出可用的预测表示

这是全文最有辨识度的机制（§3.4、§3.7，图 4）。做法是：向视频专家的自注意力层注入一组可学习的 **Causal Imprint token**，其空间布局与当前视频潜变量一致，只聚合 recent 与 current 的视觉特征，用来刻画运动、交互与状态转移（即"外观之外"的变化信息）。

训练时（未来视频 latent 加噪之前）构造"相邻潜变量差分"作为显式目标（式 (10)）：

$$\Delta z_{t,i}=z_{t+i\rho_v}-z_{t+(i-1)\rho_v},\qquad i=1,\dots,T_v,\quad z_{t+0\rho_v}=z_t$$

并配两个互补损失：

$$\mathcal{L}_{\Delta}=\left\|h_t^{\Delta}-\Delta Z_t\right\|_2^2$$

（原文式 (15)）

$$\mathcal{L}_{\mathrm{align}}=1-\cos\!\left(h_{b,p}^{\Delta,\ell_s},\ \mathrm{sg}\!\left[h_{b,p}^{F,\ell_t}\right]\right),\qquad \ell_s=8,\ \ell_t=20$$

（原文式 (16)）

其中 $\mathrm{sg}[\cdot]$ 为 stop-gradient。式 (15) 让最终层 Imprint 表示直接回归"干净未来 latent 的逐段变化"；式 (16) 把第 8 层的 Imprint token 与**未来末帧在第 20 层的视频专家特征**做空间对应的余弦对齐，相当于让 Imprint 承接视频扩散 Transformer 中间层已经学到的语义/时间表征。**教学化的直觉**：可以把 Imprint token 想成一排"变化探测器"——训练时被反复追问"接下来哪里会动、怎么动"，但它在推理时只能看 A/R/C 三帧，因此必须把"未来会怎样"内化成一种**只依赖当前观测的表示**，动作专家再直接读这排 token。

### 2.4 关键设计二：有向 MoT 与注意力掩码——把"未来"锁在训练里

![World-Action MoT 层与注意力掩码：视频流含 A/R/C/Future/Causal Imprint token，动作流独立；掩码规定未来可见已观测上下文，而 Imprint 与动作都不能看见已实现的未来](/images/dailypaper/2026-09-28/2609.31394_fig2.png)

*原文图 3（World-Action MoT layer and attention mask，§3.6）。该图说明 (a) 两路 token 分组、(b) 每个耦合层中两专家各自做 Q/K/V 投影后拼成一次联合掩码自注意力（式 (11)）再各回各流，(c) 掩码的行列关系：$F\leftarrow(A,R,C,F)$，$\Delta\leftarrow(R,C,\Delta)$，$Act\leftarrow(A,R,C,\Delta,Act)$。*

模型共 **30 个耦合 MoT 块**（§6.1.2：视频流 3072 维、动作流 1024 维）。每个块里两专家保留各自的模态参数，只通过一次共享的联合注意力交换信息（式 (11)）：$Y=\operatorname{Attn}([Q^v;Q^a],[K^v;K^a],[V^v;V^a];M)$，随后按流拆分 $(Y^v,Y^a)$，各自继续自己的 cross-attention、FFN 与残差。**掩码决定了信息方向**：future token 可以看已观测上下文（这样才能做视频生成监督），但 **Causal Imprint 与动作 token 看不到已实现的未来帧**。因此训练时未来帧只通过 $\mathcal{L}_\Delta$ 与 $\mathcal{L}_{\text{align}}$ 的"监督项"影响 Imprint 表示，而不是通过前向注意力把答案抄给动作专家（§3.6 末段：不存在从已实现未来到动作预测的任何前向激活路径）。

### 2.5 关键设计三：训练期 4D 蒸馏（图 2）

为了让视频专家获得几何与运动感知（§3.5），作者以冻结的 Track4World 为教师：教师对与动作时域对齐的真值视频窗口计算 clip 级 4D 描述子 $r_t^{\mathrm{T}}\in\mathbb{R}^{1430}$（几何 + 2D/3D 运动 + 相机运动与可见性统计，各分量先各自 $\ell_2$ 归一化再过拼接）；学生分支**只用推理可见的 A/R/C 帧**——从 VideoDiT 第 15 层取 clean-condition 隐 token，线性投影后经"16 个可学习 query + 两层 Transformer 解码器"做聚合，均值池化后投到教师维度得 $r_t^{\mathrm{S}}$，用 MSE 对齐：

$$\mathcal{L}_{\mathrm{4D}}=\frac{1}{D}\left\|r_t^{\mathrm{S}}-\mathrm{sg}\!\left[r_t^{\mathrm{T}}\right]\right\|_2^2,\qquad D=1430$$

（原文式 (17)）

教师描述子**离线预计算并缓存**，蒸馏分支推理时整体丢弃，因此不增加策略推理成本。注意这一步只监督视频专家；作者试过"把学生描述子再喂给动作专家"，结果反而略差（77.78% vs 78.37%，表 15），所以最终采用"只塑形视频专家、动作流不注入"的方案。

### 2.6 训练目标

视频与动作都用 flow matching（式 (12)(13)）：$y^\sigma=(1-\sigma)y+\sigma\epsilon$，$\mathcal{L}_{\mathrm{FM}}(y)=\mathbb{E}_{\epsilon,\sigma}\left[\left\|f_\theta(y^\sigma,\sigma)-(\epsilon-y)\right\|_2^2\right]$，并分别作用于未来视频潜序列 $Z_t^F$ 与动作块 $A_t$（式 (14)）。总目标（式 (18)）：

$$\mathcal{L}=\lambda_v\mathcal{L}_{\mathrm{video}}+\lambda_a\mathcal{L}_{\mathrm{action}}+\lambda_{\Delta}\mathcal{L}_{\Delta}+\lambda_{\mathrm{align}}\mathcal{L}_{\mathrm{align}}+\lambda_{\mathrm{4D}}\mathcal{L}_{\mathrm{4D}}$$

按表 4，$\lambda_v=0.5$、$\lambda_\Delta=0.5$、$\lambda_{\text{align}}=0.1$、$\lambda_{\text{4D}}=0.1$；动作损失权重**按数据来源分档**：真机演示 1.0、UMI 0.5、Ego2Robot 0.1、纯 egocentric 0.1（论文未说明该权重设定的依据，只在 §5.1 说明每个权重只缩放对应数据类别样本的动作损失）。

### 2.7 高效推理（图 5）

![高效推理流程：观测经 Wan VAE 编码后视频专家只前向一次并缓存各层 K/V，动作专家复用缓存做 N 步纯动作去噪，无未来视频采样与解码](/images/dailypaper/2026-09-28/2609.31394_fig3.png)

*原文图 5（Efficient inference with cached visual context，§3.8）。该图说明"观察→观察一次视频 prefill→缓存 A/R/C/Δ 的逐层 K/V→动作流 N 步去噪→执行"的循环，并标注 no future video decoding 与"每次观察一次 prefill、N 次动作更新"的成本结构。*

推理分三步（§3.8，式 (19)(20)）：给定新观测，冻结 VAE 编码 A/R/C 并经视频专家**一次 prefill**，缓存各 MoT 层上 A/R/C/Δ token 的 self-attention K/V：$\mathcal{C}_t^{\mathrm{KV}}=\{(K_t^{v,l},V_t^{v,l})\}_{l=1}^{L}$；随后从高斯噪声 $A_t^1\sim\mathcal{N}(0,I)$ 出发，只重算动作流（残差连接 + 读缓存 K/V + 经 $C_t^a$ 做 cross-attention），沿 $\sigma:1\to0$ 积分 $N$ 步得到 $\hat A_t$；预测动作块直接执行，新观测到达时更新稀疏记忆与缓存。**每个"观测→动作"周期 = 1 次视频专家 prefill + $N$ 次动作专家更新**，既不采样未来视频也不需要 VAE 解码。（论文正文未给出 $N$ 的具体数值，只以符号 $N$ 表示。）

### 2.8 数据配方：20K+ 小时异构语料

- **统一表示**（§4.1，表 1）：所有动作映射到 **80 维共享动作空间**，每个槽位绑定固定物理量，而不是沿用原数据集的维度顺序。布局为：双臂关节 $[0,7)$ 与 $[40,47)$（各 7 维）、末端位姿 $[7,16)$ 与 $[47,56)$（各 9 维）、夹爪 $[16,17)$ 与 $[56,57)$、灵巧手 $[17,29)$ 与 $[57,69)$（各 12 维）、躯干 $[29,34)$（5 维）、独立升降 $[39,40)$、头部 $[74,77)$（3 维）、移动底盘 $[77,80)$（3 维），另有 $[34,39)$、$[69,74)$ 保留槽。状态保留绝对量（关节位置、绝对 EEF 位姿——3D 位置 + 6D 连续旋转、夹爪开度或手部关节），动作区分关节空间（绝对目标位置）与任务空间（3D 平移增量 + 当前 EEF 局部坐标系的 3D 旋转向量）。
- **机器人数据**：共 15 个数据集（§4.2.1），包括 AgiBotWorld、InternData-A1、RoboMIND/2.0、RW-RL、Dexora、ABC-130K、Galaxea、RoboCOIN、RH20T、RDT-1B、RoboSet、RealSource-World、MolmoAct2-BimanualYAM、HABIT、ActionNet；另有 UMI 数据 Hy-UMI-10K 与 ego 数据 EgoDex、EgoVerse。
- **清洗流水线**（§4.2.2，固定顺序执行）：信号异常与一致性过滤（平滑轨迹偏差检测 + 状态-动作方向一致性，默认阈值 0.65）→ 静态边界裁剪 → 视觉质量过滤（黑帧、模糊、8×8 压缩块效应、时间突变）→ 动作幅度护栏（单步平移 > 0.2 m 或旋转 > 0.5 rad 的样本丢弃）→ LLM 指令正确性筛查 → VLM 视频-指令一致性检查（用夹爪开合事件把 episode 切成动作片段，逐片理解后结合全局抽帧判断行为是否匹配指令、任务是否完成）→ **人工抽检**每个数据集-本体对（回放关节轨迹、叠加 EEF 位姿与录像核对坐标系与夹爪约定）。
- **Ego2Robot 转换**（§4.3.2、图 6、图 7、算法 1）：腕部姿态当作 EEF，统一到相机坐标系（式 (21)）；夹爪开度由指尖几何估计——拇指尖到食指/中指尖中点的距离，5 cm 映射为全闭、7 cm 映射为全开（式 (22)），动作用相机相对位置增量 + EEF 局部旋转增量 + 下一帧绝对夹爪目标（式 (23)）；运动学对齐把"基座搜索"与"轨迹 IK"耦合起来（在 MuJoCo 中做由粗到细的整段轨迹校验，而不是只查代表帧，算法 1）；视觉对齐用 SAM3 分割人手、ProPainter 擦除，再把按原视角渲染的机器人做深度感知合成（物体掩码约束遮挡、时域迟滞抑制闪烁）。ego 轨迹整体放慢 2 倍以贴近机器人数据速度。
- **规模**（表 2、表 3）：机器人数据由 **13,867.71 小时 / 1,370,003 条**清洗到 **11,302.20 小时 / 1,247,656 条**（11.01 亿帧）；ego 数据由 4,640.04 小时保留 4,061.35 小时（4.39 亿帧）；UMI 保留 2,075.42 小时（2.24 亿帧）；Ego2Robot 转换覆盖 1,101.55 小时源视频、产出 **5,633.77 robot-hours / 3,730,513 条训练片段**（6.08 亿帧）。按我的核算（分析者推断，非论文原文数字）：11,302.20 + 4,061.35 + 2,075.42 + 5,633.77 ≈ **23,073 小时**，与摘要"over 20K hours"一致。

### 2.9 训练与部署配方

- **预训练**（§5.1）：视频专家用 Wan2.2-TI2V-5B 初始化，动作专家为随机初始化的 **ActionDiT**；数据配比 robot 80% / Ego2Robot 10% / UMI 8% / Ego 2%（按有效起始帧数加权，并有轨迹级均衡防止长片段主导）；样本含 33 帧视频与 32 步动作块，视频:动作频率比 4，recent 帧滞后 32 个动作步，anchor 取 episode 开头。256 张 A800、bf16、batch 16×256 = 全局 4096、AdamW、lr $5\times10^{-5}$、5% warmup + cosine；**先训 235K 步不用 4D 蒸馏，再续训 10K 步加上蒸馏（每个 GPU mini-batch 16 个样本里只有 1 个带缓存的 Track4World 描述子），共 245K 步、约 14 天**（表 4）。
- **后训练**（§5.2、§5.3）：从同一预训练 checkpoint 出发，各 benchmark / 各真机平台只换数据适配器与动作接口（表 5：LIBERO-Plus 用 LIBERO 训练集 + min-max 归一化 + 15 epoch；RoboTwin 2.0 只用 clean 数据训练、z-score + 10 epoch；EBench/RoboDojo 各 3 视角 + 10 epoch）。真机后训练采用 **training-time RTC**（Black et al., 2025d）：对每个全长样本采样已提交前缀长度 $d\sim\mathcal{U}\{0,\dots,16\}$，前 $d$ 步真值动作保持"干净"（flow 时间步置 0），其余加噪，损失只算有效后缀 token——让策略学会"在已知前缀条件下续写动作"。
- **基础设施**（§6）：训练侧用统一 Cache Manager 缓存冻结 VAE/VLM 输出（键 $\mathrm{key}=\mathrm{hash}(D,e,k,v,P,M)$，式 (25)，避免跨数据/编码器配置误复用），并对 30 层 MoT 做逐层编译（FlexAttention 64-token 块掩码、VLM 上下文 padding 到 640 token、必要时每 3 层做外部非重入 checkpointing）；LIBERO 与 RoboTwin 上端到端训练吞吐分别提速 **3.02× / 2.11×**，单独用逐层 MoT 优化也有 20–30%。部署侧：单张 **RTX 5090（32 GiB）**、控制频率 30 Hz、32 步预测视野、每执行 16 步发起一次后台推理请求、前缀长度按近期延迟保守估计并封顶在训练见过的 16 步。

## 3. 解决得怎么样？

### 3.1 验证范围

四个仿真基准（LIBERO-Plus 单臂、RoboTwin 2.0 与 RoboDojo 双臂、EBench 移动双臂），外加 4 个真机平台、11 个任务的真实部署（表 6）；对比对象既有 VLA（$\pi_0$、$\pi_{0.5}$、OpenVLA-OFT、Qwen-RobotManip-Context、X-VLA 等）也有 WAM（Fast-WAM、OpenWAM-$\alpha$、4D-WAM、ST-WAM、JEPA-WAM、Being-H0.7 等），还包括 LLM-as-policy 的 GPT-6 Astra。作者说明 baseline 数值取自各自论文或公开基准结果，采用匹配的评测协议（§7.1），未对评测环境做额外适配。

### 3.2 主要结果

| 基准 | InternW0-Δ | 最强对比方法 | 差距 |
|---|---|---|---|
| LIBERO-Plus（7 类扰动总成功率，表 9） | **92.8%** | Qwen-RobotManip-Context 91.4%；最强 WAM Being-H0.7 84.8% | +1.4 / +8.0 点 |

| EBench（表 11） | 总成功率 49.2%，**总得分最高 66.0**；Long Horizon SR 49.4% / 得分 76.5 | OpenWAM-$\alpha$ SR 49.4 / 得分 64.7；Qwen-RobotManip 45.6/60.0 | 得分 +1.3；SR 略低于 OpenWAM-$\alpha$ |

细节上：LIBERO-Plus 的提升主要来自机器人与相机扰动（robot 扰动 91.1% vs 此前最好 87.4%，camera 90.6%，language 92.9%，background 99.4%，layout 88.4%）；RoboDojo 上 Gen-Std 33.78%、Memory 34.00%、Precision 23.25% 表现突出，但 Gen-Rand 仅 11.78%、Open 仅 10.17%——**该基准的绝对水平对所有方法都还很低**，论文也承认 memory/precision/long-horizon 仍然困难（§1）。

真机侧（§7.3）：11 个任务覆盖倒试剂、配液、做三明治、叠杯等长程/精细操作，同一条预训练 checkpoint 通过不同后训练适配 4 种控制接口（AC-One 14 维双臂关节；Arx5 6 维 EEF + 1 维夹爪；Franka+XHand 双臂 6 维 EEF + 每手 12 维手部；TianJi Marvin+Wuji Hand 7 维臂关节 + 20 维手部）。预训练的价值在真机上被单独验证：同样做任务后训练，AC-One 上 toast bread 由 4/20（20%）升到 19/20（95%）、Luminol reaction 由 0/20（0%）升到 19/20（95%）（表 13，每条件 20 次评测）。异步执行的连续性对比（图 12）也支持作者选用的训练期前缀条件方案：块边界动作变化与计划内平均变化之比为 VJP 8.94、硬前缀 7.13、训练期 RTC 1.12——只有训练期条件化把边界"跳变"压到与计划内变化同量级（§7.3 RTC continuity comparison）。

### 3.3 消融是否支持作者的解释

**组件消融（表 14，全部从零独立训练、同数据同配方；LIBERO-Plus 总成功率）**：Baseline 49.59 → +SMC 53.47 → +Qwen3.5-2B 60.37 → +RynnBrain1.1-2B 69.08 → +Causal Imprint 70.80 → +$\mathcal{L}_{\text{align}}$ 76.45 → +$\mathcal{L}_{\text{4D}}$ **78.37**。两个值得注意的点：

- **增益最大的一块来自语义表示与 Causal Imprint 的对齐项**（VLM 替换 +8.71、$\mathcal{L}_{\text{align}}$ +5.65），而 Causal Imprint 自身的 $\mathcal{L}_\Delta$ 只带来 +1.72。作者的解释是：$\mathcal{L}_\Delta$ 描述"未来轨迹上的时序变化"属于低层信号，$\mathcal{L}_{\text{align}}$ 才对接到视频专家中间层更丰富的语义/时间表征，两者互补。这个解释与消融顺序一致，但论文没有做"Imprint 表示到底编码了什么"的表征分析（如线性探测/可视化），因此**"性能提升"有证据，"机制被解释清楚"只有间接证据**。
- 蒸馏设计消融（表 15）：Track4World 78.37% > CoWTracker 76.15% > Pi3X 73.63%，且**不做动作注入**（77.78%）比注入更好，支持"蒸馏只塑形视频表示、不进推理路径"的设计取向。

**数据来源消融（表 16/17）**：单用真机数据预训练在 LIBERO-Plus 上把 78.59% 提到 83.73%，RoboTwin Clean2Random 从 4.38% 提到 32.34%；Ego2Robot 转换数据（81.86% / 6.66%）明显好于原始 ego 视频（80.45% / 3.13%）；UMI 数据在 RoboTwin Clean2Random 上贡献 13.90%。作者的结论是"人类数据在观测/动作空间与机器人对齐后才更有效"。作者同时明确写了适用范围：**该结论仅限当前数据规模与评测场景**（两个基准都以夹爪操作为主），不代表 ego 视频在更大规模或灵巧操作上无益；且只测了下游成功率、没测表示质量。这是论文里少见的、值得肯定的一句自我限定。

### 3.4 代价与成本

- **训练**：预训练 256×A800 跑 14 天（245K 步，全局 batch 4096），还需要额外一轮带 4D 蒸馏的续训；每个下游目标都要各自后训练（仿真 10–15 epoch，真机 10–100 epoch，见表 5、表 7）。
- **推理**：单张 RTX 5090 上控制器观测的往返时延从 780.5 ms 降到 **152.8 ms（5.11×）**（表 8，30 Hz 下必须 <533 ms）。表 8 的累计消融显示收益大头依次是进程隔离（2.09×）、复用与编译（3.12×）、上下文缓存（3.59×）、分组执行（4.19×）、CUDA Graph 回放（5.11×）；对应 LIBERO-Plus 成功率保持在 92.23–92.78% 区间，作者以此说明这些优化不改变模型语义。
- **数据**：20K+ 小时语料本身需要跨 15 个数据源的加载器、LLM+VLM 自动过滤与**人工抽检**，外加 Ego2Robot 的 IK/渲染/合成流水线；这部分工程量在论文中被视为贡献之一，但无法从外部独立验证其清洗质量。
- **外部依赖**：探索性的 GPT 引导策略（§7.5）显示，用 GPT-6 Astra 在 RoboDojo 五个任务上做执行期 EEF 纠正，平均成功率从 10.80% 提到 **47.20%**（"classify objects" 14%→80%，"general pickup" 36%→76%，两个零成功率任务变为 20%/40%；xhigh 推理档位优于 medium，但也只是"完成全部 5 个被评测 episode"这一量级的证据），提示**当前策略在语义推理类任务上仍高度依赖外部大模型兜底**；且该探索只在 seed 0 下选出的 5 个任务上进行、每行成功率对应的 episode 数论文未报告。

### 3.5 仍未解决的问题（论文自述 + 观察）

论文 Limitations（§8）自述两点：其一，ego 人类数据的贡献没有被系统研究（不同来源、转换策略、配比、监督形式的影响都未展开）；其二，agent-assisted control 只是初步探索，未研究 agent 调用策略、长程规划、分层决策以及与 WAM 的更紧耦合。此外可观察到的边界：RoboDojo 的 Gen-Rand/Open 类别与 EBench 绝对成功率仍低；推理时的 $N$（去噪步数）、总参数量论文未报告；LIBERO-Plus 的 "Total" 列并非七类扰动的简单平均（我核算的平均值约 93.2，论文报 92.8），应以官方指标口径理解；§4.2.1 对 InternData-A1 的描述（7,400 小时）与表 2 记录的清洗前 3,528.27 小时不一致，推测本文只用了其中一个子集，但论文未说明。

**收尾**：作者发现"会预测未来视频"并不等于"会控制"——已有 WAM 要么把视频生成塞进推理路径、要么缺少场景语义与几何先验，于是提出 InternW0-Δ：用有向 MoT 把预训练视频专家与动作专家耦合，以冻结 VLM 补场景语义、以训练期 4D 蒸馏注入几何运动先验、以 Causal Imprint 把未来监督"刻"成推理可用的变化表示，并用 20K+ 小时的统一表示异构语料与两阶段训练配方把这条路线做实；实验表明它在 LIBERO-Plus（92.8%）、RoboTwin 2.0 Clean2Random（71.9%）、EBench（得分 66.0）与 RoboDojo（平均 23.91%，近乎前最强 WAM 的两倍）上领先，并能在 4 个真机上把同一 checkpoint 适配到夹爪与灵巧手接口，推理时延 152.8 ms；但 ego 数据的价值、agent 辅助控制、RoboDojo 上的泛化与开放词汇任务，以及"预测表示为什么有效"的机制层面证据，仍未解决。
